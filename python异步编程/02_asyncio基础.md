# 协程介绍

##  协程的定义

协程（Coroutine）是一种用户态的轻量级线程，也称为微线程或纤程。其核心定义是一个可以暂停执行、保存当前上下文（寄存器状态和栈），并在之后从暂停处恢复执行的函数。协程的调度完全由用户程序（事件循环）控制，属于协作式多任务处理，而非操作系统内核的抢占式调度。

## 协程的核心作用

1. 提高程序并发性

   通过在单个线程内执行多个协程，Python 能够模拟多任务的并发执行，无需开销较大的多线程或多进程。

2. 改善异步 I/O 处理

   在网络 I/O、文件读写等操作时，协程可以在等待 I/O 完成时主动让出控制权，让事件循环去执行其他任务，极大简化了异步代码的书写。

3. 提升网络通信效率

   在需要处理大量客户端连接的服务器程序中，协程可以在单个线程中并发处理数千甚至数万个网络连接，减少资源消耗。

4. 简化复杂的并行任务

   开发者可以将复杂的任务分解为小的、可管理的协程单元，无需过多关注底层线程管理和通信机制。

## 使用方式

在 Python 3.5+ 版本中，协程通过 `async` 和 `await` 关键字配合标准库 `asyncio` 来实现。

1. 定义协程函数

   使用 `async def` 定义的函数即为协程函数。调用协程函数不会立即执行函数体，而是返回一个**协程对象**（Coroutine Object）。

2. 挂起协程

   在协程函数内部，使用 `await` 关键字可以挂起当前协程，等待另一个可等待对象（如另一个协程、`asyncio.sleep()`、I/O 操作）完成，同时将控制权交还给事件循环。

3. 运行协程

   - `asyncio.run()`：作为程序的入口，负责创建事件循环、运行主协程并在结束后关闭循环。
   - `await`：在另一个协程内部等待当前协程完成。
   - `asyncio.create_task()`：将协程封装为任务（Task）并立即调度其并发执行。
   - `asyncio.gather()`：并发运行多个可等待对象，并等待它们全部完成后聚合返回结果。

## 协程与线程的区别

| 对比维度     | 线程 (Thread)                  | 协程 (Coroutine)                     |
| ------------ | ------------------------------ | ------------------------------------ |
| **调度方式** | 操作系统内核抢占式调度         | 用户程序协作式调度                   |
| **切换开销** | 较大（涉及内核态与用户态切换） | 极小（仅保存/恢复栈帧）              |
| **并发能力** | 受限于系统资源，通常数千个     | 单线程内可轻松运行数十万个           |
| **适用场景** | CPU 密集型任务（需配合多进程） | I/O 密集型任务（网络请求、文件读写） |
| **同步机制** | 需要锁（Lock）防止数据竞争     | 无需锁（单线程内交替执行）           |

## 代码示例

```python
import asyncio

# 1. 定义一个协程函数
async def say_hello():
    print("开始打招呼")
    await asyncio.sleep(1)  # 模拟 I/O 等待，不阻塞线程
    print("你好，协程！")

# 2. 定义主协程
async def main():
    # 3. 并发执行多个协程
    await asyncio.gather(say_hello(), say_hello())

# 4. 运行事件循环
if __name__ == "__main__":
    asyncio.run(main())
```

# run 函数

`asyncio.run()` 是 Python `asyncio` 模块中用于运行最高层级协程的便捷函数。它负责创建一个新的事件循环，执行传入的协程对象，并在协程完成后关闭该循环。

它会接受传递给它的任何协程，并运行直到它完成，然后返回结果。它还会对主协程完成后可能继续运行的任何内容进行清理。一切完毕后，它会关闭并结束事件循环。

这是运行顶层异步代码的推荐方式，通常用于程序的入口点，例如在 `if __name__ == "__main__":` 代码块中启动主异步任务。

## 函数格式

```python
asyncio.run(coro, *, debug=False)
```

## 参数说明

| 参数    | 作用                                                         | 可选值的类型 | 示例            |
| ------- | ------------------------------------------------------------ | ------------ | --------------- |
| `coro`  | 要运行的顶层协程对象。<br />它必须是一个 `awaitable` 对象，<br />通常是由 `async def` 定义的协程函数调用后返回的。 | 协程对象     | `main()`        |
| `debug` | 一个布尔值，用于启用或禁用 `asyncio` 的调试模式。<br />当设置为 `True` 时，会开启额外的日志记录和检查，<br />有助于发现异步编程中的常见错误。 | 布尔值       | `True`、`False` |

## 代码示例

```python
import asyncio

async def say_after(delay, what):
    await asyncio.sleep(delay)
    print(what)

async def main():
    print(f"开始时间: {asyncio.get_event_loop().time()}")
    # 并发运行两个任务
    await asyncio.gather(
        say_after(1, '你好'),
        say_after(2, '世界'),
    )
    print(f"结束时间: {asyncio.get_event_loop().time()}")

# 使用 asyncio.run() 作为程序入口点来运行主协程
asyncio.run(main())
```

# 任务

## 定义

在 Python 的 `asyncio` 异步编程中，任务（Task）是对协程（Coroutine）的进一步封装对象。它代表一个具体的、可被事件循环（Event Loop）调度的异步工作单元。当协程被封装为任务后，便会脱离当前协程的执行流，进入事件循环的任务队列中并发运行，同时提供对执行状态的跟踪与结果获取能力。

## 核心作用

1. 实现并发调度

   将协程包装为任务并加入事件循环，使其能够与其他任务并发执行，而不必等待前一个协程完成。

2. 状态跟踪与管理

   任务对象（Task）具有明确的状态（如 `pending`、`running`、`done`），允许程序在运行时查询异步操作的执行进度。

3. 结果获取与异常处理

   任务对象提供了获取协程最终返回值以及捕获、处理异步执行过程中抛出异常的机制。

4. 支持任务取消

   允许在任务执行过程中主动调用取消方法，提前终止正在挂起或运行的异步操作。

5. 支持回调机制

   可以为任务添加完成回调函数，当异步操作执行完毕时，事件循环会自动触发相应的回调逻辑。

## 使用方式

1. 创建任务

   在协程内部，通常使用 `asyncio.create_task()` 函数将协程对象封装为任务并立即调度。

2. 等待任务完成

   任务本身是可等待对象（Awaitable），可以使用 `await` 关键字暂停当前协程，直到被封装的任务执行完毕并获取结果。

3. 批量并发执行

   使用 `asyncio.gather()` 或 `asyncio.wait()` 等函数，可以并发运行多个任务，并在所有任务完成后统一收集结果。

4. 取消与超时控制

   通过调用任务对象的 `cancel()` 方法可以取消任务；结合 `asyncio.wait_for()` 可以为任务的执行设置超时时间。

## 代码示例

```python
import asyncio

# 定义一个异步协程
async def fetch_data():
    await asyncio.sleep(2)
    return "数据获取完成"

# 定义主协程
async def main():
    # 1. 将协程封装为任务并立即调度
    task = asyncio.create_task(fetch_data())
    
    # 2. 检查任务状态
    print(f"任务是否完成: {task.done()}")  # 输出: False
    
    # 3. 等待任务完成并获取结果
    result = await task
    
    # 4. 再次检查状态并输出结果
    print(f"任务是否完成: {task.done()}")  # 输出: True
    print(f"任务结果: {result}")           # 输出: 数据获取完成

# 运行事件循环
asyncio.run(main())
```

# 创建任务

`asyncio.create_task()` 是 Python 异步编程（`asyncio`）中用于实现真正并发调度的核心函数。使用时需传入一个协程对象，该函数会将其包装为一个任务（Task）对象并**立即**将其加入事件循环中调度执行，而不是像 `await` 那样阻塞当前协程等待其完成。当需要同时启动多个互不依赖的异步操作（如并发网络请求、并行数据处理）以充分利用 I/O 等待时间时，就应该使用此函数。

## 函数格式

```python
asyncio.create_task(
    coro,  # 必需参数，要包装并调度执行的协程对象
    *,  # 强制后续参数必须使用关键字形式传递
    name=None,  # 可选参数，指定任务的名称字符串，便于调试和日志追踪
    context=None,  # 可选参数（Python 3.11+），指定任务运行的自定义上下文（contextvars.Context）
    eager_start=False  # 可选参数（Python 3.14+），控制是否在创建时立即同步执行该任务，直到遇到第一个阻塞点
)
```

## 参数说明

| 参数名称      | 作用说明                                                     | 可选值的类型                        |
| ------------- | ------------------------------------------------------------ | ----------------------------------- |
| `coro`        | 需要被包装为任务并加入事件循环调度的协程对象。               | 协程对象（Coroutine）               |
| `name`        | 为任务分配一个可读的名称。<br />若未提供，将基于协程函数名自动生成默认名称。 | 字符串（`string`）或 `None`         |
| `context`     | 指定该任务运行时的上下文环境。<br />若未提供，则自动创建当前上下文的副本。 | `contextvars.Context` 对象或 `None` |
| `eager_start` | 控制任务的启动策略。<br />若为 `True`，任务会在创建时立即尝试同步执行；<br />若为 `False`，则交由事件循环稍后调度。 | 布尔值（`true`、`false`）           |

## 代码示例

```python
import asyncio

async def fetch_data(name, delay):
    print(f"开始获取数据: {name}")
    await asyncio.sleep(delay)  # 模拟耗时的 I/O 操作
    print(f"完成获取数据: {name}")
    return f"{name} 的结果"

async def main():
    # 使用 create_task 将协程包装为任务，立即在后台并发执行，不阻塞当前流程
    task1 = asyncio.create_task(fetch_data("任务A", 2), name="Task-A")
    task2 = asyncio.create_task(fetch_data("任务B", 1), name="Task-B")
    
    # 使用 gather 并发等待所有任务完成并收集结果
    results = await asyncio.gather(task1, task2)
    print("所有任务结果:", results)

asyncio.run(main())
```

# Task 对象

`asyncio.Task` 是 Python `asyncio` 模块中用于调度和并发执行协程的核心类，它是对协程的封装，使其能够被事件循环独立调度。使用时需通过 `asyncio.create_task()` 或 `loop.create_task()` 等工厂函数创建实例，而不是直接手动实例化，当需要让多个异步操作并发运行、追踪任务状态、获取异步结果或取消正在执行的操作时，就需要使用此类。

## 创建对象时的格式

```python
# 推荐的高级 API 创建方式
asyncio.create_task(
    coro,  # 必需参数，要封装并调度的协程对象
    *,  # 强制后续参数使用关键字传递
    name=None,  # 可选参数，为任务指定一个名称字符串，便于调试和追踪
    context=None,  # 可选参数（Python 3.11+），指定任务运行的上下文对象
    eager_start=False  # 可选参数（Python 3.14+），控制是否在创建时立即同步执行该任务
)

# 低层级的 API 创建方式
loop.create_task(
    coro,  # 必需参数，要封装并调度的协程对象
    name=None  # 可选参数，为任务指定一个名称字符串
)
```

## 参数详解

| 参数名称      | 作用说明                                                     |
| ------------- | ------------------------------------------------------------ |
| `coro`        | 需要被封装为任务并交由事件循环调度的协程对象。               |
| `name`        | 为任务分配一个可读的名称。若未提供，将基于协程函数名自动生成默认名称。 |
| `context`     | 指定该任务运行时的上下文环境。若未提供，则自动创建当前上下文的副本。 |
| `eager_start` | 控制任务的启动策略。<br />若为 `True`，任务会在创建时立即尝试同步执行；<br />若为 `False`，则交由事件循环稍后调度。 |

## 常用属性

| 属性名称        | 说明                                 |
| --------------- | ------------------------------------ |
| `get_name()`    | 获取任务的名称字符串。               |
| `get_coro()`    | 获取该任务所封装的原始协程对象。     |
| `get_context()` | 获取该任务运行时所使用的上下文对象。 |

## 常用方法

| 方法名称                   | 说明                                                         |
| -------------------------- | ------------------------------------------------------------ |
| `done()`                   | 检查任务是否已完成。返回 `True` 表示任务已结束、已取消或已抛出异常。 |
| `result()`                 | 获取任务完成后的返回值。若任务尚未完成，会抛出 `InvalidStateError`；<br />若任务抛出了异常，则重新抛出该异常。 |
| `exception()`              | 获取任务中抛出的异常对象。若任务正常完成，返回 `None`。      |
| `cancel()`                 | 请求取消该任务。若任务正在等待 `await` 表达式，会抛出 `CancelledError`。 |
| `cancelled()`              | 检查任务是否已被取消。返回 `True` 表示任务已被成功取消。     |
| `add_done_callback(fn)`    | 为任务添加完成回调函数。当任务完成时，事件循环会自动调用该回调。 |
| `remove_done_callback(fn)` | 从回调列表中移除指定的回调函数。                             |
| `set_name(name)`           | 动态修改任务的名称。                                         |
| `set_result(result)`       | 手动设置任务的结果（通常由内部机制调用，不建议手动使用）。   |
| `set_exception(exc)`       | 手动设置任务的异常（通常由内部机制调用，不建议手动使用）。   |
