# `slice` 介绍

在 Python 中，`slice` 是一个内置类，用于创建一个切片对象（Slice Object）。该对象表示一个序列（如列表、元组、字符串等）的特定索引范围，可用于提取、修改或迭代序列中的特定部分。

## 创建对象时的格式

```python
s = slice(
    start,  # 可选：切片的起始索引（包含该位置）。默认为 None，表示从序列的开头开始
    stop,   # 必填：切片的结束索引（不包含该位置）
    step    # 可选：切片的步长（元素之间的增量）。默认为 None，表示步长为 1
)
```

> `slice()` 函数也支持只传入一个参数的形式 `slice(stop)`，此时 `start` 默认为 `None`（即 0），`step` 默认为 `None`（即 1）。

## 参数详解

| 参数名称 | 作用说明                                                     |
| -------- | ------------------------------------------------------------ |
| `start`  | 指定切片的起始索引位置（包含该位置的元素）。<br />如果省略或为 `None`，则从序列的第一个元素开始。 |
| `stop`   | 指定切片的结束索引位置（不包含该位置的元素）。此参数为必填项。 |
| `step`   | 指定切片时的步长，即每次取元素时跨越的间隔。<br />如果省略或为 `None`，则默认步长为 1。若为负数，则表示反向切片。 |

## 常用属性

| 属性名称 | 作用说明                                                  |
| -------- | --------------------------------------------------------- |
| `start`  | 返回切片对象的起始索引值。若创建时未指定，则返回 `None`。 |
| `stop`   | 返回切片对象的结束索引值。                                |
| `step`   | 返回切片对象的步长值。若创建时未指定，则返回 `None`。     |

## 常用方法

| 方法名称          | 作用说明                                                     |
| ----------------- | ------------------------------------------------------------ |
| `indices(length)` | 接受一个整数参数 `length`（序列的长度）。<br />计算当该切片对象应用于指定长度的序列时，实际的 `start`、`stop` 和 `step` 值。<br />返回一个包含这三个整数的元组 `(start, stop, stride)`。<br />此方法常用于处理索引越界的情况，自动将越界索引截断到有效范围内。 |

## 解释

### 复用切片逻辑

当需要对多个列表、或者同一个列表的多个部分，反复执行**完全相同**的切片操作时，直接写 `1:5:2` 会显得代码冗长且容易出错。这时，可以把切片规则提取成一个 `slice` 对象。

```python
# 定义一次切片规则
COLS_TO_EXTRACT = slice(1, 5)  

row_1 = [10, 20, 30, 40, 50, 60]
row_2 = ['A', 'B', 'C', 'D', 'E', 'F']

# 优雅地复用这个规则
print(row_1[COLS_TO_EXTRACT])  # 输出: [20, 30, 40, 50]
print(row_2[COLS_TO_EXTRACT])  # 输出: ['B', 'C', 'D', 'E']
```

### 索引越界处理

`indices(length)` 方法的核心作用是把“模糊的、可能越界的”切片规则，翻译成“明确的、绝对不会越界的”实际索引。

```python
# 假设用户传入了一个切片：从索引 1 到 100，步长为 2
user_slice = slice(1, 100, 2) 

# 我们告诉它，我们的总数据长度只有 10
actual_indices = user_slice.indices(10) 

print(actual_indices)  # 输出: (1, 10, 2)，发生截断

# 假设总数居有 1000 个
print(user_slice.indices(1000)) # (1, 100, 2)，因为切片在范围内，无需处理
```

# 案例：斐波那契数列

这个案例使用了三种魔法方法并讲述了切片的使用，可以作为一个例子理解其余类似的魔法方法。

```python
class Fib:
    """
    生成斐波那契数列
    """

    def __getitem__(self, n: int | slice) -> int | list[int]:
        """
        获得第 n 个斐波那契数列。索引从 0 开始。

        Parameters
        ----------
        n : int | slice
            第 n 个或者是切片

        Returns
        -------
        int
            第 n 个斐波那契数。如果传入数据错误返回 0。
        """
        # 初始值
        a, b = 1, 1

        if isinstance(n, int):
            # 取数的逻辑必须大于 0
            n = max(0, n)

            # 索引从 0 开始，0 不会进行循环更新
            # 1 更新一次，刚好和 range 对上
            for i in range(n):
                a, b = b, a + b
            return a

        # 这里就不对负数进行处理了，默认传来的一定是正数
        # 索引从 0 开始，左闭右开
        elif isinstance(n, slice):
            start = n.start
            stop = n.stop
            result = []

            for i in range(stop):
                a, b = b, a + b
                if i < start:
                    continue
                result.append(a)

            return result

        return 0

    def __getattr__(self, name: str) -> str:
        """
        当访问一个不存在的属性时，会尝试调用这个方法来获取属性。
        return 返回的就是这个不存在的属性的值。

        Parameters
        ----------
        name : str
            未知属性

        Returns
        -------
        str
            未知属性的值
        """
        print(f"访问了一个不存在的属性：{name}")
        return "这是一个不存在的属性"

    def __call__(self, p: int, q: int) -> int:
        """
        这个方法能让实例对象能像函数一样被调用。
        计算第 p 个 和第 q 个斐波那契数的乘积。

        Parameters
        ----------
        p : int
            第 p 个斐波那契数
        q : int
            第 q 个斐波那契数

        Returns
        -------
        int
            乘积。如果传入结果错误就返回 0
        """
        try:
            x = self[p]
            y = self[q]
            assert (isinstance(x, int))
            assert (isinstance(y, int))
            return x * y
        except Exception:  # noqa: BLE001
            print("你不应该传入切片！")
            return 0


# 1 1 2 3 5 8 13 21
f = Fib()
print(f[1])  # 1 这里是第二个 1，索引从 0 开始
print(f[5])  # 8
print(f[7])  # 21
print(f[3:7])  # 3 5 8 13

print("-" * 30)

print(f.public)
print(f.local)

print("-" * 30)

print(f(5, 7)) # 168
print(f(-1, -1)) # 在 getitem 中设置了 n = max(0, n)
```
