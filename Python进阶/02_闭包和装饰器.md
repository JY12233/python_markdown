#  闭包

## 概念

>在函数嵌套的前提下，内部函数使用了外部函数的变量，并且外部函数返回了内部函数，这种：使用外部函数变量的内部函数称为闭包。

:a:  “包”：打包带走

这里的“包”，可以理解为**“打包”**。

想象一下，你（内层函数）要去外地出差。按照常理，你只能带自己的行李（局部变量）。但是，闭包允许你把**老家（外层函数）里的东西也打包带走**。

- **技术上说**：内层函数把外层函数的变量（比如那个 `x`）捆绑在自己身上，即使外层函数已经执行完了（“老家”已经拆迁了），这个变量依然被内层函数带在身边，没有被销毁。

:b: “闭”：封闭私有

这里的“闭”，可以理解为**“封闭”**或**“私有”**。

这些被打包带走的变量，外面的人是访问不到的，只有你（内层函数）自己能用。

- **技术上说**：外层函数的变量被“封闭”在内层函数内部，外部无法直接修改，形成了一个受保护的私有环境。

---

## 构成条件

>1. **有嵌套**：在函数嵌套（函数里面再定义函数）的前提下；
>2. **有引用**：内部函数使用了外部函数的变量（还包括外部函数的参数）；
>3. **有返回**：外部函数返回了内部函数名。

---

## 格式

```python
def 外部函数名(形参列表):
    外部函数的(局部)变量
    def 内部函数名(形参列表):
        使用外部函数的变量
        
    return 内部函数名
```

外部函数形参列表中的变量也属于外部函数的局部变量。

>`函数名` 和 `函数名()` 是两个概念，前者表示**对象**，后者表示调用函数。

```python
def get_sum(a, b):
    return a + b

print(get_sum) # <function get_sum at 0x0000021221B9F7F0>，对象
print(get_sum(1, 1)) # 2，调用函数，获取函数返回值

my_sum = get_sum
print(my_sum) # <function get_sum at 0x0000021221B9F7F0>
print(my_sum(1, 1)) # 2
```

函数名可以赋值给变量，这个变量就是函数对象。

---

## 作用

> 延长局部变量的生命周期。外部函数结束之后，内部函数仍然能够访问外部函数的局部变量。

---

## 用法举例

```python
# 1. 定义外部函数。
def fn_outer(num1):
    # 2. 定义内部函数
    def fn_inner(num2):         # 有嵌套
        # 3. 求和
        sum = num1 + num2       # 有引用
        print(f'求和结果: {sum}')
    return fn_inner             # 有返回

# 4. 调用上述的函数
fn_inner = fn_outer(10) # 内部的 fn_inner 记住了 num1 = 10 这个环境
fn_inner(20) # 30

fn_outer(10)(20)
```

---

## `nonlocal`关键字

>`global`：声明全局变量。
>
>`nonlocal`：声明能够让内部函数去修改外部函数的变量。

nonlocal--adj.非局部的；非本地的

非局部变量：指代既不是当前函数内的局部变量，也不是全局变量，而是处于**外层嵌套函数**作用域中的变量。

```python
# 定义
def func_out():
    a = 100
    def func_inner():
        # 声明变量
        nonlocal a  # 注意要声明
        a = a + 1   # 修改值 有引用
        print(f"修改的结果:{a}")
    return func_inner

# 观察结果
number = func_out() # 拿到func_inner函数
number() # 修改的结果:101
```

# LEGB规则

> LEGB 规则是 Python 解释器在查找变量时所遵循的一套核心机制，它定义了变量名的查找顺序。这个规则的名称是四个作用域英文首字母的缩写。

简单来说，当你使用一个变量时，Python 会按照 **L → E → G → B** 的顺序，由内到外、逐层查找，一旦找到就立即停止。

##  LEGB 规则详解

这四个字母分别代表：

1. **L (Local) - 局部作用域**
   - **定义**：当前函数或 lambda 表达式内部。
   - **内容**：在函数内部通过赋值（如 `x = 1`）定义的变量。
   - **特点**：优先级最高，但只在函数内部有效。
2. **E (Enclosing) - 嵌套作用域**
   - **定义**：任何外层函数的作用域。当一个函数内部嵌套了另一个函数时，内层函数可以访问外层函数的变量。
   - **内容**：外层函数中定义的变量。
   - **特点**：这是实现“闭包”（Closure）功能的基础。查找顺序是从最近的嵌套函数开始，逐层向外。
3. **G (Global) - 全局作用域**
   - **定义**：当前模块（即 `.py` 文件）的顶层作用域。
   - **内容**：在函数和类之外定义的变量，以及通过 `import` 导入的模块。
   - **特点**：在整个文件内都可见。
4. **B (Built-in) - 内置作用域**
   - **定义**：Python 解释器预加载的最后一个作用域。
   - **内容**：包含所有内置的函数、异常和类型，例如 `print()`, `len()`, `Exception` 等。
   - **特点**：这是查找的最后一步，如果这里也找不到，Python 就会抛出 `NameError`。

## 举例

```python
# --- G (Global) 作用域 ---
x = "我是全局变量"

def outer_function():
    # --- E (Enclosing) 作用域 ---
    y = "我是嵌套变量"

    def inner_function():
        # --- L (Local) 作用域 ---
        z = "我是局部变量"
        
        # 1. 查找 z：在 L (Local) 中找到，输出 "我是局部变量"
        print(z)
        
        # 2. 查找 y：L 中没有，去 E (Enclosing) 中找到，输出 "我是嵌套变量"
        print(y)
        
        # 3. 查找 x：L 和 E 中都没有，去 G (Global) 中找到，输出 "我是全局变量"
        print(x)
        
        # 4. 查找 print：L, E, G 中都没有，去 B (Built-in) 中找到内置的 print 函数
        print("查找结束")

    inner_function()

outer_function()
```

理解 LEGB 规则是掌握 Python 变量作用域和生命周期的关键，也能帮助你更好地理解之前遇到的 `UnboundLocalError` 等错误。

# 装饰器

## 概念

###  “装饰”：锦上添花，不伤本体

想象你有一部刚买回来的**裸机手机**（这就是你的**原函数**）。
现在，你想给它贴膜、戴个手机壳，或者挂个挂件。

- **装饰的过程**：你给手机戴上了壳。
- **结果**：手机多了“防摔”和“美观”的功能。
- **核心**：**手机本身还是那部手机**，它的核心功能（打电话、发微信）没有变，你也没有把手机拆了重装，只是在外面包了一层东西。

这就是装饰器的核心思想：**在不修改原函数代码的前提下，给函数增加额外的功能。**

### “器”：一个打包的工具

这里的“器”，可以理解为一个**工具**或**工厂**。

在 Python 中，这个“器”本质上就是一个**函数**。

- 它接收你的原函数作为参数。
- 它返回一个新的函数（原函数 + 额外功能）。

---

## 作用

>装饰器的作用是不改变原有函数的基础上，给原有函数增加额外功能。

装饰器本质上就是一个**闭包**函数。

---

## 构成条件

>- 有嵌套：在函数嵌套(函数里面再定义函数)的前提下；
>- 有引用：内部函数使用了外部函数的变量(还包括外部函数的参数)；
>- 有返回：外部函数返回了内部函数名；
>- 有额外功能：给需要装饰的原有函数增加额外功能。

---

## 语法

### 传统语法

```python
变量名 = 装饰器名(原有函数名)
变量名()
```

```python
from typing import Callable

# 1.定义一个外部函数，即装饰器(装饰器的本质是闭包)
# 形参列表是要被装饰的函数名
def check(fn: Callable[[], None]):
    def inner():				# 有嵌套
        # 额外功能
        print("登陆验证。。。")
        # 访问原函数（被装饰前），即外部函数的引用
        fn()					# 有引用

    return inner				# 有返回

# 2.需要被装饰的函数
def comment():
    print("发表评论")

# 3.使用装饰器装饰函数（增加一个登陆功能）
comment = check(comment)
comment()

print(comment.__name__)  # inner
"""
在这个阶段，comment就是一个彻头彻尾的 inner 函数，跟原来的 comment 除了功能上有继承关系，身份上毫无关系。
这个写法的弊端就是无法调用原来的comment函数。
解决可以不用comment作为变量名。
"""
```

### 语法糖

> 在需要被装饰的原函数的上面写`@装饰器名`，之后直接调用原函数即可。

```python
from typing import Callable

# 1.定义一个外部函数，即装饰器(装饰器的本质是闭包)
# 形参列表是要被装饰的函数名
def check(fn: Callable[[], None]):
    def inner():				# 有嵌套
        # 额外功能
        print("登陆验证。。。")
        # 访问原函数（被装饰前），即外部函数的引用
        fn()					# 有引用

    return inner				# 有返回（外部函数返回）

# 2.需要被装饰的函数
@check # 底层其实是comment = check(comment)
def comment():
    print("发表评论")

comment()
```

多次装饰写多个`@`，只会重复增加功能。

## 使用

> 装饰器内部函数格式与原函数一致。

### 无参无返回

```python
def decoration(fn):
    def inner():
        print("正在努力计算中...")
        fn()
        		# 缺少了返回值

@decoration
def add(): # 本质add = decoration(add)，但是decoration返回None
    x = 10
    y = 20
    print(x + y)


print(callable(add)) #False
print(add) # None


# 改正
def decoration(fn):
    def inner():
        print("正在努力计算中...")
        fn()			# 添加了返回值
    return inner

@decoration
def add():
    x = 10
    y = 20
    print(x + y)

add() # 正在努力计算中...\n30
```

### 有参无返回

```python
def decoration(fn):
    def inner(*args):
        print('正在努力计算...')
        add(*args)				# 这里出了问题，应该是fn(*args)

    return inner

@decoration # add = decoration(add)
"""
这里不会报错，因为原函数add是引用，装饰之后依然只是引用，没有调用
"""
def add(x, y):
    print(x + y)

add(10, 20)
"""
递归错误：无限递归。因为调用的时候本质上是在调用inner，当执行到add(*args)时，这里的add是装饰之前的，会再次装饰，一直重复这个过程，产生无限递归
"""
```

### 无参有返回

```python
def decoration(fn):
    def inner():
        print('正在努力计算...')
        fn() # 这里出了问题，应该是return fn()

    return inner

@decoration # add = decoration(add) 这里不会报错
def add():
    x = 10
    y = 20
    return x + y

print(add())
"""
会输出None，因为执行的是inner函数，虽然原add函数有返回，但是inner是没有返回的。也就是说inner函数里的fn调用之后会返回一个值，这个值还需要返回。
"""
```

### 有参有返回

```python
    def inner(a, b):
        print('正在努力计算...')
        return fn(a, b)

    return inner

@decoration # add = decoration(add) 这里不会报错
def add(x, y):
    return x + y

print(add(10, 20))


"""
这串代码在第一次运行时没有出错😁
"""
```

### 多个装饰器装饰一个函数

> 离函数==最近==的装饰器先装饰，然后外面的装饰器再进行装饰，由内到外的装饰过程。

- `@` 语法糖

  是从下往上装饰，最下面的装饰器最先执行（最靠近原函数），最上面的装饰器最后执行（最外层）。因为最上面的会把下面的看成一个整体。

- 显式调用

  完全取决于括号怎么套。谁在外面，谁就先执行。

```python
"""
发表评论前需要登陆、验证码验证
"""

from typing import Callable

# 登录
def login(fn: Callable[[], None]):
    """
    检查登录

    Parameters
    ----------
    fn : Callable[[], None]
        回调函数
    """
    def inner():
        print("检查登录...")
        fn()

    return inner

# 验证码验证
def verify(fn: Callable[[], None]):
    """
    验证码验证

    Parameters
    ----------
    fn : Callable[[], None]
        回调函数
    """
    def inner():
        print("验证码验证中...")
        fn()
    
    return inner

# 发表评论
@login # comment = login(comment) 后面的comment是被verify装饰后的，其实就是迭代的思想
@verify # 连着下面的看作一个整体被login装饰
def comment():
    """
    发表评论
    """
    print("我是天才！")

# comment = login_in(verify(comment)) # 语法糖本质就是这个
comment()
```

### 带参数的装饰器

> 使用语法糖格式时，`@`后面的是函数引用，表示用改函数操作一下被装饰的函数，python会自动地把原函数传递到装饰器中。
>
> 当装饰器有参数时，如果`@`后的装饰器传递了参数，代表调用该装饰器并返回值了。
>
> 因此，需要使用三层嵌套，第一层接受参数并返回装饰器。

```python
"""
既能装饰加法，又能装饰减法
"""
from typing import Callable

def symbol_dec(symbol: str): # 第一层：接受参数，并返回装饰器
    """
    装饰加减法

    Parameters
    ----------
    symbol : str
        运算符号
    """
    def decorator(fn: Callable[[int, int], None]): # 第二层，装饰器
        """
        装饰加减法

        Parameters
        ----------
        fn : Callable[[], None]
            回调函数
        symbol : str
            运算符号
        """
        def inner(x, y): # 第三层，装饰的功能
            """
            加减法有不同的装饰
            """
            if symbol == '+':
                print('正在努力求和中...')
                fn(x, y)
            elif symbol == '-':
                print('正在努力求差中...')
                fn(x, y)

        return inner # 返回被装饰后的函数
    return decorator # 返回装饰器

# 加法
@symbol_dec('+') # 这里symbol_dec立马被调用并且返回decorator
def add(x, y):
    print(x + y)

@symbol_dec('-')
def subtract(x, y):
    print(x - y)

add(10, 20)
subtract(20, 10)
```

当然，上面的代码也可以写成这样：

```python
"""
既能装饰加法，又能装饰减法
"""
from typing import Callable

def decorator(fn: Callable[[int, int], None]):
    """
    装饰加减法

    Parameters
    ----------
    fn : Callable[[], None]
        回调函数
    symbol : str
        运算符号
    """
    def inner(x, y):
        """
        加减法有不同的装饰
        """
        if fn.__name__ == 'add':
            print('正在努力求和中...')
            fn(x, y)
        elif fn.__name__ == 'subtract':
            print('正在努力求差中...')
            fn(x, y)

    return inner

# 加法
@decorator
def add(x, y):
    print(x + y)

# 减法
@decorator
def subtract(x, y):
    print(x - y)

add(10, 20)
subtract(20, 10)
```

| `@abstractmethod`  | abc         | 定义抽象方法，强制约束子类必须实现特定的方法。               | 定义接口或基类，确保继承体系中的子类具备必要的行为规范。     |
| `@overload`        | typing      | 为同一个函数定义多个“类型签名”，提供精确的类型提示。         | 解决同一个函数根据传入参数不同而返回不同类型的问题，增强 IDE 智能提示和静态类型检查。 |
| `@final`           | typing      | 限制代码的扩展性，防止类被继承或方法被重写。                 | 保护核心逻辑不被意外篡改，告诉类型检查器该类或方法是“最终”形态。 |

# 深浅拷贝

## 可变类型与不可变类型

1. 不可变对象

   > 一旦创建就不可修改的对象，包括字符串、元组、数值类型（整型、浮点型）
   > 该对象所指向的内存中的值不能被改变。当改变某个变量时候，由于其所指的值不能被改变，相当于把原来的值复制一份后再改变，这会开辟一个新的地址，变量再指向这个新的地址。

2. 可变对象

   > 可以修改的对象，包括列表、字典、集合

# `Property`属性

## 作用

把函数当**属性**使用，以简化代码。

- `@property`  修饰获取值的函数
- `@获取值的函数名.setter` 修饰设置值的函数
- 只定义了 `@property` 装饰器的方法（即 getter），而没有定义对应的 `@属性名.setter` 方法，那么这个属性就是**只读的**。

## 定义

### 装饰器方式

```python
"""
定义学生类，私有age属性，通过Property属性简化调用
"""
# 这种写法没有意义，而且很难用闭包的思路去理解
class Student:
    def __init__(self,age: int) -> None:
        self.__age = age

    @property
    def get_age(self):
        return self.__age

    @get_age.setter
    def set_age(self, age):
        self.__age = age

s1 = Student(20)
s1.set_age = 10
print(s1.get_age)

"""
10
"""
```

实际开发一般写成下面的样式：

```python
"""
定义学生类，私有age属性，通过Property属性简化调用
"""

class Student:
    def __init__(self,age: int) -> None:
        self.__age = age

	# 把 age 搞成 property 对象，相当于 property(age)
    @property
    def age(self):
        return self.__age

    # age.setter(age)，age 这个东西又被更新了
    @age.setter
    def age(self, age):
        self.__age = age

s1 = Student(20)
s1.age = 10 # 会调用 setter 里的 age 方法
print(s1.age)
```

### 类属性方式

`类属性 = property(获取方法名, 设置方法名)`

```python
"""
定义学生类，私有age属性，通过Property属性简化调用
"""

class Student:
    def __init__(self,age: int) -> None:
        self.__age = age

    def get_age(self):
        return self.__age
    
    def set_age(self, age):
        self.__age = age

    age = property(get_age, set_age)

s1 = Student(20)
s1.age = 10
print(s1.age)
```

# `Property` 介绍

在 Python 中，`property` 是一个内置类，用于将方法转换为属性（即“属性化”）。它允许你在获取、设置或删除某个属性时，执行自定义的逻辑（如数据验证、计算等），同时保持调用方式与普通属性完全一致，完美遵循了面向对象编程中的“封装”原则。

## 创建对象时的格式

```python
prop = property(
    fget,      # 可选：获取属性值时调用的函数（相当于 getter）
    fset,      # 可选：设置属性值时调用的函数（相当于 setter）
    fdel,      # 可选：删除属性时调用的函数（相当于 deleter）
    doc        # 可选：该属性的文档字符串（若未提供，则默认使用 fget 的文档字符串）
)
```

> 在实际开发中，更推荐使用 `@property`、`@xxx.setter` 和 `@xxx.deleter` 装饰器语法，这比直接调用 `property()` 构造函数更加优雅和 Pythonic。

## 参数详解

| 参数名称 | 作用说明                                                     | 常见可选值或示例             |
| -------- | ------------------------------------------------------------ | ---------------------------- |
| `fget`   | 获取属性值时触发的回调函数。该函数通常只接收 `self` 参数，并返回一个值。 | `get_name`（获取名称的方法） |
| `fset`   | 设置属性值时触发的回调函数。该函数接收 `self` 和要设置的 `value` 两个参数，常用于数据校验。 | `set_name`（设置名称的方法） |
| `fdel`   | 删除属性（使用 `del` 关键字）时触发的回调函数。该函数仅接收 `self` 参数。 | `del_name`（删除名称的方法） |
| `doc`    | 为该属性指定文档说明。如果不传此参数，`property` 会自动复制 `fget` 函数的文档字符串。 | `"用户的姓名属性"`           |

## 常用属性

| 属性名称  | 作用说明                                                     |
| --------- | ------------------------------------------------------------ |
| `fget`    | 返回当前绑定的获取属性值的函数。如果没有绑定，则返回 `None`。 |
| `fset`    | 返回当前绑定的设置属性值的函数。如果没有绑定，则返回 `None`。 |
| `fdel`    | 返回当前绑定的删除属性的函数。如果没有绑定，则返回 `None`。  |
| `__doc__` | 返回该属性的文档字符串。                                     |

## 常用方法

| 方法名称        | 作用说明                                                     |
| --------------- | ------------------------------------------------------------ |
| `getter(fget)`  | 返回一个新的 `property` 对象，其获取逻辑被替换为传入的 `fget` 函数。<br />这也是 `@xxx.getter` 装饰器的底层实现。 |
| `setter(fset)`  | 返回一个新的 `property` 对象，其设置逻辑被替换为传入的 `fset` 函数。<br />对应 `@xxx.setter` 装饰器。 |
| `deleter(fdel)` | 返回一个新的 `property` 对象，其删除逻辑被替换为传入的 `fdel` 函数。<br />对应 `@xxx.deleter` 装饰器。 |

## 影响

| 配套语法 / 场景           | 行为影响                                                     |
| ------------------------- | ------------------------------------------------------------ |
| 仅使用 `@property`        | 该属性变为只读。外部尝试赋值（如 `obj.attr = value`）时，<br />会抛出 `AttributeError: can't set attribute`。 |
| 缺少 `@attr_name.setter`  | 同上，无法通过赋值操作修改属性。                             |
| 缺少 `@attr_name.deleter` | 外部尝试删除属性（如 `del obj.attr`）时，<br />会抛出 `AttributeError: can't delete attribute`。 |
| 方法名不一致              | 如果 `@attr_name.setter` 中的 `attr_name` 与 `@property` 下方的方法名不同，<br />Python 会将其视为一个全新的、与属性无关的普通方法。 |

## 底层实现示例

```python
class ClassName:
    @property                    # 1. 声明获取属性的方法（相当于 fget）
    def attr_name(self):         # 定义获取属性值时的逻辑，必须返回一个值
        return self._attr_name

    @attr_name.setter            # 2. 声明设置属性的方法（相当于 fset）
    def attr_name(self, value):  # 定义设置属性值时的逻辑，通常包含数据校验
        self._attr_name = value

    @attr_name.deleter           # 3. 声明删除属性的方法（相当于 fdel）
    def attr_name(self):         # 定义删除属性时的逻辑
        del self._attr_name
        
class ClassName:
    def __getattr_name(self):
        print("get 方法调用")
        return self._attr_name

    def __setattr_name(self, value):
        print("set 方法调用")
        self._attr_name = value

    def __delattr_name(self):
        print("del 方法调用")
        del self._attr_name

    attr_name = property()
    # 下面的都是返回新的 property，所以这里要覆盖一下
    attr_name = attr_name.getter(__getattr_name)
    attr_name = attr_name.setter(__setattr_name)
    attr_name = attr_name.deleter(__delattr_name)


c = ClassName()
c.attr_name = 10  	# set
print(c.attr_name) 	# get
del c.attr_name 	# del
ClassName.attr_name = 1000 # 覆盖了 attr_name
print(c.attr_name)

"""
set 方法调用
get 方法调用
10
del 方法调用
1000
"""
```
