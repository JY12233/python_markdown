# `__new__`

## 介绍

在类实例化时被调用。要创建一个单例，或者一些和 metaclass 有关的才会用到`__new__`函数。

单例模式是指在整个应用程序中，某个类只能有一个实例存在，且该实例可以被任何模块访问到。这种模式的应用场景包括数据库连接池、日志对象等需要全局唯一性的对象。

## 代码示例

```python
from typing import Self


class App:
    # new 在实例化对象时被调用
    def __new__(cls) -> Self:
        print("使用 __new__ 方法")
        return super().__new__(cls)

    def __init__(self) -> None:
        print("使用 __init__ 方法")


class Single:
    _instance = None

    def __new__(cls) -> Self | None:
        """
        看 _instance 是否为 None。如果是，就创建一个新的实例并分配给 _instance。
        如果不是，就直接返回这个 _instance。
        因为 `__new__` 方法在实例化对象的时候被调用，这样可以保证所有对象都是一样的。
        也就是这个类只有一个实例。
        """

        print("调用 __new__ 方法")
        # 这一步创建一个新的对象
        if cls._instance is None:
            print("执行创建 Single 对象")
            # 类也是一个对象，这里使用 object 创建一个对象
            cls._instance = super().__new__(cls)

        # 返回这个新的对象
        # 因为只在 None 的时候创建，所以返回的对象都是相同的
        # 也就保证了只有一个实例
        return cls._instance


if __name__ == "__main__":
    a = App()

    print("-" * 30)

    s1 = Single()
    s2 = Single()
    print(s1 is None)  # False
    print(s1 is s2)  # True
    s1.name = "张三"  # type: ignore
    print(s2.name)  # 张三，类的实例化对象是相同的 # type: ignore

```

# `__call__` 介绍

## 作用

`__call__` 是一个特殊的（“魔术”）方法。当一个类的实例被当作函数调用时（即使用 `()` 运算符），Python 解释器会自动调用该实例的 `__call__` 方法。一个对象之所以能被调用，是因为它的**类**（或元类）实现了 `__call__` 方法。

## 区别

- `object` 类**没有** `__call__` 方法。

    这意味着，通过 `object()` 创建的直接实例是不可调用的。尝试调用一个 `object` 实例会引发 `TypeError`。
    
    ```python
    >>> obj = object()
    >>> obj()
    Traceback (most recent call last):
          ...
    TypeError: 'object' object is not callable
    ```
    
- `type` 有 `__call__` 方法。

    Python 中类本身是可调用的。当执行 `MyClass()` 创建一个实例时，实际上是调用了元类 `type` 的 `__call__` 方法。`type` 的 `__call__` 方法负责调用类的 `__new__` 和 `__init__` 方法。
    
    - `type` **有** `__call__` 方法，因此类是可调用的。
    - `object` **没有** `__call__` 方法，因此它的普通实例不可调用。

## 实现

若想让自定义类的实例可调用，需要在类中实现 `__call__` 方法。

```python
class CallableClass:
    def __call__(self):
        print("Instance is called!")

# 实例化
instance = CallableClass()
# 调用实例，触发 __call__ 方法
instance()  # 输出: Instance is called!
```

## 修改实例化

```python
class SingletonType(type):
    _instances = {}

    # 当 MyClass 调用创建示例时，会调用其元类的 __call__ 方法获取一个实例
    # 这里就限定了返回的实例都是同一个东西，跟用 __new__ 的实现差不多
    # 只是这里是写在元类里面的
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class MyClass(metaclass=SingletonType):
    pass


```



# `type` 介绍

`type` 类是 Python 中所有类的元类（metaclass），即所有类都是 `type` 类的实例。`type` 类本身也是一个类，它继承自 `object`，同时又是 `object` 的元类。

`type` 类提供两种核心功能：一是作为函数调用时，返回对象的类型；二是作为元类，用于动态创建新的类。

## 创建对象

`type` 类可接受两种不同数量的参数，分别对应两种用途。

### 单参数形式：获取对象的类型

```python
type(object)  # object：需要获取类型的对象
```

当只传入一个参数时，`type` 返回该参数对象的类型对象。返回值与 `object.__class__` 相同。

### 三参数形式：动态创建新类

```python
type(
    name, 			# name：类的名称（字符串）
    bases,			# bases：父类元组（tuple）
    dict,			# dict：类属性与方法的命名空间字典（dict）
    **kwds 			# **kwds：可选的关键字参数，传递给元类
)
```

当传入三个参数时，`type` 动态创建一个新类并返回。这种形式与使用 `class` 语句定义类是等价的。

## 参数详细说明及可选值

### 单参数形式

| 参数名   | 类型     | 作用说明             | 备注     |
| :------- | :------- | :------------------- | :------- |
| `object` | 任意对象 | 需要获取其类型的对象 | 必填参数 |

### 三参数形式

| 参数名   | 类型       | 作用说明                       | 可选值 / 备注                                                |
| :------- | :--------- | :----------------------------- | :----------------------------------------------------------- |
| `name`   | `str`      | 要创建的类的名称               | 必填参数，通常与变量名保持一致                               |
| `bases`  | `tuple`    | 父类的元组，指定新类的继承关系 | 必填参数。<br />若为 `()`，则新类继承自 `object`；<br />若只有一个父类，需使用元组的单元素写法，如 `(Parent,)`；<br />支持多重继承 |
| `dict`   | `dict`     | 类的属性和方法的命名空间字典   | 必填参数。<br />键为属性名（字符串），值为属性值或方法函数；<br />若为空字典 `{}`，则新类不包含任何自定义属性或方法 |
| `**kwds` | 关键字参数 | 传递给元类的额外关键字参数     | 可选参数。用于高级元编程场景，可控制类创建时的额外行为       |

## 单参数返回值说明

`type(obj)` 输出结果中 `<class '...'>` 引号内的内容，其决定规则非常明确：它直接取自该对象所属类的 `__qualname__` 属性。

### `__qualname__` 属性

`__qualname__`（qualified name，即“限定名”）是 Python 3.3 引入的一个属性，旨在比旧的 `__name__` 属性更精确地描述一个类或函数的定义位置。

- 对于顶层定义的类

  `__qualname__` 的值就是类名本身。

- 对于嵌套定义的类

  `__qualname__` 的值会包含其外部类的名称，用点号 `.` 连接，清晰地展示了其层级结构。

`type()` 函数的字符串表示形式正是使用了 `__qualname__` 来填充引号中的内容。

### 代码示例

#### 顶层类

对于在模块顶层直接定义的类，引号内就是类名。

```python
class Dog:
    pass

d = Dog()
print(type(d)) 
# 输出: <class '__main__.Dog'>
# 解释: Dog.__qualname__ 的值是 'Dog'。
# '__main__' 是当前模块的名称。
```

#### 嵌套类

对于在另一个类或函数内部定义的类，引号内会包含其外部作用域的名称。

```python
class Animal:
    class Cat:
        pass

c = Animal.Cat()
print(type(c))
# 输出: <class '__main__.Animal.Cat'>
# 解释: Animal.Cat.__qualname__ 的值是 'Animal.Cat'。
# 这清晰地表明了 Cat 类是在 Animal 类内部定义的。
```

#### 对比 `__name__`

这个对比能更清楚地展示 `__qualname__` 的优势。

```python
class Outer:
    class Inner:
        pass

# 对于嵌套类，__name__ 只返回类本身的名字
print(Outer.Inner.__name__)     # 输出: Inner

# 而 __qualname__ 返回包含外部类名的完整路径
print(Outer.Inner.__qualname__) # 输出: Outer.Inner

# type() 的显示结果与 __qualname__ 一致
print(type(Outer.Inner()))      
# 输出: <class '__main__.Outer.Inner'>
```

### 总结

`type(obj)` 输出中 `<class '...'>` 引号里的内容，就是 `obj` 所属类的 `__qualname__` 属性值。这个属性精确地描述了类在代码中的定义位置，尤其能清晰地展示嵌套关系。

## 作为泛型类

在类型提示的上下文中，`type[SomeClass]` 是一个标准的泛型语法，专门用来表示“某个类或其子类本身”，以区别于该类的实例。

比如，`type[Exception]` 期望接收的值，必须是 `Exception` 类本身，或者是 `Exception` 的任意子类。

## 常用属性和方法

### 常用属性

| 属性名         | 类型            | 作用说明                                           |
| :------------- | :-------------- | :------------------------------------------------- |
| `__name__`     | `str`           | 类或类型的名称                                     |
| `__qualname__` | `str`           | 类或类型的限定名称（包含嵌套路径）                 |
| `__module__`   | `str`           | 类定义所在的模块名称                               |
| `__bases__`    | `tuple`         | 类的父类元组                                       |
| `__mro__`      | `tuple`         | 方法解析顺序（Method Resolution Order）元组        |
| `__dict__`     | `dict`          | 类的属性命名空间字典                               |
| `__doc__`      | `str` 或 `None` | 类的文档字符串                                     |
| `__class__`    | `type`          | 对象所属的类（对于 `type` 实例，指向 `type` 本身） |

### 常用方法

| 方法名                             | 作用说明                                                     |
| :--------------------------------- | :----------------------------------------------------------- |
| `__new__(cls, *args, **kwargs)`    | 元类的构造方法，在创建类时被调用，负责分配内存并返回类对象。 |
| `__init__(cls, *args, **kwargs)`   | 元类的初始化方法，在 `__new__` 之后被调用，用于初始化类对象。 |
| `__call__(cls, *args, **kwargs)`   | 使得 `type` 的实例（即类）可被调用。<br />当实例化一个类时，`type.__call__` 被触发，进而调用类的 `__new__` 和 `__init__`。 |
| `__subclasses__(cls)`              | 返回类的所有直接子类列表。                                   |
| `__instancecheck__(cls, instance)` | 检查一个对象是否是该类的实例（由 `isinstance` 触发）。       |
| `__subclasscheck__(cls, subclass)` | 检查一个类是否是该类的子类（由 `issubclass` 触发）。         |
| `mro(cls)`                         | 返回类的方法解析顺序（MRO）列表，与 `__mro__` 属性等价。     |

## 使用示例

### 获取对象类型（单参数）

```python
>>> type(42)
<class 'int'>
>>> type("hello")
<class 'str'>
>>> type([1, 2, 3])
<class 'list'>
```

### 动态创建类（三参数）

```python
# 定义一个方法
def greet(self):
    return "Hello, " + self.name

# 使用 type 动态创建类
Person = type('Person', (), {'name': 'Alice', 'say_hello': greet})

# 实例化并使用
p = Person()
print(p.say_hello())  # 输出：Hello, Alice
```

### 创建带有继承关系的类

```python
class Animal:
    def speak(self):
        return "动物叫声"

# 动态创建子类，继承 Animal，并添加新属性
Dog = type('Dog', (Animal,), {'breed': '金毛'})

d = Dog()
print(d.speak())  # 输出：动物叫声
print(d.breed)    # 输出：金毛
```

# `object` 介绍

## 介绍

`object` 类是 Python 中所有类的最终基类（ultimate base class）。在 Python 3 中，所有类无论是否显式声明，都隐式继承自 `object`。该类提供了一个最小化且无特性的对象，仅包含所有 Python 对象共用的基本方法。

由于 `object` 实例没有 `__dict__` 属性，因此**无法**为其设置任意属性。

## 创建对象

`object` 类的构造函数不接受任何参数。

```python
object()  # 创建一个新的空对象实例
```

## 常用属性

| 属性名      | 类型            | 作用说明                                             |
| :---------- | :-------------- | :--------------------------------------------------- |
| `__class__` | `type`          | 对象所属的类                                         |
| `__doc__`   | `str` 或 `None` | 类的文档字符串                                       |
| `__dict__`  | `dict`          | 对象的属性命名空间字典（仅当对象支持动态属性时存在） |

> **注意**：直接通过 `object()` 创建的实例没有 `__dict__` 属性，因此无法添加自定义属性。

## 常用方法

`object` 类为所有 Python 对象提供了默认的方法实现。下表列出 `object` 类的核心方法：

| 方法名                            | 作用说明                                         |
| :-------------------------------- | :----------------------------------------------- |
| `__new__(cls[, ...])`             | 静态方法，用于创建类的新实例（构造器）           |
| `__init__(self[, ...])`           | 初始化方法，在实例创建后被调用，用于设置初始状态 |
| `__repr__(self)`                  | 返回对象的官方字符串表示，供开发者调试使用       |
| `__str__(self)`                   | 返回对象的用户友好字符串表示                     |
| `__eq__(self, other)`             | 定义相等性比较行为（`==` 运算符）                |
| `__ne__(self, other)`             | 定义不等性比较行为（`!=` 运算符）                |
| `__hash__(self)`                  | 返回对象的哈希值，用于字典键和集合元素           |
| `__getattribute__(self, name)`    | 拦截所有属性访问操作                             |
| `__setattr__(self, name, value)`  | 拦截属性赋值操作                                 |
| `__delattr__(self, name)`         | 拦截属性删除操作                                 |
| `__dir__(self)`                   | 返回对象的属性列表，供 `dir()` 函数使用          |
| `__format__(self, format_spec)`   | 定义 `format()` 函数的行为                       |
| `__lt__(self, other)`             | 定义小于比较行为（`<` 运算符）                   |
| `__le__(self, other)`             | 定义小于等于比较行为（`<=` 运算符）              |
| `__gt__(self, other)`             | 定义大于比较行为（`>` 运算符）                   |
| `__ge__(self, other)`             | 定义大于等于比较行为（`>=` 运算符）              |
| `__reduce__(self)`                | 用于对象序列化（pickle 协议）                    |
| `__reduce_ex__(self, protocol)`   | 用于对象序列化（pickle 协议，指定版本）          |
| `__sizeof__(self)`                | 返回对象占用的内存大小（字节）                   |
| `__init_subclass__(cls)`          | 在子类被定义时调用                               |
| `__subclasshook__(cls, subclass)` | 用于自定义 `issubclass` 的行为                   |

## 使用示例

**创建 `object` 实例**
```python
>>> obj = object()
>>> obj
<object object at 0x1079e6f90>
```

**将 `object` 用作哨兵值（Sentinel Value）**
```python
SENTINEL = object()  # 创建一个独一无二的标记值

class Circle:
    def __init__(self, radius):
        self.radius = radius
        self._diameter = SENTINEL

    @property
    def diameter(self):
        if self._diameter is SENTINEL:  # 判断是否已计算
            self._diameter = self.radius * 2
        return self._diameter

circle = Circle(5)
print(circle.diameter)  # 输出：10
```

**所有类隐式继承自 `object`**
```python
>>> class MyClass:
...     pass
...
>>> isinstance(MyClass(), object)
True
```

**显式继承自 `object`（Python 3 中可选）**
```python
class Point(object):  # 显式继承，与 class Point: 等价
    def __init__(self, x, y):
        self.x = x
        self.y = y
```

# 元类（Metaclass）

## 基本概念

### 一切皆对象思想

Python 中，类本身也是对象。使用 `class` 关键字定义类时，Python 解释器会在内存中创建一个对象。类对象拥有创建实例的能力，同时本身也是对象，可以被赋值给变量、作为函数参数传递、动态添加属性等。

| 对象类型           | 说明                 | 示例                  |
| ------------------ | -------------------- | --------------------- |
| 类型对象（类）     | 可以被实例化和继承   | `class MyClass: pass` |
| 非类型对象（实例） | 不可以被实例化和继承 | `obj = MyClass()`     |

### 对象体系的关系

Python 对象体系中存在两种关系：

- 父子关系（继承）：通过 `__bases__` 表示父类。
- 类型实例关系：通过 `__class__` 表示创建者，也就是这个对象是由谁创建的。

**核心结论**

- `type` 是所有对象的创建者（类型顶点），所有对象都创建自 `type`。
- `object` 是所有类的父类（继承顶点），所有类都继承自 `object`。
- `type` 继承自 `object`，同时 `object` 又是 `type` 的实例。object和type是Python中的两个源对象，它们是互相依赖对方来定义，所以它们不能分开而论。

```python
>>> class MyClass: pass
>>> MyClass.__class__      # type
>>> MyClass.__bases__      # (object,)
>>> object.__class__       # type
>>> object.__bases__	   # []
>>> type.__bases__         # (object,)
>>> type.__class__         # type（type 创建自本身）
```

`object` 和 `type` 互相依赖定义，是 Python 中的两个源对象。

### 元类的定义

**元类（metaclass）是创建类的类**。正如类是用来创建对象的模板，元类是用来创建类的模板。

- `str` 类创建字符串对象。
- `int` 类创建整数对象。
- `type` 类（元类）创建类对象。

类比理解：
- 元类 -> 制作蛋糕模具的机床
- 类 -> 制作蛋糕的模具（由元类创建）
- 实例 -> 蛋糕（由类创建）

## 元类的工作原理

### 类的创建过程

```python
# 以下两种写法等价

# 方式一：使用 class 语句
# 只要 class 了，相当于执行了 type()，只不过变量名和 name 参数都是 class 后面的字面量
class MyClass:
    pass

# 方式二：使用 type() 动态创建
MyClass = type('MyClass', (), {})
```

`type()` 函数接受三个参数：
- 第一个参数：类名（字符串）
- 第二个参数：父类元组
- 第三个参数：属性和方法的字典

### 元类的生命周期

元类控制类实例的创建过程：

1. 定义类时

   元类的 `__new__` 方法被调用，用于创建类对象。

   > 因为类定义就是在实例化元类，创建元类的对象。而根据之前的知识，在类实例化时，先调用 `__new__` 返回这个类的实例，在调用 `__init__` 给这个实例设置初始状态。

2. 定义类后

   元类的 `__init__` 方法被调用，用于初始化类对象。

3. 实例化类时

   元类的 `__call__` 方法被调用，进而调用类的 `__new__` 和 `__init__`。

```
类定义 → 元类.__new__() → 元类.__init__() → 类对象
类实例化 → 元类.__call__() → 类.__new__() → 类.__init__() → 实例对象
```

### 元类与继承的区别

| 特性     | 继承       | 元类     |
| -------- | ---------- | -------- |
| 作用时机 | 实例创建时 | 类定义时 |
| 控制对象 | 实例的行为 | 类的行为 |
| 作用层级 | 实例层级   | 类层级   |

## 元类的创建与使用

### 定义元类

元类继承自 `type` 或其子类：

```python
class SimpleMeta(type):
    pass
```

### 使用元类

在类定义中通过 `metaclass` 关键字参数指定：

```python
class MyClass(metaclass=SimpleMeta):
    pass
```

## 元类的核心方法

1. `__new__` 方法：在类被创建时调用，用于创建类对象。

    ```python
    class Meta(type):
        def __new__(cls, name, bases, class_dict):
            # cls: 元类本身
            # name: 要创建的类的名称
            # bases: 父类元组
            # class_dict: 类的属性/方法字典
            return super().__new__(cls, name, bases, class_dict)
    ```

2. `__init__` 方法：在 `__new__` 之后调用，用于初始化类对象。

    ```python
    class Meta(type):
        def __init__(cls, name, bases, class_dict):
            super().__init__(name, bases, class_dict)
            # 可在此处对类进行额外操作
    ```

3. `__call__` 方法：当通过类创建实例（即调用类本身）时调用，用于控制实例的创建和初始化过程。

    ```python
    class Meta(type):
        def __call__(cls, *args, **kwargs):
            # cls: 要实例化的类对象
            # *args: 传递给 __init__ 的位置参数
            # **kwargs: 传递给 __init__ 的关键字参数
            # 调用自身的 __new__ 搞出一个实例，也就是我们所 class 的类所创建的实例
            # 初始化之后返回，这样才能有一个实例，不然什么都没有
            instance = cls.__new__(cls, *args, **kwargs)
            cls.__init__(instance, *args, **kwargs)
            return instance
    ```

### 示例：自动注册类

```python
# 元类是用来创建类的模板，也就是用来创建类的类
# 把它定义为一个元类，当它被实例化的时候，也就是基于它去创建一个类，用调用或者 class 都行，
# 就会调用这个元类的 __new__ 方法
class RegistryMeta(type):
    registered_classes = []

    def __new__(cls, name, bases, dct):
        print(f"创建类: {name}")
        # 使用 type 返回实例，每个实例不相同 ---> a is b -> False
        return super().__new__(cls, name, bases, dct)

    # 类实例化之后，给这个实例设置初始状态
    def __init__(cls, name, bases, dct):
        super().__init__(name, bases, dct)
        # 更新类变量
        RegistryMeta.registered_classes.append(cls)
    
    # 当元类所创建出的类被调用时才会用到这个，比如 d = Dog()
    def __call__(cls):
        pass

# 记住：普通的 class 一个类，就是在实例化元类，这里指定元类为 RegistryMeta，
# 所以这段一写出来就会调用 RegistryMeta 中的 __new__ 获得实例，__init__ 设置初始状态
class Dog(metaclass=RegistryMeta):
    pass

class Cat(metaclass=RegistryMeta):
    pass

print(RegistryMeta.registered_classes)
# 输出: [<class '__main__.Dog'>, <class '__main__.Cat'>]
```

### 示例：自动修改类属性

将类中所有属性名转换为大写：

```python
class UpperAttrMeta(type):
    def __new__(cls, name, bases, class_dict):
        upper_attrs = {}
        for attr_name, attr_value in class_dict.items():
            if not attr_name.startswith('__'):
                upper_attrs[attr_name.upper()] = attr_value
            else:
                upper_attrs[attr_name] = attr_value
        return super().__new__(cls, name, bases, upper_attrs)

class MyClass(metaclass=UpperAttrMeta):
    bar = 'bip'

print(MyClass.BAR)  # 输出: bip
```

## 元类的应用场景

- ORM（对象关系映射）
  
  Django ORM、SQLAlchemy 等框架的核心机制基于元类实现。元类可将类属性自动映射为数据库表字段。
  
- 单例模式
  
  通过元类控制类的实例化过程，确保一个类只有一个实例。
  
  ```python
  class SingletonMeta(type):
      _instances = {}
  
      def __call__(cls, *args, **kwargs):
          if cls not in cls._instances:
              cls._instances[cls] = super().__call__(*args, **kwargs)
          return cls._instances[cls]
  
  class Singleton(metaclass=SingletonMeta):
      pass
  ```
  
- 抽象基类（ABC）
  
  `abc.ABCMeta` 是 Python 标准库中元类的典型应用。
  
- 类属性验证与规范
  
  强制类包含某些属性或方法，或自动为类添加通用方法。
  
- API 客户端生成
  
  根据接口定义（如 OpenAPI/Swagger）自动生成 API 客户端代码，减少重复开发工作。
  
- 插件系统与依赖注入
  
  元类可用于自动注册插件，例如在框架启动时扫描并收集所有继承自基类的子类，无需手动维护注册表。

## 注意事项

- 谨慎使用：元类是深度魔法，99% 的用户不需要直接使用元类。只有在非常清楚需要做什么时才使用元类。
- 保持代码清晰：过度使用元类会降低代码可读性。
- 优先考虑更简单的方案：装饰器、类装饰器、描述符等通常足以解决问题。

# 类定义与实例化的元类驱动过程

在 Python 中，类定义（`class` 语句）和类实例化（`ClassName()`）的过程由元类（metaclass）全程驱动。理解这一过程需要区分两个阶段：

- 类对象创建阶段：当解释器执行 `class` 语句时，元类被调用来创建类对象。
- 类实例创建阶段：当调用类对象（即 `ClassName()`）时，元类被调用来创建类的实例。

## 过程描述

1. 类定义时（执行 `class` 语句）
   - Python 解释器收集类名、父类元组和类体命名空间（属性和方法字典）。
   
   - 查找类的元类（由 `metaclass` 关键字指定，否则从父类或默认 `type` 继承）。
   
   - 调用元类的 `__new__` 方法，传入 `(metaclass, class_name, bases, class_dict)`，返回一个新的类对象。

   - 如果 `__new__` 返回的是一个类对象，则调用元类的 `__init__` 方法，传入该类对象以及其他参数，进行初始化。
   
     > 因为返回类对象才表明实例化完成，实例化一完成肯定就要进入 `__init__` 设置该实例的初始状态。
   
   - 最终将创建好的类对象绑定到指定的名称。
   
2. 类实例化时（执行 `ClassName()`）
   - 调用类对象时，实际上触发的是元类的 `__call__` 方法。
   - 元类的 `__call__` 方法内部**通常**执行：
     - 调用类的 `__new__` 方法（若未定义则默认继承 `object.__new__`），创建一个实例对象。
     - 如果 `__new__` 返回的是该类的实例，则调用类的 `__init__` 方法，传入实例和参数进行初始化。
     
     > 不是必须执行。假设里面什么都不写，那么就无法初始化。
   - 最终返回初始化后的实例。

## 代码示例

自定义元类 `Meta`，在关键方法中添加打印，观察执行顺序。

```python
"""
类创建时，相当于把元类实例化，会先调用元类的 __new__，再调用 __init__。
"""

# 定义一个元类演示过程
from typing import Any


class Meta(type):
    def __new__(
        cls, name: str, bases: tuple[type, ...], namespace: dict[str, Any]
    ) -> Meta:
        """
        在元类实例化时，调用的函数，用于控制实例化的过程和结果。

        Parameters
        ----------
        cls : type[Self]
            指向当前类本身，这里就是 `Meta` 自身
        name : str
            实例化的类的名称。如果是 `Meta()` 形式，通常与变量名保持一致/
            如果是 `class` 形式，就是 `class` 后面的字面量。
        bases : tuple[type, ...]
            实例化的类的继承关系。
        namespace : dict[str, Any]
            实例化的类具有的属性和方法。`str` 为名称。
        """
        print(f"Meta 开始实例化，名称为：{name}")

        # 调用父类的 __new__ 获得一个实例，这里是 type
        # type.__new__ 返回的是 Self@__new__
        instance = super().__new__(cls, name, bases, namespace)

        print("Meta 实例化完成。")
        return instance

    def __init__(
        self, name: str, bases: tuple[type, ...], dict: dict[str, Any], /, **kwds: Any
    ) -> None:
        print(f"Meta 的 {name} 实例开始初始化。")

        super().__init__(name, bases, dict, **kwds)

        print(f"Meta 的 {name} 实例初始化完成。")

    def __call__(self, *args: Any, **kwds: Any):
        # 以 Dog 为例，type(self) -> Meta     self -> Dog
        print(f"Meta 的 {self.__name__} 实例开始创建自己的实例")
        print(f"Meta 的 {self.__name__} 创建的实例参数为：{args} {kwds}")

        # 我们要创建的是类的实例，不是元类的实例，所以要用 object
        # 因为 Dog 的父类是 object，我们创建一个普通的类肯定是基于父类去创建
        instance = object.__new__(self)
        # 我们执行的是 object 的 __new__，拿到了 Self 的实例，也就是 Dog
        # 也就是说，在 Dog 的 __new__ 之前，先执行的 Meta 的 __call__。
        # type(instance)  -> <class '__main__.Dog'>，
        # 就这样创建了一个 Dog 的实例。
        # 接下来会进入 Dog 的 __new__ 和 __init__。
        # self.__init__(self, *args, *kwds)

        print(f"Meta 的 {self.__name__} 创建的实例完成")
        return instance


print("====== 开始创建 Meta 的实例 ======")


# 记住：class 就是创建元类的实例
class Dog(metaclass=Meta):
    pass


print()

Cat = Meta("Cat", (object,), {})

print("====== Meta 的实例创建完成 ======")


print()


print("====== 开始创建 Dog 的实例 ======")

d = Dog()

print("====== Dog 的实例创建完成 ======")

```

## 流程总结

| 步骤 | 触发时机                                 | 执行的方法           | 职责                             |
| :--- | :--------------------------------------- | :------------------- | :------------------------------- |
| 1    | `class` 语句执行                         | `TraceMeta.__new__`  | 创建类对象（相当于分配内存）     |
| 2    | `class` 语句执行（`__new__` 返回后）     | `TraceMeta.__init__` | 初始化类对象（添加属性、方法等） |
| 3    | 调用类对象 `MyClass()`                   | `TraceMeta.__call__` | 接管实例化过程                   |
| 4    | 元类 `__call__` 内部                     | `MyClass.__new__`    | 创建实例对象                     |
| 5    | 元类 `__call__` 内部（`__new__` 返回后） | `MyClass.__init__`   | 初始化实例对象                   |

## 关键点说明

- 元类的 `__new__` 和 `__init__` 作用于类本身，在类定义时执行，且只执行一次。
- 元类的 `__call__` 在每次类实例化时执行，它负责调度类的 `__new__` 和 `__init__`。
- 类的 `__new__` 负责创建实例（分配内存），而 `__init__` 负责填充实例属性。
- `object.__new__(cls)` 是默认的实例创建者，自定义类通常直接继承它。
