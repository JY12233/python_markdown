# 多任务概述

1. 概念

   在同一时间内执行多个任务。

2. 优势

   充分利用CPU资源，提高程序的运行效率。

3. 表现形式

   - 并发

     在一段时间内，交替执行任务。任务数大于CPU核数。

   - 并行

     在一段时间内，同时执行多个任务。需要多核CPU。

# 进程

## 概念

进程（process），**CPU资源分配**的最小单位，操作系统进行资源费配和调度运行的基本单位。

> 通常来说，一个运行的程序就是一个进程，比如每个.exe文件。

## 创建步骤

1. 导入进程工具包

   `import multiprocessing`

2. 通过进程类 实例化进程 对象

   `子进程对象 = multiprocessing.Process()`

3. 启动进程执行任务

   `进程对象.start()`

>子进程对象 =
>`multiprocessing.Process(group=None, target=None, name=None, args=(), kwargs={})`
>
>- `group`—参数未使用，值始终为 `None`。
>- `target`—表示调用对象，即子进程要执行的任务（回调函数入口地址）。
>- `args`—表示以元组的形式向子任务函数传参，元组方式传参一定要和参数的顺序保持一致（位置传参）。
>- `kwargs`—表示以字典的方式给子任务函数传参，字典方式传参字典中的key要和参数名保持一致（关键字传参）。
>- `name`—为子进程的名称。

## 获取进程的编号

1. 编号的作用

   进程编号唯一标识一个进程，方便管理进程。

2. 特点

   在一个操作系统中，一个进程拥有的进程号是唯一的。当进程释放时，进程号也会释放。进程号可以反复使用。

3. 作用

   获取进程编号的目的是验证主进程和子进程的关系，可以得知子进程是由哪个主进程创建出来的。

4. 获取进程编号的两种操作

   - 获取当前进程编号。

     `os.getpid()` —— process id

     `multiprocessing.current_process().pid`

   - 获取当前父进程编号。

     `os.getppid()` —— parent process id

5. 细节

   main 中创建的进程，如果没有特殊指定，它的父进程都是main进程。

   main 进程的父进程是 当前运行程序（比如PyCharm或者VS Code）的pid。

```python
# 导包
import multiprocessing
import time, os

# 定义函数1
def coding(name: str):
    for i in range(1, 11):
        time.sleep(0.1) # 模拟耗时操作，更好地查看多任务的效果
        print(f'{name}正在敲第{i}遍代码，请稍后...')
    print(f'子进程的id是{os.getpid()}, 父进程的id是{os.getppid()}')

# 定义函数2
def music(name: str, song: str):
    for i in range(1, 11):
        time.sleep(0.1)
        print(f'{name}正在听第{i}遍音乐：{song}。')
    print(f'子进程的id是{os.getpid()}, 父进程的id是{os.getppid()}')

# 通过main（主进程）创建子进程
if __name__ == '__main__':
    # 进行p1关联
    p1 = multiprocessing.Process(target=coding, name='写代码', args=('Alice', ))

    # 进行p2关联
    p2 = multiprocessing.Process(target=music, name='听音乐', kwargs={'name': 'Bob', 'song': '9420'})

    p_id = multiprocessing.current_process().pid
    pp_id = os.getppid()
    print(f'main进程的id是{p_id}，父进程的id是{pp_id}')

    # 启动进程
    p1.start()
    p2.start()
```

### 主进程会等待所有的子进程执行结束再结束。

在 Python 中，主进程结束时子进程的命运取决于**子进程的类型**。默认情况下，子进程会继续运行，直到主进程等待其结束或主动将其终止。

具体来说，有以下三种情况：

#### 默认行为：主进程会等待子进程

默认情况下，当主进程的所有代码执行完毕后，它**不会立即退出**，而是会等待所有由它创建的、非守护（non-daemon）的子进程结束后，才会最终退出。

这是 `multiprocessing` 模块的默认行为，目的是确保子任务能够完整执行。

```python
import multiprocessing
import time

def worker():
    for i in range(5):
        print(f"子进程工作中... {i}")
        time.sleep(1)

if __name__ == '__main__':
    p = multiprocessing.Process(target=worker)
    p.start()
    print("主进程代码执行完毕，但会等待子进程...")
    # 主进程在此处不会立即退出，而是等待 p 进程结束
```

**输出结果：**

主进程打印完信息后，子进程依然会继续打印 5 次，然后整个程序才结束。

#### 设置为守护进程：随主进程一同结束

如果你希望主进程一结束，子进程也立刻被强制终止，可以将子进程设置为**守护进程（Daemon Process）**。

这通过设置进程对象的 `daemon` 属性为 `True` 来实现。**注意：此属性必须在调用 `start()` 方法之前设置。**

```python
import multiprocessing
import time

def worker():
    for i in range(5):
        print(f"守护子进程工作中... {i}")
        time.sleep(1)

if __name__ == '__main__':
    p = multiprocessing.Process(target=worker)
    p.daemon = True  # 设置为守护进程
    p.start()
    print("主进程即将结束...")
    time.sleep(2) # 主进程等待2秒后结束
    print("主进程结束！")
```

**输出结果：**

主进程打印“主进程结束！”后，整个程序退出，守护子进程被强制终止，不会继续打印剩余的内容。

#### 主动终止子进程

也可以在主进程结束前，通过调用子进程对象的 `terminate()` 方法来主动、强制地结束它。

```python
import multiprocessing
import time

def worker():
    while True:
        print("子进程持续运行中...")
        time.sleep(1)

if __name__ == '__main__':
    p = multiprocessing.Process(target=worker)
    p.start()
    time.sleep(3)
    p.terminate() # 主动终止子进程
    p.join()      # 等待子进程资源被回收
    print("主进程结束！")
```

不使用`join`，子进程会变成僵尸进程，占用系统资源。

#### 总结

| 子进程类型          | 主进程结束时的行为               | 设置方法                              |
| ------------------- | -------------------------------- | ------------------------------------- |
| **普通进程 (默认)** | 主进程会**等待**子进程结束       | `p = Process(target=func)`            |
| **守护进程**        | 子进程被**强制终止**             | `p.daemon = True` （在 `start()` 前） |
| **主动终止**        | 主进程通过代码**强制结束**子进程 | `p.terminate()`                       |

# 线程

## 概念

进程是分配资源的基本单位，一旦创建一个进程就会分配一定的资源。

线程是CPU调度的基本单位，每个进程至少都有一个线程，而这个线程就是我们通常说的主线程。

## 创建

```python
# 导包
import threading

# 定义函数1
def coding():
    for i in range(1, 11):
        print(f'正在敲第{i}遍代码...')

# 定义函数2
def music():
    for i in range(1, 11):
        print(f'正在听第{i}遍音乐...')

if __name__ == '__main__':
    # 关联函数
    t1 = threading.Thread(target=coding)
    t2 = threading.Thread(target=music)

    # 启动线程
    t1.start()
    t2.start()
    
"""
正在敲第1遍代码...
正在敲第2遍代码...
正在听第1遍音乐...
正在敲第3遍代码...
正在听第2遍音乐...
正在敲第4遍代码...
正在敲第5遍代码...
正在听第3遍音乐...
正在敲第6遍代码...
正在敲第7遍代码...
正在敲第8遍代码...
正在听第4遍音乐...
正在敲第9遍代码...
正在敲第10遍代码...
正在听第5遍音乐...
正在听第6遍音乐...
正在听第7遍音乐...
正在听第8遍音乐...
正在听第9遍音乐...
正在听第10遍音乐...
"""
```



## 特点

1. 多线程执行任务具有随机性。
2. 默认情况下，主线程会等所有子线程执行完再结束。
3. 线程之间资源共享。
4. 多线程共享全局变量，容易出现问题。

```python
# 导包
import threading

# 定义全局变量
num = 0
# 定义函数1
def coding():
    global num
    for i in range(1000000):
        num += 1
    print(f'代码函数：{num}')

# 定义函数2
def music():
    global num
    for i in range(1000000):
        num += 1
    print(f'音乐函数：{num}')

if __name__ == '__main__':
    # 关联函数
    t1 = threading.Thread(target=coding)
    t2 = threading.Thread(target=music)

    # 启动线程
    t1.start()
    t2.start()
    
"""
代码函数：1642837
音乐函数：2000000
"""
```

原因：线程1还没执行完，资源就被抢走了。

> 比如，`code`函数抢到了资源，还没有加，此时`music`就抢了过去。此时，两个函数都对0操作。每个函数加一次，总共加了两次，但返回的值都是一。

解决：使用**互斥锁**。

## 互斥锁

1. 作用

   对共享数据进行锁定，保证同一时间只有一个线程去操作。

2. 相关函数

   | 函数                       | 函数说明     |
   | -------------------------- | ------------ |
   | `mutex = threading.Lock()` | 互斥锁的创建 |
   | `mutex.acquire()`          | 上锁         |
   | `mutex.release()`          | 释放锁       |

   `threading.Lock`是一个类。

3. 死锁

   - 概念

     一直等待对方释放锁的情景就是死锁。

   - 原因
     
     未在合适的地方释放锁。
     
   - 结果
     
     会造成应用程序的停止响应，应用程序无法再继续往下执行。

```python
# 导包
import threading

# 定义全局变量
num = 0

# 创建锁
mutex = threading.Lock()
# 定义函数1
def coding():
    # 上锁
    mutex.acquire() # 也可以使用with mutex:
    global num
    for i in range(1000000):
        num += 1
    print(f'代码函数：{num}')
    # 解锁
    mutex.release()

# 定义函数2
def music():
    # 上锁
    mutex.acquire()
    global num
    for i in range(1000000):
        num += 1
    print(f'音乐函数：{num}')
    # 解锁
    mutex.release()

if __name__ == '__main__':
    # 关联函数
    t1 = threading.Thread(target=coding)
    t2 = threading.Thread(target=music)

    # 启动线程
    t1.start()
    t2.start()
    
"""
代码函数：1000000
音乐函数：2000000
"""
```

锁必须要相同，这样才能避免访问。

## 进程与线程的对比

1. 关系

   线程依赖进程，没有进程就没有线程。

   一个进程可以创建多个线程，默认提供一个线程。

2. 区别

   1. 进程之间不共享全局变量。

   2. 线程之间共享全局变量，但是要注意资源竞争的问题，解决办法：互斥锁。

   3. 创建进程的资源开销要比创建线程的**资源开销要大**。

   4. 进程是操作系统资源分配的基本单位，线程是CPU调度的基本单位。

   5. 线程不能够独立执行，必须依存在进程中。

   6. Python中多进程开发比单进程多线程开发**稳定性要强**。

      > 比如三个功能三个软件和一个软件三个功能。

3. 进程优缺点：

   - 优点：可以用多核。

   - 缺点：资源开销大。

4. 线程优缺点：

   - 优点：资源开销小。

   - 缺点：不能使用多核。
