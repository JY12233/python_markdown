# 面向对象基础

## 编程思想

就是人们利用计算机来解决问题的思维。

分类：

1. 面向过程

   一种编程思想，强调以步骤（过程）为基础完成各种操作。

2. 面向对象

   一种编程思想，强调以对象为基础完成各种操作，基于面向过程。

   特点：

   >1. 更符合人们的思考习惯。
   >2. 把复杂的事情简单化。
   >3. 把程序员从执行者变成指挥者。

## 三大特性

| 特性 | 描述                                                         |
| ---- | ------------------------------------------------------------ |
| 封装 | 把属性和方法封装在一起，仅提供对外的方法让别人去访问。好处：简化编程。 |
| 继承 | 子类可使用父类的东西。好处：代码复用。                       |
| 多态 | 同样一个函数（消息）在不同场景下表现出不同形态。好处：解耦合，可拓展。 |

封装：

>在面向对象中，封装就是隐藏对象的属性和实现细节，仅对外公开接口，控制在程序中属性的读和修改的访问级别，将抽象得到的数据和行为（或功能）相结合，形成一个有机的整体，也就是将数据与操作数据的源代码进行有机的结合，形成“类”，其中数据和函数都是类的成员。

>封装的目的是简化编程，增强安全性。
>
>- 使用者不必了解具体的实现细节，而只是要通过外部接口
>- 以特定的访问权限来使用类的成员。

继承：

>继承就是子类继承父类的属性和方法，使得子类对象具有父类的特征和行为。
>
>满足：满足 is a 关系。比如A is a C，B is a C，因此使用C作为父类，A、B作为子类。

多态：

>指不同类的对象对同一消息做出相应，即同一消息可根据发送对象的不同而采用多种不同的行为方式。比如键盘同一个键在不同的软件中有不同的功能。

- 介绍


  > 1个类有多个对象，这些对象都可以通过`对象名.`的方式访问类中的方法。函数默认有self属性，通过self来区分到底是哪个对象调用的函数。

- 类内调用函数

  > 在函数中使用`self.函数名`。

### 属性

- 介绍

  > 表示固有特征，在python中使用变量表示。

- 设置

  - 类外

    > 只有python能在类外设置新的属性。

  - 类内

    通过魔法方法`__init__`

- 获取

  - 类外

    ```python

    ```

  - 类内

    ```python

    ```

   删除对象时调用。当.py文件执行结束或者手动释放对象资源时，会自动调用该函数。

# 面向对象高阶

## Python中的继承

###  描述

类是用来描述现实世界中同一组事务的共有特性的抽象模型，但是类也有上下级和范围之分。

面向对象代码中的“继承”：指子类继承父类的属性和方法。

###  格式

```python
class Father:
    ...
    
class Son(Father):
    ...

```

### 作用

继承：

> 一个类从另一个已有的类获得其成员的相关特性，就叫作继承（站在子类角度）。

派生：

> 从一个已有的类产生一个新的类，称为派生（站在父类角度）。

子类默认拥有父类的属性和行为，耦合性增强。

###  分类

- 单继承

  > 一个类只有一个父类。

- 多继承

  1. 定义

     >多继承就是一个类同时继承了多个父类，并且同时具有所有父类的属性和方法。

  2. 格式

     ```python
     class Son(Father1, Father2, ...):
         ...
     ```

  3. 调用顺序

     > 默认使用第一个父类的属性和方法。就近原则，从左到右。

     当一个类有多个父类时，默认使用第一个父类的同名属性和方法，可以使用`类名.__mro__`属性或`类名.mro()`方法查看调用的先后顺序。

     注：MRO(Method Resolution Order)：方法解析顺序。

     ```python
     class Father1:
         pass
     
     class Father2:
         pass
     
     class Son(Father1, Father2):
         pass
     
     print(Son.mro()) # 输出Son, Father1, Father2, object
     # print(Son.__mro__)
     ```

     当调用时没有父类中找到，会报错。

- 多层继承

  >类A继承类B，类B继承类C。

###  重写

- 概念

  > 子类重写父类同名方法和属性。

  重写也叫作覆盖，就是当子类属性或方法与父类的属性或方法名字相同时，从父类继承下来的成员可以被重新定义。

- 作用

  > 子类重写父类的属性和方法，优先会调用子类的属性和方法。

### 子类调用父类方法

- 方式

  ```python
  class Father1:
      def run():
          pass
  
  class Father2:
      def run():
          pass
  
  class Son(Father1, Father2):
      # 第一种：父类.父类方法名(self)
      # 精准访问
      def son_run(self):
          Father1.run(self)
  
      # 第二种（适合单继承使用）
      # 查找最近的父类，有就用，没有往后继续查找，都没找到就报错
      def son_run_fast(self):
          super().run()
  ```

- 练习一

  ```python
  # 老师
  class Master:
      def __init__(self):
          self.skill = ['古法煎饼']
  
      def make_cake(self):
          print(f'{self.skill}')
  
  # 学校
  class School:
      def __init__(self) -> None:
          self.skill = ['学校煎饼']
  
      def make_cake(self):
          print(f'{self.skill}')
  
  # 学徒
  class Student(School, Master):
      def __init__(self) -> None:
          self.skill = ['独创煎饼']
  
      def make_cake(self):
          print(f'{self.skill}')
  
      def make_master_cake(self):
          Master.make_cake(self)
  
  xm = Student()
  xm.make_cake()
  xm.make_master_cake() # self指代的是xm，也就是Student的对象，因此输出['独创煎饼']
  ```

- 练习二

  ```python
  # 老师
  class Master:
      def __init__(self):
          self.skill = ['古法煎饼']
  
      def make_cake(self):
          print(f'{self.skill}')
  
  # 学校
  class School:
      def __init__(self) -> None:
          self.skill = ['学校煎饼']
  
      def make_cake(self):
          print(f'{self.skill}')
  
  # 学徒
  class Student(School, Master):
      def __init__(self) -> None:
          self.skill = ['独创煎饼']
  
      def make_cake(self):
          print(f'{self.skill}')
  
      def make_master_cake(self):
          Master.__init__(self) # 借用 Master 的初始化方法来重置当前对象的属性
          Master.make_cake(self)
  
  xm = Student()
  xm.make_cake()
  xm.make_master_cake() # 输出['古法煎饼']
  xm.make_cake() # 输出['古法煎饼']
  '''
  原因：
      self指代的是当前的实例对象，在Master.__init__(self)中传入的是Student的self，
      即改变了当前实例对象也就是xm的skill属性。
      因此，xm.make_cake()输出['古法煎饼']
  '''
  ```

## Python中的封装

### 定义

>在软件编程中，将属性和方法书写到类的里面的操作即为封装，封装可以为属性和方法添加私有权限。隐藏对象的属性和实现细节，仅对外提供公共的访问方式。

### 私有属性和私有方法

>在Python中，可以为属性和方法设置私有权限，即设置某个属性或方法不继承给子类。
>设置私有属性和方法的方式：在属性或方法名前面加上__。

```python
class Bank:
    def __init__(self):
        self.__password = 1235
        
    def __check(self):
        print(self.__password)
```

私有属性和方法只能在**类的内部**使用，不能在类的外部使用；如果想在类的外部使用通过**公共接口**。

- 好处：

  1. 提高代码的安全性。

  2. 提高代码的复用性。

- 坏处：

  - 增加了代码量，因为私有内容外界想访问必须提供公共的访问方式。

- 访问：

  - 需要父类中提供公共的访问方式。

    ```python
    class Bank:
        def __init__(self):
            self.__password = 1235
            
        def check_password(self):
            return self.__password
            
        def set_password(self, password):
            self.__password = password
            
    ```

>**单下划线、双下划线、头尾双下划线说明**
>
>- `__foo__`
>
>  定义的是特殊方法，一般是系统定义名字 ，类似 **__init__()** 之类的。
>
>- `_foo`
>
>  以单下划线开头的表示的是 protected 类型的变量，即保护类型只能允许其本身与子类进行访问，不能用于 `from module import *`
>
>- `__foo`
>
>  双下划线的表示的是私有类型(private)的变量, 只能是允许这个类本身进行访问了。

## Python中的多态

###  概念

>多态，多种状态。比如，同样一个函数在不同的场景下有不同的状态。

### 条件

>1. 有继承：定义父类、定义子类，子类继承父类（针对Java等语言）。
>2. 函数重写：子类重写父类的函数，不然多态无意义。
>3. 父类引用指向子类对象：子类对象传给父类对象调用者，父类引用指向子类对象。

```python
class Animal: # 抽象类，因为含有抽象方法，也叫接口
    def speak(self): # 抽象方法，相当于给其子类定义了一种标准，具体实现由子类完成
        pass

class Dog(Animal):
    def speak(self):
        print("汪汪汪")

class Cat(Animal):
    def speak(self):
        print("喵喵喵")

# 定义函数，接收不同的动物对象，调用speak方法
def make_noise(animal: Animal): 
    animal.speak()

dog = Dog() # dog是父类的Animal的引用
cat = Cat()

# 多态
make_noise(dog)  # 输出：汪汪汪
make_noise(cat)  # 输出：喵喵喵
```

### 作用

在不改变代码框架的情况下，实现模块与模块之间的解耦合，实现了软件系统的可拓展。

在python中，多态无法精确指定类型。

## 特性

### 属性

用于描述事物的外在特征。

- 类属性

  - 概念

    > 指类所拥有的属性，被共享于整个类中，可以被直接调用。

  - 定义格式

    > 定义到类中、函数外（与定义变量的格式相同），可通过类名.属性名或者对象.属性名调用。

  - 修改

    > 通过`类名.属性名 = ...`修改。

- 对象属性

  - 概念

    > 属于对象，每个对象的属性值都有可能不同，修改一个对象的属性不影响另一个对象。

  - 定义格式

    > 定义到`__init__`魔法方法中的属性，每个对象都有自己的内容。

### 类方法

- 概念

  >所谓类方法，指的是类所拥有的方法，并需要使用装饰器`@classmethod`来标识其为类方法，同时一定要注意的是对于类方法的第一个参数必须是类对象，通常以cls作为第一个参数名。

- 格式

  ```python
  class Student:
      @classmethod
      def 方法名(cls): # cls表示类对象，只是一个普通参数，可以换成a、b等
          pass
  ```

- 调用

  > 可以使用类名.方法名或者对象.方法名

### 静态方法

- 概念

  >静态方法需要通过装饰器 `@staticmethod` 来标识其为静态方法，且静态方法不需要多定义参数。

  没有使用self或者cls的时候就可以使用静态方法。

- 定义格式

  ```python
  class Game(object):
      @staticmethod
      def show_menu():
          print("="*20)
          print("【1】开始游戏;")
          print("【2】暂停;")
          print("【0】结束.")
  
  Game.show_menu() # 类名直接访问
  game = Game()
  game.show_menu() # 对象名访问
  ```

- 调用

  > `类名.静态方法名` 或者 `对象名.静态方法名` 

### 抽象方法

- 概念

  > 所谓抽象方法，指的是在父类中**只声明但不提供具体实现**的方法，需要使用装饰器 `@abstractmethod` 来标识。包含抽象方法的类被称为**抽象类**，抽象类必须从 `abc` 模块中的 `ABC` 类继承。子类必须强制重写（实现）父类中的所有抽象方法，否则该子类无法被实例化。

  抽象类是一种特殊的类，只能作为父类存在，不能对象化。

- 格式

  ```python
  from abc import ABC, abstractmethod
  # Abstract Base Classes
  
  class Animal(ABC):      # 必须继承 ABC 才能成为抽象类，或者导入 ABCMeta 也行
      @abstractmethod
      def speak(self):    # 只声明不实现，通常只写 pass
          pass
  ```

- 调用

  > 抽象方法不能直接通过抽象类调用，必须通过继承了该抽象类并实现了所有抽象方法的子类对象来调用。

# super 介绍

在 Python 中，`super()` 是一个内置函数，它返回一个代理对象（Proxy Object），该对象可以将方法或属性的调用委托给父类或同级类。这在处理单继承和多继承（尤其是菱形继承）时非常有用，能够避免硬编码父类名称，并遵循方法解析顺序（MRO）。

## 创建对象时的格式

```python
super_obj = super(
    type,               # 可选：指定从 MRO（方法解析顺序）中哪个类之后开始查找
    object_or_type      # 可选：指定一个对象或类，用于确定要使用的 MRO 查找序列
)
```

> 在 Python 3 中，如果在类的实例方法或类方法内部使用 `super()` 且不传任何参数，Python 解释器会自动根据当前栈帧填充这两个参数（等价于 `super(当前类, self)` 或 `super(当前类, cls)`）。

## 参数详解

| 参数名称         | 作用说明                                                     | 常见可选值或示例                        |
| ---------------- | ------------------------------------------------------------ | --------------------------------------- |
| `type`           | 指定在 MRO 列表中从哪个类**之后**开始检索方法或属性。如果不提供，返回的 `super` 对象是未绑定的（Unbound）。 | `CurrentClass`（当前类名）              |
| `object_or_type` | 提供 MRO 查找序列。如果是实例对象，必须是 `type` 的实例；如果是类，必须是 `type` 的子类。 | `self`（当前实例）<br />`cls`（当前类） |

## 常用属性

| 属性名称         | 作用说明                                                     |
| ---------------- | ------------------------------------------------------------ |
| `__thisclass__`  | 返回 `super()` 调用时传入的第一个参数（即 `type`），表示当前正在为其寻找父类的类。 |
| `__self__`       | 返回 `super()` 调用时传入的第二个参数（即 `object_or_type`），表示绑定的实例或类。 |
| `__self_class__` | 返回 `__self__` 所属的类。如果 `__self__` 本身是一个类，则返回该类自身。 |

## 常用方法

`super()` 返回的代理对象本身没有自己专属的业务方法，它主要是作为桥梁，动态调用 MRO 链中下一个类的方法或属性。

| 方法 / 调用方式                   | 作用说明                                                     |
| --------------------------------- | ------------------------------------------------------------ |
| `super().__init__(...)`           | 调用父类（或 MRO 中的下一个类）的构造函数，常用于子类初始化时继承父类的属性。 |
| `super().method_name(...)`        | 调用父类中被重写（Override）的普通实例方法，在扩展功能的同时保留原有逻辑。 |
| `super(ClassName, self).method()` | 显式指定从 `ClassName` 之后开始查找方法。<br />常用于多继承中跳过某个特定的父类，直接调用更上层的类或兄弟类的方法。 |
| `super().class_method(...)`       | 在 `@classmethod` 中使用，调用父类的类方法，此时 `cls` 会自动传递。 |

## 代码示例

```python
class grandPa:
    def speak(self):
        print("爷爷说话了。")


class Father:
    def speak(self):
        print("父亲说话了。")


class Son(Father, grandPa):
    def speak(self):
        print("儿子说话了。")

    def speakGrandPa(self):
        # 是从 Father 之后开始找，不是从 Father 开始找
        super(Father, self).speak()

    def speakFather(self):
        # 相当于 super(Son, self)
        super().speak()

s = Son()
s.speak()
s.speakFather()
s.speakGrandPa()

"""
儿子说话了。
父亲说话了。
爷爷说话了
"""
```

# 属性限制

`__slots__` 是一个特殊的类变量（属性）。它主要用于显式声明类的数据成员，强制 Python 使用固定大小的内存结构来存储属性，从而替代默认的字典存储机制。

## 背景介绍

在默认情况下，Python 在创建类的新实例时，会为其创建一个 `__dict__` 属性和一个 `__weakref__` 属性。`__dict__` 是一个字典，用于动态存储实例的所有属性和值。这种机制虽然灵活，但会带来以下问题：

- 内存开销大

  每个实例都要维护一个字典，当创建大量对象时，内存占用非常可观。

- 访问速度较慢

  通过字典查找（哈希表）属性比直接访问内存要慢。

- 容易出错

  如果拼错了属性名，Python 不会报错，而是默默地在 __`dict`__ 中创建一个新变量，导致难以察觉的 Bug。

## `__slots__` 的作用

在类中定义了 `__slots__` 后：

- 节省内存

  Python 会为声明的属性分配固定的内存空间，不再创建 `__dict__` 和 `__weakref__`。

- 提升速度

  属性访问变成了直接的内存访问，速度比字典查找更快。

- 属性限制与防错

  只能赋值在 `__slots__` 中声明过的属性。如果尝试赋值未声明的属性（例如拼写错误），Python 会直接抛出 `AttributeError`，增强了代码的安全性。

## 语法格式

```python
class ClassName:
    __slots__ = ('attr1', 'attr2')  # 声明允许实例拥有的属性名称序列（通常使用元组或列表），禁止实例拥有未声明的属性
```

## 语法成分详解

| 语法成分           | 作用说明                                                     | 数据类型要求及可选写法                                       |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `__slots__`        | 显式声明类实例允许绑定的属性，阻止 `__dict__` 和 `__weakref__` 的创建，从而节省内存并提升属性访问速度。 | 序列类型（元组、列表）、可迭代对象或字符串（表示仅允许一个属性）。 |
| `'attr1', 'attr2'` | 具体的属性名称字符串。                                       | 字符串。<br />若需支持弱引用，需显式加入 `'__weakref__'`；<br />若需保留部分动态性，需显式加入 `'__dict__'`。 |

## 常见配套语法

| 配套语法 / 场景      | 行为影响                                                     |
| -------------------- | ------------------------------------------------------------ |
| 子类继承 `__slots__` | 子类必须显式定义自己的 `__slots__` 才能继承优化效果；<br />若子类未定义，则会恢复生成 `__dict__`，失去内存优化意义。 |
| 多重继承             | 当多个父类均定义了 `__slots__` 时，子类需显式声明 `__slots__` 以合并父类的槽位；<br />若多个父类具有非空 `__slots__` 且布局冲突，可能引发 `TypeError`。 |
| 动态赋值未声明属性   | 尝试为未在 `__slots__` 中声明的属性赋值（包括拼写错误），<br />将直接抛出 `AttributeError` 异常。 |
| 访问 `__dict__`      | 定义了 `__slots__` 的实例默认不再拥有 `__dict__` 属性，<br />直接访问会抛出 `AttributeError`。 |

## 代码示例

```python
class Person:
    # 限制实例只能拥有 name 和 age 两个属性
    __slots__ = ('name', 'age')

    def __init__(self, name, age):
        self.name = name
        self.age = age

p = Person('张三', 20)
print(p.name)          # 正常访问，输出: 张三

# p.salary = 5000      # 抛出 AttributeError，因为 salary 未在 __slots__ 中声明
```

# `Self` 介绍

## 本质

`typing.Self` 是 Python 3.11 引入的特殊类型提示，用于表示"当前类本身"。它不是一个可以被实例化的类，而是一个类型标记，在静态分析阶段被类型检查器（如 mypy、pyright、Pylance）识别和解释。

它没有构造函数，也不存在“创建对象”的格式。它被用作类型注解，告诉类型检查器（如 mypy, pyright）或 IDE，某个函数或方法的返回值类型就是其所在的类。

>**核心用途**
>
>在方法中返回 `cls` 或 `self` 时，精确表达返回类型就是"调用它的那个类"，尤其在继承和方法链式调用中非常关键。

`Self` 本身不接受任何参数，也没有属性或方法，它就是一个完整的类型标记。

## 使用场景

**场景一：工厂方法返回当前类**

```python
from typing import Self

class Animal:
    @classmethod
    def create(cls, name: str) -> Self:
        return cls(name)

class Dog(Animal):
    pass

# 类型检查器能正确推断：
# Animal.create("xx") 返回 Animal
# Dog.create("xx") 返回 Dog（而非 Animal）
```

如果将返回类型写成 `Animal`，那么 `Dog.create("xx")` 的类型检查器会认为返回的是 `Animal`，丢失了子类信息。使用 `Self` 则能精确表达"返回调用它的那个类"。

**场景二：链式调用**

```python
from typing import Self

class Builder:
    def set_name(self, name: str) -> Self:
        self.name = name
        return self

    def set_age(self, age: int) -> Self:
        self.age = age
        return self

# 类型检查器能正确推断链式调用的返回类型
builder = Builder().set_name("test").set_age(10)
```

## 悬停提示中的类型符号解读

VS Code 的类型检查器（Pylance）在悬停提示中使用了一套可视化符号来精确表达变量的类型身份。

### `Self@Meta`

带作用域标记的 Self。

- `Self`

  代表"当前类"。

- `@Meta`

  作用域标记（或命名空间标记），指明这个 `Self` 具体指的是哪个类的定义内部。

特指在 `Meta` 这个类定义内部的 `Self`。当存在复杂的继承体系或多个类同时使用 `Self` 时，类型检查器通过这个"地址"来精确区分，避免混淆。

### `type[Self@Meta]`

类对象本身的类型。

- `type[...]`

  在类型提示中，`type[X]` 表示"X 这个类的类型"，即元类层面的类型。

- `Self@Meta`

  特指 `Meta` 这个类。

`Meta` 这个类对象的类型。在元类的 `__new__` 方法中，参数 `cls` 的悬停提示通常就是 `type[Self@Meta]`，因为 `__new__` 是类方法，`cls` 接收到的就是 `Meta` 类本身。

```python
class Meta(type):
    def __new__(cls, name, bases, namespace):
        # cls 的类型提示为 type[Self@Meta]
        # 表示 cls 就是 Meta 这个类对象
        return super().__new__(cls, name, bases, namespace)
```

### `Meta*`

星号标记表示实例。

- `Meta`

  类名。

- `*`

  特殊标记，表示"这个类的实例"。

`Meta` 类的一个实例。星号 `*` 主要用于处理继承场景下的返回值类型推断——当方法定义在父类中，但在子类实例上被调用时，类型检查器通过 `*` 标记推断出返回值是子类的实例，而非父类的实例。

## 符号体系对照

| 类型提示          | 含义                            | 出现场景                                     |
| ----------------- | ------------------------------- | -------------------------------------------- |
| `Self@Meta`       | 特指 `Meta` 这个类本身          | 类内部的方法返回类型                         |
| `type[Self@Meta]` | `Meta` 类对象的类型（元类层面） | 元类的 `__new__`、`__init__` 中的 `cls` 参数 |
| `Meta*`           | `Meta` 类的一个实例             | 方法的返回值类型                             |

## 元类中 `self` 与 `cls` 的身份辨析

在元类的不同方法中，`self` 和 `cls` 的身份完全不同，这是理解上述类型注解的关键前提。

| 方法            | 第一个参数 | 实际指向                   | 类型提示          |
| --------------- | ---------- | -------------------------- | ----------------- |
| `Meta.__new__`  | `cls`      | `Meta` 类本身              | `type[Self@Meta]` |
| `Meta.__init__` | `cls`      | `Meta` 类本身              | `type[Self@Meta]` |
| `Meta.__call__` | `self`     | 被元类管理的类（如 `Dog`） | `Self@Meta`       |

在 `__new__` 和 `__init__` 中，操作的对象是"类"本身，因此第一个参数是类对象，类型为 `type[Self@Meta]`。

在 `__call__` 中，当执行 `d = Dog()` 时，`Dog` 类被调用，触发 `Meta.__call__`。此时 `self` 指向的是 `Dog` 这个类对象（即 `Meta` 的实例），因此类型为 `Self@Meta`。

## 核心要点总结

- `Self` 是类型提示，不是可实例化的类，不接受参数，没有属性和方法。
- `Self` 的核心价值在于精确表达"返回调用它的那个类"，解决继承中的类型丢失问题。
- `@类名` 是作用域标记，用于在复杂继承体系中精确定位 `Self` 所指的具体类。
- `type[X]` 表示"X 这个类的类型"，用于描述类对象本身。
- `类名*` 中的星号表示"该类的实例"，用于返回值类型的继承推断。
- 元类中 `__new__`/`__init__` 的 `cls` 和 `__call__` 的 `self` 指向不同的对象，类型注解也因此不同。

# 对象的分类

在 Python 中，**没有**像 Java 或 C++ 那样严格意义上的“基本数据类型（Primitive Types）”和“引用数据类型（Reference Types）”的区分。

Python 的核心设计哲学是**“一切皆对象（Everything is an object）”**。这意味着，无论是整数、字符串，还是列表、字典、自定义类，它们在内存中都是对象，变量本质上都是指向这些对象的“引用（指针）”。

不过，虽然 Python 没有语法层面的类型划分，但在**底层行为和内存模型**上，它确实将对象分为了两类：不可变对象（Immutable）和可变对象（Mutable）。这对应了其他语言中基本类型和引用类型的行为差异。

## 不可变对象

类似其他语言的基本数据类型。

这类对象一旦创建，其值就不能被修改。如果尝试修改，Python 实际上是在内存中创建了一个新对象，并让变量指向新对象。

- 包含的类型

  `int`、`float`、`bool`、`str`、`tuple`（元组）、`frozenset`。

- 行为特征

  - 赋值：创建新对象或指向已有对象。
  - 传参：传递的是对象引用的副本（类似值传递的效果）。在函数内部修改不会影响外部原变量。

- 示例

  ```python
  a = 10
  b = a
  b += 1  # b 指向了新的内存地址，a 依然是 10
  print(a)  # 10
  ```

## 可变对象

类似其他语言的引用数据类型。

这类对象在创建后，其内部状态（值）可以被原地修改，而内存地址保持不变。

- 包含的类型

  `list`、`dict`、`set`、自定义类实例。

- 行为特征

  - 赋值：仅仅是增加了一个指向同一内存地址的引用（别名）。
  - 传参：传递的是对象引用的副本（类似引用传递的效果）。在函数内部修改其内容，会直接影响外部原对象。

- 示例

  ```python
  list_a = [1, 2, 3]
  list_b = list_a
  list_b.append(4)  # 原地修改，list_a 和 list_b 指向同一块内存
  print(list_a)  # [1, 2, 3, 4]
  ```

## 传对象引用

Pass by Object Reference。

在其他语言中，基本类型传值，引用类型传址。但在 Python 中，**所有的函数传参都是统一的机制：传对象引用**。

- 当传递一个**不可变对象**时，虽然传的是引用，但因为对象不能被原地修改，表现出来的效果就像“值传递”。
- 当传递一个**可变对象**时，传的是引用，且对象可以被原地修改，表现出来的效果就像“引用传递”。

## 总结

- 概念上

  Python 没有基本类型和引用类型的区分，**全都是对象（引用）**。

- 行为上

  Python 用**“可变性（Mutability）”**代替了类型划分。不可变对象（如数字、字符串）对应基本类型的行为，可变对象（如列表、字典）对应引用类型的行为。
