# 介绍

`uvicorn` 是一个基于 Python 的高性能异步服务器网关接口（ASGI）服务器，专为运行 FastAPI、Starlette 等异步 Web 框架而设计；在编写完 Web 应用代码后，需要通过 `uvicorn` 来启动服务、监听网络端口并处理客户端请求，通常在开发调试或生产部署阶段使用。

# 核心作用

1. 监听网络请求

   绑定指定的 IP 地址和端口，持续接收来自浏览器或客户端工具的 HTTP 和 WebSocket 请求。

2. 协议解析与转换

   将原始的 HTTP 协议数据解析并封装为符合 ASGI 规范的数据格式，传递给 Web 框架进行业务处理。

3. 响应封装与返回

   接收框架处理后的响应数据，将其封装为标准的 HTTP 响应格式，通过网络返回给客户端。

4. 支撑异步特性

   底层基于 `asyncio` 事件循环，并可选使用 `uvloop` 和 `httptools` 进行性能优化，高效处理高并发和长连接场景。

5. 开发环境热重载

   在开发模式下监听文件变化，当代码修改时自动重启服务器，提升调试效率。

6. 生产环境多进程支持

   支持启动多个工作进程，充分利用多核 CPU 提升并发处理能力。

# 内部模块与类

1. `uvicorn.Config`

   配置类，用于集中管理服务器的所有启动参数（如主机、端口、日志级别等）。

2. `uvicorn.Server`

   服务器核心类，负责管理服务器的完整生命周期（启动、运行、关闭）及 Socket 连接。

3. `uvicorn.run()`

   核心编程接口函数，用于在 Python 代码中动态启动 Uvicorn 服务器。

4. `uvicorn.workers.UvicornWorker`

   工作进程类，用于与 Gunicorn 进程管理器配合，在生产环境中实现多进程部署。

5. `uvicorn.middleware`

   中间件模块，包含代理头处理、调试信息等内置中间件。

6. `uvicorn.protocols`

   协议处理模块，包含 HTTP/1.1 和 WebSocket 协议的底层实现。

7. `uvicorn.loops`

   事件循环模块，包含 `asyncio` 和高性能 `uvloop` 的实现。

# 常用属性与方法

| 属性/方法名                     | 说明                                                         |
| ------------------------------- | ------------------------------------------------------------ |
| `uvicorn.run()`                 | 在代码中启动服务器的核心函数，支持传入应用实例或字符串导入路径 |
| `uvicorn.Config`                | 服务器配置类，用于封装所有启动参数                           |
| `uvicorn.Server`                | 服务器实例类，提供 `serve()` 方法以异步方式启动服务          |
| `uvicorn.workers.UvicornWorker` | 配合 Gunicorn 使用的异步工作进程类                           |
| `--host`                        | 命令行参数，指定绑定的主机地址（默认 `127.0.0.1`）           |
| `--port`                        | 命令行参数，指定监听的端口号（默认 `8000`）                  |
| `--reload`                      | 命令行参数，开启开发模式热重载（生产环境禁用）               |
| `--workers`                     | 命令行参数，指定工作进程数量（与 `--reload` 互斥）           |
| `--log-level`                   | 命令行参数，设置日志级别（如 `info`，`debug`，`warning`）    |
| `--ssl-keyfile`                 | 命令行参数，指定 SSL 私钥文件路径以启用 HTTPS                |
| `--ssl-certfile`                | 命令行参数，指定 SSL 证书文件路径以启用 HTTPS                |
