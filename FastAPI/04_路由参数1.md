# 路径操作

在 FastAPI 框架中，“路径操作”是一个核心概念，它由“路径操作装饰器”与“路径操作函数”两部分紧密配合组成。其本质是建立“HTTP 请求方法 + URL 路径”与“具体业务处理逻辑”之间的映射关系。当客户端发起请求时，框架会根据路径操作将请求精准分发到对应的处理函数，并自动完成参数解析、数据验证及响应序列化。

## 路径操作装饰器

### 定义与作用

路径操作装饰器（Path Operation Decorator）是紧贴在函数上方的 Python 装饰器（以 `@` 符号开头）。其作用是告诉 FastAPI 框架：紧挨着该装饰器下方的函数，专门负责处理特定 HTTP 方法和特定 URL 路径的请求。

### 核心组成

- HTTP 方法

  如 `get`、`post`、`put`、`delete` 等，代表请求的意图（如读取、创建、更新、删除）。

- URL 路径

  如 `/items/{item_id}`，代表请求的资源地址。

### 使用逻辑

在 `FastAPI` 应用实例上调用对应 HTTP 方法的小写形式，并传入路径字符串。例如 `@app.get("/items/")`。

## 路径操作函数

### 定义与作用

路径操作函数（Path Operation Function）是紧跟在路径操作装饰器下方的普通 Python 函数（可以是同步函数或异步函数）。其作用是作为实际的“工人”，负责执行具体的业务逻辑，包括接收请求数据、处理业务、与数据库交互以及返回响应结果。

### 核心职责

1. 接收请求数据

   通过函数参数自动接收路径参数、查询参数、请求体等数据。

2. 处理业务逻辑

   在函数体内编写核心业务代码。

3. 返回响应

   返回字典、列表或 Pydantic 模型等对象，框架会自动将其序列化为 JSON 格式返回给客户端。

### 使用逻辑

定义一个 Python 函数，函数名可自定义（建议使用具有描述性的命名），函数参数用于接收各类请求数据。

## 路径操作参数

路径操作参数（Path Operation Parameters）是指在路径操作函数中声明的形参。FastAPI 会根据参数的声明方式和类型，自动从 HTTP 请求的不同位置提取数据并注入到函数中。

| 参数声明方式                                    | 数据来源       | 说明                                 |
| ----------------------------------------------- | -------------- | ------------------------------------ |
| 参数名与路径中的 `{变量名}` 一致                | URL 路径       | 自动识别为路径参数                   |
| 单值类型（如 `int`、`str`、`bool`）且不在路径中 | URL 查询字符串 | 自动识别为查询参数                   |
| Pydantic 模型类型                               | HTTP 请求体    | 自动识别为请求体参数，解析 JSON 数据 |

## 完整路径操作示例逻辑

一个标准的路径操作由以下三部分组成：

1. 装饰器

   `@app.get("/items/{item_id}")` —— 声明处理 GET 请求，路径为 `/items/{item_id}`。

2. 函数定义

   `async def read_item(item_id: int, q: str = None):` —— 声明异步函数，接收路径参数 `item_id` 和可选查询参数 `q`。

3. 返回结果

   `return {"item_id": item_id, "q": q}` —— 返回字典，框架自动转换为 JSON 响应。

## 核心优势

1. 代码即文档

   通过 Python 类型提示，框架自动生成符合 OpenAPI 规范的交互式文档。

2. 自动数据校验

   基于类型提示和 Pydantic，自动验证输入数据的类型与格式，无效数据触发 422 错误。

3. 高开发效率

   无需手动解析请求数据，框架自动完成参数提取、转换与注入。

# 路径参数概述

路由的路径参数（Path Parameters）是 Web 框架中用于在 URL 路径内部嵌入动态变量的机制。通过在路由定义中使用特定的占位符（如 `{变量名}`），框架能够自动从请求的 URL 中提取对应位置的值，并将其作为参数传递给处理函数。路径参数是构建 RESTful API 的核心基础，主要用于定位特定的资源或标识符。

## 核心作用

1. 资源定位

   通过唯一的标识符（如用户 ID、商品 ID、文章 ID）来精确定位并获取特定的资源数据。

2. 动态路由匹配

   允许使用同一条路由规则处理无数个具有相同结构但参数值不同的请求，避免了为每个资源单独定义静态路由的冗余。

3. 语义化 URL

   使 URL 结构更加清晰、直观且符合 RESTful 设计规范（例如 `/users/123` 比 `/users?id=123` 更具语义化）。

4. 自动类型校验

   框架会根据处理函数中的类型提示，自动对提取的路径参数进行数据类型转换与校验，无效数据会直接触发错误响应。

## 使用逻辑

路径参数的使用逻辑主要包含“定义”与“提取”两个核心步骤：

1. 定义占位符

   在路由装饰器的路径字符串中，使用花括号 `{}` 包裹变量名来声明路径参数。

2. 声明形参

   在处理函数中，必须声明与花括号内变量名完全相同的形参。

3. 自动注入

   当请求到达时，框架会自动解析 URL，提取对应值并注入到处理函数的形参中。

## 常见应用场景

1. 获取单个资源详情

   例如根据用户 ID 获取用户信息（`GET /users/{user_id}`）。

2. 更新或删除特定资源

   例如根据商品 ID 更新商品数据（`PUT /products/{product_id}`）。

3. 多级资源定位

   支持在路径中定义多个参数，例如获取某用户下的特定订单（`GET /users/{user_id}/orders/{order_id}`）。

## 与查询参数的区别

| 对比维度       | 路径参数                             | 查询参数                                  |
| -------------- | ------------------------------------ | ----------------------------------------- |
| **位置**       | 嵌入在 URL 路径中（如 `/users/123`） | 附加在 URL 问号之后（如 `/users?id=123`） |
| **语义**       | 通常代表资源的唯一标识或层级结构     | 通常代表过滤、排序、分页等可选条件        |
| **必要性**     | 通常是必传的，缺失会导致路由不匹配   | 通常是可选的，具有默认值                  |
| **SEO 友好度** | 较高，URL 结构清晰                   | 相对较低                                  |

## 代码示例

```py
from fastapi import FastAPI

app = FastAPI()

# 1. 定义路径参数：在路径中使用 {item_id} 声明动态变量
# 2. 声明函数形参：函数参数名必须与花括号内的变量名完全一致
# 3. 添加类型提示：声明为 int 类型，框架会自动进行类型转换与校验
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}
```

# 查询参数概述

路由的查询参数（Query Parameters）是附加在 URL 路径末尾、以问号 `?` 开头的键值对参数。在 Web 框架中，查询参数通常用于传递非资源标识类的附加信息，如过滤条件、排序规则、分页信息等。与路径参数不同，查询参数不是 URL 路径的固定组成部分，因此通常是可选的。

## 核心作用

1. 数据过滤与筛选

   允许客户端通过传递不同的参数值来筛选资源，例如按类别、状态或关键词过滤列表数据。

2. 分页控制

   通过传递页码和每页数量等参数，实现对大量数据的分页加载。

3. 排序与配置

   允许客户端指定数据的排序方式（如按时间、价格排序）或调整接口的返回行为。

4. 可选参数传递

   提供灵活的参数传递机制，当参数缺失时，框架可使用预设的默认值，保证接口的健壮性。

## 使用逻辑

查询参数的使用逻辑主要包含“声明”与“提取”两个核心步骤：

1. 声明形参

   在处理函数中声明形参，该形参的名称即为查询参数的键（Key）。

   > 所有没在路由路径中出现的参数就是查询参数。

2. 设置默认值

   为形参设置默认值，使其成为可选参数。若未设置默认值，则该查询参数变为必传参数。

3. 自动解析

   当请求到达时，框架会自动解析 URL 问号后的键值对，并将匹配的值注入到处理函数的对应形参中。

## 常见应用场景

1. 列表筛选

   例如获取商品列表时，传递 `?category=electronics&status=active` 来筛选特定类别和状态的商品。

2. 分页查询

   例如 `?page=1&limit=20`，用于控制返回数据的页码和每页条数。

3. 搜索功能

   例如 `?keyword=fastapi`，用于传递搜索关键词。

4. 排序控制

   例如 `?sort_by=price&order=desc`，用于指定排序字段和排序方向。

## 与路径参数的区别

| 对比维度     | 路径参数                             | 查询参数                                  |
| ------------ | ------------------------------------ | ----------------------------------------- |
| **位置**     | 嵌入在 URL 路径中（如 `/users/123`） | 附加在 URL 问号之后（如 `/users?id=123`） |
| **语义**     | 通常代表资源的唯一标识或层级结构     | 通常代表过滤、排序、分页等可选条件        |
| **必要性**   | 通常是必传的，缺失会导致路由不匹配   | 通常是可选的，具有默认值                  |
| **URL 结构** | 是路由匹配规则的一部分               | 不影响路由匹配，仅作为附加数据            |

## URL 结构示例

一个包含查询参数的完整 URL 结构如下：

`/api/users?role=admin&status=active&page=1`

1. 路径部分

   `/api/users`

2. 查询参数部分

   `role=admin&status=active&page=1`

3. 参数解析

   `role` 的值为 `admin`，`status` 的值为 `active`，`page` 的值为 `1`。

## 代码示例

```py
from fastapi import FastAPI

app = FastAPI()

# 1. 定义查询参数：在函数中声明形参，且该形参不出现在路径字符串中
# 2. 设置默认值：为形参设置默认值（如 None），使其成为可选参数
# 3. 添加类型提示：声明为 str 类型，框架会自动从 URL 问号后的键值对中提取数据
@app.get("/items/")
async def read_items(skip: int = 0, limit: int = 10):
    return {"skip": skip, "limit": limit}
```

# 路径转化器

路径转换器（Path Converters）是 FastAPI（底层基于 Starlette）中用于改变路径参数默认匹配规则与数据类型的特殊语法机制。通过在路径参数中使用 `{参数名:转换器类型}` 的格式，框架能够自动对 URL 中的字符串进行类型转换、格式校验或匹配包含斜杠的完整子路径。

路径转换器的核心价值在于实现更精准的路由匹配与自动化的数据类型处理。

## 核心作用

1. 数据类型自动转换

   将 URL 中的字符串自动转换为 Python 的原生数据类型（如整数、浮点数），避免在函数内部手动进行类型转换。

2. 数据格式校验

   在请求到达处理函数之前，自动校验传入的参数是否符合指定格式（如是否为合法整数、UUID），不符合则直接返回 404 或 422 错误。

3. 匹配复杂路径

   解决普通路径参数无法匹配包含斜杠（`/`）的完整文件路径或子路径的问题。

4. 提升文档准确性

   转换器的类型信息会被自动写入 OpenAPI 规范，使生成的交互式文档能准确展示参数的预期类型。

## 内置路径转换器

FastAPI 提供了多种内置的路径转换器，以下是常用的转换器及其作用：

| 转换器语法      | 作用说明                                              | 匹配示例                      |
| --------------- | ----------------------------------------------------- | ----------------------------- |
| `{param:str}`   | 匹配不包含斜杠的非空字符串（默认行为）                | `/items/foo`                  |
| `{param:int}`   | 匹配正整数（包含 0），并自动转换为 `int` 类型         | `/items/123`                  |
| `{param:float}` | 匹配浮点数，并自动转换为 `float` 类型                 | `/items/1.5`                  |
| `{param:path}`  | 匹配包含斜杠的完整子路径，常用于文件路径              | `/files/static/css/style.css` |
| `{param:uuid}`  | 匹配标准的 UUID 格式字符串，并转换为 `uuid.UUID` 对象 | `/items/3fa85f64-...`         |

## 代码示例

路径转换器直接在路由装饰器的路径字符串中声明。

### `int` 转换器

```python
from fastapi import FastAPI

app = FastAPI()

# 使用 :int 转换器，框架会自动将 "123" 转换为整数 123
# 若访问 /items/foo，会直接返回 404 错误
@app.get("/items/{item_id:int}")
async def read_item(item_id: int):
    return {"item_id": item_id, "type": type(item_id).__name__}
```

### `path` 转换器

针对路径参数是一个路径的情况，比如 `/user/{file}`。

如果 `file_path` 是 `/static/file01.txt`，则拼接的时候是 `/user//static/file01.txt`，这样子无法匹配，会出现 404 错误。

要解决，只需要把它声明为 `path` 就行了：`/user/{file: path}`。

```python
# 使用 :path 转换器，可以匹配包含斜杠的完整路径
# 访问 /files/static/docs/intro.txt 时，file_path 的值为 "static/docs/intro.txt"
@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

## 路径转换器与类型提示的关系

在 FastAPI 的日常开发中，由于 Python 类型提示（Type Hints）的强大功能，`str`、`int`、`float` 等类型转换器通常被更直观的函数参数类型注解所替代（例如直接写 `item_id: int`）。

但是，**`path` 转换器是独一无二的**。因为 Python 没有内置的“路径字符串”类型，所以当需要捕获包含斜杠的完整路径时，必须显式地使用 `{param:path}` 这种语法。

## 自定义路径转换器

除了内置转换器，Starlette 还支持注册自定义的路径转换器，用于匹配特定的正则表达式或进行特殊的类型转换（例如日期时间格式）。这通常通过 `starlette.convertors` 模块中的 `register_url_convertor` 函数来实现。

# Path 函数

## 介绍

`Path` 是 FastAPI 框架中专门用于**路径参数**（Path Parameters）的高级配置与校验函数；该函数通常在需要为路径参数添加额外的元数据（如标题、描述）或施加严格的数值与字符串校验规则（如大小限制、长度限制、正则匹配）时使用，通过将其作为函数参数的默认值或结合 `Annotated` 类型注解，实现对 URL 路径变量的精细化控制与自动化文档生成。

> 路径参数是 URL 的关键组成部分，如果缺少对路径参数值的传递，则不构成完整的 URL 请求。
>
> 任何路径参数值都应该声明为必填项。若将路径参数声明为非必填项，如 `user_id: int = Path(None)`，则这个声明不会起作用，因为它还是一个路径参数。

## 使用格式

```python
from fastapi import Path

path_param = Path(
    default=...,  # 路径参数的默认值（路径参数通常为必填，此处通常使用省略号 ...）
    *,  # 强制后续参数必须使用关键字传参
    alias=None,  # 参数的别名（注意：路径参数通常不支持别名，因为变量名必须与路径一致）
    title=None,  # 参数的标题，用于 OpenAPI 文档展示
    description=None,  # 参数的详细描述，支持 Markdown 语法
    gt=None,  # 大于（Greater Than），仅适用于数值类型
    ge=None,  # 大于等于（Greater Than or Equal），仅适用于数值类型
    lt=None,  # 小于（Less Than），仅适用于数值类型
    le=None,  # 小于等于（Less Than or Equal），仅适用于数值类型
    min_length=None,  # 字符串或列表的最小长度
    max_length=None,  # 字符串或列表的最大长度
    pattern=None,  # 正则表达式匹配模式（Pydantic v2 推荐使用此参数）
    regex=None,  # 正则表达式匹配模式（已废弃，建议使用 pattern）
    strict=False,  # 是否开启严格模式（禁止隐式类型转换）
    multiple_of=None,  # 数值必须是该值的倍数
    allow_inf_nan=None,  # 是否允许无穷大（inf）和非数字（nan）
    max_digits=None,  # 十进制数的最大位数
    decimal_places=None,  # 十进制数的小数点后最大位数
    example=None,  # 参数示例（已废弃，建议使用 examples）
    examples=None,  # 多个参数示例列表或字典
    deprecated=None,  # 标记该参数是否已弃用
    include_in_schema=True,  # 是否将该参数包含在 OpenAPI 文档中
    json_schema_extra=None,  # 额外的 JSON Schema 元数据
    **extra  # 额外的 JSON Schema 字段（已废弃，建议使用 json_schema_extra）
)
```

| `json_schema_extra` | 添加自定义的 JSON Schema 扩展字段                    | 字典，`None`            |

## 常用属性与方法

`Path` 本身是一个配置声明函数，其返回的对象主要作为元数据被 FastAPI 内部解析，通常不直接调用其方法。以下是其核心属性：

| 属性/方法名                 | 说明                         |
| --------------------------- | ---------------------------- |
| `default`                   | 获取当前设置的默认值         |
| `title`                     | 获取当前设置的标题           |
| `description`               | 获取当前设置的描述           |
| `gt` / `ge` / `lt` / `le`   | 获取当前设置的数值范围限制   |
| `min_length` / `max_length` | 获取当前设置的长度限制       |
| `pattern`                   | 获取当前设置的正则表达式模式 |
| `extra`                     | 获取额外的 JSON Schema 字段  |

## 代码使用示例

```python
from fastapi import FastAPI, Path

app = FastAPI()

@app.get("/items/{item_id}")
async def read_item(
    item_id: int = Path(
        ...,  # 表示该路径参数为必填，明确表示 item_id 必须从 URL 中获取。
        title="商品 ID",  # 文档标题
        description="商品的唯一标识符，必须大于 0 且小于等于 1000",  # 文档描述
        gt=0,  # 必须大于 0
        le=1000  # 必须小于等于 1000
    )
):
    return {"item_id": item_id}
```

# Query 函数

`Query` 是 FastAPI 框架中专门用于**查询参数**（Query Parameters）的高级配置与校验函数；该函数通常在需要为查询参数添加额外的元数据（如标题、描述、别名）或施加严格的数值与字符串校验规则（如大小限制、长度限制、正则匹配）时使用，通过将其作为函数参数的默认值或结合 `Annotated` 类型注解，实现对 URL 查询字符串的精细化控制与自动化文档生成。

## 使用时的格式

```python
from fastapi import Query

query_param = Query(
    default=...,  # 查询参数的默认值（若设为 ... 或省略，则表示该参数为必填项）
    *,  # 强制后续参数必须使用关键字传参
    alias=None,  # 参数的别名，用于在 URL 中使用与 Python 变量名不同的键名
    alias_priority=None,  # 别名的优先级，影响是否使用别名生成器
    validation_alias=None,  # 仅用于验证的别名（“白名单”验证步骤）
    serialization_alias=None,  # 仅用于序列化的别名（“黑名单”验证步骤）
    title=None,  # 参数的标题，用于 OpenAPI 文档展示
    description=None,  # 参数的详细描述，支持 Markdown 语法
    gt=None,  # 大于（Greater Than），仅适用于数值类型
    ge=None,  # 大于等于（Greater Than or Equal），仅适用于数值类型
    lt=None,  # 小于（Less Than），仅适用于数值类型
    le=None,  # 小于等于（Less Than or Equal），仅适用于数值类型
    min_length=None,  # 字符串或列表的最小长度
    max_length=None,  # 字符串或列表的最大长度
    pattern=None,  # 正则表达式匹配模式（Pydantic v2 推荐使用此参数）
    regex=None,  # 正则表达式匹配模式（已废弃，建议使用 pattern）
    strict=False,  # 是否开启严格模式（禁止隐式类型转换）
    multiple_of=None,  # 数值必须是该值的倍数
    allow_inf_nan=None,  # 是否允许无穷大（inf）和非数字（nan）
    max_digits=None,  # 十进制数的最大位数
    decimal_places=None,  # 十进制数的小数点后最大位数
    example=None,  # 参数示例（已废弃，建议使用 examples）
    examples=None,  # 多个参数示例列表或字典
    deprecated=None,  # 标记该参数是否已弃用
    include_in_schema=True,  # 是否将该参数包含在 OpenAPI 文档中
    json_schema_extra=None,  # 额外的 JSON Schema 元数据
    **extra  # 额外的 JSON Schema 字段（已废弃，建议使用 json_schema_extra）
)
```

## 代码示例

以下示例展示了如何使用 `Query` 函数为查询参数添加校验规则和文档元数据：

```python
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/items/")
async def read_items(
    q: str = Query(
        default=None,  # 默认值为 None，表示该参数为可选
        title="搜索关键词",  # 文档标题
        description="用于搜索商品的关键词，长度必须在 3 到 50 个字符之间",  # 文档描述
        min_length=3,  # 最小长度为 3
        max_length=50,  # 最大长度为 50
        pattern="^[a-zA-Z0-9]+$"  # 仅允许字母和数字
    ),
    page: int = Query(
        default=1,  # 默认页码为 1
        title="页码",
        ge=1,  # 页码必须大于等于 1
        le=100  # 页码必须小于等于 100
    )
):
    return {"q": q, "page": page}
```

# 布尔参数

如果声明的参数是布尔类型，FastAPI 会对其类型进行转换。但是，有且只有三种东西能转换：

1. `true` 和 `false`，忽略大小写。
2. `0` -> `False`，`1` -> `true`。
3. `off` -> `False`，`off` -> `true`。

其余的任何东西都会报错。

```py
"""
布尔参数，有且只有三种情况：
true / false
1 / 0
on / off
"""

import uvicorn
from fastapi import FastAPI

app = FastAPI(title="布尔类型的参数转换")


@app.get("/")
def root():
    return {"index": "root"}


@app.get("/{is_bool}")
def check(is_bool: bool):
    return {"is_bool": is_bool}


if __name__ == "__main__":
    uvicorn.run(app)

```
