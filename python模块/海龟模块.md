# 1. 导入模块

```python
import turtle
```

# 2. 创建画布和海龟

通常直接使用模块提供的默认海龟对象：

```python
import turtle
t = turtle.Turtle()   # 创建一只名为 t 的海龟
```

# 3. 基本移动命令

- `t.forward(distance)` 或 `t.fd(distance)` – 向前移动指定像素
- `t.backward(distance)` 或 `t.bk(distance)` – 向后移动
- `t.right(angle)` 或 `t.rt(angle)` – 右转角度（度）
- `t.left(angle)` 或 `t.lt(angle)` – 左转角度
- `t.goto(x, y)` – 移动到绝对坐标 (x, y)
- `t.setx(x)` – 仅改变 x 坐标
- `t.sety(y)` – 仅改变 y 坐标
- `t.setheading(angle)` 或 `t.seth(angle)` – 设置朝向（0=右，90=上，180=左，270=下）

# 4. 画笔控制

- `t.penup()` 或 `t.up()` – 抬起笔，移动时不画线
- `t.pendown()` 或 `t.down()` – 落下笔，移动时画线
- `t.pensize(width)` 或 `t.width(width)` – 设置笔的粗细
- `t.pencolor(color)` – 设置笔的颜色（可用颜色名如 `'red'`，或 RGB 元组如 `(0.2,0.5,0.8)`）
- `t.fillcolor(color)` – 设置填充颜色
- `t.begin_fill()` – 开始填充区域
- `t.end_fill()` – 结束填充

# 5. 绘制简单图形示例

```python
import turtle

t = turtle.Turtle()

# 画一个红色的正方形
t.pencolor('red')
t.pensize(3)
for _ in range(4):
    t.forward(100)
    t.left(90)

# 画一个蓝色的填充圆
t.pencolor('blue')
t.fillcolor('lightblue')
t.begin_fill()
t.circle(50)   # 半径50的圆
t.end_fill()

# 移动到新位置画线，不画轨迹
t.penup()
t.goto(-100, -100)
t.pendown()
t.forward(200)

turtle.done()   # 保持窗口打开（手动关闭）
```

# 6. 其他常用命令

- `t.clear()` – 清除所有图形，海龟位置不变
- `t.reset()` – 清除图形，海龟恢复初始位置和状态
- `t.hideturtle()` / `t.showturtle()` – 隐藏/显示海龟图标
- `t.speed(speed)` – 设置速度，1~10（最慢到最快），0 表示无动画
- `turtle.done()` 或 `turtle.mainloop()` – 保持窗口不自动关闭（脚本结束时需要）
