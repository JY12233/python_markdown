# 套接字概念

## 定义

套接字（Socket）是计算机网络中进程间通信的端点抽象，也是操作系统提供的一套独立于协议的网络编程接口（API）。其本质是应用程序与网络协议栈（如 TCP/IP）进行交互的接口，上联应用进程，下联网络协议栈，负责完成两个应用程序之间的数据传输。

## 核心作用

1. 实现双向通信

   作为网络中不同主机上应用进程之间进行双向通信的端点，完成两个应用程序之间的数据传输。

2. 屏蔽底层复杂性

   隐藏底层网络协议（如 TCP/IP）的复杂细节，为开发者提供简洁的 API 函数，使应用程序能方便地访问通信协议。

3. 数据缓冲与传输控制

   将应用程序数据从用户缓冲区复制到内核发送缓冲区以交付发送，或从内核接收缓冲区复制到用户缓冲区以读取数据。

4. 支持多种通信模式

   提供流式套接字（基于 TCP，面向连接、可靠）、数据报套接字（基于 UDP，无连接、不可靠）及原始套接字（读写内核未处理的 IP 数据包）等多种类型，适应不同通信需求。

## 核心组成

要建立套接字连接，必须明确以下关键信息：

1. IP 地址

   定位网络中的目标设备（如 `192.168.1.100`）。

2. 端口号

   定位设备上的目标应用程序或进程（如 `80` 代表 HTTP 服务）。

3. 通信协议

   规定数据传输的规则（如 TCP 面向连接，UDP 无连接）。

## 使用流程

套接字通信遵循客户端-服务器模型，根据传输协议不同分为 TCP 和 UDP 两种流程。

### TCP 通信流程（面向连接）

- **服务端流程**：
  1. 创建套接字：调用 `socket()` 函数创建套接字描述符，指定地址族（如 `AF_INET`）、套接字类型（`SOCK_STREAM`）及协议。
  2. 绑定地址：调用 `bind()` 函数将套接字与本地 IP 地址和端口号绑定。
  3. 监听连接：调用 `listen()` 函数将套接字转为被动监听模式，并设置连接请求队列长度。
  4. 接受连接：调用 `accept()` 函数阻塞等待客户端连接，成功后返回一个新的已连接套接字用于数据交互，原监听套接字继续等待其他连接。
  5. 数据收发：通过新套接字调用 `send()`/`recv()` 函数进行双向数据传输，可循环多次交互。
  6. 关闭连接：通信结束后调用 `close()` 函数关闭套接字，释放资源。
- **客户端流程**：
  1. 创建套接字：调用 `socket()` 函数创建套接字。
  2. 发起连接：调用 `connect()` 函数向服务端指定 IP 和端口发起 TCP 三次握手连接请求。
  3. 数据收发：连接建立后，调用 `send()`/`recv()` 函数与服务端进行数据交换。
  4. 关闭连接：数据传输完毕后调用 `close()` 函数关闭套接字。

### UDP 通信流程（无连接）

- **服务端流程**：
  1. 创建套接字：调用 `socket()` 函数，套接字类型指定为 `SOCK_DGRAM`。
  2. 绑定地址：调用 `bind()` 函数绑定本地 IP 和端口。
  3. 数据收发：直接调用 `recvfrom()`/`sendto()` 函数接收或发送数据报，无需建立连接。
  4. 关闭连接：调用 `close()` 函数关闭套接字。
- **客户端流程**：
  1. 创建套接字：调用 `socket()` 函数创建 `SOCK_DGRAM` 类型套接字。
  2. 数据收发：直接调用 `sendto()`/`recvfrom()` 函数与服务端进行数据交换。
  3. 关闭连接：调用 `close()` 函数关闭套接字。

## 主要类型

| 类型                         | 协议     | 特点                                 | 应用场景                   |
| ---------------------------- | -------- | ------------------------------------ | -------------------------- |
| 流套接字（`SOCK_STREAM`）    | TCP      | 面向连接、可靠传输、字节流、双工通信 | HTTP/HTTPS、文件传输、邮件 |
| 数据报套接字（`SOCK_DGRAM`） | UDP      | 无连接、不可靠、数据报、效率高       | 视频流、语音通话、DNS 查询 |
| 原始套接字（`SOCK_RAW`）     | 原始协议 | 直接访问 IP 层，用于协议开发         | 网络诊断工具、自定义协议   |

# `scoket` 概述

`socket` 是 Python 标准库中用于底层网络编程的核心模块。使用时需通过 `socket.socket()` 函数创建套接字对象，并根据通信需求选择 TCP（`SOCK_STREAM`）或 UDP（`SOCK_DGRAM`）协议，随后调用 `bind()`、`listen()`、`accept()`、`connect()`、`send()`、`recv()` 等方法完成数据的发送与接收，当需要直接控制网络通信底层、实现自定义网络协议或开发网络调试工具时，就可以使用该模块。

## 核心作用

1. 底层网络接口

   提供对 BSD Socket API 的直接访问，支持 TCP、UDP 等多种传输层协议。

2. 跨平台兼容

   作为标准库的一部分，能够在 Windows、Linux、macOS 等操作系统上无缝运行。

3. 自定义协议构建

   提供对网络通信的低级别控制，适合构建定制化的网络协议。

4. 高性能网络应用基础

   可结合 `select` 或 `asyncio` 模块实现高效的 I/O 多路复用，构建高并发网络服务。

## 核心类与常量

1. `socket`

   核心套接字类，用于创建和管理网络连接。

2. 地址族常量

   - `AF_INET`：IPv4 网络协议。
   - `AF_INET6`：IPv6 网络协议。
   - `AF_UNIX`：Unix 域套接字，用于同一台机器上的进程间通信。

3. 套接字类型常量

   - `SOCK_STREAM`：面向连接的 TCP 套接字，提供可靠、有序的字节流传输。
   - `SOCK_DGRAM`：无连接的 UDP 套接字，不保证可靠传输和顺序，但传输速度快。
   - `SOCK_RAW`：原始套接字，可直接读写内核未处理的 IP 数据包。

# `socket` 类

`socket.socket` 是 Python `socket` 模块中的核心类，用于创建网络通信的端点（套接字）。使用时需通过实例化该类并指定地址族、套接字类型及协议来创建套接字对象，随后结合 `bind()`、`listen()`、`connect()`、`send()`、`recv()` 等方法实现数据的发送与接收，当需要开发网络服务器、客户端程序或进行底层网络协议调试时，就可以使用该类。

## 创建对象时的格式

```python
socket.socket(
    family=-1,  # 可选，指定地址族（网络协议类型），默认为 -1（即 AF_INET）
    type=-1,  # 可选，指定套接字类型（传输协议类型），默认为 -1（即 SOCK_STREAM）
    proto=-1  # 可选，指定协议号，默认为 -1（即 0，由系统自动选择）
)
```

## 参数详解

| 参数名称 | 作用说明                                   | 可选值或类型说明                                             | 示例                            |
| -------- | ------------------------------------------ | ------------------------------------------------------------ | ------------------------------- |
| `family` | 指定套接字的地址族，即使用的网络协议类型。 | **整数（常量）**：<br />`socket.AF_INET`（IPv4）、<br />`socket.AF_INET6`（IPv6）、<br />`socket.AF_UNIX`（Unix 域套接字）。 | `socket.AF_INET`                |
| `type`   | 指定套接字的类型，即传输层协议类型。       | **整数（常量）**：<br />`socket.SOCK_STREAM`（TCP）、<br />`socket.SOCK_DGRAM`（UDP）、<br />`socket.SOCK_RAW`（原始套接字）。 | `socket.SOCK_STREAM`            |
| `proto`  | 指定具体的协议号，通常用于原始套接字。     | **整数**：默认为 `0`，<br />表示由系统根据地址族和套接字类型<br />自动选择合适的协议。 | `0`、<br />`socket.IPPROTO_TCP` |

## 常用属性

| 属性名称 | 说明                                   |
| -------- | -------------------------------------- |
| `family` | 返回套接字的地址族（如 `AF_INET`）。   |
| `type`   | 返回套接字的类型（如 `SOCK_STREAM`）。 |
| `proto`  | 返回套接字的协议号。                   |

## 常用方法

| 方法名称                 | 说明                                                         |
| ------------------------ | ------------------------------------------------------------ |
| `bind(address)`          | 将套接字绑定到指定的地址和端口。服务端必须调用此方法。       |
| `listen(backlog=...)`    | 开始监听 TCP 连接。`backlog` 指定等待队列中的最大连接数。    |
| `accept()`               | 接受一个客户端连接。返回一个新的套接字对象和客户端地址。此方法为阻塞式。 |
| `connect(address)`       | 客户端主动连接到指定的服务器地址和端口。                     |
| `send(bytes)`            | 发送数据。返回实际发送的字节数。                             |
| `sendall(bytes)`         | 发送完整数据。会持续发送直到所有数据发出或发生错误。         |
| `recv(bufsize)`          | 接收数据。返回接收到的字节串，最大长度为 `bufsize`。         |
| `sendto(bytes, address)` | UDP 专用方法，向指定地址发送数据。                           |
| `recvfrom(bufsize)`      | UDP 专用方法，接收数据。返回数据和发送方地址。               |
| `close()`                | 关闭套接字，释放相关资源。                                   |
| `settimeout(value)`      | 设置套接字操作的超时时间（秒）。`None` 表示阻塞模式，`0` 表示非阻塞模式。 |
