# 模块作用

`string` 模块是 Python 标准库中专注于字符串处理的基础模块。它的核心功能是提供一系列常用的字符串常量（如字母表、数字集合、标点符号等），以及用于字符串格式化和模板替换的类。

> 在 Python 3 中，许多基础的字符串操作（如大小写转换、查找替换、分割连接等）已经直接集成到了 `str` 类中。因此，`string` 模块目前更多用于提供特定的字符集合常量，或处理高级的字符串模板与格式化需求。

# 包含的类与函数

该模块主要提供了以下核心类和函数：

- **`string.Template`**

  一个基于 `$` 占位符的字符串模板类，适用于简单的字符串替换和格式化。

- **`string.Formatter`**

  一个基于 `{}` 占位符的格式化类，提供了与内置 `str.format()` 方法相同的底层实现，常用于自定义复杂的格式化行为。

- **`string.capwords(s)`**

  一个实用函数，用于将字符串中的每个单词的首字母大写，其余字母小写。

# 常用属性（字符串常量）

| 属性名称          | 作用说明                                                     |
| ----------------- | ------------------------------------------------------------ |
| `ascii_letters`   | 包含所有 ASCII 字母（小写和大写）的字符串。                  |
| `ascii_lowercase` | 包含所有小写 ASCII 字母的字符串。                            |
| `ascii_uppercase` | 包含所有大写 ASCII 字母的字符串。                            |
| `digits`          | 包含所有十进制数字字符（'0' 到 '9'）的字符串。               |
| `hexdigits`       | 包含所有十六进制数字字符的字符串。                           |
| `octdigits`       | 包含所有八进制数字字符的字符串。                             |
| `punctuation`     | 包含所有 ASCII 标点符号字符的字符串。                        |
| `whitespace`      | 包含所有 ASCII 空白字符（如空格、制表符、换行符等）的字符串。 |
| `printable`       | 包含所有可打印的 ASCII 字符的字符串（包括数字、字母、标点和空白）。 |

# 常用方法与类

| 名称          | 作用说明                                                     |
| ------------- | ------------------------------------------------------------ |
| `capwords(s)` | 将字符串 `s` 按空格分割，把每个单词的首字母转为大写，其余转为小写，最后用空格连接返回。 |
| `Template`    | 提供基于 `$` 占位符的字符串模板功能。<br />通过 `substitute()` 或 `safe_substitute()` 方法进行变量替换。 |
| `Formatter`   | 提供基于 `{}` 占位符的字符串格式化功能。<br />通过 `format()` 方法进行格式化，支持自定义格式化逻辑。 |
