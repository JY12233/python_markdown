# 输入框

`tk.Entry` 是 `tkinter` 中用于接收用户单行文本输入的核心控件。与 `tk.Label`（仅展示）和 `tk.Button`（仅点击）不同，`tk.Entry` 允许用户编辑文本，是实现登录框、搜索框、数据表单等交互场景的基础。

## 创建对象的格式

创建 `tk.Entry` 对象时，除了指定父容器，通常还会设置其显示样式、宽度以及关联的动态变量。以下是创建对象的标准语法格式：

```python
entry = tk.Entry(
    master=None,              # 指定该输入框的父级容器（如主窗口或Frame），必选
    width=20,                 # 设置输入框的显示宽度，单位为字符数
    font=None,                # 设置输入框内文本的字体、大小和样式
    bg="white",               # 设置输入框的背景颜色（background）
    fg="black",               # 设置输入框内文本的前景色/字体颜色（foreground）
    bd=2,                     # 设置输入框边框的宽度，单位为像素（borderwidth）
    relief="sunken",          # 设置边框的立体样式（如 flat, raised, sunken, groove, ridge）
    show=None,                # 设置替代显示字符，常用于密码输入框（如 show="*"）
    state="normal",           # 设置输入框的状态（normal, disabled, readonly）
    textvariable=None,        # 绑定一个 StringVar 对象，实现输入框内容的动态同步
    justify="left",           # 设置文本在输入框内的对齐方式（left, center, right）
    insertbackground="black", # 设置插入光标（闪烁的竖线）的颜色
    insertwidth=2,            # 设置插入光标的宽度（像素）
    insertofftime=300,        # 设置插入光标闪烁时熄灭的时间间隔（毫秒）
    insertontime=600,         # 设置插入光标闪烁时点亮的时间间隔（毫秒）
    selectbackground="blue",  # 设置选中文本时的背景颜色
    selectforeground="white", # 设置选中文本时的前景色（字体颜色）
    selectborderwidth=0,      # 设置选中文本区域的边框宽度
    validate="none",          # 设置输入验证的触发时机（none, focus, focusin, focusout, key, all）
    validatecommand=None,     # 指定验证时调用的回调函数（需通过 register 注册）
    invalidcommand=None,      # 当验证函数返回 False 时调用的回调函数
    exportselection=True,     # 选中文本时是否自动复制到系统剪贴板
    xscrollcommand=None,      # 绑定水平滚动条命令，用于内容超出宽度时的滚动
    takefocus=True,           # 指定该输入框是否可以通过 Tab 键获取焦点
    cursor="xterm",           # 设置鼠标悬停在输入框内时的光标形状
    highlightbackground=None, # 设置输入框未获取焦点时的高亮边框颜色
    highlightcolor=None,      # 设置输入框获取焦点时的高亮边框颜色
    highlightthickness=1      # 设置高亮边框的宽度（像素）
)
```

## 构造参数详解

`tk.Entry` 拥有许多与 `tk.Label` 相似的视觉参数，但增加了针对文本输入和交互的特殊参数。以下是核心参数的作用及可选值：

| 参数名称            | 作用说明                   | 可选值 / 备注                                                |
| ------------------- | -------------------------- | ------------------------------------------------------------ |
| `master`            | 指定父容器                 | 通常是 `tk.Tk()` 或 `tk.Frame` 的实例                        |
| `textvariable`      | 绑定动态变量               | `tk.StringVar()` 等动态类型对象，用于双向绑定内容            |
| `show`              | 隐藏输入内容的掩码字符     | 字符串（如 `"*"` 或 `"●"`），常用于密码输入框                |
| `width`             | 输入框宽度                 | 整数；默认 `0` 表示根据内容自动调整                          |
| `font`              | 文本字体样式               | 元组形式，如 `("Arial", 12)`                                 |
| `bg` / `background` | 背景颜色                   | 颜色名称字符串（如 `"lightyellow"`）或十六进制颜色码         |
| `fg` / `foreground` | 文本前景颜色               | 颜色名称字符串或十六进制颜色码                               |
| `relief`            | 边框装饰样式               | `tk.SUNKEN`（默认）, `tk.FLAT`, `tk.RAISED`, `tk.GROOVE`, `tk.RIDGE` |
| `state`             | 输入框的交互状态           | `tk.NORMAL`（默认正常）, `tk.DISABLED`（禁用变灰）, `tk.READONLY`（只读） |
| `exportselection`   | 选中即复制功能             | `1`（默认开启）, `0`（关闭）                                 |
| `selectbackground`  | 选中状态下的背景色         | 颜色名称字符串或十六进制颜色码                               |
| `selectforeground`  | 选中状态下的文本色         | 颜色名称字符串或十六进制颜色码                               |
| `xscrollcommand`    | 绑定水平滚动条             | 通常与 `tk.Scrollbar` 控件配合使用                           |
| `validate`          | 指定输入内容验证的触发时机 | `none` 不进行验证<br />`focus` 当组件获得或失去焦点时验证<br />`focusin` 当组件获得焦点时验证<br />`focusout` 当组件失去焦点时验证<br />`key` 当输入内容时验证。`False` 时不会插入文本框。<br />`all` 当上述任何一种情况出现时验证。 |
| `validatecommand`   | 指定验证逻辑的回调函数     | 通过 `root.register()` 注册的函数引用及参数元组              |
| `invalidcommand`    | 验证失败时触发的回调函数   | 通过 `root.register()` 注册的函数引用及参数元组              |

## 常用属性

`tk.Entry` 继承自 `tk.Widget`，除了构造参数外，以下属性在开发中也较为常用：

| 属性名称     | 作用说明                                                     |
| ------------ | ------------------------------------------------------------ |
| `.master`    | 指向该输入框所属的父容器对象                                 |
| `.cget(key)` | 获取当前输入框某个配置项（如 `"width"` 或 `"show"`）的当前值 |
| `.keys()`    | 返回该输入框支持的所有配置参数键名的列表                     |

## 常用方法

`tk.Entry` 的核心在于对文本内容的增删改查。以下是其最常用的数据操作方法：

| 方法名称                        | 作用说明                                                     |
| ------------------------------- | ------------------------------------------------------------ |
| `get()`                         | 获取输入框内的当前文本内容                                   |
| `insert(index, string)`         | 在指定索引位置插入字符串（如 `entry.insert(0, "默认值")`）   |
| `delete(first, last=None)`      | 删除指定索引范围内的字符（如 `entry.delete(0, tk.END)` 清空内容） |
| `icursor(index)`                | 将输入光标移动到指定的索引位置                               |
| `index(index)`                  | 返回指定索引位置的实际数字索引值                             |
| `select_range(start, end)`      | 选中指定索引范围内的文本（要求 start < end）                 |
| `select_clear()`                | 取消当前的文本选中状态                                       |
| `select_present()`              | 判断输入框内是否有处于选中状态的文本（返回 True 或 False）   |
| `config(**options)`             | 动态修改输入框的属性（如 `entry.config(state="disabled")`）  |
| `pack()` / `grid()` / `place()` | 使用布局管理器将输入框放入父容器                             |

> 在 `tk.Entry` 中，索引（index）的使用非常灵活：可以使用从 `0` 开始的数字索引；使用 `"end"` 或 `tk.END` 表示文本的最后一个位置；使用 `"insert"` 表示当前光标所在的位置。

## 验证函数的说明

表面上看，`validatecommand` 似乎只能接收一个不带参数的函数，但实际上，`tkinter` 提供了一套非常巧妙的**“替换代码（Substitution Codes）”机制**来解决这个问题。

要让验证函数知道当前是哪个输入框，或者接收其他额外信息，需要使用 `register()` 方法结合**替换代码**来实现。

### 使用 `%W` 替换代码

在 `tkinter` 中，`validatecommand` 支持传入一个元组 `(f, s1, s2, ...)`，其中 `f` 是验证函数，`s1, s2` 等是替换代码。Tkinter 会在调用函数前，将这些代码替换为实际的运行时数据。

要区分是哪个输入框触发了验证，可以使用 **`%W`** 这个替换代码。它代表**当前触发验证的组件的名称（即组件的 ID）**。

### 具体实现步骤

#### 编写带参数的验证函数

验证函数需要接收一个参数（比如叫 `widget_name`），用来接收传入的组件名称。

#### 注册验证函数

使用 `root.register(test)` 将验证函数包装起来，获取一个 Tcl/Tk 的函数引用。

#### 传入替换代码 `%W`

在创建 `Entry` 时，将 `validatecommand` 设置为一个元组 `(testCMD, '%W')`。

### 代码示例

```python
import tkinter as tk

root = tk.Tk()

# 1. 编写带参数的验证函数，接收组件名称
def validate_input(widget_name):
    print(f"触发验证的输入框 ID 是: {widget_name}")
    # 你可以根据 widget_name 来判断当前是哪个输入框
    # 这里仅作演示，返回 True 允许输入
    return True

# 2. 注册验证函数
testCMD = root.register(validate_input)

# 3. 创建两个输入框，通过 '%W' 传递它们各自的 ID
entry1 = tk.Entry(root, validate="key", validatecommand=(testCMD, '%W'))
entry1.pack(pady=10)

entry2 = tk.Entry(root, validate="key", validatecommand=(testCMD, '%W'))
entry2.pack(pady=10)

root.mainloop()
```

### 常用的替换代码

除了 `%W`，Tkinter 还提供了很多其他替换代码，你可以将它们组合起来作为参数传给验证函数：

| 替换代码 | 传递的值           | 作用说明                                                     |
| -------- | ------------------ | ------------------------------------------------------------ |
| **`%W`** | 组件名称           | 触发验证的输入框的 ID（用于区分不同输入框）                  |
| `%P`     | 最新文本           | 如果允许修改，输入框即将变成的最新文本内容                   |
| `%s`     | 旧文本             | 修改前输入框中的文本内容                                     |
| `%S`     | 插入/删除的字符    | 用户刚刚插入或删除的具体字符（仅在 `key` 触发时有效）        |
| `%d`     | 操作类型           | `1` 表示插入，`0` 表示删除，`-1` 表示其他操作                |
| `%i`     | 索引位置           | 插入或删除操作的索引位置                                     |
| `%v`     | 验证类型           | 当前组件设置的 `validate` 选项值                             |
| `%V`     | 调用验证函数的原因 | `"focusin"`（获得焦点）<br />`"focusout"`（失去焦点）<br />`"key"`（输入或删除文本框内容）<br />`"forced"`（textvariable被程序修改） |

# 文本框

`tk.Text` 是 `tkinter` 中用于显示和编辑**多行文本**的高级控件。与 `tk.Entry`（仅限单行）不同，`Text` 控件功能极其强大，不仅支持多行文本编辑，还支持富文本格式（如字体、颜色）、嵌入图片、撤销/重做操作以及复杂的文本定位（索引、标签等）。

## 创建对象的格式

创建 `tk.Text` 对象时，通常需要指定父容器，并设置其尺寸、换行模式以及是否启用撤销功能等。以下是创建对象的标准语法格式：

```python
text_widget = tk.Text(
    master,           # 父容器对象，即该文本框将被放置在哪个窗口或框架中
    width=0,          # 文本框的宽度（以字符为单位，根据当前字体大小测量）
    height=0,         # 文本框的高度（以行数表示，根据当前字体大小测量）
    font=None,        # 文本框内文本的默认字体样式、大小等
    wrap="char",      # 文本自动换行模式（none不换行, char按字符换行, word按单词换行）
    bg="white",       # 文本框的背景颜色
    fg="black",       # 文本框的文本颜色（前景色）
    undo=False,       # 是否启用撤销功能（设为True可配合edit_undo()使用）
    maxundo=0,        # 最大撤销次数（仅在undo=True时有效，0表示无限制）
    state="normal",   # 控件状态（normal可编辑, disabled不可编辑且不可修改）
    relief="sunken",  # 文本框边框的装饰样式（默认为凹陷）
    padx=1,           # 文本区域左右两侧的内部填充大小
    pady=1,           # 文本区域上下两侧的内部填充大小
    insertbackground="black", # 插入光标的颜色
    xscrollcommand=None, # 绑定水平滚动条，使文本框在水平方向可滚动
    yscrollcommand=None  # 绑定垂直滚动条，使文本框在垂直方向可滚动
)
```

## 构造参数详解

`tk.Text` 拥有大量配置参数，以下是开发中最常用的核心参数及其可选值：

| 参数名称                            | 作用说明                         | 可选值 / 备注                                                |
| ----------------------------------- | -------------------------------- | ------------------------------------------------------------ |
| `master`                            | 指定父容器                       | 通常是 `tk.Tk()` 或 `tk.Frame` 的实例                        |
| `width` / `height`                  | 文本框的宽度和高度               | 整数；默认 `0` 表示自动调整                                  |
| `font`                              | 默认字体样式                     | 元组形式，如 `("微软雅黑", 12)`                              |
| `wrap`                              | 文本自动换行模式                 | `tk.NONE`（不换行）, `tk.CHAR`（按字符换行）, `tk.WORD`（按单词换行） |
| `bg` / `background`                 | 背景颜色                         | 颜色名称字符串或十六进制颜色码                               |
| `fg` / `foreground`                 | 文本前景颜色                     | 颜色名称字符串或十六进制颜色码                               |
| `undo`                              | 是否启用撤销功能                 | `True`（开启）, `False`（默认关闭）                          |
| `maxundo`                           | 最大撤销次数                     | 整数；`0` 表示无限制                                         |
| `state`                             | 控件的交互状态                   | `tk.NORMAL`（默认正常）, `tk.DISABLED`（禁用）               |
| `relief`                            | 边框装饰样式                     | `tk.SUNKEN`（默认）, `tk.FLAT`, `tk.RAISED`, `tk.GROOVE`, `tk.RIDGE` |
| `selectbackground`                  | 选中文本时的背景色               | 颜色名称字符串或十六进制颜色码                               |
| `selectforeground`                  | 选中文本时的文本色               | 颜色名称字符串或十六进制颜色码                               |
| `spacing1` / `spacing3`             | 每行文本上方/下方的垂直间距      | 整数（像素），默认值为 `0`                                   |
| `spacing2`                          | 自动换行时各显示行之间的垂直间距 | 整数（像素），默认值为 `0`                                   |
| `xscrollcommand` / `yscrollcommand` | 绑定水平/垂直滚动条              | 通常与 `tk.Scrollbar` 控件配合使用                           |

## 常用属性

`tk.Text` 继承自 `tk.Widget`，除了构造参数外，以下属性在开发中也较为常用：

| 属性名称     | 作用说明                                                     |
| ------------ | ------------------------------------------------------------ |
| `.master`    | 指向该文本框所属的父容器对象                                 |
| `.cget(key)` | 获取当前文本框某个配置项（如 `"width"` 或 `"state"`）的当前值 |
| `.keys()`    | 返回该文本框支持的所有配置参数键名的列表                     |

## 常用方法

`tk.Text` 的核心在于对多行文本内容的增删改查、富文本格式化以及撤销重做操作。以下是其最常用的方法：

| 方法名称                            | 作用说明                                                     |
| ----------------------------------- | ------------------------------------------------------------ |
| `get(index1, index2)`               | 获取指定范围内的文本内容（如 `text.get("1.0", tk.END)` 获取全部内容） |
| `insert(index, text)`               | 在指定索引位置插入字符串（如 `text.insert(tk.END, "追加文本")`） |
| `delete(startindex, endindex)`      | 删除指定范围内的文本（如 `text.delete("1.0", tk.END)` 清空内容） |
| `edit_undo()`                       | 撤销上一次操作（需提前设置 `undo=True`）                     |
| `edit_redo()`                       | 恢复（重做）上一次的撤销操作                                 |
| `search(pattern, start, end)`       | 在指定范围内搜索匹配的文本，返回匹配位置的索引               |
| `replace(start, end, string)`       | 替换指定范围内的文本为新的字符串                             |
| `tag_configure(tagName, **options)` | 配置标签（Tag）的样式（如字体、颜色），用于富文本格式化      |
| `tag_add(tagName, index1, index2)`  | 为指定索引范围内的文本添加标签                               |
| `image_create(index, image=img)`    | 在指定位置嵌入一个图片对象                                   |
| `see(index)`                        | 滚动文本框，使指定索引位置的文本可见                         |
| `config(**options)`                 | 动态修改文本框的属性（如 `text.config(state="disabled")`）   |
| `pack()` / `grid()` / `place()`     | 使用布局管理器将文本框放入父容器                             |

>在 `tk.Text` 中，索引（index）的语法比 `Entry` 更复杂且强大。常用的索引形式包括：
>
>- `"line.column"`：表示某一行某一列的位置，例如 `"1.0"` 表示第一行第零列（即文本开头）。
>- `tk.INSERT`：对应当前插入光标的位置。
>- `tk.CURRENT`：对应与鼠标坐标最接近的位置。
>- `tk.END`：对应文本域中最后一个字符的下一个位置。
>- `"line.end"`：表示某一行的末尾位置。
