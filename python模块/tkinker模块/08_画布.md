# 画布

`tk.Canvas` 是 `tkinter` 中最强大的控件之一，它提供了一个空白的绘图区域（画布）。与其他控件不同，`Canvas` 不仅用于绘制各种几何图形（如线条、矩形、椭圆、多边形等），还可以用来展示图片、文本，甚至嵌入其他 Tkinter 控件。画布上绘制的每一个元素都被称为“画布对象（item）”，它们拥有唯一的身份 ID，支持在创建后进行移动、修改颜色或删除等动态操作，非常适合用来制作简单的动画或数据可视化图表。

## 创建对象的格式

创建 `tk.Canvas` 对象时，通常需要指定父容器以及画布的物理尺寸。以下是创建对象的标准语法格式：

```python
canvas = tk.Canvas(
    master,             # 父容器对象，即该画布将被放置在哪个窗口或框架中
    width=0,            # 画布的宽度（以像素为单位）
    height=0,           # 画布的高度（以像素为单位）
    bg="white",         # 画布的背景颜色
    bd=2,               # 画布边框的宽度（默认为2像素）
    relief="sunken",    # 画布边框的装饰样式
    cursor="arrow",     # 鼠标悬停在画布上时的鼠标指针样式
    closeenough=1.0,    # 鼠标与画布对象距离小于该值时，视为鼠标位于对象上（浮点数）
    confine=True,       # 是否允许滚动超出 scrollregion 设置的区域
    scrollregion=None,  # 定义可滚动的最大区域（元组形式：左、上、右、下）
    xscrollcommand=None,# 绑定水平滚动条，使画布在水平方向可滚动
    yscrollcommand=None # 绑定垂直滚动条，使画布在垂直方向可滚动
)
```

## 构造参数详解

`tk.Canvas` 的参数主要围绕画布的尺寸、视觉外观以及滚动控制展开。以下是核心参数的作用及可选值：

| 参数名称                            | 作用说明               | 可选值 / 备注                                                |
| ----------------------------------- | ---------------------- | ------------------------------------------------------------ |
| `master`                            | 指定父容器             | 通常是 `tk.Tk()` 或 `tk.Frame` 的实例                        |
| `width` / `height`                  | 画布的宽度和高度       | 整数，单位为像素                                             |
| `bg` / `background`                 | 画布背景颜色           | 颜色名称字符串（如 `"yellow"`）或十六进制颜色码              |
| `bd` / `borderwidth`                | 边框的宽度             | 整数，单位为像素；默认 `2`                                   |
| `relief`                            | 边框装饰样式           | `tk.SUNKEN`（默认）, `tk.FLAT`, `tk.RAISED`, `tk.GROOVE`, `tk.RIDGE` |
| `cursor`                            | 鼠标悬停时的指针样式   | 如 `"arrow"`, `"cross"` 等                                   |
| `closeenough`                       | 鼠标命中检测的距离阈值 | 浮点数；当鼠标距离对象小于此值时触发交互                     |
| `confine`                           | 限制滚动范围           | `True`（默认，不能滚出设定区域）, `False`                    |
| `scrollregion`                      | 设置可滚动的最大区域   | 元组形式 `(w, n, e, s)`，分别代表左、上、右、下边界          |
| `xscrollcommand` / `yscrollcommand` | 绑定水平/垂直滚动条    | 通常与 `tk.Scrollbar` 控件配合使用                           |

## 常用属性

`tk.Canvas` 继承自 `tk.Widget`，除了构造参数外，以下属性在开发中也较为常用：

| 属性名称     | 作用说明                                                 |
| ------------ | -------------------------------------------------------- |
| `.master`    | 指向该画布所属的父容器对象                               |
| `.cget(key)` | 获取当前画布某个配置项（如 `"width"` 或 `"bg"`）的当前值 |
| `.keys()`    | 返回该画布支持的所有配置参数键名的列表                   |

## 常用方法

`tk.Canvas` 的核心在于使用 `create_` 系列方法绘制图形，以及使用 `move`、`delete` 等方法对已绘制的对象进行动态管理。以下是其最常用的方法：

| 方法名称                                       | 作用说明                                                     |
| ---------------------------------------------- | ------------------------------------------------------------ |
| `create_line(x1, y1, x2, y2, ..., options)`    | 绘制直线或折线；`fill` 设置颜色，`width` 设置宽度            |
| `create_rectangle(x1, y1, x2, y2, options)`    | 绘制矩形；`fill` 设置填充色，`outline` 设置边框色            |
| `create_oval(x1, y1, x2, y2, options)`         | 绘制椭圆或圆形；坐标定义了包含该椭圆的矩形边界框             |
| `create_polygon(x1, y1, x2, y2, ..., options)` | 绘制多边形；自动连接首尾点并填充内部，`smooth=True` 可使角变圆 |
| `create_arc(x1, y1, x2, y2, options)`          | 绘制扇形或弧形；`start` 为起始角度，`extent` 为跨度角度      |
| `create_text(x, y, options)`                   | 在指定坐标绘制文本；`text` 设置内容，`font` 设置字体         |
| `create_image(x, y, options)`                  | 在指定坐标放置图片；`image` 接收 `PhotoImage` 对象           |
| `move(item, dx, dy)`                           | 移动画布上的对象；`item` 为对象ID，`dx/dy` 为水平和垂直移动距离 |
| `delete(item)`                                 | 删除画布上的指定对象                                         |
| `tag_bind(item, sequence, func)`               | 为画布对象绑定事件（如鼠标点击 `<Button-1>`），实现交互      |
| `pack()` / `grid()` / `place()`                | 使用布局管理器将画布放入父容器                               |

> 在 `Canvas` 中，`create_` 系列方法的前几个参数通常是定义图形位置的坐标（左上角 `(x1, y1)` 和右下角 `(x2, y2)`，或者中心点 `(x, y)`）。这些方法在绘制完成后，会返回一个唯一的字符串 ID，开发者可以使用这个 ID 在后续代码中精确地控制该图形（例如改变颜色或移动位置）。

# 扇形

在 Tkinter 中，`create_arc` 方法用于在画布（Canvas）上绘制圆弧、扇形或弓形。

## 使用格式

```python
arc_id = canvas.create_arc(
    x1,                  # 必选：限定圆弧的边界矩形左上角的 x 坐标
    y1,                  # 必选：限定圆弧的边界矩形左上角的 y 坐标
    x2,                  # 必选：限定圆弧的边界矩形右下角的 x 坐标
    y2,                  # 必选：限定圆弧的边界矩形右下角的 y 坐标
    **kw                 # 可选：通过关键字参数传入以下各种样式、状态和交互配置
)
```

### 完整参数详解

#### 基础几何与样式参数：

| 参数名称         | 作用说明                                                     | 常见可选值或示例                                             |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `start`          | 指定圆弧开始绘制的偏移角度<br />（相对于 x 轴正方向，单位为度）。 | `0`（默认值），<br />`30`，<br />`-70`                       |
| `extent`         | 指定从 `start` 位置开始，逆时针延伸的角度（单位为度）。<br />若设为 `359` 可绘制接近完整的圆。 | `90`（默认值），<br />`180`，<br />`270`，<br />`359`        |
| `style`          | 指定绘制的图形样式。                                         | `"pieslice"`（扇形，默认），<br />`"arc"`（纯圆弧），<br />`"chord"`（弓形） |
| `fill`           | 设置图形内部的填充颜色。空字符串表示透明。<br />只有 `pieslice` 和 `chord` 才能填充颜色。 | `"red"`，<br />`"#FF0000"`，<br />`""`                       |
| `outline`        | 设置图形轮廓线（边框）的颜色。                               | `"blue"`，<br />`"black"`                                    |
| `width`          | 设置轮廓线的宽度（以像素为单位）。                           | `2`，<br />`5`                                               |
| `dash`           | 将轮廓线设置为虚线。<br />通过元组指定实线和空白的像素长度，循环绘制。 | `(5, 3)`（5像素实线，3像素空白）                             |
| `dashoffset`     | 指定虚线轮廓开始绘制的初始偏移位置。                         | `2`，<br />`5`                                               |
| `stipple`        | 使用位图（Bitmap）作为填充图案。<br />默认空字符串表示实心。对含有弧线的图形无效。 | `"gray50"`，<br />`"gray25"`                                 |
| `outlinestipple` | 使用位图来绘制边框。<br />默认空字符串表示黑色实线。弧线部分的边框无法使用位图绘制。 | `"gray50"`                                                   |
| `state`          | 指定该画布对象的状态。                                       | `"normal"`（默认），<br />`"disabled"`（不响应事件），<br />`"hidden"`（隐藏） |
| `tags`           | 为创建的画布对象添加一个或多个标签，<br />方便后续通过标签进行批量操作（如移动、删除）。 | `"my_arc"`，<br />`("group1", "arc")`                        |

#### 交互状态相关参数（当鼠标悬停或组件状态改变时生效）：

| 参数名称               | 作用说明                                                     | 常见可选值或示例 |
| ---------------------- | ------------------------------------------------------------ | ---------------- |
| `activefill`           | 当鼠标移动到该对象上方时，图形内部的填充颜色。               | `"lightblue"`    |
| `activeoutline`        | 当鼠标移动到该对象上方时，绘制的轮廓线颜色。                 | `"darkblue"`     |
| `activedash`           | 当鼠标移动到该对象上方时，绘制的虚线轮廓样式。               | `(4, 2)`         |
| `activewidth`          | 当鼠标移动到该对象上方时，指定的边框宽度。                   | `3`              |
| `activestipple`        | 当鼠标移动到该对象上方时，指定的填充位图。对含有弧线的图形无效。 | `"gray50"`       |
| `activeoutlinestipple` | 当鼠标移动到该对象上方时，指定填充轮廓的位图。对弧线无效。   | `"gray25"`       |

#### 禁用状态相关参数

> 当 `state="disabled"` 时生效

| 参数名称                 | 作用说明                                                     | 常见可选值或示例 |
| ------------------------ | ------------------------------------------------------------ | ---------------- |
| `disabledfill`           | 当对象状态为 `DISABLED` 时的填充颜色。                       | `"gray"`         |
| `disabledoutline`        | 当对象状态为 `DISABLED` 时的轮廓线颜色。                     | `"darkgray"`     |
| `disableddash`           | 当对象状态为 `DISABLED` 时的虚线样式。                       | `(2, 4)`         |
| `disabledwidth`          | 当对象状态为 `DISABLED` 时的边框宽度。                       | `1`              |
| `disabledstipple`        | 当对象状态为 `DISABLED` 时的填充位图。对含有弧线的图形无效。 | `"gray50"`       |
| `disabledoutlinestipple` | 当对象状态为 `DISABLED` 时填充轮廓的位图。对弧线无效。       | `"gray25"`       |

#### 其他参数：

| 参数名称        | 作用说明                                                     | 常见可选值或示例                        |
| --------------- | ------------------------------------------------------------ | --------------------------------------- |
| `offset`        | 指定当使用点画模式（stipple）填充时，位图的定位偏移方式。<br />对含有弧线边框的图形无效。 | `"x,y"`，<br />`"ne"`，<br />`"center"` |
| `outlineoffset` | 指定当用位图绘制轮廓线时，位图的定位偏移方式。               | `"x,y"`，<br />`"nw"`，<br />`"e"`      |

### 代码示例

以下示例展示了如何使用 `create_arc` 绘制不同样式的图形：

```python
import tkinter as tk

root = tk.Tk()
root.title("create_arc 示例")

canvas = tk.Canvas(root, width=400, height=150, bg="white")
canvas.pack()

# 1. 绘制默认样式的扇形（pieslice）
canvas.create_arc(20, 20, 100, 100, start=0, extent=90, fill="orange", outline="black")

# 2. 绘制弓形（chord）
canvas.create_arc(120, 20, 200, 100, start=0, extent=180, style="chord", fill="lightblue", outline="black")

# 3. 绘制纯圆弧（arc）
canvas.create_arc(220, 20, 300, 100, start=30, extent=120, style="arc", outline="red", width=3)

root.mainloop()
```
