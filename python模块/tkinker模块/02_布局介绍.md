# `pack`

`pack` 是 Python `tkinter` 库中最基础、最简单的布局管理器。它通过将组件“打包”到父容器中，按照添加的顺序自动调整组件的位置和大小。

> 在同一个容器中，只能使用一种布局方式。
>
> 一般，使用 `unxxx` 可以把容器拿下来。

## 使用格式

```python
widget.pack(
    side=tk.TOP,       # 指定组件在父容器中的停靠位置
    fill=tk.NONE,      # 指定组件在其分配的空间内如何填充
    expand=False,      # 指定父容器调整大小时，组件是否扩展以填充额外空间
    anchor=tk.CENTER,  # 指定组件在其分配空间内的对齐方式
    padx=0,            # 指定组件外部的水平边距
    pady=0,            # 指定组件外部的垂直边距
    ipadx=0,           # 指定组件内部的水平填充（文本与边框的距离）
    ipady=0,           # 指定组件内部的垂直填充（文本与边框的距离）
    before=None,       # 将当前组件放置在指定组件之前
    after=None,        # 将当前组件放置在指定组件之后
    in_=None           # 指定将组件打包到哪个父容器中
)
```

## 参数详解

| 参数名称           | 作用说明                                             | 常见可选值                                                   |
| ------------------ | ---------------------------------------------------- | ------------------------------------------------------------ |
| `side`             | 指定组件在父容器中的停靠方向                         | `tk.TOP`（默认，从上到下）<br />`tk.BOTTOM`（从下到上）<br />`tk.LEFT`（从左到右）<br />`tk.RIGHT`（从右到左） |
| `fill`             | 指定组件在其分配的空间内如何拉伸填充                 | `tk.NONE`（默认，不填充）<br />`tk.X`（水平填充）<br />`tk.Y`（垂直填充）<br />`tk.BOTH`（水平和垂直同时填充） |
| `expand`           | 当父容器大小改变时，组件是否扩展以填充额外的空白空间 | `False`（默认，不扩展）<br />`True`（扩展）                  |
| `anchor`           | 指定组件在其分配空间内的对齐方式                     | `tk.CENTER`（默认，居中）<br />`tk.N`（北/上）<br />`tk.S`（南/下）<br />`tk.W`（西/左）<br />`tk.E`（东/右）<br />组合如 `tk.NW` |
| `padx` / `pady`    | 控制组件与其他组件或窗口边界之间的外部距离（外边距） | 整数（如 `10`）或<br />元组（如 `(10, 20)` 分别指定左右/上下边距） |
| `ipadx` / `ipady`  | 控制组件内容（如文本）与组件边框之间的距离（内边距） | 整数（如 `5`）                                               |
| `before` / `after` | 指定组件在父容器中的相对排列位置                     | 另一个组件对象（如 `before=button1`）                        |
| `in_`              | 指定将组件打包到哪个父容器中                         | 父容器对象（如 `frame`）                                     |

## 代码示例

```python
import tkinter as tk

root = tk.Tk()
root.title("Pack布局示例")

# 创建一个按钮，停靠在左侧，垂直方向填充，并允许扩展
button1 = tk.Button(root, text="按钮 1")
button1.pack(side=tk.LEFT, padx=10, pady=10, fill=tk.Y, expand=True)

# 创建另一个按钮，停靠在右侧，同时在水平和垂直方向填充
button2 = tk.Button(root, text="按钮 2")
button2.pack(side=tk.RIGHT, padx=10, pady=10, fill=tk.BOTH, expand=True)

root.mainloop()
```

# `grid`

`grid` 是 `tkinter` 中最强大、最常用的布局管理器。它将父容器想象成一个由行和列组成的二维表格，通过将组件放置在特定的“单元格”中来实现精确的界面排版。

## 使用格式

```python
widget.grid(
    row=0,              # 指定组件所在的行号（从 0 开始）
    column=0,           # 指定组件所在的列号（从 0 开始）
    rowspan=1,          # 指定组件在垂直方向上跨越的行数
    columnspan=1,       # 指定组件在水平方向上跨越的列数
    sticky=tk.N,        # 指定组件在单元格内的对齐及拉伸方式
    padx=0,             # 指定组件外部的水平边距
    pady=0,             # 指定组件外部的垂直边距
    ipadx=0,            # 指定组件内部的水平填充
    ipady=0,            # 指定组件内部的垂直填充
    in_=None            # 指定将组件放置到哪个父容器中
)
```

## 参数详解

| 参数名称          | 作用说明                                   | 常见可选值                                                   |
| ----------------- | ------------------------------------------ | ------------------------------------------------------------ |
| `row`             | 指定组件在网格中所在的行号                 | 整数（从 `0` 开始递增）                                      |
| `column`          | 指定组件在网格中所在的列号                 | 整数（从 `0` 开始递增）                                      |
| `rowspan`         | 使组件在垂直方向上合并多个单元格           | 整数（默认为 `1`）                                           |
| `columnspan`      | 使组件在水平方向上合并多个单元格           | 整数（默认为 `1`）                                           |
| `sticky`          | 控制组件在单元格内的对齐方式及拉伸行为     | `tk.N`（上）、<br />`tk.S`（下）、<br />`tk.W`（左）、<br />`tk.E`（右），<br />可组合使用（如 `tk.NSEW` 表示四向拉伸填满） |
| `padx` / `pady`   | 控制组件与其他组件或窗口边界之间的外部距离 | 整数（如 `10`）或元组（如 `(10, 20)`）                       |
| `ipadx` / `ipady` | 控制组件内容与组件边框之间的距离           | 整数（如 `5`）                                               |
| `in_`             | 指定将组件打包到哪个父容器中               | 父容器对象（如 `frame`）                                     |

## 代码示例

以下是一个简单的示例，展示了如何使用 `grid` 构建一个包含标签、输入框和按钮的表单界面：

```python
import tkinter as tk

root = tk.Tk()
root.title("Grid布局示例")

# 创建一个标签，放在第 0 行，第 0 列，右侧对齐
label = tk.Label(root, text="用户名：")
label.grid(row=0, column=0, padx=10, pady=10, sticky=tk.E)

# 创建一个输入框，放在第 0 行，第 1 列，水平拉伸填满单元格
entry = tk.Entry(root)
entry.grid(row=0, column=1, padx=10, pady=10, sticky=tk.EW)

# 创建一个按钮，放在第 1 行，水平跨越 2 列（合并两个单元格）
button = tk.Button(root, text="登录")
button.grid(row=1, column=0, columnspan=2, pady=10, sticky=tk.EW)

# 配置第 1 列的权重，使其在窗口拉伸时能够自动扩展
root.columnconfigure(1, weight=1)

root.mainloop()
```

# `place`

`place` 是 `tkinter` 中最为灵活、但也最复杂的布局管理器。它允许开发者通过绝对坐标（像素）或相对坐标（比例）来精确指定组件的位置和大小，适合处理不规则或需要自由定制的布局。

## 使用格式

```python
widget.place(
    x=0,              # 指定组件左上角的绝对 x 坐标（像素）
    y=0,              # 指定组件左上角的绝对 y 坐标（像素）
    relx=0.0,         # 指定组件相对于父容器宽度的 x 坐标（0.0 到 1.0）
    rely=0.0,         # 指定组件相对于父容器高度的 y 坐标（0.0 到 1.0）
    width=0,          # 指定组件的绝对宽度（像素）
    height=0,         # 指定组件的绝对高度（像素）
    relwidth=0.0,     # 指定组件相对于父容器宽度的比例（0.0 到 1.0）
    relheight=0.0,    # 指定组件相对于父容器高度的比例（0.0 到 1.0）
    anchor=tk.NW,     # 指定组件相对于定位点的对齐方式（锚点）
    bordermode=tk.INSIDE  # 指定边界计算模式（包含或不包含父容器边框）
)
```

## 参数详解

| 参数名称                 | 作用说明                                               | 常见可选值                                                   |
| ------------------------ | ------------------------------------------------------ | ------------------------------------------------------------ |
| `x` / `y`                | 绝对定位，指定组件左上角相对于父容器的像素坐标         | 整数（如 `50`）                                              |
| `relx` / `rely`          | 相对定位，指定组件相对于父容器宽/高的比例坐标          | 浮点数（`0.0` 到 `1.0`）                                     |
| `width` / `height`       | 绝对尺寸，指定组件的固定宽度和高度                     | 整数（如 `100`）                                             |
| `relwidth` / `relheight` | 相对尺寸，指定组件占父容器宽/高的比例                  | 浮点数（`0.0` 到 `1.0`）                                     |
| `anchor`                 | 锚点，决定组件的哪个部位对齐到指定的坐标位置           | `tk.NW`（左上）、`tk.CENTER`（居中）、`tk.SE`（右下）等方位常量 |
| `bordermode`             | 边界模式，决定相对定位时是否将父容器的边框宽度计算在内 | `tk.INSIDE`（默认，内部）、`tk.OUTSIDE`（外部）              |

## 代码示例

以下是一个简单的示例，展示了如何使用 `place` 实现绝对定位和相对居中的效果：

```python
import tkinter as tk

root = tk.Tk()
root.title("Place布局示例")
root.geometry("400x300")

# 绝对定位：放置在距离左上角 (50, 50) 的位置，固定宽高
button1 = tk.Button(root, text="绝对定位")
button1.place(x=50, y=50, width=100, height=40)

# 相对定位：放置在窗口的正中心，并随窗口大小自适应
button2 = tk.Button(root, text="相对居中")
button2.place(relx=0.5, rely=0.5, anchor=tk.CENTER, relwidth=0.3, relheight=0.1)

root.mainloop()
```

## 三种布局管理器对比使用表

| 布局管理器 | 控制精度   | 适用场景                             | 优点                           | 缺点                           |
| ---------- | ---------- | ------------------------------------ | ------------------------------ | ------------------------------ |
| `pack`     | 自动排列   | 简单的线性布局（如工具栏、侧边栏）   | 快速布局，代码简洁             | 缺乏精确控制，复杂布局难以实现 |
| `grid`     | 网格定位   | 复杂的表单、表格或需严格对齐的界面   | 精确位置，适合复杂且规整的布局 | 代码较复杂，需提前规划行列     |
| `place`    | 像素级定位 | 自由、不规则、定制布局或动态移动组件 | 精确控制，灵活性最高           | 难以动态适配窗口大小，开发繁琐 |

**核心开发建议**

在实际开发中，**强烈建议优先使用 `grid` 布局**。

对于复杂的界面，通常采用**组合布局**的策略：使用 `pack` 划分界面的主要区域（如顶部、左侧、右侧），然后在各个区域内部使用 `grid` 来排列具体的控件。尽量避免在同一个父容器内混用 `pack` 和 `grid`，这会导致程序报错。

## 常用推荐

虽然上面有很多有趣的选项，但在实际开发中，最常用的通常是以下几个：

- **`"hand2"`**: 用于按钮或链接，提示用户可点击。
- **`"watch"`** 或 **`"clock"`**: 用于程序正在处理耗时任务时。
- **`"xterm"`**: 用于文本框，提示用户可以输入文字。
- **`"X_cursor"`**: 用于表示“禁止”或“不可用”。

## 代码示例

```python

# 设置整个窗口的鼠标样式

# 设置特定按钮的鼠标样式
btn = tk.Button(root, text="点我", cursor="hand2")
btn.pack(pady=20)

root.mainloop()
```
