# 多选框

在 Tkinter 中，`Checkbutton`（复选框）是一种允许用户进行多项选择的按钮控件。与单选按钮（`Radiobutton`）不同，各个 `Checkbutton` 之间是并列关系，用户可以同时选中多个选项。它通常用于实现“开/关”状态的切换或多选列表。

### 创建对象格式

```python
check = tk.Checkbutton(
    master=None,      # 必选：父容器（如 Tk 窗口或 Frame）
    text='',          # 可选：复选框旁边显示的文本，支持 "\n" 换行
    variable=None,    # 可选：与复选框状态绑定的 Tkinter 变量（如 IntVar, StringVar 等）
    onvalue=1,        # 可选：当复选框被选中时，绑定变量所赋的值
    offvalue=0,       # 可选：当复选框未选中时，绑定变量所赋的值
    command=None,     # 可选：当复选框状态改变时，自动调用的回调函数
    indicatoron=True, # 可选：是否绘制前面的小方块。设为 False 时，外观变为类似按钮的样式
    state='normal',   # 可选：组件状态。'normal'(正常), 'disabled'(禁用/灰显), 'active'(活动)
    selectcolor='red' # 可选：复选框被选中时，小方块内部的颜色
)
```

## 参数详解

| 参数名称      | 作用说明                                                     | 常见可选值或示例                                 |
| ------------- | ------------------------------------------------------------ | ------------------------------------------------ |
| `text`        | 设置复选框旁边显示的文本标签。                               | `"同意协议"`，<br />`"选项1"`                    |
| `variable`    | 绑定一个 Tkinter 变量以跟踪复选框的状态。<br />当用户点击时，该变量会在 `onvalue` 和 `offvalue` 之间自动切换。 | `tk.IntVar()`，<br />`tk.BooleanVar()`           |
| `onvalue`     | 自定义复选框选中状态时，`variable` 变量的值。                | `1`，<br />`True`，<br />`"Yes"`                 |
| `offvalue`    | 自定义复选框未选中状态时，`variable` 变量的值。              | `0`，<br />`False`，<br />`"No"`                 |
| `command`     | 指定一个函数，当复选框被点击（状态改变）时由 Tkinter 自动调用。 | `my_callback_function`                           |
| `indicatoron` | 控制是否显示前面的小方块指示器。<br />若设为 `False`，复选框会变成一个类似普通按钮的样式。 | `True` （默认），<br />`False`                   |
| `selectcolor` | 设置选中状态下小方块（指示器）的背景颜色。                   | `"lightblue"`，<br />`"#FF0000"`                 |
| `state`       | 设置组件的交互状态。                                         | `"normal"`，<br />`"disabled"`，<br />`"active"` |
| `image`       | 在复选框上显示图像。<br />如果设置了此参数，默认会隐藏文本（除非配合 `compound` 使用）。 | `PhotoImage` 对象                                |

## 常用属性

`Checkbutton` 本身没有供开发者直接读取的公开数据属性。其状态和外观完全通过绑定的 `variable` 对象（使用 `get()` 和 `set()` 方法）以及组件自身的配置方法（`config()`）进行管理。

## 常用方法

| 方法名称     | 作用说明                                                     | 常见使用场景                       |
| ------------ | ------------------------------------------------------------ | ---------------------------------- |
| `select()`   | 通过代码将复选框设置为选中状态（即将 `variable` 设为 `onvalue`）。 | 初始化界面时设置默认勾选           |
| `deselect()` | 通过代码取消复选框的选中状态（即将 `variable` 设为 `offvalue`）。 | 重置表单或清空选项                 |
| `toggle()`   | 切换复选框的当前状态。如果当前是选中则取消，未选中则选中。   | 模拟用户点击或快捷键切换           |
| `invoke()`   | 模拟用户点击复选框。它会调用 `command` 指定的函数，并切换状态。 | 在测试或自动化流程中触发复选框逻辑 |
| `flash()`    | 使复选框在前景色和背景色之间闪烁几次，然后恢复初始状态。     | 引起用户对某个选项的注意           |

# 单选框

在 Tkinter 中，`Radiobutton`（单选按钮）是一种用于实现“多选一”功能的控件。它的名称来源于早期收音机上的机械按钮，按下某一个频道时，其他频道会自动弹起。在 GUI 开发中，多个 `Radiobutton` 必须绑定到同一个 Tkinter 变量（如 `IntVar` 或 `StringVar`），当用户选中其中一个时，该变量的值会自动更新为当前按钮的 `value`。

## 创建对象格式

```python
radio = tk.Radiobutton(
    master=None,      # 必选：父容器（如 Tk 窗口或 Frame）
    text='',          # 可选：单选按钮旁边显示的文本内容
    variable=None,    # 必选：与单选按钮组绑定的 Tkinter 变量（同一组必须指向同一个变量）
    value=None,       # 必选：当该按钮被选中时，绑定变量所赋的值
    command=None,     # 可选：当用户更改选项（选中此按钮）时，自动调用的回调函数
    indicatoron=True, # 可选：是否绘制前面的小圆圈。设为 False 时，外观变为类似矩形按钮的样式
    selectcolor='red' # 可选：单选按钮被选中时，小圆圈内部的颜色
)
```

## 参数详解

| 参数名称      | 作用说明                                                     | 常见可选值或示例                                    |
| ------------- | ------------------------------------------------------------ | --------------------------------------------------- |
| `text`        | 设置单选按钮旁边显示的文本标签。                             | `"男生"`，<br />`"选项A"`                           |
| `variable`    | 绑定一个 Tkinter 变量以跟踪选中状态。<br />同一组中的所有按钮的 `variable` 必须指向同一个变量。 | `tk.IntVar()`，<br />`tk.StringVar()`               |
| `value`       | 自定义该按钮被选中时，`variable` 变量的值。<br />用于区分不同的选项。 | `1`，<br />`"男"`，<br />`"Python"`                 |
| `command`     | 指定一个函数，当单选按钮被选中时由 `Tkinter` 自动调用。      | `my_callback_function`                              |
| `indicatoron` | 控制是否显示前面的小圆圈指示器。<br />若设为 `False`，单选按钮会变成一个类似普通按钮的矩形样式。 | `True`（默认），<br />`False`                       |
| `selectcolor` | 设置选中状态下小圆圈（指示器）的背景颜色。                   | `"lightblue"`，<br />`"#FF0000"`                    |
| `state`       | 设置组件的交互状态。                                         | `"normal"`（正常），<br />`"disabled"`（禁用/灰显） |
| `compound`    | 控制文本和图像的混合显示模式。                               | `"center"`，<br />`"left"`，<br />`"right"`         |

## 常用属性

`Radiobutton` 本身没有供开发者直接读取的公开数据属性。其状态和外观完全通过绑定的 `variable` 对象（使用 `get()` 和 `set()` 方法）以及组件自身的配置方法（`config()`）进行管理。

## 常用方法

| 方法名称     | 作用说明                                                     | 常见使用场景                     |
| ------------ | ------------------------------------------------------------ | -------------------------------- |
| `select()`   | 通过代码将该单选按钮设置为选中状态。                         | 初始化界面时设置默认选项         |
| `deselect()` | 通过代码取消该单选按钮的选中状态。                           | 重置表单或清空选项               |
| `invoke()`   | 模拟用户点击该单选按钮。<br />它会调用 `command` 指定的函数，并切换状态。 | 在测试或自动化流程中触发选项逻辑 |
| `flash()`    | 使单选按钮在前景色和背景色之间闪烁几次，然后恢复初始状态。   | 引起用户对某个选项的注意         |
