# 介绍

`tkinter` 是 Python 内置的标准 GUI（图形用户界面）库，如果说 `turtle` 是可爱的“海龟”，那 `tkinter` 就是它背后的“舞台”和“导演”。

## 基本框架

一个 `tkinter` 程序，通常由三个核心部分组成：

1. 主窗口 `Tk` 

   一切 GUI 程序的起点和基础容器。

2. 组件树

   在窗口上添加的各种元素（按钮、标签等），它们按层级关系组织。

3. 事件循环 `mainloop` 

   让程序持续运行，等待并响应用户操作（如点击、键盘输入）的无限循环。

一个最基础的 `tkinter` 程序框架如下：

```python
import tkinter as tk

# 1. 创建主窗口
root = tk.Tk()
# 可选：设置窗口标题和大小
root.title("我的第一个GUI程序")
root.geometry("300x200")

# 2. 在这里创建和放置各种组件
# 例如：label = tk.Label(root, text="Hello, Tkinter!")
#      label.pack()

# 3. 进入主事件循环
root.mainloop()
```

## 主要功能与基本组件

`tkinter` 提供了丰富的“积木”来构建界面，以下是最常用的一些：

*   `Tk`：主窗口类，是所有组件的根容器。
*   `Label`：标签，用于显示文本或图片。
*   `Button`：按钮，用于触发一个命令或函数。
*   `Entry`：输入框，用于接收用户单行文本输入。
*   `Text`：文本框，用于多行文本的输入或显示。
*   `Frame`：框架，作为容器来组织和管理其他组件。
*   `Canvas`：画布，用于绘制图形、图表或显示自定义图像。**`turtle` 正是利用 `Canvas` 来实现绘图的**。

## 三大布局管理器

为了把组件放到窗口的指定位置，`tkinter` 提供了三种布局管理器：

*   **`pack()`**：按顺序“打包”排列，最简单。
*   **`grid()`**：类似表格，按行、列精准定位，最常用。
*   **`place()`**：通过绝对坐标 (x, y) 精确定位，最灵活。

## 事件驱动与事件绑定

GUI 程序的核心是“事件驱动”。意思是程序在 `mainloop` 中等待事件发生，然后执行相应的代码。

最典型的例子就是按钮的 `command` 参数。你也可以用 `bind` 方法为任意组件绑定更复杂的事件：

```python
def on_key_press(event):
    print(f"按下了 {event.keysym} 键")

root.bind("<KeyPress>", on_key_press) # 绑定键盘按下事件
```

## 与`turtle` 的关系

* 依赖关系

  `turtle` 模块**依赖 `tkinter`** 来实现其图形界面。如果 Python 环境没有 `tkinter`（如某些 Linux 服务器最小化安装），`turtle` 就无法运行。

* 如何协同

  `turtle` 在 `tkinter` 的 `Canvas` 组件上绘制，并将 `tkinter` 复杂的 GUI 操作（如创建窗口、处理事件）封装成了 `Screen()`、`Turtle()` 等更友好的接口。

# 主窗口类

每一个 `Tk` 实例都代表一个应用程序的**主窗口**，并且每个实例都拥有自己关联的 Tcl 解释器。

## 创建对象的格式

创建 `tkinter.Tk` 对象的标准语法格式如下：

```python
root = tkinter.Tk(
    screenName=None,  # 仅限X11系统，用于设置DISPLAY环境变量
    baseName=None,    # 预置文件的名称，默认取自程序名称(sys.argv[0])
    className='Tk',   # 控件类名称，用作预置文件名及Tcl唤起名称
    useTk=True,       # 若为True则初始化Tk子系统，若为False则不初始化
    sync=False,       # 仅限X11系统，若为True则同步执行X服务器命令以调试
    use=None          # 指定嵌入应用程序的窗口ID，而非创建独立的顶层窗口
)
```

## 构造参数详解

`tkinter.Tk` 在实例化时通常使用默认值，但了解这些参数有助于处理特殊场景（如跨平台或嵌入式开发）：

| 参数名称     | 作用说明                     | 可选值 / 备注                                               |
| ------------ | ---------------------------- | ----------------------------------------------------------- |
| `screenName` | 设置显示屏幕的环境变量       | 字符串类型；仅在 Unix/X11 平台有效                          |
| `baseName`   | 指定应用程序预置文件的名称   | 默认为 `sys.argv[0]`（即当前运行的Python文件名）            |
| `className`  | 指定控件的类名称             | 默认为 `'Tk'`；会作为 Tcl 解释器中的名称                    |
| `useTk`      | 控制是否初始化 Tk 图形子系统 | `True`（默认，正常创建GUI窗口）；`False`（仅驱动Tcl解释器） |
| `sync`       | 控制 X 服务器命令的执行模式  | `False`（默认异步）；`True`（同步执行，便于调试报错）       |
| `use`        | 将应用嵌入到其他窗口中       | 需传入目标窗口的 ID；不创建独立顶层窗口                     |

## 常用属性

在创建出 `Tk` 主窗口对象后，可以通过以下属性来访问底层解释器或获取父容器信息：

| 属性名称  | 作用说明                                                     |
| --------- | ------------------------------------------------------------ |
| `.tk`     | 提供对底层 Tcl 解释器的直接访问接口                          |
| `.master` | 指向包含该控件的父容器对象；对于 `Tk` 主窗口，该值通常为 `None` |

## 常用方法

`Tk` 实例提供了大量用于管理窗口外观、状态以及控制程序生命周期的方法。以下是开发中最常使用的方法：

| 方法名称                          | 作用说明                                                     |
| --------------------------------- | ------------------------------------------------------------ |
| `title()`                         | 设置或获取主窗口左上角的标题文字。                           |
| `geometry()`                      | 设置窗口的大小（宽x高）及在屏幕上的位置（+x+y）。            |
| `resizable()`                     | 设置窗口在水平（x）和垂直（y）方向上是否允许用户拉伸。       |
| `maxsize()` / `minsize()`         | 设置窗口允许被拉伸的最大和最小尺寸。                         |
| `config()`                        | 配置或修改窗口的各种属性（如背景色 `background`）。          |
| `attributes()`                    | 设置特殊的窗口属性，如置顶 (`-topmost`)、透明度 (`-alpha`)。 |
| `iconbitmap()`                    | 设置窗口左上角的图标（通常传入 `.ico` 文件的绝对路径）。     |
| `protocol()`                      | 注册协议处理机制，常用于拦截右上角关闭按钮 (`WM_DELETE_WINDOW`)。 |
| `update()` / `update_idletasks()` | 强制刷新页面，处理所有待处理的事件和重绘任务。               |
| `winfo_screenwidth()`             | 获取当前电脑屏幕的宽度（像素）。                             |
| `winfo_screenheight()`            | 获取当前电脑屏幕的高度（像素）。                             |
| `quit()`                          | 退出 Tkinter 的主事件循环（通常用于绑定“退出”按钮）。        |
| `destroy()`                       | 直接销毁并关闭当前窗口。                                     |
| `mainloop()`                      | 启动主事件循环，保持窗口持续显示并响应用户交互（必需）。     |

# 标签类

`tk.Label` 是 `tkinter` 中最基础也是最常用的控件之一，主要用于在窗口中显示文本或图片。它通常只作为展示使用，不具备交互功能（即用户无法点击或编辑）。

## 创建对象的格式

创建 `tk.Label` 对象时，通常需要指定其父容器（如主窗口 `root`）以及要显示的内容。以下是创建对象的标准语法格式：

```python
label = tk.Label(
    master,        # 父容器对象，即该标签将被放置在哪个窗口或框架中
    text="示例",    # 标签上要显示的文本内容
    image=None,    # 标签上要显示的图片对象（PhotoImage实例）
    compound=None, # 当同时设置了text和image时，控制两者的相对位置
    anchor="center",# 控制文本或图片在标签可用空间内的对齐方式
    bg="SystemButtonFace", # 标签的背景颜色
    fg="SystemButtonText", # 标签的文本颜色
    font=None,     # 文本的字体样式、大小等
    width=0,       # 标签的宽度（以字符为单位，若显示图片则以像素为单位）
    height=0,      # 标签的高度（以字符为单位，若显示图片则以像素为单位）
    padx=0,        # 标签内部，文本与左右边框之间的水平内边距
    pady=0,        # 标签内部，文本与上下边框之间的垂直内边距
    relief="flat", # 标签边框的装饰样式（如凸起、凹陷等）
    cursor="arrow" # 鼠标悬停在标签上时的鼠标指针样式
)
```

## 构造参数详解

`tk.Label` 拥有丰富的配置参数，允许开发者高度自定义其外观。以下是核心参数的作用及可选值：

| 参数名称            | 作用说明               | 可选值 / 备注                                                |
| ------------------- | ---------------------- | ------------------------------------------------------------ |
| `master`            | 指定父容器             | 通常是 `tk.Tk()` 或 `tk.Frame` 的实例                        |
| `text`              | 显示的文本字符串       | 任意字符串；若使用 `textvariable` 可绑定动态变量             |
| `image`             | 显示的图片对象         | 必须是 `tk.PhotoImage` 或 `tk.BitmapImage` 的实例            |
| `compound`          | 文本与图片共存时的布局 | `tk.CENTER`，`tk.TOP`，`tk.BOTTOM`，`tk.LEFT`，`tk.RIGHT`    |
| `anchor`            | 内容在标签内的对齐方式 | `tk.CENTER`，`tk.N`，`tk.S`，`tk.E`，`tk.W`，`tk.NE` 等方位  |
| `bg` / `background` | 标签背景颜色           | 颜色名称字符串（如 `"red"`）或十六进制颜色码（如 `"#FF0000"`） |
| `fg` / `foreground` | 文本前景颜色           | 颜色名称字符串或十六进制颜色码                               |
| `font`              | 文本字体样式           | 元组形式，如 `("微软雅黑", 12, "bold")` 或 `("Arial", 10)`   |
| `width`             | 标签宽度               | 整数；默认 `0` 表示根据内容自动调整                          |
| `height`            | 标签高度               | 整数；默认 `0` 表示根据内容自动调整                          |
| `padx`              | 水平内边距             | 整数，单位为像素                                             |
| `pady`              | 垂直内边距             | 整数，单位为像素                                             |
| `relief`            | 边框装饰样式           | `tk.FLAT`（默认）, `tk.RAISED`, `tk.SUNKEN`, `tk.GROOVE`, `tk.RIDGE` |
| `justify`           | 多行文本的对齐方式     | `tk.LEFT`, `tk.CENTER`, `tk.RIGHT`                           |
| `wraplength`        | 文本自动换行的宽度     | 整数，单位为像素；默认 `0` 表示不换行                        |

## 常用属性

`tk.Label` 继承自 `tk.Widget`，除了构造参数外，以下属性在开发中也较为常用：

| 属性名称     | 作用说明                                      |
| ------------ | --------------------------------------------- |
| `.master`    | 指向该标签所属的父容器对象                    |
| `.cget(key)` | 获取当前标签某个配置项（如 `"text"`）的当前值 |
| `.keys()`    | 返回该标签支持的所有配置参数键名的列表        |

## 常用方法

`tk.Label` 的方法主要用于动态更新显示内容、管理布局以及控制状态：

| 方法名称            | 作用说明                                                     |
| ------------------- | ------------------------------------------------------------ |
| `config(**options)` | 动态修改标签的属性（如 `label.config(text="新文本")`）。     |
| `pack()`            | 使用包管理器将标签放入父容器（常用参数：`side`, `fill`, `expand`）。 |
| `grid()`            | 使用网格管理器将标签放入父容器（常用参数：`row`, `column`, `sticky`）。 |
| `place()`           | 使用绝对定位管理器将标签放入父容器（常用参数：`x`, `y`, `width`, `height`）。 |
| `destroy()`         | 销毁该标签控件，将其从界面中移除。                           |
| `winfo_reqwidth()`  | 获取标签在当前配置下请求的宽度（像素）。                     |
| `winfo_reqheight()` | 获取标签在当前配置下请求的高度（像素）。                     |
| `bind()`            | 为标签绑定事件（如鼠标点击 `<Button-1>`），使其具备简单交互能力。 |

# 按钮

`tk.Button` 是 `tkinter` 中实现用户交互的核心控件之一。与 `tk.Label` 不同，按钮不仅用于显示文本或图片，还能响应用户的点击操作，从而触发特定的功能（即回调函数）。

## 创建对象的格式

创建 `tk.Button` 对象时，除了指定父容器和显示内容外，通常需要绑定一个点击事件的处理函数。以下是创建对象的标准语法格式：

```python
button = tk.Button(
    master,        # 父容器对象，即该按钮将被放置在哪个窗口或框架中
    text="点击我",  # 按钮上要显示的文本内容
    image=None,    # 按钮上要显示的图片对象（PhotoImage实例）
    command=None,  # 点击按钮时触发的回调函数（注意：只传函数名，不加括号）
    compound=None, # 当同时设置了text和image时，控制两者的相对位置
    anchor="center",# 控制文本或图片在按钮可用空间内的对齐方式
    bg="SystemButtonFace", # 按钮的背景颜色
    fg="SystemButtonText", # 按钮的文本颜色
    activebackground="SystemButtonFace", # 按钮被按下或激活时的背景颜色
    activeforeground="SystemButtonText", # 按钮被按下或激活时的文本颜色
    font=None,     # 文本的字体样式、大小等
    width=0,       # 按钮的宽度（以字符为单位，若显示图片则以像素为单位）
    height=0,      # 按钮的高度（以字符为单位，若显示图片则以像素为单位）
    padx=0,        # 按钮内部，文本与左右边框之间的水平内边距
    pady=0,        # 按钮内部，文本与上下边框之间的垂直内边距
    relief="raised",# 按钮边框的装饰样式（默认为凸起，模拟真实按钮）
    state="normal",# 按钮的交互状态（正常、禁用或激活）
    cursor="arrow", # 鼠标悬停在按钮上时的鼠标指针样式
    repeatdelay=0, # 按钮按下后，经过多少毫秒数触发
    repeatinterval=0, # 按钮长按时，持续触发的毫秒数
)
```

## 构造参数详解

`tk.Button` 继承自 `tk.Widget`，并拥有许多与 `tk.Label` 相似的视觉参数，但增加了交互相关的参数。以下是核心参数的作用及可选值：

| 参数名称            | 作用说明                   | 可选值 / 备注                                                |
| ------------------- | -------------------------- | ------------------------------------------------------------ |
| `master`            | 指定父容器                 | 通常是 `tk.Tk()` 或 `tk.Frame` 的实例。                      |
| `text`              | 显示的文本字符串           | 任意字符串。                                                 |
| `image`             | 显示的图片对象             | 必须是 `tk.PhotoImage` 或 `tk.BitmapImage` 的实例。          |
| `command`           | 点击触发的事件处理函数     | 函数名（如 `my_func`）或 `lambda` 表达式。                   |
| `compound`          | 文本与图片共存时的布局     | `tk.CENTER`，`tk.TOP`，`tk.BOTTOM`，`tk.LEFT`，`tk.RIGHT`。  |
| `anchor`            | 内容在按钮内的对齐方式     | `tk.CENTER`，`tk.N`，`tk.S`，`tk.E`，`tk.W`，`tk.NE` 等方位。 |
| `bg` / `background` | 按钮背景颜色               | 颜色名称字符串（如 `"blue"`）或十六进制颜色码。              |
| `fg` / `foreground` | 文本前景颜色               | 颜色名称字符串或十六进制颜色码。                             |
| `activebackground`  | 激活状态下的背景色         | 颜色名称字符串或十六进制颜色码。                             |
| `activeforeground`  | 激活状态下的文本色         | 颜色名称字符串或十六进制颜色码。                             |
| `font`              | 文本字体样式               | 元组形式，如 `("微软雅黑", 12, "bold")`。                    |
| `width` / `height`  | 按钮的宽度和高度           | 整数；默认 `0` 表示根据内容自动调整。                        |
| `padx` / `pady`     | 水平和垂直内边距           | 整数，单位为像素。                                           |
| `relief`            | 边框装饰样式               | `tk.RAISED`（默认）, `tk.FLAT`, `tk.SUNKEN`, `tk.GROOVE`, `tk.RIDGE`。 |
| `state`             | 按钮的交互状态             | `tk.NORMAL`（默认正常）, `tk.DISABLED`（禁用变灰）, `tk.ACTIVE`。 |
| `underline`         | 给文本中的某个字符加下划线 | 整数（从0开始计数），常用于配合快捷键提示。                  |

## 常用属性

`tk.Button` 继承自 `tk.Widget`，除了构造参数外，以下属性在开发中也较为常用：

| 属性名称     | 作用说明                                                     |
| ------------ | ------------------------------------------------------------ |
| `.master`    | 指向该按钮所属的父容器对象。                                 |
| `.cget(key)` | 获取当前按钮某个配置项（如 `"text"` 或 `"state"`）的当前值。 |
| `.keys()`    | 返回该按钮支持的所有配置参数键名的列表。                     |

## 常用方法

`tk.Button` 的方法主要用于动态更新外观、控制交互状态以及管理布局：

| 方法名称            | 作用说明                                                     |
| ------------------- | ------------------------------------------------------------ |
| `config(**options)` | 动态修改按钮的属性（如 `btn.config(text="已点击", state="disabled")`）。 |
| `invoke()`          | 在代码中模拟用户点击按钮，直接触发绑定的 `command` 回调函数。 |
| `flash()`           | 让按钮在激活态和正常态之间快速闪烁几次，提供视觉反馈。       |
| `pack()`            | 使用包管理器将按钮放入父容器（常用参数：`side`, `fill`, `expand`）。 |
| `grid()`            | 使用网格管理器将按钮放入父容器（常用参数：`row`, `column`, `sticky`）。 |
| `place()`           | 使用绝对定位管理器将按钮放入父容器（常用参数：`x`, `y`, `width`, `height`）。 |
| `destroy()`         | 销毁该按钮控件，将其从界面中移除。                           |
| `winfo_reqwidth()`  | 获取按钮在当前配置下请求的宽度（像素）。                     |
| `winfo_reqheight()` | 获取按钮在当前配置下请求的高度（像素）。                     |

# 子窗口

在 `Tkinter` 中，`Toplevel` 类用于创建独立于主窗口的**顶级子窗口**。它拥有自己的标题栏、边框等装饰，并且可以独立移动和调整大小。

与 `Tk` 类（整个应用程序的主窗口，一个程序只能有一个）不同，一个程序可以创建任意数量的 `Toplevel` 窗口。它们通常用于显示额外的窗口、对话框、设置面板或弹出提示框。

## 创建对象格式

```python
top = tk.Toplevel(
    master=None,    # 可选：指定该窗口的父窗口（通常是 Tk 实例）。如果不指定，默认使用当前的主窗口
    bg=None,        # 可选：窗口的背景颜色（如 'red', '#FF0000'）
    bd=None,        # 可选：边框宽度（以像素为单位），默认为 0
    height=None,    # 可选：窗口的初始高度（像素）
    width=None,     # 可选：窗口的初始宽度（像素）
    menu=None,      # 可选：为该窗口提供一个顶级菜单栏（Menu 对象）
    padx=None,      # 可选：窗口左侧和右侧的额外边距（像素）
    pady=None       # 可选：窗口顶部和底部的额外边距（像素）
)
```

## 参数详解

| 参数名称             | 作用说明                                                     | 常见可选值或示例              |
| -------------------- | ------------------------------------------------------------ | ----------------------------- |
| `master`             | 指定父窗口。子窗口会继承父窗口的某些属性，且父窗口关闭时子窗口也会随之关闭 | `root`（即 `tk.Tk()` 的实例） |
| `bg` / `background`  | 设置窗口的背景颜色                                           | `'lightblue'`、`'#1BA135'`    |
| `bd` / `borderwidth` | 设置窗口边框的宽度。必须配合 `relief` 参数才能看到边框效果   | `2`、`5`（默认为 0）          |
| `height` / `width`   | 设置窗口的初始高度和宽度（像素）                             | `300`、`400`                  |
| `menu`               | 为该窗口提供菜单栏。在 macOS 上会显示在屏幕顶部，在 Windows 上显示在窗口顶部 | `Menu` 对象实例               |
| `padx` / `pady`      | 设置窗口内容在水平和垂直方向上的额外边距                     | `10`、`20`                    |

## 常用属性

`Toplevel` 本身没有供开发者直接读取的公开数据属性，其状态和外观完全通过方法进行配置和获取。

## 常用方法

`Toplevel` 继承了 `Wm`（Window Manager）类，因此拥有与 `Tk` 主窗口几乎完全相同的窗口管理方法。

| 方法名称                   | 作用说明                                                     | 常见使用场景                                    |
| -------------------------- | ------------------------------------------------------------ | ----------------------------------------------- |
| `title(string)`            | 设置窗口的标题                                               | `top.title("设置面板")`                         |
| `geometry(geometry)`       | 设置窗口的大小和位置。<br />格式为 `"宽x高+x偏移+y偏移"`     | `top.geometry("400x300+100+100")`               |
| `resizable(width, height)` | 设置窗口是否允许调整大小                                     | `top.resizable(False, False)` 禁止调整大小      |
| `attributes(*args)`        | 设置平台特定的窗口属性（如透明度、置顶）                     | `top.attributes("-alpha", 0.8)` 设置 80% 透明度 |
| `transient(master)`        | 将窗口设置为父窗口的临时窗口。<br />它会**始终显示在父窗口之上**，且随父窗口最小化而最小化 | `top.transient(root)` 常用于模态对话框          |
| `grab_set()`               | **抓取全局焦点**，使该窗口成为模态窗口（阻止用户与父窗口交互） | 配合 `transient()` 实现强制弹出的确认框         |
| `destroy()`                | 销毁该子窗口。<br />仅关闭当前子窗口，不影响主窗口和其他子窗口 | 绑定到对话框的“取消”或“关闭”按钮                |
| `mainloop()`               | 启动子窗口的事件循环。<br />通常不需要对 `Toplevel` 调用此方法，主窗口的 `mainloop()` 会统一管理 | 仅在极少数独立运行子窗口的场景下使用            |

## 代码示例

```python
import tkinter as tk

class App:
    def __init__(self, root):
        self.root = root
        self.root.title("主窗口")
        self.root.geometry("400x300")

        # 在主窗口中放置一个按钮
        btn = tk.Button(
            root, 
            text="打开弹出窗口", 
            font=("Arial", 16), 
            command=self.open_popup
        )
        btn.pack(expand=True)

    def open_popup(self):
        # 1. 创建 Toplevel 子窗口，并指定父窗口为 self.root
        popup = tk.Toplevel(self.root)
        popup.title("弹出提示")
        popup.geometry("250x150")
        popup.resizable(False, False)  # 禁止调整大小

        # 2. 将子窗口设置为父窗口的临时窗口
        # 效果：子窗口始终显示在父窗口之上，且父窗口最小化时，子窗口也会跟着最小化
        popup.transient(self.root)

        # 3. 抓取全局焦点（模态窗口）
        # 效果：在子窗口关闭前，用户无法点击或操作主窗口
        popup.grab_set()

        # 4. 在子窗口中添加内容
        label = tk.Label(popup, text="这是一个模态弹出窗口！", font=("Arial", 12))
        label.pack(pady=30)

        # 5. 添加关闭按钮
        close_btn = tk.Button(
            popup, 
            text="我知道了", 
            command=popup.destroy  # 点击按钮销毁该子窗口
        )
        close_btn.pack(pady=10)

        # 6. 将焦点设置到子窗口上
        popup.focus_set()

if __name__ == "__main__":
    root = tk.Tk()
    app = App(root)
    root.mainloop()
```
