# 注册

`register` 是 `tkinter` 中用于实现高级输入验证（如 `validatecommand`）的核心方法。它的作用是将一个普通的 Python 函数包装成 Tcl/Tk 底层能够识别的回调函数，并返回一个字符串形式的函数引用，以便传递给 Tkinter 的验证参数。

## 使用格式

```python
tcl_func_ref = widget.register(
    func,            # 需要被包装的 Python 可调用对象（通常是验证函数）
    subst=None,      # 自定义的替换函数，用于在调用 func 之前处理传入的参数
    needcleanup=1    # 布尔值，指定当该组件被销毁时，是否需要自动清理底层的 Tcl 回调函数（默认为 1，即自动清理）
)
```

## 参数详解

| 参数名称      | 作用说明                                                     | 常见可选值                                                   |
| ------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `func`        | 需要被包装并注册到 Tcl/Tk 解释器的 Python 函数或方法         | 任意 Python 可调用对象<br />（如 `my_validate_func`）        |
| `subst`       | 自定义的数据预处理函数。<br />如果提供，Tkinter 会先将替换代码<br />（如 `%P`）的值传给此函数，再将返回值传给 `func` | 一个 Python 函数（默认为 `None`，<br />使用 Tkinter 默认的转换逻辑） |
| `needcleanup` | 控制底层 Tcl 函数的生命周期管理                              | `1`（默认，组件销毁时自动清理）、<br />`0`（不自动清理）     |

## 代码示例

以下是一个简单的示例，展示了如何使用 `register` 方法配合 `%W`（组件名称）替换代码，让同一个验证函数能够区分不同的输入框：

```python
import tkinter as tk

root = tk.Tk()
root.title("register方法示例")

# 1. 定义一个带参数的验证函数
def check_input(widget_name):
    print(f"触发验证的组件名称是: {widget_name}")
    return True  # 返回 True 表示验证通过，允许输入

# 2. 使用 register 方法将 Python 函数包装为 Tcl 回调，获取引用字符串
test_cmd = root.register(check_input)

# 3. 创建输入框，将引用字符串和替换代码 '%W' 组成元组传给 validatecommand
entry1 = tk.Entry(root, validate="key", validatecommand=(test_cmd, '%W'))
entry1.pack(pady=10)

entry2 = tk.Entry(root, validate="key", validatecommand=(test_cmd, '%W'))
entry2.pack(pady=10)

root.mainloop()
```

# 替换代码

## 介绍

在 Tkinter 的 `Entry` 控件中，`register` 方法用于将 Python 验证函数注册到 Tcl/Tk 解释器中。由于 Tkinter 底层基于 Tcl/Tk，Python 函数无法直接接收 Tk 内部的验证事件信息，因此需要通过**替换代码（Percent Substitution）**作为桥梁。

替换代码是以 `%` 开头的特殊字符串。当验证被触发时，Tkinter 会自动将这些代码替换为当前验证事件的真实数据（如输入的值、触发的原因等），并将它们作为参数传递给 Python 验证函数。

## 所有的替换代码

| 替换代码 | 传递的值     | 作用说明                                                     |
| -------- | ------------ | ------------------------------------------------------------ |
| `%d`     | 操作类型代码 | 指示正在尝试的操作类型。<br />`0` 表示删除（delete），<br />`1` 表示插入（insert），<br />`-1` 表示其他事件（如获得或失去焦点）。<br />注意：该值以字符串形式传递。 |
| `%i`     | 索引位置     | 对于插入或删除操作，表示被修改文本的起始索引位置（从 0 开始）。<br />对于非按键事件（如失去焦点），该值为 `-1`。注意：该值以字符串形式传递。 |
| `%P`     | 建议的新值   | 如果本次输入被允许，输入框中将显示的新文本内容。仅在按键（key）事件时有效。<br />这是实时验证中最常用的代码。 |
| `%s`     | 当前的旧值   | 在本次修改发生之前，输入框中原本存在的文本内容。仅在按键（key）事件时有效。 |
| `%S`     | 被修改的文本 | 正在被插入或删除的具体文本片段。仅在按键（key）事件时有效。  |
| `%v`     | 验证模式     | 当前 `Entry` 控件的 `validate` 选项的值（如 `key`、`focusout`、`all` 等）。 |
| `%V`     | 触发原因     | 触发本次验证的具体事件类型。可选值包括 <br />`focusin`（获得焦点）、<br />`focusout`（失去焦点）、<br />`key`（按键输入）、<br />`forced`（文本变量被强制更改）。 |
| `%W`     | 控件名称     | 触发验证的 `Entry` 控件在 Tcl/Tk 中的内部名称（字符串形式）。 |

## 核心使用提示

- 组合使用

  替换代码可以组合在一个元组中传递给 `validatecommand`。例如：`(registered_func, '%P', '%V')` 会将“建议的新值”和“触发原因”同时传给验证函数。

- 最常用组合

  在实时输入验证（`validate='key'`）中，最常用的是 `%P`（获取用户输入后的最新内容）和 `%S`（获取用户刚刚敲下的那个字符）。

- 数据类型

  所有通过替换代码传递的值，在 Python 函数中接收到的都是**字符串（str）**类型。如果需要进行数字比较，需要手动进行类型转换。

# 绑定

`bind` 是 `tkinter` 中用于为组件绑定事件和处理函数的核心方法。允许监听用户的操作（如鼠标点击、键盘输入等），并在事件发生时自动调用指定的回调函数。

## 使用格式

```python
widget.bind(
    sequence,        # 表示要绑定的事件类型的字符串（如 '<Button-1>'）
    func,            # 事件的处理函数（回调函数），当触发事件时被调用
    add=''           # 指定是替换还是追加绑定。空字符串表示替换，'+' 表示追加
)
```

## 参数详解

| 参数名称   | 作用说明                                                     | 常见可选值                                                   |
| ---------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `sequence` | 指定触发条件的事件码字符串，<br />必须包含在尖括号 `<>` 内   | `<Button-1>`（鼠标左键点击）<br />`<Return>`（回车键）<br />`<Key>`（任意按键）<br />`<Enter>`（鼠标进入）等 |
| `func`     | 事件触发时调用的回调函数。<br />该函数**必须**接收一个参数（通常命名为 `event`），<br />用于获取事件的详细信息。<br />如果函数返回的是 `break`，<br />则不会执行后续事件。 | 自定义函数名（如 `on_click`）或 `lambda` 表达式              |
| `add`      | 控制当前绑定与已有绑定的关系                                 | `''`（默认，替换该事件的其他绑定）<br />`'+'`（将该函数追加到该事件的绑定列表中） |

## 代码示例

以下是一个简单的示例，展示了如何使用 `bind` 方法绑定鼠标左键点击事件，并获取点击时的坐标：

```python
import tkinter as tk

root = tk.Tk()
root.title("bind方法示例")

# 定义事件处理函数，必须包含 event 参数
def on_click(event):
    print(f"鼠标点击位置：x={event.x}, y={event.y}")

# 创建一个画布并放置到窗口
canvas = tk.Canvas(root, width=300, height=200, bg="white")
canvas.pack(pady=20)

# 将鼠标左键点击事件绑定到画布上
canvas.bind("<Button-1>", on_click)

root.mainloop()
```

## 事件序列

在 Tkinter 中，事件序列（Event Sequence）用于定义和描述需要绑定的具体事件类型。它通常以**字符串**的形式表示，并且必须包含在**尖括号 `<...>`** 中。

### 格式与结构

事件序列的标准语法格式为：
`<modifier-type-detail>`

它由以下三个部分组成，各部分之间使用减号 `-` 分隔：

1. modifier（修饰符，可选）：
   通常用于描述组合键或连续动作。例如 `Control`、`Shift`、`Alt` 等组合键，或者 `Double`（双击）、`Triple`（三击）等连续动作。
2. type（事件类型，必填）：
   用于描述普通的事件类型，例如鼠标点击（`Button`）、键盘按键（`KeyPress`）、鼠标移动（`Motion`）等。
3. detail（事件细节，可选）：
   通常用于描述具体的按键或鼠标按键。例如 `1` 代表鼠标左键，`3` 代表鼠标右键，或者具体的字母 `A`。

#### 事件修饰符

| 修饰符名称 | 作用说明                                                     | 常见使用场景                                     |
| ---------- | ------------------------------------------------------------ | ------------------------------------------------ |
| `Control`  | 表示按下 `Ctrl` 键                                           | 绑定快捷键如 `Ctrl+C`、`Ctrl+V`                  |
| `Shift`    | 表示按下 `Shift` 键                                          | 绑定 `Shift+Tab`、<br />`Shift+Enter` 等组合操作 |
| `Alt`      | 表示按下 `Alt` 键                                            | 绑定 `Alt+F4`、<br />`Alt+Tab` 等系统级快捷键    |
| `Meta`     | 表示按下 `Meta` 键（在 Windows 上通常是 `Win` 键，在 macOS 上是 `Command` 键） | 绑定跨平台的元键组合，如 `Meta+S`                |
| `Double`   | 表示双击动作                                                 | 绑定双击鼠标左键 `<Double-Button-1>`             |
| `Triple`   | 表示三击动作                                                 | 绑定三击鼠标左键 `<Triple-Button-1>`             |
| `B1`       | 表示按住鼠标左键（Button-1）                                 | 绑定拖拽操作 `<B1-Motion>`                       |
| `B2`       | 表示按住鼠标中键（Button-2）                                 | 绑定中键拖拽 `<B2-Motion>`                       |
| `B3`       | 表示按住鼠标右键（Button-3）                                 | 绑定右键拖拽 `<B3-Motion>`                       |
| `Any`      | 表示任意修饰符（通常用于键盘事件）                           | 绑定任意组合键，如 `<Any-KeyPress>`              |

> **注意**
>
> - 组合使用
>
>   多个修饰符可以叠加使用，例如 `<Control-Shift-KeyPress-A>` 表示同时按下 `Ctrl`、`Shift` 和 `A` 键。
>
> - 大小写不敏感
>
>   修饰符名称在 Tkinter 中通常不区分大小写，但推荐使用首字母大写的标准写法（如 `Control` 而非 `control`）。
>
> - 鼠标修饰符
>
>   `B1`、`B2`、`B3` 是专门用于鼠标事件的修饰符，不能用于键盘事件。

#### 事件类型

### 常见内容示例

根据上述格式，Tkinter 支持多种事件序列的组合，以下是一些常见的示例：

- 基础鼠标事件：
  - `<Button-1>`：点击鼠标左键（`Button` 为类型，`1` 为细节）。
  - `<Button-3>`：点击鼠标右键。
  - `<Double-Button-1>`：双击鼠标左键（`Double` 为修饰符）。
  - `<B1-Motion>`：按住鼠标左键并移动。
- 基础键盘事件：
  - `<KeyPress>` 或简写 `<Key>`：按下键盘上的任意键。
  - `<KeyPress-H>`：按下键盘上的 H 键。
  - `<Return>`：按下回车键。
- 组合键事件：
  - `<Control-KeyPress-A>`：同时按下 Ctrl 键和 A 键（`Control` 为修饰符）。
  - `<Control-Shift-KeyPress-H>`：同时按下 Ctrl、Shift 和 H 键。
- 鼠标状态事件：
  - `<Enter>`：鼠标指针进入组件区域（注意：这不是指键盘的回车键）。
  - `<Leave>`：鼠标指针离开组件区域。

通过灵活组合 `modifier`、`type` 和 `detail`，开发者可以精确地捕获用户在图形界面上的各种复杂操作。

## 范围绑定

在 `tkinter` 中，`bind_all`、`bind_class` 和 `bindtags` 是三个用于控制事件绑定范围和优先级的高级方法，它们与常规的 `bind()` 方法共同构成了完整的事件处理体系。

### `bind_all`

> 全局事件绑定。

`bind_all` 用于为整个应用程序的所有组件绑定事件，无论哪个组件获得焦点，只要事件发生，绑定的处理函数就会被触发。它常用于实现全局快捷键或全局监听。

```python
import tkinter as tk

def global_shortcut(event):
    print("全局快捷键被触发！")

root = tk.Tk()
root.bind_all("<Control-Shift-X>", global_shortcut)  # 任意组件下按 Ctrl+Shift+X 都会触发
root.mainloop()
```

### `bind_class`

> 类级别事件绑定。

`bind_class` 用于为某一类组件（如所有 `Button`、所有 `Entry`）统一绑定事件。一旦绑定，该类的所有实例都会自动继承该事件处理逻辑，无需逐个设置。

```python
import tkinter as tk

def on_button_click(event):
    print(f"按钮 {event.widget['text']} 被点击")

root = tk.Tk()
btn1 = tk.Button(root, text="按钮1")
btn2 = tk.Button(root, text="按钮2")
btn1.pack()
btn2.pack()

root.bind_class("Button", "<Button-1>", on_button_click)  # 所有 Button 实例都会响应左键点击
root.mainloop()
```

### `bindtags`

>绑定标签与执行顺序控制。

`bindtags` 不是绑定事件的方法，而是用于**查看或修改**某个组件的事件绑定标签列表。`tkinter` 在处理事件时，会按照 `bindtags` 返回的**标签顺序**依次查找并执行绑定的处理函数。默认顺序通常是：组件自身 → 组件类 → 顶层窗口 → `all`。

在 Tkinter 中，当调用一个组件的 `bindtags()` 方法时，它会返回一个元组，这个元组定义了该组件在处理事件时，会按顺序检查哪些“绑定标签”（binding tags）。

> `('实例名', '类名', '父容器', 'all')` 

---

以 `Button ` 为例，元组 `('.!button', 'Button', '.', 'all')` 中的四个元素，分别代表了事件处理的四个层级：

- `'.!button'`

  这是该按钮组件自身的唯一名称（即实例名）。任何直接绑定到这个具体按钮上的事件处理函数，都会最先被检查。

- `'Button'`

  这是该组件所属的类名。所有绑定到 `Button` 类的事件处理函数（通过 `bind_class` 设置），会在实例绑定之后被检查。

- `'.'`

  表示父级窗口。这里是该组件的顶层窗口（通常是主窗口 `root`）的名称。绑定到顶层窗口的事件处理函数，会在类绑定之后被检查。

- `'all'`

  这是一个全局标签。所有通过 `bind_all` 绑定的全局事件处理函数，会在最后被检查。

---

>如果给定 `bindtags` 方法 `tagList` 参数，可以改变事件的执行顺序，这个 `tagList` 形式仿照 `bindtags` 返回的形式。比如只需要执行绑定的事件，而不需要执行其他事件，那么就设为 `button.bindtags(".!button")`。
>
>不要认为所有的 `Button` 组件的 Tcl 内部名称都是 `.!button`。设置组件的 `name` 参数可以设定组件的名称。而调用组件时写作的内部名称比较复杂，是父容器+组件名称这种写法。可以通过str(widget)返回组件的内部名称。

```python
import tkinter as tk

def custom_handler(event):
    print("自定义标签处理函数被调用")

root = tk.Tk()
label = tk.Label(root, text="点击我")
label.pack()

# 查看默认绑定标签
print(label.bindtags())  # 输出类似: ('.!Label', 'Label', '.', 'all')

# 自定义绑定标签并绑定事件
label.bindtags(("CustomTag",) + label.bindtags())  # 将自定义标签插入最前
label.bind("CustomTag", "<Button-1>", custom_handler)  # 绑定到自定义标签

root.mainloop()
```



# 事件

在 `tkinter` 中，`event` 并非一个由开发者手动实例化的类，而是由底层事件系统在事件触发时**自动创建并传递**给回调函数的对象。因此，它没有常规的构造函数，其“创建”完全依赖于事件绑定机制。

## 对象获取格式

`event` 对象是在事件绑定并触发时，由 `tkinter` 自动作为参数传递给处理函数的。其获取格式如下：

```python
def event_handler(event):     # 事件处理函数必须包含一个参数（通常命名为 event）
    # 当绑定的事件被触发时，tkinter 会自动生成 event 对象并传入此函数
    pass

widget.bind("<Button-1>", event_handler)  # 将事件序列与处理函数绑定
```

## 常用属性详解

`event` 对象携带了大量与事件相关的上下文信息，根据事件类型（鼠标、键盘、窗口等）的不同，其可用属性也会有所差异。

| 属性名称            | 作用说明                                                   | 常见适用场景                                               |
| ------------------- | ---------------------------------------------------------- | ---------------------------------------------------------- |
| `widget`            | 返回触发该事件的组件对象实例                               | 当多个组件共用一个处理函数时，用于区分是哪个组件触发了事件 |
| `x` / `y`           | 返回鼠标触发事件时，相对于**当前组件**左上角的坐标（像素） | 在 `Canvas` 上绘图、获取组件内的点击位置                   |
| `x_root` / `y_root` | 返回鼠标触发事件时，相对于**整个屏幕**左上角的坐标（像素） | 弹出右键菜单、拖动无边框窗口                               |
| `num`               | 返回触发事件的鼠标按键编号<br />（1=左键，2=中键，3=右键） | 判断用户按下了哪个鼠标按键                                 |
| `char`              | 返回触发事件的按键对应的实际字符（如 `'a'`, `'1'`）        | 捕获用户输入的字母、数字或符号（仅限键盘事件）             |
| `keysym`            | 返回触发事件的按键符号名称（如 `'Return'`, `'BackSpace'`） | 捕获功能键或特殊按键（仅限键盘事件）                       |
| `keycode`           | 返回触发事件的物理按键码（整数）                           | 跨平台时识别同一个物理按键（不区分大小写）                 |
| `delta`             | 返回鼠标滚轮的滚动量（正值向上，负值向下）                 | 实现滚轮缩放、滚动列表等交互                               |
| `width` / `height`  | 返回窗口或组件在 `<Configure>` 事件后的新尺寸              | 响应窗口大小变化，动态调整布局                             |
| `type`              | 返回事件类型的字符串标识（如 `'2'` 代表 `KeyPress`）       | 在通用事件处理器中区分事件类型                             |
| `state`             | 返回修饰键的状态码（如 `4`=Ctrl, `1`=Shift, `8`=Alt）      | 判断是否按下了组合键                                       |

>| 属性                            | 坐标系原点（参照物） | 作用说明                                                     |
>| ------------------------------- | -------------------- | ------------------------------------------------------------ |
>| `event.x` / `event.y`           | 当前组件的左上角     | 相对坐标。<br />表示鼠标点击位置距离触发事件的组件左上角的像素距离。 |
>| `event.x_root` / `event.y_root` | 整个屏幕的左上角     | 绝对坐标。<br />表示鼠标点击位置距离整个显示器屏幕左上角的像素距离。 |

## 常用方法详解

`event` 对象本身是一个数据容器，**不包含任何可调用的方法**。它的所有功能都体现在其属性上。开发者通过读取这些属性来获取事件信息，而不是调用方法。

# 虚拟事件

`event_generate` 是 `tkinter` 中用于**程序化触发事件**的方法，它允许开发者在不依赖用户实际操作的情况下，模拟生成并派发一个事件对象，从而激活已绑定的事件处理函数。

## 使用格式

```python
widget.event_generate(
    sequence, # sequence: 事件序列字符串，如 "<Button-1>"；
    **kwargs # **kwargs: 可选的事件属性参数，用于构造 event 对象的属性值
) 
```

## 参数详解

| 参数名称           | 作用说明                                                   | 常见可选值或示例                                             |
| ------------------ | ---------------------------------------------------------- | ------------------------------------------------------------ |
| `sequence`         | 指定要生成的事件类型，格式与 `bind()` 方法中的事件序列一致 | `"<Button-1>"`（左键点击）、<br />`"<KeyPress-a>"`（按下a键）、<br />`"<<CustomEvent>>"`（自定义虚拟事件） |
| `x`，`y`           | 设置事件发生时鼠标相对于组件的坐标                         | `x=100, y=200`                                               |
| `x_root`，`y_root` | 设置事件发生时鼠标相对于屏幕的坐标                         | `x_root=500, y_root=300`                                     |
| `keycode`          | 设置键盘事件的物理按键码                                   | `keycode=65`（对应A键）                                      |
| `keysym`           | 设置键盘事件的按键符号名称                                 | `keysym="Return"`（回车键）                                  |
| `char`             | 设置键盘事件输入的字符                                     | `char="a"`                                                   |
| `num`              | 设置鼠标事件的按键编号                                     | `num=1`（左键）、`num=3`（右键）                             |
| `delta`            | 设置鼠标滚轮的滚动量                                       | `delta=120`（向上滚动）                                      |
| `when`             | 控制事件插入队列的位置，影响执行时机                       | `"tail"`（默认，队尾）、`"head"`（队首）、`"mark"`（标记位置） |

## 代码示例

以下示例演示如何通过 `event_generate` 模拟点击按钮和触发自定义事件：

```python
import tkinter as tk

def on_button_click(event):
    print(f"按钮被点击！坐标: ({event.x}, {event.y})")

def on_custom_event(event):
    print(f"自定义事件触发！数据: {event.data}")

root = tk.Tk()

# 创建按钮并绑定点击事件
btn = tk.Button(root, text="点击我")
btn.pack(pady=10)
btn.bind("<Button-1>", on_button_click)

# 绑定自定义虚拟事件
root.bind("<<MyCustomEvent>>", on_custom_event)

# 模拟按钮点击（程序化触发）
btn.event_generate("<Button-1>", x=50, y=20)

# 触发自定义事件并传递额外数据
root.event_generate("<<MyCustomEvent>>", data="Hello from event_generate!")

root.mainloop()
```

# 解绑

在 Tkinter 中，`unbind` 方法用于撤销之前通过 `bind` 绑定的事件处理逻辑。它允许开发者在程序运行过程中动态地移除组件对特定事件的响应能力。

## 使用格式

```python
widget.unbind(
    sequence,     # 要解除绑定的事件序列字符串（如 '<Button-1>'）
    funcid=None   # 要解除绑定的特定回调函数引用。若省略，则移除该事件的所有绑定
)
```

## 参数详解

| 参数名称   | 作用说明                                                     | 常见可选值或示例                                             |
| ---------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `sequence` | 指定要解除绑定的事件类型，<br />格式与 `bind()` 方法中的事件序列完全一致 | `"<Button-1>"`（鼠标左键点击）、<br />`"<KeyPress-a>"`（按下a键）、<br />`"<<CustomEvent>>"`（自定义虚拟事件） |
| `funcid`   | 指定要解除绑定的特定回调函数。<br />如果省略此参数，将移除该组件上绑定到该事件的所有处理函数 | 之前通过 `bind()` 绑定的函数名<br />（如 `my_callback`）     |

> `sequence` 是空字符串可以一次性解除所有事件的绑定。

### 代码示例

以下示例演示了如何解除绑定，以及解除特定函数绑定的场景：

```python
import tkinter as tk

root = tk.Tk()
root.title("unbind方法示例")

def on_click(event):
    print("按钮被点击！")

def on_hover(event):
    print("鼠标悬停！")

btn = tk.Button(root, text="测试按钮")
btn.pack(pady=20)

# 绑定两个事件处理函数
btn.bind("<Button-1>", on_click)
btn.bind("<Button-1>", on_hover, add="+")  # 使用 add="+" 追加绑定

# 1. 解除绑定特定的函数（只移除 on_click，on_hover 仍然有效）
btn.unbind("<Button-1>", on_click)

# 2. 解除绑定的所有函数（如果不传第二个参数，该事件的所有处理函数都会被移除）
# btn.unbind("<Button-1>") 

root.mainloop()
```

# 焦点

`focus_set`，用于将键盘输入焦点设置到指定的组件上，使其能够直接接收用户的键盘输入。

## 使用格式

```python
widget.focus_set()  # widget: 需要获取焦点的组件实例（如输入框、按钮等）
```

## 参数详解

| 参数名称 | 作用说明                                                     | 常见可选值或示例                                |
| -------- | ------------------------------------------------------------ | ----------------------------------------------- |
| 无参数   | 该方法不需要传入任何参数。调用后，`Tkinter` 会尝试将焦点转移到该组件上，但前提是：<br />1. 组件处于可见状态；<br />2. 组件未被禁用（`state='normal'`）；<br />3. 组件支持接收焦点（默认 `takefocus=True`）；<br />4. 其所在的顶层窗口已经处于激活状态。 | 例如：`entry.focus_set()`、`button.focus_set()` |

## 代码示例

以下示例演示了如何在程序启动时，自动将焦点设置到第一个输入框中，方便用户直接开始输入：

```python
import tkinter as tk

root = tk.Tk()
root.title("focus_set 示例")
root.geometry("300x200")

# 创建两个输入框
entry1 = tk.Entry(root, font=("Arial", 14))
entry1.pack(pady=20)

entry2 = tk.Entry(root, font=("Arial", 14))
entry2.pack(pady=20)

# 核心操作：将焦点设置到 entry1
# 程序运行后，光标会自动在 entry1 中闪烁，无需用户先用鼠标点击
entry1.focus_set()

root.mainloop()
```

# 时间间隔

在 `Tkinter` 中，`after` 方法是实现非阻塞式定时任务和异步操作的核心工具。它允许你在指定的毫秒数后执行一个函数，而不会像 `time.sleep()` 那样冻结整个 GUI 界面。

它会返回唯一的 `after_id`，配合 `after_cancel` 可以关闭。

## 使用格式

```python
after_id = widget.after(
    delay_ms,   # 延迟时间，单位为毫秒（ms）。例如 2秒 就是 2000
    func=None,  # 延迟时间到达后要执行的回调函数
    *args       # 传递给回调函数的额外参数
)
```

## 参数详解

| 参数名称   | 作用说明                                                     | 常见可选值或示例                          |
| ---------- | ------------------------------------------------------------ | ----------------------------------------- |
| `delay_ms` | 指定延迟的时间长度，单位为毫秒。<br />例如，延迟 3 秒应传入 `3000` | `1000`（1秒）、`500`（0.5秒）             |
| `func`     | 延迟结束后要执行的回调函数。<br />必须传递函数引用，而不是函数的调用结果 | `my_callback`、`lambda: my_callback(arg)` |
| `*args`    | 传递给 `func` 的额外参数。<br />如果回调函数需要接收参数，可以在这里依次传入 | `"Hello"`、`100`                          |

## 代码示例

以下示例演示了如何使用 `after` 实现单次延迟执行，以及如何通过递归调用实现周期性定时任务（如简单的时钟）：

```python
import tkinter as tk
import time

root = tk.Tk()
root.title("after 方法示例")

label = tk.Label(root, text="等待中...", font=("Arial", 24))
label.pack(pady=50)

# 1. 单次延迟执行：3秒后更新文本
def update_text():
    label.config(text="3秒已到！")
root.after(3000, update_text)

# 2. 周期性定时任务：每秒更新一次当前时间
def update_clock():
    current_time = time.strftime("%H:%M:%S")
    label.config(text=current_time)
    # 在函数末尾再次调用 after，实现循环执行
    root.after(1000, update_clock)

# 启动时钟
root.after(1000, update_clock)

root.mainloop()
```
