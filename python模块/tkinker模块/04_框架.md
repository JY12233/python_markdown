# 框架

`tk.Frame` 是 `tkinter` 中用于**布局和容器管理**的基础控件。与之前介绍的 Label、Button 等具有视觉展示或交互功能的控件不同，`Frame` 本身通常是不可见的（除非设置了边框或背景色）。它的核心作用是作为一个“容器”，将多个子控件组合在一起，从而实现复杂界面的模块化布局。

## 创建对象的格式

创建 `tk.Frame` 对象时，主要指定其父容器，并可以通过设置边框和背景色使其在视觉上与其他区域区分开。以下是创建对象的标准语法格式：

```python
frame = tk.Frame(
    master,           # 父容器对象，即该框架将被放置在哪个窗口或框架中
    bg=None,          # 框架的背景颜色（设为颜色值可使其在视觉上显现）
    relief="flat",    # 框架边框的装饰样式（设为其他值可使其显现）
    borderwidth=0,    # 边框的宽度（以像素为单位，默认0表示无边框）
    width=0,          # 框架的宽度（以像素为单位，默认0表示自动调整）
    height=0,         # 框架的高度（以像素为单位，默认0表示自动调整）
    padx=0,           # 框架内部，子控件与左右边框之间的水平内边距
    pady=0,           # 框架内部，子控件与上下边框之间的垂直内边距
    cursor="arrow",   # 鼠标悬停在框架上时的鼠标指针样式
    highlightthickness=0 # 焦点高亮边框的宽度（默认0表示不显示）
)
```

## 构造参数详解

`tk.Frame` 的参数主要围绕容器的尺寸、视觉边界以及内部间距展开。以下是核心参数的作用及可选值：

| 参数名称             | 作用说明                 | 可选值 / 备注                                                |
| -------------------- | ------------------------ | ------------------------------------------------------------ |
| `master`             | 指定父容器               | 通常是 `tk.Tk()` 或另一个 `tk.Frame` 的实例                  |
| `bg` / `background`  | 框架背景颜色             | 颜色名称字符串（如 `"lightgray"`）或十六进制颜色码           |
| `relief`             | 边框装饰样式             | `tk.FLAT`（默认）, `tk.RAISED`, `tk.SUNKEN`, `tk.GROOVE`, `tk.RIDGE` |
| `borderwidth` / `bd` | 边框的宽度               | 整数，单位为像素；默认 `0`                                   |
| `width` / `height`   | 框架的宽度和高度         | 整数，单位为像素；默认 `0` 表示根据子控件自动调整            |
| `padx` / `pady`      | 内部填充（内边距）       | 整数，单位为像素；用于控制子控件与框架边缘的距离             |
| `cursor`             | 鼠标悬停时的指针样式     | 如 `"arrow"`, `"hand2"`, `"cross"` 等                        |
| `highlightthickness` | 焦点高亮边框宽度         | 整数，单位为像素；当框架获取键盘焦点时显示                   |
| `takefocus`          | 是否允许框架获取键盘焦点 | `True`（默认）, `False`                                      |

## 常用属性

`tk.Frame` 继承自 `tk.Widget`，除了构造参数外，以下属性在开发中也较为常用：

| 属性名称     | 作用说明                                                 |
| ------------ | -------------------------------------------------------- |
| `.master`    | 指向该框架所属的父容器对象                               |
| `.cget(key)` | 获取当前框架某个配置项（如 `"bg"` 或 `"width"`）的当前值 |
| `.keys()`    | 返回该框架支持的所有配置参数键名的列表                   |

## 常用方法

`tk.Frame` 的方法主要用于管理其内部的子控件、动态更新外观以及控制布局：

| 方法名称            | 作用说明                                                     |
| ------------------- | ------------------------------------------------------------ |
| `pack()`            | 使用包管理器将框架放入父容器（常用参数：`side`, `fill`, `expand`） |
| `grid()`            | 使用网格管理器将框架放入父容器（常用参数：`row`, `column`, `sticky`） |
| `place()`           | 使用绝对定位管理器将框架放入父容器（常用参数：`x`, `y`, `width`, `height`） |
| `config(**options)` | 动态修改框架的属性（如 `frame.config(bg="blue", relief="raised")`） |
| `destroy()`         | 销毁该框架及其内部包含的所有子控件                           |
| `winfo_children()`  | 返回该框架内所有直接子控件对象的列表                         |
| `winfo_reqwidth()`  | 获取框架在当前配置下请求的宽度（像素）                       |
| `winfo_reqheight()` | 获取框架在当前配置下请求的高度（像素）                       |
| `propagate(flag)`   | 控制框架是否根据子控件自动调整自身大小（`True` 默认开启，`False` 关闭） |

> `tk.Frame` 是构建复杂 GUI 界面的基石。在实际开发中，你通常会将一个主窗口划分为几个大的 `Frame`（例如：顶部导航栏 Frame、左侧菜单 Frame、右侧内容区 Frame），然后在每个 Frame 内部再使用 `pack()` 或 `grid()` 布局具体的按钮和标签。

## 边框颜色

`Tkinter` 原生并不支持直接修改 `relief` 边框的颜色（它默认与背景色或系统主题绑定）。如果需要**自定义边框颜色**，最通用的方法是“嵌套 Frame 法”。

```python
# 外层 Frame 作为“边框”
border_frame = tk.Frame(root, background="red", bd=0) 
border_frame.pack(padx=20, pady=20)

# 内层 Frame 作为实际内容区，留出 1 像素的边距露出外层颜色
content_frame = tk.Frame(border_frame, bg="white", bd=0)
content_frame.pack(padx=2, pady=2) 

tk.Label(content_frame, text="自定义红色边框").pack(padx=20, pady=10)
```

# 文本框架

`LabelFrame` 是 `tkinter` 中一个非常实用的容器类控件。它本质上是一个带有边框和标题的 `Frame`，主要用于在界面上将一系列相关的控件（如单选按钮、表单输入框等）进行逻辑分组，从而提供清晰的视觉层次。

## 创建对象格式

```python
label_frame = tk.LabelFrame(
    master=root,          # 指定父容器（如主窗口或另一个Frame），必选
    text="分组标题",       # 设置显示在边框上的标签文字
    font=("Arial", 10),   # 设置标签文字的字体、大小和样式
    fg="blue",            # 设置标签文字的前景色（颜色）
    bg="white",           # 设置 LabelFrame 的背景颜色
    bd=2,                 # 设置边框的宽度（像素）
    relief=tk.GROOVE,     # 设置边框的样式
    labelanchor=tk.NW,    # 设置标签文字在边框上的锚点位置
    padx=10,              # 设置内部控件与边框之间的水平内边距
    pady=10               # 设置内部控件与边框之间的垂直内边距
    labelwidget=None 	  # 使用自定义的控件代替文字
)
```

## 参数详解

| 参数名称             | 作用说明                         | 常见可选值                                                   |
| -------------------- | -------------------------------- | ------------------------------------------------------------ |
| `master`             | 指定该控件的父容器               | 窗口对象（如 `root`）或其他容器控件                          |
| `text`               | 设置分组框架的标题文本           | 任意字符串                                                   |
| `font`               | 设置标题文本的字体样式           | 元组格式，如 `("微软雅黑", 12, "bold")`                      |
| `fg` / `foreground`  | 设置标题文本的颜色               | 颜色名称（如 `"red"`）或十六进制颜色码                       |
| `bg` / `background`  | 设置框架的背景颜色               | 颜色名称或十六进制颜色码                                     |
| `bd` / `borderwidth` | 设置边框的宽度                   | 整数（像素），默认通常为 `2`                                 |
| `relief`             | 设置边框的立体样式               | `tk.FLAT`（默认）、`tk.GROOVE`、`tk.RIDGE`、`tk.RAISED`、`tk.SUNKEN` |
| `labelanchor`        | 控制标题文本在边框上的显示位置   | `tk.NW`（左上，默认）、`tk.N`（上中）、`tk.W`（左中）等方位常量 |
| `padx` / `pady`      | 设置框架内部内容与边框之间的间距 | 整数（像素）                                                 |
| `labelwidget`        | 使用自定义控件替代默认的文本标签 | 其他 Tkinter 控件对象（如 `tk.Label`）                       |

## 常用属性

| 属性名称            | 作用说明                                 |
| ------------------- | ---------------------------------------- |
| `text`              | 获取或动态修改 LabelFrame 的标题文本内容 |
| `bg` / `background` | 获取或修改框架的背景颜色                 |
| `fg` / `foreground` | 获取或修改标题文本的颜色                 |
| `relief`            | 获取或修改边框的立体样式                 |

## 常用方法

| 方法名称                        | 作用说明                                                     |
| ------------------------------- | ------------------------------------------------------------ |
| `configure(**options)`          | 动态修改 LabelFrame 的一个或多个配置参数（可简写为 `config`） |
| `cget(option)`                  | 获取当前某个配置参数的值（例如 `cget("text")`）              |
| `pack()` / `grid()` / `place()` | 继承自父类的布局管理方法，用于将 LabelFrame 放置在父容器中   |
