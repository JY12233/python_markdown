# Numpy

## 介绍

- **定义与地位**：NumPy（Numerical Python）是 Python 数据分析不可或缺的第三方库。
- 核心价值
  - 显著提升 Python 的数值运算性能；
  - 提供更精确、高效的数据类型（如 `ndarray`），支持构建复杂数据结构。
- **实现基础**：由 C 语言开发，是 Python 科学计算生态（如 SciPy、Pandas、Matplotlib 等）的基础包；理解其数据类型对数据分析至关重要。
- **主要功能**：专注于**数值计算**，尤其擅长**多维数组（矩阵）**的存储与高效处理，性能远超 Python 原生嵌套列表。

## 数组类

被叫做`ndarry`。

> 支持**布尔索引（Boolean Indexing）**，也叫 **布尔掩码（Boolean Masking）**。

1. 常用属性

   | 属性名称           | 说明                                                         |
   | ------------------ | ------------------------------------------------------------ |
   | `ndarray.ndim`     | 数组的维度（轴）数量，即秩（rank）。                         |
   | `ndarray.shape`    | 数组的形状，返回一个表示各维度大小的元组（如 `(3, 4)` 表示 3 行 4 列）。 |
   | `ndarray.size`     | 数组中元素的总个数，等于 `shape` 各维度乘积。                |
   | `ndarray.dtype`    | 数组中元素的数据类型（如 `int64`, `float32`, `bool` 等）。   |
   | `ndarray.itemsize` | 每个元素占用的字节数（例如 `int32` 为 4 字节，`float64` 为 8 字节）。 |
   | `nd.array.T`       | 矩阵转置。                                                   |

2. 创建

   > 下标从 0 开始（符合 Python 通用规范）；
   > 所有元素必须为相同数据类型（dtype 统一），保障高效计算与内存布局紧凑。

   - 转化列表

     `np.array(list)`

   - 创建一维数组

     `np.arange(start, stop, step, dtype)`

     类似python中的`range`。

   - 创建随机数矩阵

     1. 生成指定维度大小的随机多维浮点型数据

        `np.random.rand(row, col)`

        生成指定行列的数组，元素范围是$[0, 1)$。如果没有指定大小，会返回范围内的随机浮点数。

     2. 生成指定维度大小的随机多维整形数据

        `np.random.randint(start, stop, size: tuple, dtype)`

        `start`默认为0。

     3. 生成指定维度大小的随机多维浮点型数据

        `np.random.uniform(start, stop, size: tuple)`

     4. 生成具有标准正态分布的序列

        `np.random.randn(size)`

3. 类型转换

   `np.array.astype(Numpy的数据类型)`

4. 等比数列

   `np.logspace(start, stop, num=50, base=10, dtype, endpoint=True)`

   - `base`：决定开始点与结束点的底数。

   - `start`：开始点，数值为${base}^{start}$。

   - `stop`：结束点，数值为${base}^{stop}$。
   - `num`：生成的元素的个数，默认为50。
   - `dtype`：元素的类型，没有设置，默认返回的是`np.float64`的类型。
   - `endpoint`：设置是否包含结束点。

5. 等差数列

   `np.linspace(start, stop, num=50, dtype, restep=False, enpoint=True)`

   - `start`：起始值。
   - `stop`：终止值。
   - `num`：元素个数。
   - `dtype`：元素类型。
   - `restep`：设置为`True`时会返回元组，第一个是数组，第二个是公差。
   - `endpoint`：设置是否包含结束点。

   > 等差等比的公差与公比由开始值、结束值和元素个数决定。

## 内置函数

| 函数名                             | 说明                                                         |
| ---------------------------------- | ------------------------------------------------------------ |
| ``np.ceil()``                      | 向上取整：返回每个元素**不小于该值的最小整数**；参数可为标量 `number` 或数组 `array`。 |
| ``np.floor()``                     | 向下取整：返回每个元素**不大于该值的最大整数**；参数可为标量 `number` 或数组 `array`。 |
| ``np.rint()``                      | 四舍五入到最近整数（**.5 向偶数方向取整**，即“银行家舍入”）；参数可为标量 `number` 或数组 `array`。 |
| ``np.isnan()``                     | 判断元素是否为 `NaN`（Not a Number）；返回布尔数组；参数可为标量或数组。 |
| ``np.multiply()``                  | 元素级乘法（等价于 `*` 运算符）；支持广播；参数可为标量或数组。**哈达玛积（Hadamard Product）** |
| ``np.divide()``                    | 元素级除法（等价于 `/` 运算符）；支持广播；参数可为标量或数组。 |
| ``np.abs()``                       | 计算元素的绝对值；参数可为标量或数组。                       |
| ``np.where(condition, x, y)``      | 三元运算符：若 `condition` 为真，取 `x` 对应元素；否则取 `y` 对应元素；支持数组广播。 |
| `np.zeros(size: tuple, dtype)`     | 生成指定维度大小的全为0的数据。                              |
| `np.ones(size: tuple, dtype)`      | 生成指定维度大小的全为1的数据。                              |
| `np.unique()`                      | 找到唯一值并返回排序结果，类似python中的集合。               |
| `np.sort()`或者`np.ndarray.sort()` | 对数组元素进行排序。                                         |

## 统计函数

| 函数名           | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| ``np.mean()``    | 计算所有元素的**算术平均值**；参数可为标量 `number` 或数组 `array`。 |
| ``np.sum()``     | 计算所有元素的**总和**；参数可为标量 `number` 或数组 `array`。 |
| ``np.max()``     | 返回所有元素的**最大值**；参数可为标量 `number` 或数组 `array`。 |
| ``np.min()``     | 返回所有元素的**最小值**；参数可为标量 `number` 或数组 `array`。 |
| ``np.std()``     | 计算所有元素的**标准差**（总体标准差，默认 `ddof=0`）；参数可为标量或数组。 |
| ``np.var()``     | 计算所有元素的**方差**（总体方差，默认 `ddof=0`）；参数可为标量或数组。 |
| ``np.argmax()``  | 返回**最大值的下标索引**（沿默认轴，扁平化后取全局最大值索引）；参数可为标量或数组。 |
| ``np.argmin()``  | 返回**最小值的下标索引**；参数可为标量或数组。               |
| ``np.cumsum()``  | 返回一维累加数组：第 `i` 个元素 = 前 `i+1` 个元素之和；支持多维数组（默认展平）；参数可为标量或数组。 |
| ``np.cumprod()`` | 返回一维累乘数组：第 `i` 个元素 = 前 `i+1` 个元素之积；支持多维数组（默认展平）；参数可为标量或数组。 |

> `axis` 参数说明
>
> - 默认行为：
>
>   - 若不指定 `axis`，统计函数（如 `mean()`, `sum()`, `max()` 等）会对**所有元素**进行计算，返回一个标量值。
>
> - 指定轴（`axis`）的作用：
>
>   - `axis=0`
>
>     按列统计（沿行方向压缩）。
>
>     - 例如，对二维数组，会分别计算每一列的统计值，结果是一个长度等于列数的一维数组。
>
>   - `axis=1`
>
>     按行统计（沿列方向压缩）。
>
>     - 例如，对二维数组，会分别计算每一行的统计值，结果是一个长度等于行数的一维数组。

## 矩阵乘法

| 操作       | NumPy 代码                                                   | 描述                |
| ---------- | ------------------------------------------------------------ | ------------------- |
| 逐元素乘法 | `A * B`                                                      | 对应位置元素相乘。  |
| 矩阵乘法   | `A @ B` 或 `np.dot(A, B)` 或 `np.matmul(A, B)`或者`np.ndarray.dot()` | 线性代数矩阵乘法。  |
| 逐元素平方 | `A ** 2`                                                     | 每个元素自乘。      |
| 矩阵乘自身 | `A @ A`                                                      | 线性代数中的$A^2$。 |
