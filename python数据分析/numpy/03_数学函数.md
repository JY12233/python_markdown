# 三角函数

NumPy 的三角函数使用的是**弧度制**。如果你传入的是角度值，必须先将其转换为弧度，否则计算结果会完全错误。

## 核心转换公式

- **角度转弧度**：`radians = degrees * π / 180`
- **弧度转角度**：`degrees = radians * 180 / π`

## NumPy 内置转换函数

NumPy 提供了两个专用函数，可直接用于数组或标量，无需手动计算：

```python
import numpy as np

# 角度转弧度
angle_degrees = 30
angle_radians = np.deg2rad(angle_degrees)  # 等价于 angle_degrees * np.pi / 180

# 弧度转角度
radian_value = np.pi / 6
degree_value = np.rad2deg(radian_value)    # 等价于 radian_value * 180 / np.pi
```
