# 画布的创建

```python
plt.figure(
    num=None,       # 画布的编号或名称
    figsize=None,   # 画布的宽度和高度（单位：英寸）
    dpi=None,       # 画布的分辨率（每英寸像素数）
    facecolor=None, # 画布的背景颜色
    edgecolor=None, # 画布的边框颜色
    frameon=True,   # 是否绘制边框
    clear=False     # 如果画布已存在，是否清除原有内容
)
```

返回 `Figure` 对象。

# 常用方法

`plt.figure()` 函数返回的是一个 `matplotlib.figure.Figure` 对象。在 Matplotlib 的面向对象体系中，`Figure` 是整个图形的最顶层容器（可以看作一块画布），它包含了所有的子图（Axes）、标题、图例等元素。

## 子图管理

这是 `Figure` 对象最核心的功能，用于在画布上添加和管理具体的绘图区域。

- `add_subplot(nrows, ncols, index)` 

  以网格布局的方式在 `Figure` 中添加一个子图，并返回一个 `Axes` 对象。参数分别代表行数、列数和子图索引。

- `add_axes(rect)` 

  在 `Figure` 的任意位置添加一个自定义大小的子图。`rect` 是一个列表 `[左边界, 底边界, 宽度, 高度]`，取值范围为 0-1（对应画布的百分比）。

- `suptitle(t)`：为整个 `Figure` 添加一个总标题（区别于单个子图的标题）。

## 获取画布属性

当你需要检查或获取当前画布的状态时，可以使用以下方法：

- **`get_size_inches()`**：获取当前画布的大小，返回一个包含宽度和高度的元组（单位为英寸）。
- **`get_dpi()`**：获取画布的分辨率（每英寸点数 DPI），这会影响图形保存时的清晰度。
- **`get_facecolor()`**：获取画布的背景颜色，返回一个 RGBA 元组。
- **`get_edgecolor()`**：获取画布的边框颜色，返回一个 RGBA 元组。

## 获取内部元素

`Figure` 作为一个容器，内部存储了各种绘图对象，可以通过以下属性或方法获取：

- **`axes` 属性**：返回一个包含该画布中所有子图（Axes）对象的列表。如果你需要遍历所有子图进行统一设置（如添加网格），非常有用。
- **`get_children()`**：获取画布中所有的子元素（包括子图、文本、矩形背景等）。

## 4. 输出与显示

- **`savefig(fname, \**kwargs)`**：将当前的 `Figure` 保存为图像文件（如 png, jpg, pdf 等）。`fname` 为文件路径，还可以在此处指定保存时的 DPI、边框是否裁剪等参数。
- **`show()`**：在屏幕上渲染并显示当前的图形。

**使用示例：**

```python
import matplotlib.pyplot as plt

# 1. 创建 Figure 对象
fig = plt.figure(figsize=(8, 6), dpi=100, facecolor='white')

# 2. 在 Figure 上添加子图（Axes）
ax = fig.add_subplot(111)
ax.plot([1, 2, 3], [1, 4, 9])

# 3. 获取并打印画布大小
print(fig.get_size_inches())  # 输出: [8. 6.]

# 4. 保存画布
fig.savefig('my_plot.png')

# 5. 显示画布
plt.show()
```

# 网格布局的解释

`add_subplot(nrows, ncols, index)` 

“以网格布局的方式”其实就是把整张画布（Figure）想象成一个**隐形的表格**，然后在这个表格的格子里放图。

我们可以通过以下三个步骤来通俗理解：

## 把画布切成“表格”（nrows, ncols）

- `nrows`：代表把画布切成几**行**。
- `ncols`：代表把画布切成几**列**。
- 比如 `nrows=2, ncols=3`，就等于在画布上画了一个 **2行3列** 的表格，总共有 6 个格子。

## 给每个格子“编号”（index）

Matplotlib 会按照**从左到右、从上到下**的顺序，给这些格子从 1 开始编号：

- 第一行的格子编号是：1, 2, 3。
- 第二行的格子编号是：4, 5, 6。

## 把图“放进”指定的格子（index）

当你调用 `add_subplot(2, 3, 1)` 时，意思就是：“把画布切成 2 行 3 列，然后我要在**第 1 个格子**里画图”。

## 直观的代码示例

假设你想在一个画布上画 4 个图，摆成一个“田”字格（2行2列）：

```python
import matplotlib.pyplot as plt

# 1. 创建画布
fig = plt.figure(figsize=(10, 8))

# 2. 把画布切成 2行2列，并在第1个格子（左上角）画图
ax1 = fig.add_subplot(2, 2, 1)
ax1.plot([1, 2, 3], [1, 4, 9])
ax1.set_title('第1个格子 (左上)')

# 3. 在第2个格子（右上角）画图
ax2 = fig.add_subplot(2, 2, 2)
ax2.plot([1, 2, 3], [9, 4, 1])
ax2.set_title('第2个格子 (右上)')

# 4. 在第3个格子（左下角）画图
ax3 = fig.add_subplot(2, 2, 3)
ax3.plot([1, 2, 3], [1, 2, 3])
ax3.set_title('第3个格子 (左下)')

# 5. 在第4个格子（右下角）画图
ax4 = fig.add_subplot(2, 2, 4)
ax4.plot([1, 2, 3], [3, 2, 1])
ax4.set_title('第4个格子 (右下)')

plt.show()
```

## 总结

“以网格布局的方式”就是**切蛋糕**：

- 前两刀决定切几行几列（`nrows`, `ncols`）。
- 最后一个参数决定你在哪一块蛋糕上放草莓（`index`）。

**补充说明**：这种布局方式非常规整，但缺点是它要求每个格子大小一样。如果你想在一张画布上画一个“一大一小”的图（比如左边占2/3，右边占1/3），就需要用到我们之前提到的另一个方法 `add_axes()` 来手动指定坐标了。

# `add_subplot`

```python
x = np.linspace(0, 2* np.pi, 400)
y1 = np.sin(x )+x
y2 = np.sin(x ** 2)+2*x
y3 = np.sin(x ** 3)+3*x
y4 = np.sin(x ** 4)+4*x

# 2.创建一个新的图形对象
fig = plt.figure()

# 2.1 在2x2的网格中添加子图
ax1 = fig.add_subplot(2, 2, 1) # 左上
ax2 = fig.add_subplot(2, 2, 2) # 右上
ax3 = fig.add_subplot(2, 2, 3) # 左下
ax4 = fig.add_subplot(2, 2, 4) # 右下

# 2.2.再各个子图中绘制数据

ax1.plot(x, y1)
ax1.set_title('Subplot 1')

ax2.plot(x, y2)
ax2.set_title('Subplot 2')

ax3.plot(x, y3)
ax3.set_title('Subplot 3')

ax4.plot(x, y4)
ax4.set_title('Subplot 4')

plt.show()
```

## 不传参数并不会报错

在源码的 `Parameters` 部分，明确写着：

> ```python
> *args : int, (int, int, *index*), or .SubplotSpec, default: (1, 1, 1)
> ```

这说明，如果你直接调用 `fig.add_subplot()` 而不传任何参数，它**不会抛出 TypeError 报错**，而是会使用默认值 `(1, 1, 1)`。也就是说，它等同于 `fig.add_subplot(1, 1, 1)`，直接在画布上创建一个铺满全屏的默认子图。

## 2. 极其灵活的参数传递方式

源码中列出了四种合法的调用签名（Call signatures），Matplotlib 对 `*args` 做了非常聪明的解析：

- **三整数模式**

  `add_subplot(nrows, ncols, index)`。

  这是最标准、最通用的写法。

- **三合一整数模式**

  `add_subplot(pos)`。

  源码特别指出，如果传入一个三位数整数（如 `235`），它会被自动拆解为 `2, 3, 5`。这完全是为了写代码方便（比如 `fig.add_subplot(231)`），但源码也提示了限制：只有当子图不超过 9 个时才能这么用。

- **跨行跨列模式**

  `index` 不仅可以是一个数字，还可以是一个元组。

  源码写道：`index can also be a two-tuple specifying the (first, last) indices`。例如 `fig.add_subplot(3, 1, (1, 2))`，意思是在 3行1列 的网格中，**同时占据第 1 格和第 2 格**（即占据上方 2/3 的空间）。

- **直接添加已有对象**

  `add_subplot(ax)`。你可以把一个已经创建好的 Axes 实例传进去，把它“挂”到当前的 Figure 上。

## 强大的子图定制能力（**kwargs）

`add_subplot` 返回的是一个 `Axes` 对象，但你可以在创建它的时候，直接通过 `**kwargs` 传入各种属性来定制它。

- `projection` 

  改变坐标系。

  - 默认是 `'rectilinear'`（普通直角坐标系）

  - `'polar'` 画极坐标图
  - `'aitoff'` 等地图投影。

- `sharex` / `sharey` 

  共享坐标轴。传入另一个 Axes 对象，可以让多个子图共用同一个 X 轴或 Y 轴的刻度与范围。

  这在画多子图对比时非常有用。

- `facecolor` 

  直接设置该子图的背景色（如源码示例中的 `facecolor="red"`）。

- **`frameon`**

  是否绘制子图的边框（如源码示例中的 `frameon=False` 可以隐藏边框）。

## 源码中的实用示例解析

在源码的 `Examples` 部分，官方给出了非常标准的写法：

```python
fig.add_subplot(231)             # 偷懒写法：等同于 2,3,1
ax1 = fig.add_subplot(2, 3, 1)   # 标准写法：创建并获取 ax1 对象
fig.add_subplot(233, projection='polar') # 直接在创建时指定为极坐标
fig.add_subplot(234, sharex=ax1) # 与 ax1 共享 X 轴
ax1.remove()                     # 从画布中移除 ax1
fig.add_subplot(ax1)             # 把 ax1 重新添加回画布
```

**总结**

这段源码展示了 Matplotlib 设计者的良苦用心。`add_subplot` 不仅仅是一个简单的“切分网格”工具，它还是一个**高度封装的工厂方法**。它既能通过默认值保证“无参数调用”的安全性，又能通过解析元组实现复杂的跨格布局，还能在创建子图的一瞬间完成投影、配色和坐标轴共享等高级定制。

# 画布调整

| 函数/方法               | 核心作用                                     | 适用场景                                                     |
| ----------------------- | -------------------------------------------- | ------------------------------------------------------------ |
| `plt.margins()`         | 设置坐标轴数据边缘的留白比例。               | 消除折线图或散点图两侧空白，让数据点紧贴边界。               |
| `plt.subplots_adjust()` | 精确控制子图与画布边缘的距离（归一化坐标）。 | 为长标签、标题预留空间，或手动微调多子图间距。               |
| `plt.tight_layout()`    | 自动计算并优化子图间距及边缘距离。           | 最常用。防止多子图标签重叠、被裁切，一键自动排版。           |
| `fig.set_size_inches()` | 调整画布的物理尺寸（英寸）。                 | 改变图表整体大小，间接影响内容的视觉占比和留白感。           |
| `ax.set_position()`     | 指定单个子图在画布中的绝对位置和大小。       | 需要非对称布局，或将特定子图放大、偏移以突出显示。           |
| `bbox_inches='tight'`   | **保存**时自动裁剪掉画布周围多余的空白区域。 | **导出图片专用**。确保保存的文件没有大片的白色背景浪费。     |
| `constrained_layout`    | 创建画布时开启的自动布局引擎。               | `tight_layout` 的现代替代品，对复杂嵌套子图（如 `GridSpec`）支持更好。 |
