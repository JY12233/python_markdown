# 介绍

专门用于开发2D、3D图标的python第三方库，以渐进式、交互式实现数据可视化。

可视化是在整个数据挖掘的关键辅助工具，可以清晰的理解数据，从而调整分析方法。

- 能将数据进行可视化,更直观的呈现。
- 使数据更加客观、更具说服力。

官方案例库：https://matplotlib.org/stable/gallery/index.html

# 绘图流程

## 导包

```python
import matplotlib.pyplot as plt
```

## 设置字体

```python
plt.rcParams['font.sans-serif'] = ['SimHei']  # Windows 系统常用黑体

# 解决中文显示为方块的问题，并统一字体大小
plt.rcParams['font.sans-serif'] = ['STKaiti']  # 华文楷体
plt.rcParams['axes.unicode_minus'] = False    # 解决负号显示异常
plt.rcParams['font.size'] = 12                # 设置全局字体大小
```

## 创建画布

```python
plt.figure(
    num=None,       # 画布的编号或名称
    figsize=None,   # 画布的宽度和高度（单位：英寸）
    dpi=None,       # 画布的分辨率（每英寸像素数）
    facecolor=None, # 画布的背景颜色
    edgecolor=None, # 画布的边框颜色
    frameon=True,   # 是否绘制边框
    clear=False     # 如果画布已存在，是否清除原有内容
)
```

返回`Figure`对象。

| 参数名      | 类型            | 默认值       | 说明                                                         |
| ----------- | --------------- | ------------ | ------------------------------------------------------------ |
| `num`       | int 或 str      | `None`       | 画布的唯一标识。<br />如果指定了编号，再次调用时会激活该画布；<br />如果省略，会自动按顺序创建新画布。 |
| `figsize`   | tuple（宽，高） | `(6.4, 4.8)` | 设置画布的大小，单位是英寸。<br />比如 `figsize=(10, 6)` 表示宽10英寸、高6英寸。 |
| `dpi`       | int             | `100`        | 分辨率（Dots Per Inch）<br />。数值越大，图片越清晰（文件体积也越大）。<br />打印时通常建议设为 150 或 300。 |
| `facecolor` | color           | `'w'` (白色) | 画布的背景色。<br />可以传入颜色名称（如 `'lightgray'`）<br />或十六进制颜色码（如 `'#FFFF00'`）。 |
| `edgecolor` | color           | `'w'` (白色) | 画布的边框颜色。<br />通常需要配合较大的 `linewidth` 才能明显看到效果。 |
| `frameon`   | bool            | `True`       | 是否显示画布的边框和背景色。<br />设为 `False` 时，背景会变为透明。 |

## 设置x轴和y轴

| 功能         | Pyplot 接口 (`plt.`)                                | 说明                                           |
| ------------ | --------------------------------------------------- | ---------------------------------------------- |
| 设置范围     | `plt.xlim()` / `plt.ylim()`                         | 限制坐标轴显示的最小值和最大值。               |
| 设置刻度位置 | `plt.xticks()` / `plt.yticks()`                     | 指定刻度线出现的具体数值位置。                 |
| 设置刻度标签 | `plt.xticks(labels=...)` / `plt.yticks(labels=...)` | 将刻度位置的数值替换为自定义文本。             |
| 设置轴名称   | `plt.xlabel()` / `plt.ylabel()`                     | 给坐标轴加上描述性的标题（如“时间”、“销量”）。 |
| 设置比例尺   | `plt.xscale()` / `plt.yscale()`                     | 切换线性(`linear`)、对数(`log`)等比例。        |

## 保存

`plt.savefig(文件名, )`

务必**先调用 `savefig()` 再调用 `plt.show()`**。因为 `plt.show()` 会释放绘图资源，如果顺序颠倒，保存下来的将会是一张空白图片。

## 可视化

`plt.show(x, y)`

# 图像类型

## 折线图

`plt.plot(x, y, format_string, **kwargs)`

- `x, y`：分别代表横坐标和纵坐标的数据（通常是列表或 NumPy 数组）。如果只提供 `y`，Matplotlib 会自动生成从 0 开始的整数序列作为 `x` 轴。
- `format_string`：一个可选的快捷格式字符串，用于快速定义线条的**颜色、标记点形状和线型**。
- `**kwargs`：通过关键字参数对线条进行更精细的控制（如线宽、透明度、标签等）。

> **`format_string`**
>
> 一个非常高效的写法，语法结构为 `'[颜色][标记][线型]'`。
>
> - 颜色
>
>   | 字符  | 含义 | 字符  | 含义 |
>   | ----- | ---- | ----- | ---- |
>   | `'r'` | 红色 | `'m'` | 洋红 |
>   | `'g'` | 绿色 | `'y'` | 黄色 |
>   | `'b'` | 蓝色 | `'k'` | 黑色 |
>   | `'c'` | 青色 | `'w'` | 白色 |
>
> - 标记
>
>   针对于坐标点。
>
>   | 符号  | 符号说明                    | 符号             | 符号说明                     |
>   | ----- | --------------------------- | ---------------- | ---------------------------- |
>   | `'.'` | 点（point）                 | `','`            | 像素（pixel）                |
>   | `'o'` | 圆圈（circle）              | `'v'`            | 下三角（triangle_down）      |
>   | `'^'` | 上三角（triangle_up）       | `'<'`            | 左三角（triangle_left）      |
>   | `'>'` | 右三角（triangle_right）    | `'1'`            | 下三叉（tri_down）           |
>   | `'2'` | 上三叉（tri_up）            | `'3'`            | 左三叉（tri_left）           |
>   | `'4'` | 右三叉（tri_right）         | `'8'`            | 八角形（octagon）            |
>   | `'s'` | 正方形（square）            | `'p'`            | 五边形（pentagon）           |
>   | `'*'` | 星形（star）                | `'h'`            | 六边形1（hexagon1）          |
>   | `'H'` | 六边形2（hexagon2）         | `'+'`            | 加号（plus）                 |
>   | `'x'` | 叉号（x）                   | `'D'`            | 菱形（diamond）              |
>   | `'d'` | 瘦菱形（thin_diamond）      | `'|'`            | 竖线（vline）                |
>   | `'_'` | 横线（hline）               | `'P'`            | 填充加号（plus_filled）      |
>   | `'X'` | 填充叉号（x_filled）        | `'None'` / `' '` | 无标记（nothing）            |
>   | `0`   | 左刻度线（tickleft）        | `1`              | 右刻度线（tickright）        |
>   | `2`   | 上刻度线（tickup）          | `3`              | 下刻度线（tickdown）         |
>   | `4`   | 左箭头（caretleft）         | `5`              | 右箭头（caretright）         |
>   | `6`   | 上箭头（caretup）           | `7`              | 下箭头（caretdown）          |
>   | `8`   | 靠左底箭头（caretleftbase） | `9`              | 靠右底箭头（caretrightbase） |
>   | `10`  | 靠上底箭头（caretupbase）   | `11`             | 靠下底箭头（caretdownbase）  |
>
>   Matplotlib 还支持直接使用 LaTeX 数学公式作为标记。例如 `marker='$f$'` 会把字母 f 作为标记，`marker='$\\clubsuit$'` 可以画出一个梅花符号。
>
> - 线型
>
>   | 字符   | 含义   |
>   | ------ | ------ |
>   | `'-'`  | 实线   |
>   | `'--'` | 虚线   |
>   | `'-.'` | 点划线 |
>   | `':'`  | 点线   |

**可选关键字参数**

| 参数名       | 说明                                           | 示例                               |
| ------------ | ---------------------------------------------- | ---------------------------------- |
| `color`      | 指定线条颜色（支持十六进制颜色码）。           | `color='red'` 或 `color='#FF5733'` |
| `linestyle`  | 指定线条样式。                                 | `linestyle='--'`                   |
| `linewidth`  | 指定线条宽度（数字）。                         | `linewidth=2.5`                    |
| `marker`     | 指定数据点的标记形状。                         | `marker='o'`                       |
| `markersize` | 指定标记的大小。                               | `markersize=8`                     |
| `label`      | 为线条添加标签，配合 `plt.legend()` 显示图例。 | `label='2024年销量'`               |

## 散点图

通过在二维平面上绘制一系列数据点，来直观展示两个连续变量之间的关系（如相关性、聚类、异常值等）。

强调数据的**分布和关系**，点与点之间默认不连线。

`plt.scatter(x, y, **kwargs)`

- `x, y`：必填项，分别是数据点的横坐标和纵坐标数组（或列表），两者的长度必须相同。
- `**kwargs`：可选项，用于控制散点的大小、颜色、形状、透明度等丰富样式。

| 参数名       | 作用                                           | 常用取值示例                                                 |
| ------------ | ---------------------------------------------- | ------------------------------------------------------------ |
| `s`          | 设置散点的大小（面积）。                       | `50` （固定大小）<br />或与 `x` 等长的数组 （每个点大小不同）。 |
| `c`          | 设置散点的颜色。                               | `'red'`、`'blue'`<br />或数值数组 （配合 `cmap` 实现渐变色）。<br />数组会自动去重，然后分配颜色。 |
| `marker`     | 设置散点的形状。                               | `'o'` （圆形，默认）<br />`'s'` （方形）<br />`'^'` （上三角）<br />`'D'` （菱形）<br />`'*'` （星形）等。 |
| `alpha`      | 设置散点的透明度。                             | `0.5` （半透明）<br />`1.0` （完全不透明，默认）。           |
| `cmap`       | 颜色映射（配色方案）。                         | `'viridis'`<br />`'plasma'`<br />`'coolwarm'`<br />`'Reds'`<br /> （当 `c` 为数值数组时生效）。 |
| `edgecolors` | 设置散点边缘的颜色。                           | `'black'`<br />`'red'`<br />`'face'` （与填充色相同）。      |
| `linewidths` | 设置散点边缘的线宽。                           | `0.5`<br />`1.0` （数值越大边缘越粗）。                      |
| `label`      | 为散点添加标签，配合 `plt.legend()` 显示图例。 | `label='2024年销量'`。                                       |

> **颜色映射参数**
>
> 这四个参数是 Matplotlib 中用于控制散点图颜色映射的预设方案，它们决定了数据值如何被转换为视觉上的颜色。选择合适的 `cmap` 能让图表更直观、更易读，甚至能避免误导。以下是这四个值的详细作用：
>
> ##### 'viridis'
>
> - **类型**：顺序型（Sequential），感知均匀。
> - **特点**：这是 Matplotlib 的默认配色方案。它从深紫色平滑过渡到亮黄色，亮度变化非常均匀，对色盲用户友好，且在黑白打印时也能保持清晰的灰度层次。
> - **适用场景**：**通用首选**。适用于绝大多数需要展示数值大小、密度或强度的场景，如热力图、等高线图、散点图中的连续变量着色。
>
> ##### 'plasma'
>
> - **类型**：顺序型（Sequential），高对比度。
> - **特点**：从深紫色/黑色过渡到亮橙色/黄色。它的色彩饱和度更高，视觉上比 `viridis` 更“热烈”和醒目，同样具有良好的感知均匀性。
> - **适用场景**：当你希望图表在屏幕上更“抓眼球”，或者数据范围很大、需要更强视觉冲击力时使用。也常用于科学可视化中强调高值区域。
>
> ##### 'coolwarm'
>
> - **类型**：发散型（Diverging）。
> - **特点**：以白色或浅灰色为中心，向两端分别过渡到蓝色（冷）和红色（暖）。它特别适合展示有正负之分或以某个中心值为基准的数据。
> - **适用场景**：**温度变化、相关系数矩阵、误差分布、偏差分析**。例如，用蓝色表示低于平均值，红色表示高于平均值，白色表示接近平均值。
>
> ##### 'Reds'
>
> - **类型**：顺序型（Sequential），单色系。
> - **特点**：从浅粉色/白色平滑过渡到深红色。它是一个纯粹的单色渐变，视觉上非常简洁、专业。
> - **适用场景**：**强调单一维度的强度或密度**，如人口密度、浓度、频率等。当你的数据只有“多”与“少”的概念，没有正负之分时，`Reds` 是一个非常清晰且不易引起歧义的选择。
>
> ##### 使用提示
>
> - **生效条件**：这些 `cmap` 只有在 `scatter` 函数的 `c` 参数传入一个**数值数组**（而非单一颜色字符串）时才会生效。此时，`c` 数组中的每个值都会根据 `cmap` 被映射成一个颜色。
> - **搭配 Colorbar**：使用 `cmap` 时，强烈建议调用 `plt.colorbar()` 添加颜色条，它为读者提供了“颜色-数值”的对照图例，是理解图表的关键。
> - **避免使用 'jet'**：虽然你没问，但请注意，经典的 `jet` 配色方案因存在虚假色带和对色盲不友好等问题，已被官方弃用，应优先选择上述四种或 `inferno`、`magma` 等现代方案。

## 柱状图

通过高度不同的矩形柱子，来直观地展示和对比不同类别的数值大小（例如不同产品的销量、各个月份的业绩等）。

`plt.bar(x, height, **kwargs)`。

- `x`：必填项，表示每个柱子在 X 轴上的中心位置（可以是数字、字符串标签或数组）。
- `height`：必填项，表示每个柱子的高度，也就是 Y 轴对应的数值。
- `**kwargs`：可选项，用于控制柱子的宽度、颜色、边框、对齐方式等丰富样式。

| 参数名      | 作用                            | 常用取值示例                                                 |
| ----------- | ------------------------------- | ------------------------------------------------------------ |
| `width`     | 设置柱子的宽度。                | `0.8` （默认值）、`0.4` （更细的柱子）。                     |
| `color`     | 设置柱子的填充颜色。            | `'skyblue'`、`'red'`、`['#FF6B6B', '#4ECDC4']` <br />（传入列表可为每个柱子设不同颜色）。 |
| `edgecolor` | 设置柱子边框的颜色。            | `'black'`、`'white'`。                                       |
| `linewidth` | 设置柱子边框的线宽。            | `1`、`1.5` （数值越大边框越粗）。                            |
| `alpha`     | 设置柱子的透明度。              | `0.7` （半透明）、`1.0` （完全不透明，默认）。               |
| `bottom`    | 设置柱子底部的起始高度。        | `0` （默认从0开始）、`[10, 20, 30]` （用于绘制堆叠柱状图）。 |
| `align`     | 设置柱子与 X 轴刻度的对齐方式。 | `'center'` （居中对齐，默认）、`'edge'` （边缘对齐）。       |
| `hatch`     | 设置柱子内部的填充纹理。        | `'/'` （斜线）、`'x'` （交叉线）、`'o'` （圆圈）。           |

> **`hatch`参数**
>
> | 符号   | 视觉效果说明                                                 |
> | ------ | ------------------------------------------------------------ |
> | `'/'`  | 向右倾斜的斜线                                               |
> | `'\\'` | 向左倾斜的斜线（注意在 Python 字符串中通常需要写成 `'\\\\'` 进行转义） |
> | `'-'`  | 水平线条                                                     |
> | `'+'`  | 垂直与水平线条交叉（十字网格）                               |
> | `'x'`  | 斜向线条交叉（X形网格）                                      |
> | `'o'`  | 小圆圈                                                       |
> | `'O'`  | 大圆圈                                                       |
> | `'.'`  | 小点（像素点）                                               |
> | `'*'`  | 星号                                                         |
>
> 可以复合使用，`'+/'` 会在十字网格的基础上叠加向右的斜线，`'o.'` 会同时填充圆圈和点。

## 饼状图

通过将一个圆形分割成不同大小的扇形，来直观地展示各个部分占整体的比例关系（例如市场份额、预算分配等）。

`plt.pie(x, **kwargs)`

- `x`：必填项，表示每个扇形对应的数据值（会自动计算占比）。
- `**kwargs`：可选项，用于控制饼图的标签、颜色、百分比显示、突出显示等丰富样式。

| 参数名          | 作用                                                         | 常用取值示例                                                 |
| --------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `labels`        | 为每个扇形添加文本标签。                                     | `['A', 'B', 'C']`。                                          |
| `colors`        | 为每个扇形指定填充颜色。                                     | `['red', 'blue', 'green']`。                                 |
| `autopct`       | 自动计算并显示百分比数值。                                   | `'%1.1f%%'` （保留一位小数）、`'%d%%'` （显示整数）。        |
| `explode`       | 将某些扇形从圆心“拉出来”以突出显示。                         | `(0, 0.1, 0)` （第二个扇形向外偏移 10% 的半径）。            |
| `startangle`    | 设置饼图的起始绘制角度。                                     | `90` （从正上方 90° 开始逆时针绘制）。                       |
| `shadow`        | 是否为饼图添加阴影效果。                                     | `True` （添加阴影）、`False` （默认无阴影）。                |
| `wedgeprops`    | 设置扇形（楔形）的边框等属性。                               | `{'width': 0.3}` （用于绘制圆环图）、`{'edgecolor': 'white'}`。 |
| `textprops`     | 统一设置饼图中文本的字体属性。                               | `{'fontsize': 12, 'color': 'black'}`。                       |
| `pctdistance`   | 控制百分比数值（`autopct`）距离圆心的相对位置。              | `0.6` （默认在内部）、`1.1` （移到饼图外侧）。               |
| `labeldistance` | 控制文本标签（`labels`）距离圆心的相对位置。                 | `1.1` （默认在外部）、`0.8` （移到饼图内部）。               |
| `radius`        | 设置整个饼图的半径大小。                                     | `1` （默认大小）、`0.8` （缩小饼图）。                       |
| `wedgeprops`    | 以字典形式设置扇形（楔形）的高级属性。                       | `{'width': 0.3}` （制作圆环图）、`{'edgecolor': 'white'}`。  |
| `hatch`         | 为扇形添加填充纹理（黑白打印或色盲友好时极有用）。           | `'/'` （斜线）、`'\\'` （反斜线）、`'.'` （点状）。          |
| `counterclock`  | 决定扇形的排列方向是逆时针还是顺时针。                       | `True` （默认逆时针）、`False` （改为顺时针）。              |
| `normalize`     | 是否强制将数据归一化（总和为1）。设为 `False` 可画缺角饼图。 | `True` （默认自动归一化）、`False` （按原始数据绘制）。      |
| `rotatelabels`  | 是否让外部的文本标签跟随扇形的角度自动旋转。                 | `False` （默认水平文字）、`True` （文字随角度倾斜）。        |

> **autopct参数**
>
> - 形式
>
>   `%[宽度].[精度]f%%`
>
>   末尾的两个百分号 `%%` 是为了转义。
>
>   - `宽度`表示整个数字字符串**至少**占多少个字符的位置。
>
>   - `精度`表示保留几位小数。
>
> - 举例
>
>   | 格式化写法  | 最终显示效果 | 解释说明                                                     |
>   | ----------- | ------------ | ------------------------------------------------------------ |
>   | `% .1f %%`  | `35.7%`      | 精度为1：保留1位小数（四舍五入）。没写宽度，按实际长度显示。 |
>   | `% .3f %%`  | `35.678%`    | 精度为3：保留3位小数。                                       |
>   | `% 8.1f %%` | `␣␣␣35.7%`   | 宽度为8，精度为1：保留1位小数后，整个字符串（含%）不足8位，左边补了3个空格（用␣表示）。 |
>   | `% 3.1f %%` | `35.7%`      | 宽度为3，精度为1：虽然宽度设为3，但 `35.7%` 实际有5个字符，宽度被自动撑开，完整显示。 |

## 直方图

通过统计连续数据在不同区间内的频数（出现次数），来直观地展示数据的整体分布情况（例如数据的集中趋势、偏态、异常值等）。

`plt.hist(x, **kwargs)`。

- `x`：必填项，表示要绘制直方图的连续型数据（可以是一维数组、列表等）。
- `**kwargs`：可选项，用于控制直方图的区间数量、颜色、透明度、归一化等丰富样式。

| 参数名        | 作用                           | 常用取值示例                                                 |
| ------------- | ------------------------------ | ------------------------------------------------------------ |
| `bins`        | 设置直方图的区间（箱子）数量。 | `10` （默认值）、`30` （划分更细的区间）。                   |
| `color`       | 设置柱子的填充颜色。           | `'skyblue'`、`'red'`。                                       |
| `alpha`       | 设置柱子的透明度。             | `0.7` （半透明，方便观察多组重叠数据）、`1.0` （默认不透明）。 |
| `edgecolor`   | 设置柱子边框的颜色。           | `'black'`、`'white'`。                                       |
| `density`     | 是否将频数归一化为概率密度。   | `False` （默认显示频数）、`True` （Y轴显示概率密度）。       |
| `cumulative`  | 是否绘制累积分布直方图。       | `False` （默认）、`True` （显示累积分布）。                  |
| `histtype`    | 设置直方图的类型。             | `'bar'` （默认柱状）、`'step'` （无填充的折线轮廓）。        |
| `orientation` | 设置直方图的方向。             | `'vertical'` （默认垂直）、`'horizontal'` （水平方向）。     |

## 颜色条

`plt.colorbar()` 是 Matplotlib 中用于在图表中添加颜色条（Colorbar）的核心函数。它的主要作用是**建立图像颜色与数值之间的映射关系**，充当图表的“图例”，帮助读者直观地理解散点图、热力图或等高线图中不同颜色所代表的具体数据值或物理量。

### 函数使用格式

以下是 `plt.colorbar()` 的基础调用格式及核心参数注释：

```python
plt.colorbar(
    mappable=None,      # 指定要与颜色条关联的绘图对象（如 scatter 或 imshow 返回的对象）
    cax=None,           # 指定用于绘制颜色条的特定坐标轴（Axes），若设置则 ax 参数失效
    ax=None,            # 指定颜色条关联的父坐标轴，用于自动调整布局以腾出空间
    use_gridspec=False, # 是否使用 gridspec 布局管理器来放置颜色条
    **kwargs            # 其他用于自定义颜色条外观的关键字参数（如标签、方向、刻度等）
)
```

### 参数

| 参数          | 作用说明                                                     | 可选值 / 类型                                                |
| ------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `mappable`    | 核心参数，指定颜色条的映射依据。<br />通常传入 `scatter()`、`imshow()` 等绘图函数的返回值。<br />若不传，函数会自动检索当前坐标轴中的绘图对象。 | `ScalarMappable` 对象<br />（如 `AxesImage`, `QuadMesh` 等） |
| `cax`         | 精确指定颜色条绘制在哪个坐标轴上。<br />常用于多子图共享一个颜色条的复杂布局。 | `Axes` 实例                                                  |
| `ax`          | 指定父坐标轴。<br />Matplotlib 会根据该参数自动从父图中“挤”出空间来绘制颜色条。 | `Axes` 实例或 <br />`Axes` 列表                              |
| `orientation` | 控制颜色条的显示方向。                                       | `'vertical'`（默认垂直）<br />`'horizontal'`（水平）         |
| `label`       | 设置颜色条长轴上的标题标签。<br />用于说明颜色代表的物理量。 | 字符串（如 `'Temperature (°C)'`）                            |
| `location`    | 指定颜色条相对于主图的位置。                                 | `'right'`（默认）<br />`'left'`<br /> `'top'`<br />`'bottom'` |
| `ticks`       | 自定义颜色条上的刻度位置。                                   | 列表（如 `[0, 0.5, 1]`）或<br />`Locator` 定位器对象         |
| `format`      | 格式化刻度标签的显示精度或样式。                             | 字符串格式（如 `'%.2f'`, `'%d%%'`）                          |
| `shrink`      | 颜色条长度的缩放比例。<br />用于微调颜色条与主图的对齐效果。 | 浮点数（默认 `1.0`，如 `0.8` 表示缩短为 80%）                |
| `extend`      | 当数据超出设定范围时，颜色条两端的扩展样式。                 | `'neither'`（默认）<br />`'both'`<br />`'min'`<br />`'max'`  |
| `aspect`      | 控制颜色条的长宽比。                                         | 浮点数（默认 `20`）                                          |

### 使用

- 基础用法

  在调用 `plt.scatter()` 或 `plt.imshow()` 后，直接调用 `plt.colorbar()` 即可自动生成默认颜色条。

- 面向对象用法

  如果使用的是 `fig, ax = plt.subplots()` 的面向对象绘图方式，推荐使用 `fig.colorbar(mappable, ax=ax)`，这样能更精准地控制颜色条与特定子图的绑定关系。

# 子图

## 介绍

`plt.subplots()` 是 Matplotlib 中用于创建子图（Subplots）最强大且最常用的方法。它可以一次性创建一个画布（Figure）以及一个或多个子图（Axes），并返回这两个对象。

## 创建

```python
from matplotlib.axes import Axes # 做类型注解需要

fig, ax = plt.subplots(nrows=1, ncols=1, **kwargs)

plt.show()
```

> 子图中，大部分方法都变成了`set_xxx`。

- `fig`：即 Figure 对象，代表整个画板（图形窗口）。
- `ax`：即 Axes 对象（或 Axes 对象的数组），代表画板上的具体子图。使用`ax[row, col]`获取子图。

| 参数名               | 作用                                 | 常用取值示例                                      |
| -------------------- | ------------------------------------ | ------------------------------------------------- |
| `nrows`              | 设置子图的行数。                     | `1` （默认）、`2` （两行）。                      |
| `ncols`              | 设置子图的列数。                     | `1` （默认）、`2` （两列）。                      |
| `dpi`                | 设置子图的像素。                     | `80`。                                            |
| `figsize`            | 设置整个画布的宽高（单位：英寸）。   | `(8, 6)`、`(16, 9)`。                             |
| `sharex` / `sharey`  | 是否让所有子图共享 X 轴或 Y 轴。     | `False` （默认各自独立）、`True` （共享坐标轴）。 |
| `gridspec_kw`        | 以字典形式微调子图之间的间距。       | `{'hspace': 0.3, 'wspace': 0.2}`。                |
| `subplot_kw`         | 向每个子图传递额外的绘图参数字典。   | `{'facecolor': 'grey'}` （设置子图背景色）。      |
| `constrained_layout` | 是否自动调整子图布局，避免元素重叠。 | `False` （默认）、`True` （自动紧凑布局）。       |

## 设置子图间距

- `plt.tight_layout()` 

  自动调整间距.

- 在创建时使用`gridspec_kw`

  `hspace`：子图间的高度间距。

  `wspace`：子图间的宽度间距。

- `fig.subplots_adjust()` 手动微调，需要传递参数

  | 参数     | 含义说明                                                  | 默认参考值      |
  | -------- | --------------------------------------------------------- | --------------- |
  | `wspace` | 子图之间的水平间距（相对于子图平均宽度的比例）。          | `0.2`           |
  | `hspace` | 子图之间的垂直间距（相对于子图平均高度的比例）。          | `0.2`           |
  | `left`   | 子图区域左侧与画布左边缘的距离（占画布宽度的比例，0~1）。 | `0.125`         |
  | `right`  | 子图区域右侧与画布右边缘的距离（占画布宽度的比例，0~1）。 | `0.9`           |
  | `top`    | 子图区域顶部与画布上边缘的距离（占画布高度的比例，0~1）。 | `0.88` 或 `0.9` |
  | `bottom` | 子图区域底部与画布下边缘的距离（占画布高度的比例，0~1）。 | `0.11` 或 `0.1` |

- 开启自动约束布局 `constrained_layout=True`

  类似于 `tight_layout`，但它是基于约束求解器来自动调整布局的。在创建子图时直接开启即可。

## 设置总标题

```python
fig.suptitle('你的总标题内容', fontsize, fontweight, y)
```

- `fontsize`：控制总标题的字体大小。
- `fontweight`：控制字体粗细，比如设为 `'bold'` 加粗。
- **`y`**：用来微调总标题的垂直位置。默认是 `0.98`，如果觉得总标题压到了子图的标题，可以把它调大一点（比如 `1.05`），让标题往上移。

>`suptitle` 中的 `sup` 其实是英文单词 super 的缩写，在这里代表 “superior”（在……之上的） 或 “superscript”（上标） 的意思。

# 中文设置说明

`plt.rcParams`（全称 runtime configuration parameters）是 Matplotlib 中一个极其重要的全局配置工具。它本质上是一个**字典对象（dict-like object）**，存储了 Matplotlib 绘图时的所有默认配置参数。

## 作用

通过修改 `plt.rcParams`，可以**全局性地自定义**图表的各种默认属性，而无需在每次绘图时重复设置。它可以控制的内容非常广泛，包括：

- 窗体大小、每英寸点数（DPI）
- 线条的宽度、颜色、样式
- 坐标轴、网格线的属性
- 文本、字体的样式（如解决中文乱码问题）

## `[]` 里的参数

`plt.rcParams` 的 `[]` 中需要填入**固定的参数名称（字符串）**，右侧赋值为该参数对应的**具体值**。

以下是 `plt.rcParams` 常用参数及其对应赋值的总结表格：

| 参数名称               | 赋值类型与说明                                               |
| ---------------------- | ------------------------------------------------------------ |
| `'font.sans-serif'`    | **列表**。设置无衬线字体族。<br />例如 `['STKaiti']` 或 `['SimHei']`（黑体），用于解决中文显示乱码。 |
| `'axes.unicode_minus'` | **布尔值**。设置是否使用 Unicode 编码的减号。<br />赋值为 `False` 可解决负号显示为方块的问题。 |
| `'figure.figsize'`     | **元组**。设置默认图像尺寸（宽, 高），单位为英寸。例如 `(10, 5)`。 |
| `'figure.dpi'`         | **整数**。设置屏幕显示图像的分辨率（每英寸点数）。例如 `100`。 |
| `'savefig.dpi'`        | **整数**。设置保存图像文件时的分辨率。例如 `300`（适合论文发表）。 |
| `'font.size'`          | **浮点数**。设置全局默认的字体大小（磅值）。例如 `12`。      |
| `'axes.labelsize'`     | **浮点数或字符串**。设置坐标轴标签的字体大小。例如 `14` 或 `'large'`。 |
| `'lines.linewidth'`    | **浮点数**。设置默认线条的宽度。例如 `2.0`。                 |
| `'lines.linestyle'`    | **字符串**。设置默认线条的样式。例如 `'-'`（实线）、`'--'`（虚线）。 |
| `'axes.grid'`          | **布尔值**。设置是否默认显示坐标轴网格线。例如 `True`。      |
| `'image.cmap'`         | **字符串**。设置默认的颜色映射（Colormap）。例如 `'viridis'`、`'gray'`。 |

## 补充提示

除了使用 `plt.rcParams['参数名'] = 值` 这种类似字典的方式逐一修改外，Matplotlib 还提供了其他便捷的修改方式：

- 批量修改

  使用 `plt.rcParams.update(字典)` 一次性更新多个配置。

- 按组修改

  使用 `plt.rc('lines', linewidth=2, color='red')` 修改特定分组下的多个参数。

- 局部临时修改

  使用 `with plt.rc_context({'lines.linewidth': 3}):` 上下文管理器，仅在缩进代码块内生效，不影响全局。

- 恢复默认

  如果修改乱了，可以使用 `plt.rcdefaults()` 一键恢复 Matplotlib 的内部默认设置。
