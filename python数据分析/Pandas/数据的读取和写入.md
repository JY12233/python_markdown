# csv文件

## 读取

`pd.read_csv` 是 Pandas 库中最常用的数据读取函数之一，它的主要作用是将逗号分隔值（CSV）文件读取并转换为 Pandas 的 DataFrame 对象，方便后续进行数据分析与处理。

### 函数使用格式

```python
pd.read_csv(
    filepath_or_buffer,   # 文件路径、URL 或文件对象，指定要读取的 CSV 文件位置
    sep=',',              # 数据列之间的分隔符，默认为逗号
    header='infer',       # 指定哪一行作为列名（表头），默认为自动推断
    names=None,           # 自定义列名列表，若文件无表头可在此指定
    index_col=None,       # 指定某一列作为 DataFrame 的行索引
    usecols=None,         # 指定需要读取的列，可以是列名列表或列索引列表
    dtype=None,           # 指定各列的数据类型，可以是字典或单一类型
    encoding=None,        # 文件的编码格式，如 'utf-8'、'gbk' 等
    skiprows=None,        # 跳过文件开头指定的行数或行号
    na_values=None,       # 指定哪些字符串应被识别为缺失值（NaN）
    parse_dates=False,    # 尝试将指定的列解析为日期时间格式
    nrows=None,           # 仅读取文件的前 N 行数据，常用于调试
    chunksize=None        # 分块读取大文件，指定每块包含的行数
)
```

### 参数详解

| 参数                 | 作用说明                                         | 可选值与注意事项                                             |
| -------------------- | ------------------------------------------------ | ------------------------------------------------------------ |
| `filepath_or_buffer` | 指定要读取的文件路径或缓冲区。                   | 支持本地路径字符串、URL（http/ftp/s3）或文件句柄。           |
| `sep`                | 指定字段之间的分隔符。                           | 默认为 `,`。<br />若为制表符可设为 `'\t'`，分号可设为 `';'`。 |
| `header`             | 指定作为列名的行号。                             | 默认为 `0`（第一行）；<br />若文件无表头，需设为 `None`。    |
| `names`              | 手动指定列名。                                   | 传入列表，如 `['ID', 'Name']`。<br />若传入了该参数，`header` 默认变为 `None`。 |
| `index_col`          | 指定作为行标签（索引）的列。                     | 可传入列名、列索引整数，或 `False`（强制不使用第一列作索引）。 |
| `usecols`            | 仅读取指定的部分列，能有效减少内存占用。         | 可传入列名列表（如 `['A', 'B']`）或列索引列表（如 `[0, 2]`）。 |
| `dtype`              | 强制指定列的数据类型，防止 Pandas 自动推断出错。 | 可传入字典，如 `{'id': 'str', 'age': 'int'}`。               |
| `encoding`           | 指定文件的字符编码，解决中文乱码问题。           | 常见值为 `'utf-8'`、<br />`'gbk'`（Windows 导出常见）、<br />`'latin1'`。 |
| `skiprows`           | 跳过文件开头的某些行（如注释或无关信息）。       | 可传入整数（跳过前 N 行）或行号列表（如 `[0, 2]`）。         |
| `na_values`          | 将数据中的特定字符串识别为缺失值（NaN）。        | 可传入列表，如 `['NULL', '-', 'N/A']`。                      |
| `parse_dates`        | 自动将指定列解析为 datetime 类型。               | 可传入列名列表（如 `['date']`）或字典。                      |
| `nrows`              | 限制读取的行数。                                 | 传入整数，常用于预览数据或调试大文件。                       |
| `chunksize`          | 将大文件分块迭代读取，避免内存溢出。             | 传入整数，返回一个可迭代的 `TextFileReader` 对象。           |

### 代码示例

以下是一个综合了常用参数的实战示例，展示了如何读取一个包含中文、且可能存在缺失值标识的 CSV 文件：

```python
import pandas as pd

# 读取一个使用 gbk 编码（常见于 Windows 系统导出）的 CSV 文件
# 仅读取 'user_id' 和 'login_time' 两列
# 将 '-' 和 'N/A' 识别为缺失值，并将 'user_id' 强制转为字符串类型，'login_time' 解析为日期
df = pd.read_csv(
    '员工数据.csv',
    encoding='gbk',
    usecols=['user_id', 'login_time'],
    na_values=['-', 'N/A'],
    dtype={'user_id': 'str'},
    parse_dates=['login_time']
)

# 查看前几行数据
print(df.head())
```

`df.to_sql(name, con, schema=None, if_exists='fail', index=True, index_label=None, chunksize=None, dtype=None, method=None)`

| 参数                             | 参数说明                                                     |
| -------------------------------- | ------------------------------------------------------------ |
| `name` (str)                     | 必需参数。指定要写入的数据库表名。                           |
| `con`                            | 必需参数。数据库连接对象。通常推荐使用 `sqlalchemy` 创建的数据库引擎（engine），它支持绝大多数主流数据库（如 MySQL, PostgreSQL, SQLite, SQL Server 等）。 |
| `if_exists` (str, 默认 `'fail'`) | 当数据库中已经存在同名表时：<br />`'fail'` 表示抛出异常，不进行任何写入操作；<br />`'replace'` 表示先删除原表，然后重新创建并插入新数据；<br />`'append'` 表示保留原表，将新数据追加到原表的末尾。 |
| `index` (bool, 默认 `True`)      | 是否将 DataFrame 的索引（index）作为单独的一列写入数据库。<br />通常如果索引没有实际业务意义，建议设为 `False`。 |
| `chunksize` (int, 可选)          | 指定每次批量写入的行数。<br />当数据量非常大时，设置一个合理的 `chunksize`（例如 10000）可以有效避免内存溢出，并提高写入效率。 |
| `dtype` (dict, 可选)             | 一个字典，用于手动指定数据库列的数据类型。<br />格式为 `{'列名': sqlalchemy.types.数据类型}`。<br />这在 Pandas 自动推断的类型不符合数据库要求时非常有用。 |
| `method` (可选)                  | 控制 SQL 插入的方式。<br />`None`（默认）表示逐行生成标准的 `INSERT` 语句；<br />`'multi'` 表示使用单条 `INSERT` 语句插入多行数据（例如 `INSERT INTO table VALUES (...), (...), (...)`），这在写入大量数据时能极大提升速度。 |

> - mysql的字段最长为64，写入的时候记得检查一下。
> - 写入后，如果早打开了库，记得刷新一下。

## 读取

`pd.read_sql(sql, con, index_col=None, coerce_float=True, params=None, parse_dates=None, columns=None, chunksize=None)`

| 参数           | 参数说明                                                     |
| -------------- | ------------------------------------------------------------ |
| `sql`          | 必填，可以是 SQL 查询语句字符串，也可以是数据库的表名。      |
| `con`          | 必填，数据库连接对象。推荐使用 `sqlalchemy` 创建的 `engine` 对象。 |
| `index_col`    | 可选，指定将数据库中的哪一列作为 DataFrame 的行索引（Index）。 |
| `coerce_float` | 可选，默认为 （True）尝试将数据库中的非字符串、非数字对象转换为 Python 的 float 浮点数。 |
| `params`       | 可选，用于安全地传递 SQL 语句中的参数（防止 SQL 注入），可以是列表、元组或字典。 |
| `parse_dates`  | 可选，指定将哪些列解析为日期时间格式（datetime）。           |
| `columns`      | 可选，当 `sql` 参数传入的是表名时，可以用这个参数指定只读取哪些列。 |
| `chunksize`    | 可选， 如果数据量非常大，可以指定每次读取的行数，函数会返回一个迭代器，避免内存溢出。 |

> 1. **`pd.read_sql(sql, con)`**：这是**最通用**的函数，它是一个“二合一”的包装器。
>
>    - 如果传入的是一个 **SQL 查询语句**（如 `"SELECT * FROM users"`），它会自动调用 `read_sql_query`。
>
>    - 如果传入的是一个 **数据库表名**（如 `"users"`），它会自动调用 `read_sql_table`。
>
> 2. **`pd.read_sql_table(table_name, con)`**：专门用于直接读取数据库中的**整张表格**。它的参数较少，不能执行复杂的 SQL 查询。
>
> 3. **`pd.read_sql_query(sql, con)`**：专门用于执行 **SQL 查询语句**（如 `SELECT`, `JOIN`, `WHERE` 等）并将结果读取为 DataFrame。

# 使用pymysql读取数据

```python
# 导入 pymysql 库
import pymysql

try:
    # 1. 建立数据库连接
    # host: 数据库服务器地址，通常是 'localhost' 或 '127.0.0.1'
    # port: 数据库服务端口号，MySQL 默认是 3306
    # user: 你的数据库用户名，这里是 'root'
    # password: 你的数据库密码
    # database: 要连接的具体数据库名
    # charset: 设置字符编码，'utf8mb4' 是更全面的 UTF-8 编码，推荐使用
    connection = pymysql.connect(
        host='127.0.0.1',
        port=3306,
        user='root',
        password='zjy1234',
        database='day04',
        charset='utf8mb4'
    )

    # 2. 创建游标对象 (Cursor)
    # 游标是执行 SQL 语句和获取结果的工具，就像一个指针，指向查询结果集。
    cursor = connection.cursor()

    # 3. 定义要执行的 SQL 查询语句
    sql_query = "SELECT * FROM data_gdp LIMIT 5;"  # 示例：查询表中前 5 条记录

    # 4. 执行 SQL 语句
    cursor.execute(sql_query)

    # 5. 获取查询结果
    # fetchall(): 获取所有查询到的结果，返回一个元组 (tuple)，每个元素是一个代表一行数据的元组。
    # fetchone(): 获取结果集中的下一行。
    # fetchmany(size): 获取结果集中的 size 行。
    results = cursor.fetchall()

    # 6. 处理或打印结果
    # 为了更清晰地展示，我们先获取列名
    column_names = [desc[0] for desc in cursor.description]
    print("列名:", column_names)
    print("-" * 50)
    
    for row in results:
        print(row) # 每个 row 是一个元组，代表一行数据

    print(f"\n总共查询到 {len(results)} 条记录。")

except pymysql.MySQLError as e:
    # 如果发生错误，会在这里捕获并打印错误信息
    print(f"数据库操作出错: {e}")

finally:
    # 7. 关闭资源 (非常重要!)
    # 无论是否发生异常，都要确保游标和连接被关闭，释放数据库资源。
    try:
        cursor.close()
    except:
        pass # 如果 cursor 未定义或已关闭，则跳过

    try:
        connection.close()
    except:
        pass # 如果 connection 未定义或已关闭，则跳过
```

> 1. **导入库**: `import pymysql`
> 2. **连接数据库**: `pymysql.connect(...)`
> 3. **创建游标**: `connection.cursor()`
> 4. **执行查询**: `cursor.execute("SQL语句")`
> 5. **获取结果**: `cursor.fetchall()` / `fetchone()` / `fetchmany()`
> 6. **处理结果**: 打印或进行其他操作。
> 7. **关闭连接**: `cursor.close()` 和 `connection.close()`，通常放在 `finally` 块中以确保执行。

# json文件读取

```python
pd.read_json(
    path_or_buf,      # 【必填】JSON文件路径、URL链接或JSON字符串
    orient=None,      # 【核心】指定JSON数据的结构格式（如 'records', 'split' 等）
    typ='frame',      # 指定返回的对象类型，默认为 'frame' (DataFrame)，也可设为 'series'
    dtype=None,       # 强制指定列的数据类型，可传字典如 {'age': 'int64'}
    convert_axes=None,# 是否尝试将行索引和列名转换为合适的数据类型
    convert_dates=True,# 是否自动将符合日期格式的字符串解析为日期类型
    keep_default_dates=True, # 是否包含默认的日期转换器
    numpy=False,      # 是否将JSON数据直接解析为NumPy数组
    precise_float=False,    # 是否启用高精度的浮点数解析
    date_unit=None,   # 日期单位，如 's'(秒), 'ms'(毫秒), 'us'(微秒), 'ns'(纳秒)
    encoding=None,    # 指定读取文件时使用的字符编码，如 'utf-8'
    lines=False,      # 是否按行读取（处理 JSON Lines 格式的大文件时设为 True）
    chunksize=None,   # 分块读取的大小，配合 lines=True 使用，防止内存溢出
    compression='infer' # 指定压缩格式（如 'gzip', 'zip'），'infer' 表示自动推断
)
```

| 参数            | 参数说明                                                     |
| --------------- | ------------------------------------------------------------ |
| `path_or_buf`   | (必填) 接收 JSON 文件的路径（字符串）、URL 或者一个包含 JSON 数据的字符串。 |
| `orient`        | (核心) 指定 JSON 数据的结构格式。常见值有 `'split'`, `'records'`, `'index'`, `'columns'`, `'values'`。如果不指定，Pandas 会尝试自动推断。 |
| `typ`           | 指定返回的对象类型，默认为 `'frame'`（返回 DataFrame），也可以设置为 `'series'`（返回 Series）。 |
| `dtype`         | 强制指定 DataFrame 中各列的数据类型。可以传入一个字典，例如 `{'age': 'int64'}`。 |
| `convert_axes`  | 默认为 `True`。尝试将行索引和列名的数据类型转换为更合适的类型。 |
| `convert_dates` | 默认为 `True`。自动将符合日期格式的字符串解析为日期类型。如果传入列表，则只解析指定的列。 |
| `encoding`      | 指定读取文件时使用的字符编码，例如 `'utf-8'` 或 `'gbk'`。    |
| `lines`         | 默认为 `False`。如果设置为 `True`，则会按行读取文件，将每一行都当作一个独立的 JSON 对象（常用于处理 JSON Lines 格式的大数据文件）。 |
| `chunksize`     | 当 `lines=True` 时生效。指定每次读取的行数，返回一个迭代器，用于处理超大规模的数据集，防止内存溢出。 |

> **`orient`参数解释**
>
> | 参数值      | 参数说明                                                     | JSON 结构举例                                                |
> | ----------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
> | `'split'`   | 将数据拆分为三个独立的部分：索引、列名和数据。结构非常清晰，适合机器读取。 | `{"index": ["row1", "row2"], "columns": ["A", "B"], "data": [[1, 2], [3, 4]]}` |
> | `'records'` | (最常用) 列表里包含多个字典，每个字典代表一行完整的数据。非常符合直觉，类似 API 返回的列表。 | `[{"A": 1, "B": 2}, {"A": 3, "B": 4}]`                       |
> | `'index'`   | 字典的键（Key）作为 DataFrame 的行索引，对应的值是每一行的数据字典。 | `{"row1": {"A": 1, "B": 2}, "row2": {"A": 3, "B": 4}}`       |
> | `'columns'` | 字典的键（Key）作为 DataFrame 的列名，对应的值是每一列的数据字典。 | `{"A": {"row1": 1, "row2": 3}, "B": {"row1": 2, "row2": 4}}` |
> | `'values'`  | 只保留最纯粹的二维数据数组，不包含任何列名和索引信息。       | `[[1, 2], [3, 4]]`                                           |

```python
df.to_json(
    path_or_buf=None,       # 【必填】文件路径或文件对象。设为None时，直接返回JSON字符串
    orient=None,            # 【核心】指定JSON的结构格式（如 'records', 'split', 'columns' 等）
    date_format=None,       # 日期格式，可选 'epoch'（时间戳，默认）或 'iso'（标准日期字符串）

    default_handler=None,   # 自定义处理无法被序列化的对象的函数
    lines=False,            # 是否按行输出（JSON Lines格式）。配合 orient='records' 处理大数据
    compression='infer',    # 压缩格式（如 'gzip', 'zip'），'infer' 表示根据文件后缀自动推断
    index=True,             # 【重要】是否在JSON中包含DataFrame的行索引
    indent=None,            # 【重要】缩进空格数（整数）。设为None则无换行缩进，设为数字可美化格式
    storage_options=None,   # 远程存储（如S3）的认证等额外选项
    mode='w'                # 【重要】文件写入模式，默认为 'w'（覆盖写入）
)
```

| 参数               | 参数说明                                                     |
| ------------------ | ------------------------------------------------------------ |
| `path_or_buf`      | (必填) 接收写入的目标文件路径（字符串）或文件对象。<br />如果设置为 `None`，则不会写入文件，而是直接返回一个 JSON 格式的字符串。 |
| `orient`           | (核心) 指定输出的 JSON 数据结构格式。<br />常见值有 `'split'`, `'records'`, `'index'`, `'columns'`, `'values'`, `'table'`。 |
| `force_ascii`      | 默认为 `True`。会将非 ASCII 字符（如中文）进行转义（例如 `\u4e2d\u6587`）。<br />如果需要保留正常的中文显示，务必将其设置为 `False`。 |
| `indent`           | 指定缩进的空格数（整数）。如果不设置，输出的 JSON 会挤在一行；<br />设置后（如 `indent=2` 或 `4`）可以美化输出格式，方便人类阅读。 |
| `lines`            | 默认为 `False`。当 `orient='records'` 时，如果将其设为 `True`，会以 JSON Lines 格式输出（即每一行都是一个独立的 JSON 对象），非常适合处理大规模流式数据。 |
| `date_format`      | 指定日期类型数据的输出格式。可选 `'epoch'`（时间戳，默认）或 `'iso'`（ISO8601 标准日期字符串）。 |
| `double_precision` | 指定浮点数保留的小数位数，默认为 10 位。                     |
| `default_handler`  | 一个可调用的函数。当遇到无法被正常序列化的对象时，会调用这个函数来进行自定义处理。 |
| `compression`      | 指定输出文件的压缩格式（如 `'gzip'`, `'zip'` 等），默认为 `'infer'`（根据文件后缀名自动推断）。 |
| `index`            | 默认为 `True`。控制是否在输出的 JSON 中包含 DataFrame 的行索引。在`orient`为`record`时不能写，会报错。 |

```python
)
```

| 参数          | 作用说明                   | 可选值 / 类型                                                |
| ------------- | -------------------------- | ------------------------------------------------------------ |
| `io`          | 指定要读取的 Excel 文件源  | 字符串路径、URL、字节流、文件对象等                          |
| `sheet_name`  | 指定要读取的工作表         | `0`（默认，第一个表）；<br />字符串（表名）；<br />整数列表或字符串列表（读取多个表，返回字典）；<br />`None`（读取所有表） |
| `header`      | 指定用作列名的行           | 整数（行索引，默认0）；<br />整数列表（多级列名）；<br />`None`（无列名） |
| `names`       | 自定义结果的列名           | 列表（如 `['A', 'B', 'C']`），长度需与数据列数一致           |
| `index_col`   | 指定用作行索引的列         | 整数（列索引）；字符串（列名）；整数/字符串列表（多级索引）  |
| `usecols`     | 指定只读取特定的列         | 字符串（如 `'A:C'` 或 `'A,C,E'`）；<br />也可以使用 `(A, E:)` 读取 A 列 和 C列及之后的所有列；<br />整数（读取前N列）；<br />整数列表（如 `[0, 2, 4]`） |
| `dtype`       | 强制指定列的数据类型       | 字典，例如 `{'ID': str, 'Price': float}`                     |
| `engine`      | 指定底层解析 Excel 的引擎  | `'openpyxl'`（推荐用于 .xlsx）；<br />`'xlrd'`（用于旧版 .xls） |
| `converters`  | 对特定列应用自定义转换函数 | 字典，例如 `{'列名': lambda x: x.strip()}`                   |
| `skiprows`    | 跳过文件开头不需要的行     | 整数（跳过前N行）；<br />列表（跳过指定行号，如 `[0, 2]`）   |
| `nrows`       | 限制读取的数据行数         | 整数（例如 `100` 表示只读前100行）                           |
| `na_values`   | 自定义缺失值标记           | 字符串或列表（例如 `['NULL', '-']` 会被转为 NaN）            |
| `parse_dates` | 尝试将指定列解析为日期时间 | `True`（自动解析）；<br />列名列表（如 `['date_col']`）      |

## 写入

```python
pandas.DataFrame.to_excel(
    excel_writer,      # 必需参数，要保存的 Excel 文件路径或 ExcelWriter 对象
    sheet_name='Sheet1', # 指定要写入的工作表名称，默认为 'Sheet1'
    na_rep='',         # 指定在写入过程中用于替代缺失值（NaN）的字符串
    float_format=None, # 设置浮点数的输出格式（如 '%.2f' 保留两位小数）
    columns=None,      # 指定要写入的列，默认为 None（写入所有列）
    header=True,       # 是否写入列名，默认为 True
    index=True,        # 是否写入行索引，默认为 True
    index_label=None,  # 指定行索引的列标题名称
    startrow=0,        # 指定数据在 Excel 工作表中写入的起始行位置
    startcol=0,        # 指定数据在 Excel 工作表中写入的起始列位置
    engine=None,       # 指定使用的 Excel 写入引擎（如 openpyxl, xlsxwriter）
    merge_cells=True,  # 是否合并包含多级索引（MultiIndex）的单元格
    encoding=None,     # 指定保存 Excel 文件时的字符编码
    freeze_panes=None  # 指定要冻结的窗格位置（如 (1, 0) 冻结首行）
)
```

| 参数           | 作用说明                                         | 可选值 / 类型                                                |
| -------------- | ------------------------------------------------ | ------------------------------------------------------------ |
| `excel_writer` | 指定要保存的 Excel 文件路径或 `ExcelWriter` 对象 | 字符串路径（如 `'output.xlsx'`）或 `ExcelWriter` 实例        |
| `sheet_name`   | 指定数据要写入的工作表名称                       | 字符串（默认 `'Sheet1'`）                                    |
| `na_rep`       | 指定缺失值（NaN）在 Excel 中的显示内容           | 字符串（默认 `''`，即显示为空）                              |
| `float_format` | 格式化浮点数在 Excel 中的显示样式                | 字符串格式（如 `'%.2f'`）                                    |
| `columns`      | 限制只将特定的列写入到 Excel 中                  | 列表（如 `['列名A', '列名B']`）                              |
| `header`       | 控制是否将 DataFrame 的列名写入 Excel            | `True`（默认写入）；<br />`False`（不写入）；字符串列表（自定义列名） |
| `index`        | 控制是否将 DataFrame 的行索引写入 Excel          | `True`（默认写入）；<br />`False`（不写入）                  |
| `index_label`  | 为写入的行索引指定一个列标题                     | 字符串或序列（仅在 `index=True` 时生效）                     |
| `startrow`     | 设置数据写入的起始行（0 代表第一行）             | 整数（默认 `0`）                                             |
| `startcol`     | 设置数据写入的起始列（0 代表第一列）             | 整数（默认 `0`）                                             |
| `engine`       | 指定底层写入 Excel 的引擎                        | `'openpyxl'`（推荐用于 .xlsx）；<br />`'xlsxwriter'`；<br />`'xlwt'`（用于旧版 .xls） |
| `merge_cells`  | 控制是否自动合并多级索引产生的重复单元格         | `True`（默认合并）；<br />`False`（不合并）                  |
| `encoding`     | 指定文件保存时的字符编码                         | 字符串（如 `'utf-8'`）                                       |
| `freeze_panes` | 设置 Excel 中的冻结窗格，方便查看表头            | 元组（如 `(1, 0)` 冻结第一行；<br />`(1, 1)` 冻结首行首列）  |
