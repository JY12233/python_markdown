# `pd.cut`

`pd.cut()` 是 Pandas 库中非常强大的一个函数，它的核心作用就是**把连续的数值数据，切分成一个个离散的区间（分箱）**。把数据划分到区间里面并返回这个包含区间的Series等。

```python
pandas.cut(
    x, 
    bins, 
    right=True, 
    labels=None, 
    retbins=False, 
    precision=3, 
    include_lowest=False, 
    duplicates='raise'
)
```

| 参数             | 说明                                                         | 在 RFM 中的常见用法                                          |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `x`              | 需要进行分箱的一维数组或 Series（例如你的 `rfm['R']` 列）。  | 传入具体的 R、F 或 M 数值列。                                |
| `bins`           | 定义分割的边界。<br />可以是**整数**（等宽分箱），也可以是**列表**（自定义具体边界）。 | RFM 中通常传入列表，如 `[0, 30, 60, 90]`，以符合业务阈值。   |
| `right`          | 布尔值，默认为 `True`。<br />决定区间是左开右闭 `(a, b]` 还是左闭右开 `[a, b)`。 | 建议设为 `False`（左闭右开），这样 `[0, 30)` 刚好对应“0到29天”，符合直觉。 |
| `labels`         | 为每个区间指定标签（如 `['低', '中', '高']` ，打分之后返回的就是分数，没有区间了。长度需比 `bins` 少 1。 | 传入对应的 RFM 打分，如 `[5, 4, 3, 2, 1]`。                  |
| `include_lowest` | 布尔值，默认为 `False`。<br />如果为 `True`，第一个区间的左边界也会被包含进去。 | 当数据中存在最小值且担心被区间开闭规则剔除时，可设为 `True`。 |
| `retbins`        | 布尔值，默认为 `False`。<br />如果为 `True`，会额外返回实际使用的边界数组。 | 如果你让 Pandas 自动计算边界（`bins` 传整数），开启它可以查看具体分界点。 |
| `precision`      | 整数，默认为 `3`。控制边界显示的小数点精度。                 | 处理金额（M值）时，如果边界有小数，可用它控制显示位数。      |
| `duplicates`     | 处理重复边界的方式，默认为 `'raise'`（报错）。<br />可设为 `'drop'` 忽略重复值。 | 如果自定义的 `bins` 列表里不小心写了重复数字，设为 `'drop'` 可防报错。 |

> **`bin`参数理解**
>
> 在英文中，Bin 这个词最原始的意思就是**“箱子”、“储物柜”或者“垃圾桶”**（比如 recycle bin 回收站，dustbin 垃圾桶）。
>
> - 当`bins`为整数 -- “**等宽分箱**”
>
>   根据数据中的最大值和最小值，把整个数值范围平均切成 N 份。
>
>   1. **计算总跨度（Range）**：
>      先算出数据的最大值减去最小值，即 `总跨度 = max - min`。
>   2. **计算每个箱子的宽度（Width）**：
>      用总跨度除以你设定的箱子数量，即 `箱子宽度 = (max - min) / n`。
>
>   然后，它就会以 `min` 为起点，以 `箱子宽度` 为步长，依次画出 n 个区间。
>
> - 当`bins`为列表
>
>   `bins = [a, b, c, d]`，Pandas 会直接生成以下 3 个区间：
>
>   1. 第一个箱子：`a` 到 `b`。
>   2. 第二个箱子：`b` 到 `c`。
>   3. 第三个箱子：`c` 到 `d`。

> **`labels`参数理解**
>
> 一个关于“边界”与“区间”的数学关系问题。
>
> 比如 `bins = [0, 30, 60, 90]`，这里一共有 **4个** 边界数字。
>
> 区间（箱子）这 4个边界数字，两两组合，刚好能围出 **3个**区间（箱子）：
>
> - 第1个箱子：0 到 30。
> - 第2个箱子：30 到 60。
> - 第3个箱子：60 到 90。
>
> `labels` 的作用就是给这些“箱子”贴标签。既然 4个边界只围出了 3个箱子，那自然只需要准备 **3个**标签。

# `DataFrame.quatile`

Pandas 中用于计算**分位数**（Quantile）的方法。

分位数是统计学中非常重要的概念，它可以将一组数据按从小到大的顺序排列后，划分成若干个等份。最常见的分位数包括**中位数**（50%分位数）、**四分位数**（25%、50%、75%分位数）等。

```python
DataFrame.quantile(
    q=0.5, 
    axis=0, 
    numeric_only=False, 
    interpolation='linear'
)
```

| 参数            | 说明                                                         | 常见用法                                                     |
| --------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `q`             | 要计算的分位数，取值范围在 0 到 1 之间。可以是单个浮点数，也可以是列表或数组。 | `0.5`（中位数）、<br />`[0.25, 0.5, 0.75]`（四分位数）。     |
| `axis`          | 计算方向（仅 DataFrame 有效）。                              | `0` 或 `'index'`（按列计算，默认）；<br />`1` 或 `'columns'`（按行计算）。 |
| `interpolation` | 当分位点落在两个数据点之间时，采用的插值方法。               | `'linear'`（默认线性插值）、<br />`'lower'`（取较小值）、<br />`'nearest'`（取最近值）等。 |
| `numeric_only`  | 是否只计算数值型列（仅 DataFrame 有效）。                    | 默认为 `False`，<br />若数据含非数值列建议设为 `True` 避免报错。 |

> **分位数的计算说明**
>
> quantile - n. 分位数。
>
> 对于 1、2、3、4 这四个数，它们的 0.25 分位数（即第一四分位数）是 **1.75**。
>
> 1. **数据排序**：首先数据必须是从小到大排列的。
>
> 2. 确定位置（索引）
>
>    Pandas 默认使用线性插值法。计算位置的公式是 $(n - 1) \times q$。
>
>    - `n` 是数据的总个数，这里是 4。
>    - `q` 是要求的分位数，这里是 0.25。
>    - 代入公式：`(4 - 1) * 0.25 = 3 * 0.25 = 0.75`。
>      这说明 0.25 分位数落在**第 0.75 个位置**上。
>
> 3. 线性插值计算
>
>    第 0.75 个位置，意味着它在第 0 个数（也就是 1）和第 1 个数（也就是 2）之间，并且偏向第 1 个数。
>
>    - 具体算法是：`第0个数 + (第1个数 - 第0个数) * 0.75`
>    - 代入数值：`1 + (2 - 1) * 0.75 = 1 + 0.75 = 1.75`。
>
> - 如果用 `'lower'`（取较小的那个数）：结果就是 **1**。
> - 如果用 `'higher'`（取较大的那个数）：结果就是 **2**。
> - 如果用 `'nearest'`（取最近的数）：因为 0.75 离 1（第1个数）更近，结果就是 **2**。
> - 如果用 `'midpoint'`（取中间值）：结果就是$(1+2) \div 2 = 1.5$。

# `size`

1. 作为 `groupby` 后的聚合方法（也适用于透视表）

    对数据进行分组（`groupby`）后，`.size()` 是一个专门用来**统计每个分组总行数**的聚合方法。

    - **核心特点**：它统计的是“行数”，**包含缺失值（NaN）**。只要这一行数据存在，它就会被算进去。
    - **返回结果**：返回一个 `Series`，索引是分组的名字，值是该组的行数。
    - `size()` 不需要指定列名，直接统计整行。
    - `count()` 必须指定某一列（例如 `df.groupby('A')['B'].count()`），而且它只统计该列中**非空（非 NaN）**的值。如果数据中有缺失值，用 `count()` 可能会导致统计结果偏少。

    ```python
    # 统计每种“旅游方式”和“景点类型”组合的总行数（包含任何含有NaN的行）
    result = df.groupby(['旅游方式', '景点类型']).size()
    print(result)
    ```
    
2. 作为 DataFrame 或 Series 的属性（基础属性）

    直接在一个完整的 DataFrame 或 Series 后面调用 `.size`（注意这里没有括号 `()`，因为它是一个属性而不是方法），它的作用是**返回数据的总元素个数**。

    - 计算公式：`总行数 × 总列数`。
    
```python
    # 假设 df 是一个 100行、5列 的表格
print(df.size)  # 输出 500 (即 100 * 5)
    
    # 假设 s 是一个包含 100 个元素的 Series
    print(s.size)   # 输出 100
```

# `where`

```python
DataFrame.where(
    cond, # 一个布尔表达式
    other=nan,  # 当条件为False时，替换原数据的值
    inplace=False, 
    axis=None
)
```

```python
# 假设 df 是学生成绩表
# 只有分数 >= 60 的保留，不及格的变成 NaN
df_passed = df.where(df >= 60)

# 不及格的分数显示为 0
df_passed = df.where(df >= 60, other=0)

# 或者替换为文字（如果列类型允许）
df_passed = df.where(df >= 60, other='不及格')

# 将所有负数替换为 0
df.positive_only = df.where(lambda x: x > 0, 0)
```

- `where`：保留满足条件的，修改不满足的。
- `mask`：修改满足条件的，保留不满足的。

> **与 numpy 的区别**
>
> - NumPy (`np.where`)：采用经典的“三元运算符”结构，必须同时传入三个参数。
>   - 语法：`np.where(condition, x, y)`
>   - 含义：如果条件为真，取 `x` 的值；否则取 `y` 的值。
> - Pandas (`df.where`)：采用“条件保留+默认替换”的结构，第二个参数是可选的。
>   - 语法：`df.where(cond, other=nan)`
>   - 含义：如果条件为真，**保留原始值**；如果条件为假，则替换为 `other` 指定的值（默认为 `NaN`）。

# Pandas增加一列

在 Pandas 中，**根据某一列的数值**来添加新的映射列，有几种非常常用且高效的方法。假设你的 DataFrame 叫 `df`，数字列叫 `score`（1代表好学生，2代表中等学生），以下是三种最推荐的实现方式：

##  `map()` 映射

需要准备一个字典，把对应的关系写好即可。

```python
import pandas as pd

# 假设这是你的原始数据
df = pd.DataFrame({'score': [1, 1, 1, 2, 2, 2]})

# 1. 定义映射关系的字典
mapping = {1: '好学生', 2: '中等学生'}

# 2. 使用 map 方法直接生成新列
df['level'] = df['score'].map(mapping)

print(df)
```

*优点：代码极其简洁，执行速度快，非常适合这种类别转换。*

##  `np.where()`

逻辑是“如果是1就...否则就...”，可以使用 numpy 的 `where` 函数。适合条件少、逻辑简单的场景。

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({'score': [1, 1, 1, 2, 2, 2]})

# 如果 score 等于 1，填入'好学生'，否则填入'中等学生'
df['level'] = np.where(df['score'] == 1, '好学生', '中等学生')

print(df)
```

*优点：写起来像 Excel 的 IF 函数，非常符合直觉。*

##  `apply()` 配合自定义函数

如果你的判断条件非常复杂（比如：1是好学生，2是中等学生，3到5是普通学生，其他是不及格），用普通的函数会最清晰。（适合逻辑复杂的场景）。

```python
import pandas as pd

df = pd.DataFrame({'score': [1, 1, 1, 2, 2, 2]})

# 1. 写一个普通的 Python 函数来处理逻辑
def get_level(score):
    if score == 1:
        return '好学生'
    elif score == 2:
        return '中等学生'
    else:
        return '其他'

# 2. 使用 apply 应用到每一行
df['level'] = df['score'].apply(get_level)

print(df)
```

*优点：灵活性最高，无论多复杂的 `if-else` 逻辑都能轻松搞定。*

##  `assign()` 链式操作

如果你希望代码看起来更“高级”且连贯（比如在一长串数据处理中顺便加一列），可以使用 Pandas 的 `assign()` 方法。它不会修改原数据，而是返回一个加了新列的新 DataFrame。

```python
# 结合 map 和 assign 的链式写法
mapping = {1: '好学生', 2: '中等学生'}
df = df.assign(level=df['score'].map(mapping))
```

## `df.loc` 直接赋值

通过 `len(df)` 可以自动获取当前 DataFrame 的长度作为新的索引，也可以指定新的索引。

```python
# 假设df的有四列，分别是 animal、age、visits、priority

# 准备新行数据
new_row = ['elephant', 2.6, 2, 'yes']
# 直接在末尾添加（索引会自动变为当前最大长度）
df.loc[len(df)] = new_row
```

*注意：这种方法要求传入的列表长度必须与 DataFrame 的列数完全一致，且顺序要一一对应。*

## 使用 Python 列表暂存

如果你是在一个循环中不断生成数据并想添加到 DataFrame 中，**绝对不要**在循环里反复使用 `concat` 或 `loc`。最推荐的做法是先用 Python 的普通列表（List）收集数据，最后再一次性转换为 DataFrame。

```python
# 假设你有一个数据流或循环
data_list = []

# 先收集所有数据（包括原本df里的，和新加的）
data_list.extend(df.to_dict('records'))  # 把原来的数据转为字典列表
data_list.append({'animal': 'elephant', 'age': 2.6, 'visits': 2, 'priority': 'yes'})

# 循环结束后，一次性构建新的 DataFrame
df = pd.DataFrame(data_list)
```

*这种方法的时间复杂度接近 O(1)，在处理大量数据时性能远超其他方法。*

## 使用 `pd.concat` 配合字典

其实可以直接传入一个字典列表，Pandas 会自动对齐列名，更加安全且不易出错。

```python
# 将新行包装成字典，Pandas 会自动根据键名匹配列
new_row_df = pd.DataFrame([{'animal': 'elephant', 'age': 2.6, 'visits': 2, 'priority': 'yes'}])

# 合并（ignore_index=True 会自动重置索引，不需要再额外调用 sort_index）
df = pd.concat([df, new_row_df], ignore_index=True)
```

# `unstack`

`unstack` 是 Pandas 中一个非常强大的数据重塑函数，它的核心作用是**将 DataFrame 或 Series 的某个级别的行索引（Index）转换为列索引（Columns）**，通俗地说，就是把数据从“长格式”拉宽，或者说是“旋转”数据。

## 核心概念解释

有一个多级索引（MultiIndex）的 DataFrame 或 Series。这个索引有多层，比如第一层是“动物类型”，第二层是“访问次数”。

```python
import pandas as pd

# 示例数据，使用 groupby 创建一个多级索引 Series
df_example = pd.DataFrame({
    'animal': ['cat', 'cat', 'dog', 'dog'],
    'visits': [1, 2, 1, 2],
    'age': [5, 6, 7, 8]
})
grouped_result = df_example.groupby(['animal', 'visits'])['age'].mean()
print(grouped_result)
# 输出:
# animal  visits
# cat     1         5.0
#         2         6.0
# dog     1         7.0
#         2         8.0
# dtype: float64
# 这是一个 Series，它的索引是 (animal, visits) 的多级索引。
```

现在，如果想让“访问次数”（`visits`）变成列，让“动物类型”（`animal`）作为行，从而得到一个二维表格。

当`grouped_result`调用 `unstack('visits')` 时，它会：

1. 找到名为 `'visits'` 的索引级别。
2. 将这个级别的所有唯一值（在这里是 `1` 和 `2`）作为新的列标签。
3. 将原来的 Series 数据重新排列，使得原来属于 `(cat, 1)` 的值 `5.0` 成为新 DataFrame 中行 `cat` 列 `1` 的值，依此类推。

```python
wide_format = grouped_result.unstack('visits')
print(wide_format)
# 输出:
# 	visits    1    2
# animal        
# cat     	5.0  6.0
# dog    	7.0  8.0
```

得到了一个宽格式的 DataFrame，`visits` 变成了列，这比原来的长格式 Series 更易读，也方便进行后续的数据分析或可视化。

## 参数说明

- `level`: 指定要进行 `unstack` 操作的索引级别。可以传入级别号（如 `0`, `1`）或级别名称（如 `'visits'`）。如果索引只有两级，默认会对最后一个级别进行操作。
- `fill_value`: 在原始数据中不存在的组合（例如，某个动物没有对应的访问次数）会导致结果中出现 `NaN`，可以使用 `fill_value` 参数来指定一个默认值来填充这些 `NaN`，例如 `fill_value=0`。

## 总结

`unstack` 的主要用途就是**将索引中的一个维度转换为列维度**，实现从长格式到宽格式的数据重塑。它经常与 `groupby` 结合使用，因为 `groupby` 的结果通常是带有层级索引的 Series 或 DataFrame，`unstack` 可以将其转换为更直观的透视表形式。它的反向操作是 `stack`，`stack` 是将列索引转换回行索引。

# `shift`

`df.shift()` 函数在 Pandas 中用于**沿指定轴移动数据**。它不会改变 DataFrame 的形状，而是将数据向前或向后“平移”指定的步数，移动后留下的空位会用 `NaN`（对于数字类型）或 `NaT`（对于时间类型）填充。

```python
DataFrame.shift(
    periods: int = 1, # 指定移动的步数
    freq=None,  # 主要用于时间序列数据
    axis: Union[int, str] = 0,  # 指定沿着哪个轴移动数据
    fill_value: Any = None # 用来填充因移动而产生的缺失值
)
```

1. `periods` 
   - 含义：指定移动的步数。
   - 正数：数据向下（对于行）或向右（对于列）移动。例如，`periods=1` 表示将第 n行的数据移动到第 n+1 行。
   - 负数：数据向上（对于行）或向左（对于列）移动。例如，`periods=-1` 表示将第 n行的数据移动到第 n−1 行。
   - 零：数据不移动。
2. `axis` 
   - 含义: 指定沿着哪个轴移动数据。
   - `axis=0` 或 `'index'`（默认）：沿着行索引方向移动（数据在行之间移动）。
   - `axis=1` 或 `'columns'`: 沿着列索引方向移动（数据在列之间移动）。
3. `freq`: 这个参数主要用于时间序列数据。它可以是一个 DateOffset、Timedelta 或字符串（如 'D', 'H'），用于在移动的同时调整日期索引。通常在 `DatetimeIndex` 上使用。
4. `fill_value`: 用来填充因移动而产生的缺失值。如果不指定，默认为 `NaN` 或 `NaT`。

DataFrame.nlargest(

- `keep`
  - `'first'`: 当遇到并列（tie）时，保留第一个出现的。
  - `'last'`: 当遇到并列（tie）时，保留最后一个出现的。
  - `'all'`: 返回所有并列的行（可能会返回超过 n 行）。

# `groupby(Series)`

在 Pandas 的 `groupby` 中传入一个 Series 时，它的分组实现核心逻辑是**“索引对齐（Index Alignment）”**。

Pandas 会拿这个 Series 的索引（Index）去和原 DataFrame（或原 Series）的索引进行匹配，然后把**对应索引位置的值**作为分组的**依据**。

```python
# 原数据
df = pd.DataFrame({'A': [10, 20, 30, 40]}, index=['a', 'b', 'c', 'd'])

# 传入的 Series（作为分组键）
group_keys = pd.Series(['第一组', '第二组', '第一组', '第二组'], index=['a', 'b', 'c', 'd'])

# 进行分组
df.groupby(group_keys).sum()

"""
a    第一组
b    第二组
c    第一组
d    第二组
"""
```

1. Pandas 发现 `df` 的索引是 `['a', 'b', 'c', 'd']`。
2. 它去查 `group_keys` 这个 Series：索引 `'a'` 对应的值是 `'第一组'`，索引 `'b'` 对应的是 `'第二组'`……
3. 于是，`df` 中索引为 `'a'` 和 `'c'` 的行被分到了 `'第一组'`，`'b'` 和 `'d'` 的行被分到了 `'第二组'`。

*如果某个索引在传入的 Series 中找不到，该行数据就会被**自动丢弃**（不参与分组）。*

# `transform`

核心定位是：**“分组计算，原位返回”**。

允许对 `groupby` 后的每个组执行某种计算，但**返回的结果索引与原始 DataFrame 完全对齐**。这使得你可以直接将计算结果作为新列赋值回原表，而无需进行繁琐的 `merge` 操作。

1. **形状保持**：`transform` 强制要求返回值的长度必须与输入组的长度一致（或与原始 DataFrame 等长）。这保证了结果能无缝拼回原表。
2. **性能优化**：对于内置的聚合字符串（如 `'mean'`，`'sum'`），`transform` 底层使用了高度优化的 CPython/C 代码，比 `apply(lambda x: ...)` 快几个数量级。

## 组内标准化 / Z-Score 计算

这是 `transform` 最经典的用法。需要用每组的均值和标准差来标准化该组内的每一行数据。

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'class': ['A', 'A', 'B', 'B'],
    'score': [80, 90, 70, 60]
})

# ✅ 一行搞定：每组分数减去该组均值，再除以该组标准差
df['z_score'] = df.groupby('class')['score'].transform(
    lambda x: (x - x.mean()) / x.std()
)
```

> **对比**：如果用 `apply`，你得到的是一个以 `class` 为索引的 Series，还需要 `reset_index` + `merge` 才能拼回原表，既慢又麻烦。

## 填充组内缺失值

用每组的均值/众数来填充该组内的 NaN。

```python
# 用每组的均值填充该组的缺失值
df['score_filled'] = df.groupby('class')['score'].transform(
    lambda x: x.fillna(x.mean())
)
```

## 组内排名 / 累计计算

```python
# 组内排名
df['rank_in_class'] = df.groupby('class')['score'].transform('rank')

# 组内累计求和
df['cumsum_in_class'] = df.groupby('class')['score'].transform('cumsum')
```

## 使用内置字符串加速

当你的转换逻辑恰好对应 Pandas 内置方法时，**务必使用字符串而非 lambda**：

```python
# ❌ 慢：lambda 会逐组调用 Python 函数
df.groupby('class')['score'].transform(lambda x: x.mean())

# ✅ 快：直接使用字符串，触发底层 C 优化
df.groupby('class')['score'].transform('mean')
```

## 常见陷阱与注意事项

| 问题                   | 说明                                                         | 解决方案                                                     |
| ---------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **返回值长度不匹配**   | `transform` 严格要求输出长度 == 输入长度，否则报 `ValueError` | 检查你的函数是否意外做了聚合（如返回了标量）。若需聚合后广播，改用 `.groupby().transform('mean')` 字符串形式。 |
| **多列同时 transform** | 对多列 `groupby` 后直接 `.transform(func)` 可能行为不符合预期 | 建议逐列处理，或使用 `DataFrameGroupBy.transform` 配合字典映射。 |
| **与 agg 混淆**        | `agg` 返回的是**聚合结果**（行数=组数），`transform` 返回的是**逐行结果**（行数=原始行数） | 需要新列赋回原表 → `transform`；需要汇总统计表 → `agg`。     |
| **自定义函数性能差**   | 复杂的 lambda 无法被向量化优化                               | 尽量拆解为内置字符串组合，或用 `numba` 加速自定义函数。      |
