# `join`

`pandas.DataFrame.join` 是 Pandas 中用于高效合并两个或多个 DataFrame 列的方法。它的核心特点是**默认基于索引（Index）进行连接**，类似于 Excel 中的 VLOOKUP 操作，非常适合将具有相同索引的数据集水平拼接在一起。

## 函数使用格式

```python
DataFrame.join(
    other,         # 要连接的另一个 DataFrame、Series 或包含它们的列表
    on=None,       # 指定调用者（当前 DataFrame）中用于连接的列名，默认为 None（即基于索引连接）
    how='left',    # 指定连接方式，默认为左连接
    lsuffix='',    # 当左右两个 DataFrame 存在重叠列名时，用于左侧列名的后缀
    rsuffix='',    # 当左右两个 DataFrame 存在重叠列名时，用于右侧列名的后缀
    sort=False,    # 是否按连接键对结果进行字典序排序，默认为 False
    validate=None  # 检查连接类型，如 '1:1'（一对一）、'm:1'（多对一）等，默认为 None
)
```

## 参数详解

| 参数       | 作用说明                                    | 可选值与注意事项                                             |
| ---------- | ------------------------------------------- | ------------------------------------------------------------ |
| `other`    | 指定要与当前 DataFrame 进行合并的数据对象。 | 必须是 DataFrame、Series（需设置 name 属性）或包含它们的列表。 |
| `on`       | 指定当前 DataFrame 中用于匹配的列。         | 字符串或列表。若为 None，则默认使用索引进行连接。<br />`join` 总是使用 `other` 的索引进行匹配。 |
| `how`      | 控制如何处理两个对象的索引或键。            | `'left'`（默认）：保留调用者的索引；<br />`'right'`：保留 other 的索引；<br />`'outer'`：取并集；<br />`'inner'`：取交集；<br />`'cross'`：生成笛卡尔积。 |
| `lsuffix`  | 解决左右数据框列名重复的问题。              | 字符串，默认为空。若左右有同名且未加后缀，会报错。           |
| `rsuffix`  | 解决左右数据框列名重复的问题。              | 字符串，默认为空。                                           |
| `sort`     | 控制结果是否按连接键排序。                  | 布尔值，默认为 False。<br />若为 False，连接键的顺序取决于 `how` 参数。 |
| `validate` | 验证连接键的唯一性，防止数据意外膨胀。      | `'1:1'`（一对一）、<br />`'1:m'`（一对多）、<br />`'m:1'`（多对一）、<br />`'m:m'`（多对多，不检查）。 |

## 代码示例

假设我们有两个包含员工信息的 DataFrame，我们希望基于“员工编号”将两个表连接起来。

```python
import pandas as pd

# 1. 准备两个原始 DataFrame
df = pd.DataFrame({
    'key': ['K0', 'K1', 'K2', 'K3'], 
    'name': ['Alice', 'Bob', 'Charlie', 'David']
})

other = pd.DataFrame({
    'key': ['K0', 'K1', 'K2'], 
    'department': ['HR', 'IT', 'Finance']
})

# 2. 使用 join 进行连接
# 方法：将 other 的 'key' 列设为索引，然后通过 on='key' 指定当前 df 的匹配列
# 设置 rsuffix='_other' 以防列名冲突（本例中无冲突，仅作演示）
df_joined = df.join(other.set_index('key'), on='key', rsuffix='_other')

# 3. 查看连接后的结果
print("连接后的数据：")
print(df_joined)
```

**运行结果：**

```
连接后的数据：
   key     name department
0   K0    Alice         HR
1   K1      Bob         IT
2   K2  Charlie      Finance
3   K3    David        NaN
```

在这个示例中，`join` 方法通过 `on='key'` 参数，将当前 `df` 的 `key` 列与 `other` 的索引进行了匹配。

由于默认是左连接（`how='left'`），`df` 中的所有记录都被保留了下来。当 `key` 为 'K3' 时，在 `other` 中没有找到匹配项，因此 `department` 列被自动填充为 `NaN`。

# 三大连接的区别

没问题！在 Pandas 中，`merge`、`join` 和 `concat` 是最核心的三大合并工具。

## 核心合并函数对比

| 函数     | 核心定位                  | 默认连接依据  | 连接方向   | 适用场景                                                     |
| -------- | ------------------------- | ------------- | ---------- | ------------------------------------------------------------ |
| `merge`  | 类似 SQL 的 JOIN 操作     | 列（Columns） | 水平拼接   | 基于共同列名进行复杂的数据表关联（如多对多、左连接等）。     |
| `join`   | 类似 Excel 的 VLOOKUP     | 索引（Index） | 水平拼接   | 基于索引快速拼接数据；<br />或一个表基于列、另一个表基于索引的关联。 |
| `concat` | 类似 Numpy 的 concatenate | 索引或列      | 水平或垂直 | 纯粹的数据堆叠（如将多张结构相同的表上下拼在一起）。         |

## 核心区别详解

### `pd.merge()`

最灵活的“列关联”工具。

- **特点**：功能最强大，参数最丰富。它完全模仿了数据库（SQL）中的连接逻辑。
- **连接键**：必须基于**列名**（通过 `on`、`left_on`、`right_on` 指定）。
- **常用参数**：`how`（连接方式）、`on`（连接键）、`suffixes`（处理重名列）。
- **口诀**：**“找共同列，用 merge”**。

### `df.join()`

最便捷的“索引关联”工具。

- **特点**：`merge` 的便捷封装版，语法更简洁。
- **连接键**：默认基于**索引（Index）**。如果想基于列连接，必须先将右表的列设为索引（`other.set_index()`）。
- **常用参数**：`how`、`on`（仅指定左表的列）、`lsuffix/rsuffix`。
- **口诀**：**“看索引对齐，用 join”**。

### `pd.concat()`：最纯粹的“数据堆叠”工具

- **特点**：不关心数据的业务逻辑关联，只负责机械地拼接。
- **连接键**：基于轴标签（索引或列名）。
- **常用参数**：`axis`（0为上下拼，1为左右拼）、`ignore_index`（是否重置索引）。
- **口诀**：**“上下叠罗汉，用 concat”**。

## 综合代码示例

假设我们有三份数据，分别演示这三种函数的用法：

```python
import pandas as pd

# 准备数据
df1 = pd.DataFrame({'ID': [1, 2, 3], 'Name': ['Alice', 'Bob', 'Charlie']})
df2 = pd.DataFrame({'ID': [2, 3, 4], 'Score': [95, 88, 76]})
df3 = pd.DataFrame({'ID': [5, 6], 'Name': ['David', 'Eve']})

# 1. 使用 merge：基于共同的 'ID' 列进行内连接
merged_df = pd.merge(df1, df2, on='ID', how='inner')
print("merge 结果（基于列）：")
print(merged_df)

# 2. 使用 join：将 df2 的 ID 设为索引，与 df1 的 ID 列进行左连接
# 注意：join 默认使用右表的索引，所以右表需要先 set_index
joined_df = df1.set_index('ID').join(df2.set_index('ID'), how='left')
print("\njoin 结果（基于索引）：")
print(joined_df)

# 3. 使用 concat：将结构相同的 df1 和 df3 上下堆叠
concat_df = pd.concat([df1, df3], ignore_index=True)
print("\nconcat 结果（上下堆叠）：")
print(concat_df)
```

**运行结果：**

```
merge 结果（基于列）：
   ID     Name  Score
0   2      Bob     95
1   3  Charlie     88

join 结果（基于索引）：
      Name  Score
ID               
1    Alice    NaN
2      Bob   95.0
3  Charlie   88.0

concat 结果（上下堆叠）：
   ID     Name
0   1    Alice
1   2      Bob
2   3  Charlie
3   5    David
4   6      Eve
```

## 总结建议

- 如果你在做**数据分析**，需要把两张表通过“学号”、“订单号”等共同列关联起来，首选 **`merge`**。
- 如果你的数据已经**设好了索引**，或者只是想快速把几个表横向拼在一起，用 **`join`** 代码更优雅。
- 如果你从数据库或文件夹里导出了**100张结构完全一样**的表格，需要把它们首尾相连变成一张大表，必须用 **`concat`**。

# `pct_change`

`pandas.DataFrame.pct_change` 是 Pandas 中用于计算当前元素与前一个元素之间百分比变化（Percentage Change）的函数。其核心计算公式为 `(当前值 - 前值) / 前值`。它在金融时序分析、业务指标的环比与同比计算、以及增长率建模等场景中极为常用。

## 函数使用格式

```python
DataFrame.pct_change(
    periods=1,      # 指定用于计算百分比变化的偏移周期数，默认为 1（即与上一行/列做比较）
    fill_method='pad', # 指定在计算变化率之前，如何处理缺失值（NaN），默认为前向填充
    limit=None,     # 限制连续填充缺失值的最大数量，默认为 None（无限制）
    freq=None,      # 指定时间序列的增量（如 'M' 月、'BDay' 工作日），仅对时间序列索引生效
    **kwargs        # 其他关键字参数，会被传递给底层的 shift() 方法
)
```

## 参数详解

| 参数          | 作用说明                                        | 可选值与注意事项                                             |
| ------------- | ----------------------------------------------- | ------------------------------------------------------------ |
| `periods`     | 控制计算百分比变化时向前或向后偏移的行数/列数。 | 整数，默认为 1。<br />正数表示与之前的元素比较（如 `periods=12` 常用于计算同比）；<br />负数表示与之后的元素比较。 |
| `fill_method` | 决定在计算前如何预处理缺失值（NaN）。           | `'pad'` 或 `'ffill'`（默认）：用上一个有效值向前填充；<br />`None`：不进行填充，直接计算（缺失值会导致结果链式缺失）。 |
| `limit`       | 限制连续缺失值的填充步数。                      | 整数，默认为 None。<br />若连续 NaN 超过该数量，则停止填充。 |
| `freq`        | 用于时间序列数据的对齐。                        | 字符串（如 `'M'`, `'Y'`）、`DateOffset` 或 `timedelta`。<br />仅当 DataFrame 索引为 `DatetimeIndex` 时生效。 |
| `**kwargs`    | 传递给底层 `shift()` 方法的额外参数。           | 例如 `axis`（指定轴向，默认为 0）等。                        |

**特别注意**

1. 由于第一行（或前 `periods` 行）没有前置参考值，计算结果会自动填充为 `NaN`。
2. 如果作为分母的“前值”为 0，结果会返回 `inf`（正无穷）或 `-inf`（负无穷），在 Pandas 中通常显示为 `NaN`，需注意排查。
3. 该函数默认只认“行顺序”而不认“时间”。如果原始数据未按时间排序，或中间存在月份缺失，直接计算会导致结果失真。

## 代码示例

假设我们有一份包含时间序列的股票交易数据，我们希望计算每日的环比变化率，以及处理缺失值的情况。

```python
import pandas as pd
import numpy as np

# 1. 准备原始数据（包含一个缺失值）
df = pd.DataFrame({
    'Date': pd.date_range('2026-01-01', periods=4, freq='D'),
    'Price': [100.0, 105.0, np.nan, 110.0]
})
# 将 Date 设为索引
df.set_index('Date', inplace=True)

print("原始数据：")
print(df)

# 2. 默认计算：与上一行做百分比变化 (periods=1)
# 注意：由于第3行价格为 NaN，默认 fill_method='pad' 会用 105.0 填充它再进行计算
df_pct_default = df.pct_change()
print("\n默认百分比变化（前向填充 NaN）：")
print(df_pct_default)

# 3. 不进行填充直接计算 (fill_method=None)
# 此时第3行本身为 NaN，且第4行因为前值（第3行）是 NaN，结果也会变成 NaN
df_pct_no_fill = df.pct_change(fill_method=None)
print("\n不进行填充的百分比变化：")
print(df_pct_no_fill)
```

**运行结果：**

```
原始数据：
            Price
Date             
2026-01-01  100.0
2026-01-02  105.0
2026-01-03    NaN
2026-01-04  110.0

默认百分比变化（前向填充 NaN）：
            Price
Date             
2026-01-01    NaN
2026-01-02  0.050
2026-01-03  0.000
2026-01-04  0.048

不进行填充的百分比变化：
            Price
Date             
2026-01-01    NaN
2026-01-02  0.050
2026-01-03    NaN
2026-01-04    NaN
```

在这个示例中，`pct_change()` 清晰地展示了不同缺失值处理策略带来的影响。

在默认模式下，2026-01-03 的缺失值被前向填充为 105.0，因此其变化率为 0.000，且 2026-01-04 能够基于 105.0 算出约 4.8% 的增长率。而在 `fill_method=None` 模式下，缺失值导致了计算链的断裂，后续数据均返回了 `NaN`。

# `reindex`

`pandas.DataFrame.reindex` 是 Pandas 中一个非常强大且基础的方法，它的核心作用是**“重新索引”**。

你可以把它理解为一个“对齐”或“重塑”工具。它能让你按照新的顺序排列行和列，或者增加/删除行和列，使其符合你指定的新索引。当新的索引在原始数据中不存在时，它会引入缺失值（`NaN`），当然你也可以指定其他值来填充。

## 函数使用格式

```python
DataFrame.reindex(
    labels=None,      # 新的索引标签（用于行或列，取决于 axis 参数）
    index=None,       # 用于指定新的行索引的序列或数组
    columns=None,     # 用于指定新的列索引的序列或数组
    axis=None,        # 指定操作的轴，0 或 'index' 代表行，1 或 'columns' 代表列
    method=None,      # 填充缺失值的方法，如 'backfill', 'pad', 'nearest'
    copy=True,        # 是否复制底层数据，默认为 True
    level=None,       # 在 MultiIndex（多层索引）的某一层上进行匹配
    fill_value=NaN,   # 用于填充新引入的缺失值的标量值，默认为 NaN
    limit=None,       # 在使用 method 参数时，限制连续填充的最大数量
    tolerance=None    # 在匹配索引时，允许的最大距离容差
)
```

## 参数详解

| 参数               | 作用说明                                         | 可选值与注意事项                                             |
| ------------------ | ------------------------------------------------ | ------------------------------------------------------------ |
| `labels`           | 用于指定新索引的标签。                           | 数组或列表。<br />如果 `axis` 为 0（默认），则作用于行索引；<br />如果 `axis` 为 1，则作用于列索引。 |
| `index`, `columns` | 分别用于指定新的行索引和列索引。                 | 数组或列表。<br />这两个参数比 `labels` 更明确，推荐直接使用它们来分别控制行和列。 |
| `axis`             | 指定操作的目标轴。                               | `{0 or 'index', 1 or 'columns'}`。<br />默认为 0，表示操作行索引。 |
| `method`           | 指定如何填充因重新索引而产生的缺失值。           | `'pad'`/`'ffill'`（用前一个有效值填充）<br />`'backfill'`/`'bfill'`（用后一个有效值填充）<br />`'nearest'`（用最近的值填充）。 |
| `fill_value`       | 用于填充缺失值的标量。                           | 任何标量值，如 `0`, `999` 等。<br />默认为 `numpy.nan`。<br />在处理独热编码对齐时，常设为 `0`。 |
| `level`            | 用于在多层索引（MultiIndex）的特定层上进行匹配。 | 整数或名称。仅在索引是 MultiIndex 时有效。                   |
| `limit`            | 限制连续填充的数量。                             | 整数。与 `method` 参数配合使用。                             |
| `tolerance`        | 指定匹配索引时的最大距离容差。                   | 数值。例如，在时间序列中，可以设置一个时间差容差。           |

## 代码示例

### 行列对齐

这个示例展示了如何使用 `reindex` 来对齐两个数据集的列，这正是你之前遇到的问题的解决方案。

```python
import pandas as pd
import numpy as np

# 1. 创建两个列不完全相同的 DataFrame
# 模拟你的训练集，有 A, B, C 三列
df_train = pd.DataFrame({
    'A': [1, 2, 3],
    'B': [4, 5, 6],
    'C': [7, 8, 9]
})

# 模拟你的测试集，只有 A, B 两列，缺少了 C 列
df_test = pd.DataFrame({
    'A': [10, 11],
    'B': [12, 13]
})

print("--- 原始训练集 ---")
print(df_train)
print("\n--- 原始测试集 ---")
print(df_test)

# 2. 使用 reindex 对齐列
# 以训练集的列名为标准，强制测试集与之对齐
df_test_aligned = df_test.reindex(columns=df_train.columns, fill_value=0)

print("\n--- 对齐后的测试集 ---")
print(df_test_aligned)
```

**输出结果：**

```
--- 原始训练集 ---
   A  B  C
0  1  4  7
1  2  5  8
2  3  6  9

--- 原始测试集 ---
    A   B
0  10  12
1  11  13

--- 对齐后的测试集 ---
    A   B  C
0  10  12  0
1  11  13  0
```

可以看到，`df_test_aligned` 现在拥有了和 `df_train` 完全相同的列 `['A', 'B', 'C']`。对于原来不存在的 `C` 列，`reindex` 自动创建并用我们指定的 `fill_value=0` 进行了填充。

### 行列重排

```python
import pandas as pd

df = pd.DataFrame({
    'apple': [1, 2],
    'banana': [3, 4],
    'cherry': [5, 6]
}, index=['row_1', 'row_2'])

# 按照新顺序重新排列列
df_reordered_cols = df.reindex(columns=['cherry', 'apple', 'banana'])

# 按照新顺序重新排列行
df_reordered_rows = df.reindex(index=['row_2', 'row_1'])
```

```python
# 引入新列 'date'，并用 0 填充
df_filled = df.reindex(columns=['apple', 'banana', 'date'], fill_value=0)

# 为 df 增加一个名为 'new_row' 的空行
df_with_new_row = df.reindex(index=['row_1', 'row_2', 'new_row'])

# 为 df 增加一个名为 'new_col' 的空列
df_with_new_col = df.reindex(columns=['apple', 'banana', 'cherry', 'new_col'])
```

### 行列筛选

```python
# 只保留 'apple' 和 'cherry' 这两列
df_filtered = df.reindex(columns=['apple', 'cherry'])
```

dates = pd.to_datetime(['2023-01-01', '2023-01-03', '2023-01-06'])

# `resample`

`pandas.DataFrame.resample` 是 Pandas 库中专门用于处理**时间序列**数据的核心方法。它的主要作用是对时间序列数据进行频率转换（即重采样），可以将数据从高频转换为低频（降采样，如按天转为按月），或者从低频转换为高频（升采样，如按月转为按天）。

> 本质就是按时间分组（Groupby） + 聚合（Aggregation）。

## 函数使用格式

```python
df.resample(
    rule,              # 目标转换的频率规则，如字符串 'D'（天）、'M'（月）或 '5min'（5分钟）
    axis=0,            # 重采样的轴方向，0 或 'index' 表示对行（索引）重采样，1 或 'columns' 表示对列重采样
    closed=None,       # 指定时间区间边界的闭合方式，可选 'right'（右闭）或 'left'（左闭）
    label=None,        # 指定重采样后结果使用哪个边界作为标签，可选 'right'（右边界）或 'left'（左边界）
    convention='start',# 仅适用于 PeriodIndex，控制使用规则的开始（'start'）或结束（'end'）
    kind=None,         # 将结果索引转换为指定类型，可选 'timestamp'（时间戳）或 'period'（时间段）
    on=None,           # 对于 DataFrame，指定用于重采样的时间列名（而非使用索引）
    level=None,        # 对于多级索引，指定用于重采样的层级（名称或编号）
    origin='start_day',# 调整时间分组的起点，如 'epoch'、'start'、'start_day' 等
    offset=None,       # 添加到原点（origin）的偏移时间间隔
    group_keys=False   # 在使用 .apply() 时，是否将组键包含在结果的索引中
)
```

## 参数详解

| 参数         | 作用说明                         | 可选值与注意事项                                             |
| ------------ | -------------------------------- | ------------------------------------------------------------ |
| `rule`       | 定义重采样的目标频率规则。       | 字符串<br />'D'(天)、'W'(周)、'M'(月末)、'Q'(季末)、'Y'(年末)、'H'(小时)、'T'(分钟)；<br />或 DateOffset 对象。 |
| `axis`       | 指定重采样操作沿哪个轴进行。     | 默认为 `0`（对行索引重采样）；<br />设为 `1` 可对列重采样。  |
| `closed`     | 控制时间频率分组区间的闭合端点。 | `'right'`（右闭）或 `'left'`（左闭）。<br />'M'、'Q'、'Y'、'W' 等默认为右闭，其余默认左闭。 |
| `label`      | 控制重采样后输出结果的标签位置。 | `'right'`（使用右边界作标签）或 `'left'`（使用左边界作标签）。<br />默认规则同 `closed`。 |
| `convention` | 指定重采样约定的位置。           | 仅适用于 PeriodIndex，可选 `'start'` 或 `'end'`<br />默认为 `'start'`。 |
| `kind`       | 指定重采样结果索引的时间类型。   | `'timestamp'`（转为 DateTimeIndex）<br />`'period'`（转为 PeriodIndex），默认保留输入类型。 |
| `on`         | 指定用于重采样的特定列。         | 传入列名字符串。<br />该列必须是类似日期时间的类型，适用于不想将时间列设为索引的情况。 |
| `level`      | 指定用于重采样的多级索引层级。   | 传入层级名称（字符串）或层级编号（整数）。                   |
| `origin`     | 调整时间分组的起始原点。         | `'epoch'`(1970-01-01)、<br />`'start'`(序列首个值)、<br />`'start_day'`(第一天午夜)等。<br />仅对固定频率有效。 |
| `offset`     | 对原点添加额外的时间偏移量。     | Timedelta 对象或字符串，默认为 `None`。                      |
| `group_keys` | 控制分组键是否包含在结果索引中。 | `True` 或 `False`，默认为 `False`。<br />主要在使用 `.apply()` 时生效。 |

## 代码示例

以下是一个简单的实战示例，演示了如何将每日数据降采样为每周数据，并计算每周的总和：

```python
import pandas as pd

# 1. 创建一个包含日期和数值的示例 DataFrame
data = {
    'date': pd.date_range(start='2021-01-01', end='2021-01-31'),
    'value': range(31)
}
df = pd.DataFrame(data)

# 2. 使用 resample 方法按每周 ('W') 进行重采样，并计算每周的数值总和
# 这里通过 on 参数指定了 'date' 列作为重采样的时间基准
df_resampled = df.resample('W', on='date').sum()

# 3. 打印重采样后的结果
print(df_resampled)
```

通过 `resample` 方法，你可以轻松地将细颗粒度的时间序列数据汇总为更宏观的视图，非常适合用于时间序列的趋势分析和可视化。
