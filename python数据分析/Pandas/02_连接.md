# `join`

`pandas.DataFrame.join` 是 Pandas 中用于高效合并两个或多个 DataFrame 列的方法。它的核心特点是**默认基于索引（Index）进行连接**，类似于 Excel 中的 VLOOKUP 操作，非常适合将具有相同索引的数据集水平拼接在一起。

## 函数使用格式

```python
DataFrame.join(
    other,         # 要连接的另一个 DataFrame、Series 或包含它们的列表
    on=None,       # 指定调用者（当前 DataFrame）中用于连接的列名，默认为 None（即基于索引连接）
    how='left',    # 指定连接方式，默认为左连接
    lsuffix='',    # 当左右两个 DataFrame 存在重叠列名时，用于左侧列名的后缀
    rsuffix='',    # 当左右两个 DataFrame 存在重叠列名时，用于右侧列名的后缀
    sort=False,    # 是否按连接键对结果进行字典序排序，默认为 False
    validate=None  # 检查连接类型，如 '1:1'（一对一）、'm:1'（多对一）等，默认为 None
)
```

## 参数详解

| 参数       | 作用说明                                    | 可选值与注意事项                                             |
| ---------- | ------------------------------------------- | ------------------------------------------------------------ |
| `other`    | 指定要与当前 DataFrame 进行合并的数据对象。 | 必须是 DataFrame、Series（需设置 name 属性）或包含它们的列表。 |
| `on`       | 指定当前 DataFrame 中用于匹配的列。         | 字符串或列表。若为 None，则默认使用索引进行连接。<br />`join` 总是使用 `other` 的索引进行匹配。 |
| `how`      | 控制如何处理两个对象的索引或键。            | `'left'`（默认）：保留调用者的索引；<br />`'right'`：保留 other 的索引；<br />`'outer'`：取并集；<br />`'inner'`：取交集；<br />`'cross'`：生成笛卡尔积。 |
| `lsuffix`  | 解决左右数据框列名重复的问题。              | 字符串，默认为空。若左右有同名且未加后缀，会报错。           |
| `rsuffix`  | 解决左右数据框列名重复的问题。              | 字符串，默认为空。                                           |
| `sort`     | 控制结果是否按连接键排序。                  | 布尔值，默认为 False。<br />若为 False，连接键的顺序取决于 `how` 参数。 |
| `validate` | 验证连接键的唯一性，防止数据意外膨胀。      | `'1:1'`（一对一）、<br />`'1:m'`（一对多）、<br />`'m:1'`（多对一）、<br />`'m:m'`（多对多，不检查）。 |

## 代码示例

假设我们有两个包含员工信息的 DataFrame，我们希望基于“员工编号”将两个表连接起来。

```python
import pandas as pd

# 1. 准备两个原始 DataFrame
df = pd.DataFrame({
    'key': ['K0', 'K1', 'K2', 'K3'], 
    'name': ['Alice', 'Bob', 'Charlie', 'David']
})

other = pd.DataFrame({
    'key': ['K0', 'K1', 'K2'], 
    'department': ['HR', 'IT', 'Finance']
})

# 2. 使用 join 进行连接
# 方法：将 other 的 'key' 列设为索引，然后通过 on='key' 指定当前 df 的匹配列
# 设置 rsuffix='_other' 以防列名冲突（本例中无冲突，仅作演示）
df_joined = df.join(other.set_index('key'), on='key', rsuffix='_other')

# 3. 查看连接后的结果
print("连接后的数据：")
print(df_joined)
```

**运行结果：**

```
连接后的数据：
   key     name department
0   K0    Alice         HR
1   K1      Bob         IT
2   K2  Charlie      Finance
3   K3    David        NaN
```

在这个示例中，`join` 方法通过 `on='key'` 参数，将当前 `df` 的 `key` 列与 `other` 的索引进行了匹配。

由于默认是左连接（`how='left'`），`df` 中的所有记录都被保留了下来。当 `key` 为 'K3' 时，在 `other` 中没有找到匹配项，因此 `department` 列被自动填充为 `NaN`。

# 三大连接的区别

在 Pandas 中，`merge`、`join` 和 `concat` 是最核心的三大合并工具。

## 核心合并函数对比

| 函数     | 核心定位                  | 默认连接依据  | 连接方向   | 适用场景                                                     |
| -------- | ------------------------- | ------------- | ---------- | ------------------------------------------------------------ |
| `merge`  | 类似 SQL 的 JOIN 操作     | 列（Columns） | 水平拼接   | 基于共同列名进行复杂的数据表关联（如多对多、左连接等）。     |
| `join`   | 类似 Excel 的 VLOOKUP     | 索引（Index） | 水平拼接   | 基于索引快速拼接数据；<br />或一个表基于列、另一个表基于索引的关联。 |
| `concat` | 类似 Numpy 的 concatenate | 索引或列      | 水平或垂直 | 纯粹的数据堆叠（如将多张结构相同的表上下拼在一起）。         |

## 核心区别详解

### `merge`

最灵活的“列关联”工具。

- **特点**：功能最强大，参数最丰富。它完全模仿了数据库（SQL）中的连接逻辑。
- **连接键**：必须基于**列名**（通过 `on`、`left_on`、`right_on` 指定）。
- **常用参数**：`how`（连接方式）、`on`（连接键）、`suffixes`（处理重名列）。

### `join`

最便捷的“索引关联”工具。

- **特点**：`merge` 的便捷封装版，语法更简洁。
- **连接键**：默认基于**索引（Index）**。如果想基于列连接，必须先将右表的列设为索引（`other.set_index()`）。
- **常用参数**：`how`、`on`（仅指定左表的列）、`lsuffix/rsuffix`。

### `concat`

- **特点**：不关心数据的业务逻辑关联，只负责机械地拼接。
- **连接键**：基于轴标签（索引或列名）。
- **常用参数**：`axis`（0为上下拼，1为左右拼）、`ignore_index`（是否重置索引）。

## 综合代码示例

假设我们有三份数据，分别演示这三种函数的用法：

```python
import pandas as pd

# 准备数据
df1 = pd.DataFrame({'ID': [1, 2, 3], 'Name': ['Alice', 'Bob', 'Charlie']})
df2 = pd.DataFrame({'ID': [2, 3, 4], 'Score': [95, 88, 76]})
df3 = pd.DataFrame({'ID': [5, 6], 'Name': ['David', 'Eve']})

# 1. 使用 merge：基于共同的 'ID' 列进行内连接
merged_df = pd.merge(df1, df2, on='ID', how='inner')
print("merge 结果（基于列）：")
print(merged_df)

# 2. 使用 join：将 df2 的 ID 设为索引，与 df1 的 ID 列进行左连接
# 注意：join 默认使用右表的索引，所以右表需要先 set_index
joined_df = df1.set_index('ID').join(df2.set_index('ID'), how='left')
print("\njoin 结果（基于索引）：")
print(joined_df)

# 3. 使用 concat：将结构相同的 df1 和 df3 上下堆叠
concat_df = pd.concat([df1, df3], ignore_index=True)
print("\nconcat 结果（上下堆叠）：")
print(concat_df)
```

**运行结果：**

```
merge 结果（基于列）：
   ID     Name  Score
0   2      Bob     95
1   3  Charlie     88

join 结果（基于索引）：
      Name  Score
ID               
1    Alice    NaN
2      Bob   95.0
3  Charlie   88.0

concat 结果（上下堆叠）：
   ID     Name
0   1    Alice
1   2      Bob
2   3  Charlie
3   5    David
4   6      Eve
```

## 总结建议

- 如果在做**数据分析**，需要把两张表通过“学号”、“订单号”等共同列关联起来，首选 **`merge`**。
- 如果的数据已经**设好了索引**，或者只是想快速把几个表横向拼在一起，用 **`join`** 代码更优雅。
- 如果从数据库或文件夹里导出了**100张结构完全一样**的表格，需要把它们首尾相连变成一张大表，必须用 **`concat`**。

# `combine`

`pandas.DataFrame.combine` 是 Pandas 中用于按列（column-wise）合并两个 DataFrame 的函数。它通过用户自定义的函数，逐列对两个 DataFrame 进行元素级或序列级的组合。最终生成的 DataFrame 的行索引和列名将是两个原始 DataFrame 的并集。

## 函数使用格式

```python
DataFrame.combine(
    other,         # 需要与当前 DataFrame 进行列向合并的另一个 DataFrame 对象
    func,          # 接收两个 Series 作为输入，并返回一个 Series 或标量的函数，用于逐列合并数据
    fill_value=None, # 在将列传递给合并函数之前，用于填充 NaN（缺失值）的标量值
    overwrite=True   # 如果为 True，当前 DataFrame 中存在但另一个 DataFrame 中不存在的列将被 NaN 覆盖
)
```

## 参数详解

| 参数         | 作用说明                                                     | 可选值与注意事项                                             |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `other`      | 指定要进行列向合并的第二个 DataFrame。                       | 必须是 DataFrame 类型。                                      |
| `func`       | 定义如何合并两个 DataFrame 的列。该函数会被逐列调用。        | 必须是函数类型。<br />例如可以使用 `np.minimum` 进行逐元素取最小值，或自定义 lambda 函数。 |
| `fill_value` | 在合并前预处理缺失值。如果两个 DataFrame 对应位置都有缺失值，结果仍会保留为 NaN。 | 默认为 `None`。<br />可以设置为任意标量值（如 `0`、`-1` 等）。 |
| `overwrite`  | 控制当两个 DataFrame 列名不完全匹配时的覆盖行为。            | `True`（默认）：若当前 DataFrame 的列在 `other` 中不存在，该列会被 NaN 覆盖；<br />`False`：保留当前 DataFrame 中独有的列及其原始值。 |

## 代码示例

假设我们有两个包含不同数值的 DataFrame，我们希望使用 `combine` 函数，通过 `np.minimum` 逐元素取两个 DataFrame 中的较小值。

```python
import pandas as pd
import numpy as np

# 1. 准备两个原始 DataFrame
df1 = pd.DataFrame({
    'A': [5, 0], 
    'B': [2, 4]
})

df2 = pd.DataFrame({
    'A': [1, 1], 
    'B': [3, 3]
})

# 2. 使用 combine 进行合并
# 传入 np.minimum 作为合并函数，逐元素比较并取较小值
df_combined = df1.combine(df2, np.minimum)

# 3. 查看合并后的结果
print("合并后的数据：")
print(df_combined)
```

**运行结果：**

```
合并后的数据：
   A  B
0  1  2
1  0  3
```

在这个示例中，`combine` 函数逐列比较了 `df1` 和 `df2`。

以第一行为例，A 列中 `5` 和 `1` 取最小值得到 `1`，B 列中 `2` 和 `3` 取最小值得到 `2`。

此外，如果在合并时遇到缺失值，可以通过设置 `fill_value` 参数来预先填充，从而避免合并结果中出现意外的 NaN。

# `align`

`pandas.DataFrame.align` 是 Pandas 中用于显式对齐两个 DataFrame 或 Series 轴（行索引和列标签）的方法。与 `merge()` 或 `concat()` 等组合数据的方法不同，`align()` 的核心作用是同步两个对象的结构，确保它们在进行算术运算或比较时，对应的元素基于标签严格对齐，从而避免因索引或列名不匹配而产生的隐式错误。

## 函数使用格式

```python
DataFrame.align(
    other,          # 需要与当前 DataFrame 进行对齐的另一个 DataFrame 或 Series 对象
    join='outer',   # 指定对齐时使用的连接方式（如取并集、交集等），默认为 'outer'
    axis=None,      # 指定要对齐的轴，0为行索引，1为列，None表示同时对齐两者，默认为 None
    level=None,     # 如果索引是多层索引（MultiIndex），指定在哪个层级上进行匹配和广播，默认为 None
    copy=True,      # 是否返回数据的副本。若为 False 且无需重索引，则可能返回原始对象，默认为 True
    fill_value=None # 对齐后产生的缺失值（NaN）用什么标量值来填充，默认为 np.NaN
)
```

## 参数详解

| 参数         | 作用说明                               | 可选值与注意事项                                             |
| ------------ | -------------------------------------- | ------------------------------------------------------------ |
| `other`      | 指定要与调用对象对齐的第二个数据对象。 | 必须是 DataFrame 或 Series 类型。                            |
| `join`       | 控制对齐时保留哪些标签（键）。         | `'outer'`（默认）：取两个对象标签的并集；<br />`'inner'`：取交集；<br />`'left'`：仅保留调用对象的标签；<br />`'right'`：仅保留传入对象的标签。 |
| `axis`       | 指定在哪个轴上执行对齐操作。           | `None`（默认）：同时对齐行索引和列名；<br />`0` 或 `'index'`：仅对齐行索引；<br />`1` 或 `'columns'`：仅对齐列名。 |
| `level`      | 用于处理多层索引（MultiIndex）的情况。 | 传入整数或层级名称，表示在指定的层级上匹配索引值并进行广播。 |
| `copy`       | 控制是否创建数据的新副本。             | `True`（默认）：总是返回新对象；<br />`False`：如果不需要重索引，则返回原始对象 |
| `fill_value` | 用于填充对齐后产生的空缺位置。         | 默认为 `np.NaN`，可以设置为任何兼容的标量值（如 `0`），<br />以避免后续运算出现大量 NaN。 |

## 代码示例

假设我们有两个行索引和列名都不完全相同的 DataFrame，我们希望将它们对齐，以便进行后续的对比或计算。

```python
import pandas as pd

# 1. 准备两个结构不完全相同的 DataFrame
df1 = pd.DataFrame(
    [[1, 2], [3, 4]], 
    columns=["A", "B"], 
    index=[1, 2]
)

df2 = pd.DataFrame(
    [[10, 20], [30, 40]], 
    columns=["B", "C"], 
    index=[2, 3]
)

# 2. 使用 align 进行对齐
# 设置 join='outer'（取并集），axis=None（同时对齐行和列），fill_value=0（缺失值填0）
aligned_df1, aligned_df2 = df1.align(df2, join='outer', axis=None, fill_value=0)

# 3. 查看对齐后的结果
print("对齐后的 df1：")
print(aligned_df1)
print("\n对齐后的 df2：")
print(aligned_df2)
```

**运行结果：**

```
对齐后的 df1：
   A  B  C
1  1  2  0
2  3  4  0
3  0  0  0

对齐后的 df2：
   A   B   C
1  0   0   0
2  0  10  20
3  0  30  40
```

在这个示例中，`align` 将两个 DataFrame 的行索引统一为 `[1, 2, 3]`，列名统一为 `['A', 'B', 'C']`。原本不存在的数据位置，根据 `fill_value=0` 被填充为了 0。这样，两个对象就拥有了完全相同的结构，可以直接安全地进行如 `aligned_df1 + aligned_df2` 这样的算术运算。
