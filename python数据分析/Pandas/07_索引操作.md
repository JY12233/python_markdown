# `reindex`

`pandas.DataFrame.reindex` 是 Pandas 中一个非常强大且基础的方法，它的核心作用是**“重新索引”**。

可以把它理解为一个“对齐”或“重塑”工具。它能让按照新的顺序排列行和列，或者增加/删除行和列，使其符合指定的新索引。当新的索引在原始数据中不存在时，它会引入缺失值（`NaN`），当然也可以指定其他值来填充。

## 函数使用格式

```python
DataFrame.reindex(
    labels=None,      # 新的索引标签（用于行或列，取决于 axis 参数）
    index=None,       # 用于指定新的行索引的序列或数组
    columns=None,     # 用于指定新的列索引的序列或数组
    axis=None,        # 指定操作的轴，0 或 'index' 代表行，1 或 'columns' 代表列
    method=None,      # 填充缺失值的方法，如 'backfill', 'pad', 'nearest'
    copy=True,        # 是否复制底层数据，默认为 True
    level=None,       # 在 MultiIndex（多层索引）的某一层上进行匹配
    fill_value=NaN,   # 用于填充新引入的缺失值的标量值，默认为 NaN
    limit=None,       # 在使用 method 参数时，限制连续填充的最大数量
    tolerance=None    # 在匹配索引时，允许的最大距离容差
)
```

## 参数详解

| 参数               | 作用说明                                         | 可选值与注意事项                                             |
| ------------------ | ------------------------------------------------ | ------------------------------------------------------------ |
| `labels`           | 用于指定新索引的标签。                           | 数组或列表。<br />如果 `axis` 为 0（默认），则作用于行索引；<br />如果 `axis` 为 1，则作用于列索引。 |
| `index`, `columns` | 分别用于指定新的行索引和列索引。                 | 数组或列表。<br />这两个参数比 `labels` 更明确，推荐直接使用它们来分别控制行和列。 |
| `axis`             | 指定操作的目标轴。                               | `{0 or 'index', 1 or 'columns'}`。<br />默认为 0，表示操作行索引。 |
| `method`           | 指定如何填充因重新索引而产生的缺失值。           | `'pad'`/`'ffill'`（用前一个有效值填充）<br />`'backfill'`/`'bfill'`（用后一个有效值填充）<br />`'nearest'`（用最近的值填充）。 |
| `fill_value`       | 用于填充缺失值的标量。                           | 任何标量值，如 `0`, `999` 等。<br />默认为 `numpy.nan`。<br />在处理独热编码对齐时，常设为 `0`。 |
| `level`            | 用于在多层索引（MultiIndex）的特定层上进行匹配。 | 整数或名称。仅在索引是 MultiIndex 时有效。                   |
| `limit`            | 限制连续填充的数量。                             | 整数。与 `method` 参数配合使用。                             |
| `tolerance`        | 指定匹配索引时的最大距离容差。                   | 数值。例如，在时间序列中，可以设置一个时间差容差。           |

## 代码示例

### 行列对齐

这个示例展示了如何使用 `reindex` 来对齐两个数据集的列。

```python
import pandas as pd
import numpy as np

# 1. 创建两个列不完全相同的 DataFrame
# 模拟你的训练集，有 A, B, C 三列
df_train = pd.DataFrame({
    'A': [1, 2, 3],
    'B': [4, 5, 6],
    'C': [7, 8, 9]
})

# 模拟你的测试集，只有 A, B 两列，缺少了 C 列
df_test = pd.DataFrame({
    'A': [10, 11],
    'B': [12, 13]
})

print("--- 原始训练集 ---")
print(df_train)
print("\n--- 原始测试集 ---")
print(df_test)

# 2. 使用 reindex 对齐列
# 以训练集的列名为标准，强制测试集与之对齐
df_test_aligned = df_test.reindex(columns=df_train.columns, fill_value=0)

print("\n--- 对齐后的测试集 ---")
print(df_test_aligned)
```

**输出结果：**

```
--- 原始训练集 ---
   A  B  C
0  1  4  7
1  2  5  8
2  3  6  9

--- 原始测试集 ---
    A   B
0  10  12
1  11  13

--- 对齐后的测试集 ---
    A   B  C
0  10  12  0
1  11  13  0
```

可以看到，`df_test_aligned` 现在拥有了和 `df_train` 完全相同的列 `['A', 'B', 'C']`。对于原来不存在的 `C` 列，`reindex` 自动创建并用我们指定的 `fill_value=0` 进行了填充。

### 行列重排

```python
import pandas as pd

df = pd.DataFrame({
    'apple': [1, 2],
    'banana': [3, 4],
    'cherry': [5, 6]
}, index=['row_1', 'row_2'])

# 按照新顺序重新排列列
df_reordered_cols = df.reindex(columns=['cherry', 'apple', 'banana'])

# 按照新顺序重新排列行
df_reordered_rows = df.reindex(index=['row_2', 'row_1'])
```

### 插入行列

```python
# 引入新列 'date'，并用 0 填充
df_filled = df.reindex(columns=['apple', 'banana', 'date'], fill_value=0)

# 为 df 增加一个名为 'new_row' 的空行
df_with_new_row = df.reindex(index=['row_1', 'row_2', 'new_row'])

# 为 df 增加一个名为 'new_col' 的空列
df_with_new_col = df.reindex(columns=['apple', 'banana', 'cherry', 'new_col'])
```

### 行列筛选

```python
# 只保留 'apple' 和 'cherry' 这两列
df_filtered = df.reindex(columns=['apple', 'cherry'])
```

### 时间序列重采样

```python
# 创建一个不规则的时间序列
dates = pd.to_datetime(['2023-01-01', '2023-01-03', '2023-01-06'])
ts = pd.Series([100, 110, 105], index=dates)

# 创建一个规则的每日日期范围
new_index = pd.date_range('2023-01-01', '2023-01-06', freq='D')

# 重采样，并用前一个值填充缺失的日期

```

# `resample`

`pandas.DataFrame.resample` 是 Pandas 库中专门用于处理**时间序列**数据的核心方法。它的主要作用是对时间序列数据进行频率转换（即重采样），可以将数据从高频转换为低频（降采样，如按天转为按月），或者从低频转换为高频（升采样，如按月转为按天）。

> 本质就是按时间分组（Groupby） + 聚合（Aggregation）。

## 函数使用格式

```python
df.resample(
    rule,              # 目标转换的频率规则，如字符串 'D'（天）、'M'（月）或 '5min'（5分钟）
    axis=0,            # 重采样的轴方向，0 或 'index' 表示对行（索引）重采样，1 或 'columns' 表示对列重采样
    closed=None,       # 指定时间区间边界的闭合方式，可选 'right'（右闭）或 'left'（左闭）
    label=None,        # 指定重采样后结果使用哪个边界作为标签，可选 'right'（右边界）或 'left'（左边界）
    convention='start',# 仅适用于 PeriodIndex，控制使用规则的开始（'start'）或结束（'end'）
    kind=None,         # 将结果索引转换为指定类型，可选 'timestamp'（时间戳）或 'period'（时间段）
    on=None,           # 对于 DataFrame，指定用于重采样的时间列名（而非使用索引）
    level=None,        # 对于多级索引，指定用于重采样的层级（名称或编号）
    origin='start_day',# 调整时间分组的起点，如 'epoch'、'start'、'start_day' 等
    offset=None,       # 添加到原点（origin）的偏移时间间隔
    group_keys=False   # 在使用 .apply() 时，是否将组键包含在结果的索引中
)
```

## 参数详解

| 参数         | 作用说明                         | 可选值与注意事项                                             |
| ------------ | -------------------------------- | ------------------------------------------------------------ |
| `rule`       | 定义重采样的目标频率规则。       | 字符串<br />'D'(天)、'W'(周)、'M'(月末)、'Q'(季末)、'Y'(年末)、'H'(小时)、'T'(分钟)；<br />或 DateOffset 对象。 |
| `axis`       | 指定重采样操作沿哪个轴进行。     | 默认为 `0`（对行索引重采样）；<br />设为 `1` 可对列重采样。  |
| `closed`     | 控制时间频率分组区间的闭合端点。 | `'right'`（右闭）或 `'left'`（左闭）。<br />'M'、'Q'、'Y'、'W' 等默认为右闭，其余默认左闭。 |
| `label`      | 控制重采样后输出结果的标签位置。 | `'right'`（使用右边界作标签）或 `'left'`（使用左边界作标签）。<br />默认规则同 `closed`。 |
| `convention` | 指定重采样约定的位置。           | 仅适用于 PeriodIndex，可选 `'start'` 或 `'end'`<br />默认为 `'start'`。 |
| `kind`       | 指定重采样结果索引的时间类型。   | `'timestamp'`（转为 DateTimeIndex）<br />`'period'`（转为 PeriodIndex），默认保留输入类型。 |
| `on`         | 指定用于重采样的特定列。         | 传入列名字符串。<br />该列必须是类似日期时间的类型，适用于不想将时间列设为索引的情况。 |
| `level`      | 指定用于重采样的多级索引层级。   | 传入层级名称（字符串）或层级编号（整数）。                   |
| `origin`     | 调整时间分组的起始原点。         | `'epoch'`(1970-01-01)、<br />`'start'`(序列首个值)、<br />`'start_day'`(第一天午夜)等。<br />仅对固定频率有效。 |
| `offset`     | 对原点添加额外的时间偏移量。     | Timedelta 对象或字符串，默认为 `None`。                      |
| `group_keys` | 控制分组键是否包含在结果索引中。 | `True` 或 `False`，默认为 `False`。<br />主要在使用 `.apply()` 时生效。 |

## 代码示例

以下是一个简单的实战示例，演示了如何将每日数据降采样为每周数据，并计算每周的总和：

```python
import pandas as pd

# 1. 创建一个包含日期和数值的示例 DataFrame
data = {
    'date': pd.date_range(start='2021-01-01', end='2021-01-31'),
    'value': range(31)
}
df = pd.DataFrame(data)

# 2. 使用 resample 方法按每周 ('W') 进行重采样，并计算每周的数值总和
# 这里通过 on 参数指定了 'date' 列作为重采样的时间基准
df_resampled = df.resample('W', on='date').sum()

# 3. 打印重采样后的结果
print(df_resampled)
```

通过 `resample` 方法，可以轻松地将细颗粒度的时间序列数据汇总为更宏观的视图，非常适合用于时间序列的趋势分析和可视化。

# `unstack`

`unstack` 是 Pandas 中一个非常强大的数据重塑函数，它的核心作用是**将 DataFrame 或 Series 的某个级别的行索引（Index）转换为列索引（Columns）**，通俗地说，就是把数据从“长格式”拉宽，或者说是“旋转”数据。

## 核心概念解释

有一个多级索引（MultiIndex）的 DataFrame 或 Series。这个索引有多层，比如第一层是“动物类型”，第二层是“访问次数”。

```python
import pandas as pd

# 示例数据，使用 groupby 创建一个多级索引 Series
df_example = pd.DataFrame({
    'animal': ['cat', 'cat', 'dog', 'dog'],
    'visits': [1, 2, 1, 2],
    'age': [5, 6, 7, 8]
})
grouped_result = df_example.groupby(['animal', 'visits'])['age'].mean()
print(grouped_result)
# 输出:
# animal  visits
# cat     1         5.0
#         2         6.0
# dog     1         7.0
#         2         8.0
# dtype: float64
# 这是一个 Series，它的索引是 (animal, visits) 的多级索引。
```

现在，如果想让“访问次数”（`visits`）变成列，让“动物类型”（`animal`）作为行，从而得到一个二维表格。

当`grouped_result`调用 `unstack('visits')` 时，它会：

1. 找到名为 `'visits'` 的索引级别。
2. 将这个级别的所有唯一值（在这里是 `1` 和 `2`）作为新的列标签。
3. 将原来的 Series 数据重新排列，使得原来属于 `(cat, 1)` 的值 `5.0` 成为新 DataFrame 中行 `cat` 列 `1` 的值，依此类推。

```python
wide_format = grouped_result.unstack('visits')
print(wide_format)
# 输出:
# 	visits    1    2
# animal        
# cat     	5.0  6.0
# dog    	7.0  8.0
```

得到了一个宽格式的 DataFrame，`visits` 变成了列，这比原来的长格式 Series 更易读，也方便进行后续的数据分析或可视化。

## 参数说明

- `level`: 指定要进行 `unstack` 操作的索引级别。可以传入级别号（如 `0`, `1`）或级别名称（如 `'visits'`）。如果索引只有两级，默认会对最后一个级别进行操作。
- `fill_value`: 在原始数据中不存在的组合（例如，某个动物没有对应的访问次数）会导致结果中出现 `NaN`，可以使用 `fill_value` 参数来指定一个默认值来填充这些 `NaN`，例如 `fill_value=0`。

## 总结

`unstack` 的主要用途就是**将索引中的一个维度转换为列维度**，实现从长格式到宽格式的数据重塑。它经常与 `groupby` 结合使用，因为 `groupby` 的结果通常是带有层级索引的 Series 或 DataFrame，`unstack` 可以将其转换为更直观的透视表形式。它的反向操作是 `stack`，`stack` 是将列索引转换回行索引。
