# transform

`pandas` 中的 `transform` 是一种对 `Series`、`DataFrame` 或 `GroupBy` 对象应用函数并返回与输入轴长度相同结果的转换方法；使用时通过 `func` 指定函数，并可用 `axis`、`*args`、`**kwargs` 控制应用方向与参数传递；它适合在保持原始索引不变的前提下做数值转换、分组统计广播、组内标准化、缺失值填充或分组过滤，而不适合返回长度不一致的聚合结果。

## 使用格式

```python
DataFrame.transform(func, axis=0, *args, **kwargs)  # DataFrame 上的转换方法
Series.transform(func, axis=0, *args, **kwargs)     # Series 上的转换方法
func,        # 用于转换数据的函数，可接受函数、字符串函数名、函数列表、函数字典
axis=0,      # 应用方向；DataFrame 上可用 0 或 1，Series 上通常仅用于兼容
*args,       # 传递给 func 的额外位置参数
**kwargs,    # 传递给 func 的额外关键字参数
```

## 参数说明

| 参数       | 作用                                                         | 类型与可选值                                                 |
| ---------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `func`     | 指定转换函数；可作用于整个 `DataFrame`/`Series`，<br />也可作用于每个分组 | `function`、`str`、`list`、`dict`；<br />字符串可用 `'sum'`、`'mean'`、`'sqrt'` 等；<br />列表 `[np.exp, 'sqrt']`；<br />字典 `{"A": np.sqrt, "B": np.exp}` |
| `axis`     | 指定函数应用的轴；<br />`DataFrame.transform` 中 `0` 表示按列应用，`1` 表示按行应用；<br />`Series.transform` 中该参数通常仅用于兼容 `DataFrame` 接口 | `{0, 1}` 或<br /> `{'index', 'columns'}`；<br />默认 `0`     |
| `*args`    | 向 `func` 传递额外位置参数                                   | 可变位置参数                                                 |
| `**kwargs` | 向 `func` 传递额外关键字参数                                 | 可变关键字参数                                               |

需要注意：`transform` 返回结果的长度必须与输入一致；如果返回长度不同，会抛出 `ValueError`。

## 简单示例

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "group": ["A", "A", "B", "B"],
    "value": [10, 20, 30, 40]
})

df["group_mean"] = df.groupby("group")["value"].transform("mean")
print(df)
```

**输出**

```text
  group  value  group_mean
0     A     10        15.0
1     A     20        15.0
2     B     30        35.0
3     B     40        35.0
```

这里 `transform("mean")` 先按组计算均值，再把结果广播回原始索引，因此可以直接作为新列加入原表。

# Pandas增加一列

在 Pandas 中，**根据某一列的数值**来添加新的映射列，有几种非常常用且高效的方法。假设你的 DataFrame 叫 `df`，数字列叫 `score`（1代表好学生，2代表中等学生），以下是三种最推荐的实现方式：

##  `map()` 映射

需要准备一个字典，把对应的关系写好即可。

```python
import pandas as pd

# 假设这是你的原始数据
df = pd.DataFrame({'score': [1, 1, 1, 2, 2, 2]})

# 1. 定义映射关系的字典
mapping = {1: '好学生', 2: '中等学生'}

# 2. 使用 map 方法直接生成新列
df['level'] = df['score'].map(mapping)

print(df)
```

*优点：代码极其简洁，执行速度快，非常适合这种类别转换。*

##  `np.where()`

逻辑是“如果是1就...否则就...”，可以使用 numpy 的 `where` 函数。适合条件少、逻辑简单的场景。

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({'score': [1, 1, 1, 2, 2, 2]})

# 如果 score 等于 1，填入'好学生'，否则填入'中等学生'
df['level'] = np.where(df['score'] == 1, '好学生', '中等学生')

print(df)
```

*优点：写起来像 Excel 的 IF 函数，非常符合直觉。*

##  `apply()` 配合自定义函数

如果你的判断条件非常复杂（比如：1是好学生，2是中等学生，3到5是普通学生，其他是不及格），用普通的函数会最清晰。（适合逻辑复杂的场景）。

```python
import pandas as pd

df = pd.DataFrame({'score': [1, 1, 1, 2, 2, 2]})

# 1. 写一个普通的 Python 函数来处理逻辑
def get_level(score):
    if score == 1:
        return '好学生'
    elif score == 2:
        return '中等学生'
    else:
        return '其他'

# 2. 使用 apply 应用到每一行
df['level'] = df['score'].apply(get_level)

print(df)
```

*优点：灵活性最高，无论多复杂的 `if-else` 逻辑都能轻松搞定。*

##  `assign()` 链式操作

如果你希望代码看起来更“高级”且连贯（比如在一长串数据处理中顺便加一列），可以使用 Pandas 的 `assign()` 方法。它不会修改原数据，而是返回一个加了新列的新 DataFrame。

```python
# 结合 map 和 assign 的链式写法
mapping = {1: '好学生', 2: '中等学生'}
df = df.assign(level=df['score'].map(mapping))
```

# Pandas中新加一行

## `df.loc` 直接赋值

通过 `len(df)` 可以自动获取当前 DataFrame 的长度作为新的索引，也可以指定新的索引。

```python
# 假设df的有四列，分别是 animal、age、visits、priority

# 准备新行数据
new_row = ['elephant', 2.6, 2, 'yes']
# 直接在末尾添加（索引会自动变为当前最大长度）
df.loc[len(df)] = new_row
```

*注意：这种方法要求传入的列表长度必须与 DataFrame 的列数完全一致，且顺序要一一对应。*

## 使用 Python 列表暂存

如果你是在一个循环中不断生成数据并想添加到 DataFrame 中，**绝对不要**在循环里反复使用 `concat` 或 `loc`。最推荐的做法是先用 Python 的普通列表（List）收集数据，最后再一次性转换为 DataFrame。

```python
# 假设你有一个数据流或循环
data_list = []

# 先收集所有数据（包括原本df里的，和新加的）
data_list.extend(df.to_dict('records'))  # 把原来的数据转为字典列表
data_list.append({'animal': 'elephant', 'age': 2.6, 'visits': 2, 'priority': 'yes'})

# 循环结束后，一次性构建新的 DataFrame
df = pd.DataFrame(data_list)
```

*这种方法的时间复杂度接近 O(1)，在处理大量数据时性能远超其他方法。*

## 使用 `pd.concat` 配合字典

其实可以直接传入一个字典列表，Pandas 会自动对齐列名，更加安全且不易出错。

```python
# 将新行包装成字典，Pandas 会自动根据键名匹配列
new_row_df = pd.DataFrame([{'animal': 'elephant', 'age': 2.6, 'visits': 2, 'priority': 'yes'}])

# 合并（ignore_index=True 会自动重置索引，不需要再额外调用 sort_index）
df = pd.concat([df, new_row_df], ignore_index=True)
```
