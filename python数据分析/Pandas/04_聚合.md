# `groupby(Series)`

在 Pandas 的 `groupby` 中传入一个 Series 时，它的分组实现核心逻辑是**“索引对齐（Index Alignment）”**。

Pandas 会拿这个 Series 的索引（Index）去和原 DataFrame（或原 Series）的索引进行匹配，然后把**对应索引位置的值**作为分组的**依据**。

```python
# 原数据
df = pd.DataFrame({'A': [10, 20, 30, 40]}, index=['a', 'b', 'c', 'd'])

# 传入的 Series（作为分组键）
group_keys = pd.Series(['第一组', '第二组', '第一组', '第二组'], index=['a', 'b', 'c', 'd'])

# 进行分组
df.groupby(group_keys).sum()

"""
a    第一组
b    第二组
c    第一组
d    第二组
"""
```

1. Pandas 发现 `df` 的索引是 `['a', 'b', 'c', 'd']`。
2. 它去查 `group_keys` 这个 Series：索引 `'a'` 对应的值是 `'第一组'`，索引 `'b'` 对应的是 `'第二组'`……
3. 于是，`df` 中索引为 `'a'` 和 `'c'` 的行被分到了 `'第一组'`，`'b'` 和 `'d'` 的行被分到了 `'第二组'`。

*如果某个索引在传入的 Series 中找不到，该行数据就会被自动丢弃（不参与分组）。*

# `pd.cut`

`pd.cut()` 是 Pandas 库中非常强大的一个函数，它的核心作用就是**把连续的数值数据，切分成一个个离散的区间（分箱）**。把数据划分到区间里面并返回这个包含区间的Series等。

```python
pandas.cut(
    x, 
    bins, 
    right=True, 
    labels=None, 
    retbins=False, 
    precision=3, 
    include_lowest=False, 
    duplicates='raise'
)
```

| 参数             | 说明                                                         | 在 RFM 中的常见用法                                          |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `x`              | 需要进行分箱的一维数组或 Series（例如你的 `rfm['R']` 列）。  | 传入具体的 R、F 或 M 数值列。                                |
| `bins`           | 定义分割的边界。<br />可以是**整数**（等宽分箱），也可以是**列表**（自定义具体边界）。 | RFM 中通常传入列表，<br />如 `[0, 30, 60, 90]`，<br />以符合业务阈值。 |
| `right`          | 布尔值，默认为 `True`。<br />决定区间是左开右闭 `(a, b]` 还是左闭右开 `[a, b)`。 | 建议设为 `False`（左闭右开），<br />这样 `[0, 30)` 刚好对应“0到29天”，<br />符合直觉。 |
| `labels`         | 为每个区间指定标签（如 `['低', '中', '高']` ，打分之后返回的就是分数，没有区间了。长度需比 `bins` 少 1。 | 传入对应的 RFM 打分，<br />如 `[5, 4, 3, 2, 1]`。            |
| `include_lowest` | 布尔值，默认为 `False`。<br />如果为 `True`，第一个区间的左边界也会被包含进去。 | 当数据中存在最小值且担心被区间开闭规则剔除时，可设为 `True`。 |
| `retbins`        | 布尔值，默认为 `False`。<br />如果为 `True`，会额外返回实际使用的边界数组。 | 如果让 Pandas 自动计算边界（`bins` 传整数），开启它可以查看具体分界点。 |
| `precision`      | 整数，默认为 `3`。控制边界显示的小数点精度。                 | 处理金额（M值）时，如果边界有小数，可用它控制显示位数。      |
| `duplicates`     | 处理重复边界的方式，默认为 `'raise'`（报错）。<br />可设为 `'drop'` 忽略重复值。 | 如果自定义的 `bins` 列表里不小心写了重复数字，设为 `'drop'` 可防报错。 |

## `bin` 解释

在英文中，Bin 这个词最原始的意思就是**“箱子”、“储物柜”或者“垃圾桶”**（比如 recycle bin 回收站，dustbin 垃圾桶）。

- 当`bins`为整数 -- “**等宽分箱**”

  根据数据中的最大值和最小值，把整个数值范围平均切成 N 份。

  1. 计算总跨度（Range）

     先算出数据的最大值减去最小值，即 `总跨度 = max - min`。

  2. 计算每个箱子的宽度（Width）

     用总跨度除以设定的箱子数量，即 `箱子宽度 = (max - min) / n`。

  然后，它就会以 `min` 为起点，以 `箱子宽度` 为步长，依次画出 n 个区间。

- 当`bins`为列表

  `bins = [a, b, c, d]`，Pandas 会直接生成以下 3 个区间：

  1. 第一个箱子：`a` 到 `b`。
  2. 第二个箱子：`b` 到 `c`。
  3. 第三个箱子：`c` 到 `d`。

## `labels` 解释

一个关于“边界”与“区间”的数学关系问题。

比如 `bins = [0, 30, 60, 90]`，这里一共有 **4个** 边界数字。

区间（箱子）这 4个边界数字，两两组合，刚好能围出 **3个**区间（箱子）：

- 第1个箱子：0 到 30。
- 第2个箱子：30 到 60。
- 第3个箱子：60 到 90。

`labels` 的作用就是给这些“箱子”贴标签。既然 4个边界只围出了 3个箱子，那自然只需要准备 **3个**标签。

# `pct_change`

`pandas.DataFrame.pct_change` 是 Pandas 中用于计算当前元素与前一个元素之间百分比变化（Percentage Change）的函数。其核心计算公式为 `(当前值 - 前值) / 前值`。它在金融时序分析、业务指标的环比与同比计算、以及增长率建模等场景中极为常用。

## 函数使用格式

```python
DataFrame.pct_change(
    periods=1,      # 指定用于计算百分比变化的偏移周期数，默认为 1（即与上一行/列做比较）
    fill_method='pad', # 指定在计算变化率之前，如何处理缺失值（NaN），默认为前向填充
    limit=None,     # 限制连续填充缺失值的最大数量，默认为 None（无限制）
    freq=None,      # 指定时间序列的增量（如 'M' 月、'BDay' 工作日），仅对时间序列索引生效
    **kwargs        # 其他关键字参数，会被传递给底层的 shift() 方法
)
```

## 参数详解

| 参数          | 作用说明                                        | 可选值与注意事项                                             |
| ------------- | ----------------------------------------------- | ------------------------------------------------------------ |
| `periods`     | 控制计算百分比变化时向前或向后偏移的行数/列数。 | 整数，默认为 1。<br />正数表示与之前的元素比较（如 `periods=12` 常用于计算同比）；<br />负数表示与之后的元素比较。 |
| `fill_method` | 决定在计算前如何预处理缺失值（NaN）。           | `'pad'` 或 `'ffill'`（默认）：用上一个有效值向前填充；<br />`None`：不进行填充，直接计算（缺失值会导致结果链式缺失）。 |
| `limit`       | 限制连续缺失值的填充步数。                      | 整数，默认为 None。<br />若连续 NaN 超过该数量，则停止填充。 |
| `freq`        | 用于时间序列数据的对齐。                        | 字符串（如 `'M'`, `'Y'`）、`DateOffset` 或 `timedelta`。<br />仅当 DataFrame 索引为 `DatetimeIndex` 时生效。 |
| `**kwargs`    | 传递给底层 `shift()` 方法的额外参数。           | 例如 `axis`（指定轴向，默认为 0）等。                        |

**特别注意**

1. 由于第一行（或前 `periods` 行）没有前置参考值，计算结果会自动填充为 `NaN`。
2. 如果作为分母的“前值”为 0，结果会返回 `inf`（正无穷）或 `-inf`（负无穷），在 Pandas 中通常显示为 `NaN`，需注意排查。
3. 该函数默认只认“行顺序”而不认“时间”。如果原始数据未按时间排序，或中间存在月份缺失，直接计算会导致结果失真。

## 代码示例

假设我们有一份包含时间序列的股票交易数据，我们希望计算每日的环比变化率，以及处理缺失值的情况。

```python
import pandas as pd
import numpy as np

# 1. 准备原始数据（包含一个缺失值）
df = pd.DataFrame({
    'Date': pd.date_range('2026-01-01', periods=4, freq='D'),
    'Price': [100.0, 105.0, np.nan, 110.0]
})
# 将 Date 设为索引
df.set_index('Date', inplace=True)

print("原始数据：")
print(df)

# 2. 默认计算：与上一行做百分比变化 (periods=1)
# 注意：由于第3行价格为 NaN，默认 fill_method='pad' 会用 105.0 填充它再进行计算
df_pct_default = df.pct_change()
print("\n默认百分比变化（前向填充 NaN）：")
print(df_pct_default)

# 3. 不进行填充直接计算 (fill_method=None)
# 此时第3行本身为 NaN，且第4行因为前值（第3行）是 NaN，结果也会变成 NaN
df_pct_no_fill = df.pct_change(fill_method=None)
print("\n不进行填充的百分比变化：")
print(df_pct_no_fill)
```

**运行结果：**

```
原始数据：
            Price
Date             
2026-01-01  100.0
2026-01-02  105.0
2026-01-03    NaN
2026-01-04  110.0

默认百分比变化（前向填充 NaN）：
            Price
Date             
2026-01-01    NaN
2026-01-02  0.050
2026-01-03  0.000
2026-01-04  0.048

不进行填充的百分比变化：
            Price
Date             
2026-01-01    NaN
2026-01-02  0.050
2026-01-03    NaN
2026-01-04    NaN
```

在这个示例中，`pct_change()` 清晰地展示了不同缺失值处理策略带来的影响。

在默认模式下，2026-01-03 的缺失值被前向填充为 105.0，因此其变化率为 0.000，且 2026-01-04 能够基于 105.0 算出约 4.8% 的增长率。而在 `fill_method=None` 模式下，缺失值导致了计算链的断裂，后续数据均返回了 `NaN`。

# `DataFrame.quatile`

## 介绍

Pandas 中用于计算**分位数**（Quantile）的方法。

分位数是统计学中非常重要的概念，它可以将一组数据按从小到大的顺序排列后，划分成若干个等份。最常见的分位数包括**中位数**（50%分位数）、**四分位数**（25%、50%、75%分位数）等。

```python
DataFrame.quantile(
    q=0.5, 
    axis=0, 
    numeric_only=False, 
    interpolation='linear'
)
```

| 参数            | 说明                                                         | 常见用法                                                     |
| --------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `q`             | 要计算的分位数，取值范围在 0 到 1 之间。可以是单个浮点数，也可以是列表或数组。 | `0.5`（中位数）、<br />`[0.25, 0.5, 0.75]`（四分位数）。     |
| `axis`          | 计算方向（仅 DataFrame 有效）。                              | `0` 或 `'index'`（按列计算，默认）；<br />`1` 或 `'columns'`（按行计算）。 |
| `interpolation` | 当分位点落在两个数据点之间时，采用的插值方法。               | `'linear'`（默认线性插值）、<br />`'lower'`（取较小值）、<br />`'nearest'`（取最近值）等。 |
| `numeric_only`  | 是否只计算数值型列（仅 DataFrame 有效）。                    | 默认为 `False`，<br />若数据含非数值列建议设为 `True` 避免报错。 |

## 分位数的计算说明

quantile - n. 分位数。

对于 1、2、3、4 这四个数，它们的 0.25 分位数（即第一四分位数）是 **1.75**。

1. **数据排序**：首先数据必须是从小到大排列的。

2. 确定位置（索引）

   Pandas 默认使用线性插值法。计算位置的公式是 $(n - 1) \times q$。

   - `n` 是数据的总个数，这里是 4。
   - `q` 是要求的分位数，这里是 0.25。
   - 代入公式：`(4 - 1) * 0.25 = 3 * 0.25 = 0.75`。
     这说明 0.25 分位数落在**第 0.75 个位置**上。

3. 线性插值计算

   第 0.75 个位置，意味着它在第 0 个数（也就是 1）和第 1 个数（也就是 2）之间，并且偏向第 1 个数。

   - 具体算法是：`第0个数 + (第1个数 - 第0个数) * 0.75`
   - 代入数值：`1 + (2 - 1) * 0.75 = 1 + 0.75 = 1.75`。

- 如果用 `'lower'`（取较小的那个数）：结果就是 **1**。
- 如果用 `'higher'`（取较大的那个数）：结果就是 **2**。
- 如果用 `'nearest'`（取最近的数）：因为 0.75 离 1（第1个数）更近，结果就是 **2**。
- 如果用 `'midpoint'`（取中间值）：结果就是$(1+2) \div 2 = 1.5$。

# `size`

1. 作为 `groupby` 后的聚合方法（也适用于透视表）

    对数据进行分组（`groupby`）后，`.size()` 是一个专门用来**统计每个分组总行数**的聚合方法。

    - 核心特点：它统计的是“行数”，**包含缺失值（NaN）**。只要这一行数据存在，它就会被算进去。
    - 返回结果：返回一个 `Series`，索引是分组的名字，值是该组的行数。
    - `size()` 不需要指定列名，直接统计整行。
    - `count()` 必须指定某一列（例如 `df.groupby('A')['B'].count()`），而且它只统计该列中**非空（非 NaN）**的值。如果数据中有缺失值，用 `count()` 可能会导致统计结果偏少。

    ```python
    # 统计每种“旅游方式”和“景点类型”组合的总行数（包含任何含有NaN的行）
    result = df.groupby(['旅游方式', '景点类型']).size()
    print(result)
    ```

2. 作为 DataFrame 或 Series 的属性（基础属性）

    直接在一个完整的 DataFrame 或 Series 后面调用 `.size`（注意这里没有括号 `()`，因为它是一个属性而不是方法），它的作用是**返回数据的总元素个数**。

    计算公式：`总行数 × 总列数`。

    ```py
    # 假设 df 是一个 100行、5列 的表格
    print(df.size)  # 输出 500 (即 100 * 5)
    
    # 假设 s 是一个包含 100 个元素的 Series
    print(s.size)   # 输出 100
    ```

# rolling

`pandas.Series.rolling()` 是处理时间序列和趋势分析的核心工具。它的核心作用是创建一个**滚动窗口对象（Rolling Window Object）**，让你能够对数据进行**滑动窗口计算**（如移动平均、移动标准差等）。

在金融分析、气象数据处理或任何需要平滑短期波动、识别长期趋势的场景中，它都是首选工具。

## 函数参数简要说明

```python
Series.rolling(
    window,         # 窗口大小（整数表示行数，字符串表示时间跨度）
    min_periods,    # 计算所需的最小非空值数量
    center,         # 是否将窗口标签置于中心（默认为右对齐）
    win_type,       # 窗口类型（如三角窗、汉明窗等，默认为普通矩形窗）
    on,             # 指定用于计算窗口的列（仅适用于 DataFrame）
    closed,         # 定义窗口的闭合区间（如 'left', 'right', 'both', 'neither'）
    method,         # 计算引擎方法（默认为 'single'，支持 'table'）
)
```

## 参数详细说明表

| 参数名        | 详细说明                                                     |
| ------------- | ------------------------------------------------------------ |
| `window`      | 核心参数。<br />若为整数，表示固定大小的滑动窗口（包含当前值及前 N-1 个值）；<br />若为时间偏移量（如 '3D', '2H'），则基于时间索引计算实际时间跨度内的窗口。 |
| `min_periods` | 窗口内至少需要多少个非空（非 NaN）值才能产生计算结果。<br />默认为 `None`（即等于 window 大小）。<br />设为 `1` 时，即使窗口未填满，只要有数据就会开始计算。 |
| `center`      | 控制窗口对齐方式。<br />默认为 `False`（窗口向后滚动，结果标签在最右侧/当前点）；<br />设为 `True` 时，窗口会居中，聚合结果的标签对应窗口的中心点，常用于避免趋势滞后。 |
| `win_type`    | 指定加权窗口的类型。<br />默认为 `None`（普通矩形窗，所有数据权重相同）。<br />可选值包括 `'triang'`（三角窗）、`'hamming'`、`'hann'` 等，用于信号处理或平滑数据。 |
| `on`          | 仅适用于 `DataFrame`。<br />指定用于计算滚动窗口的列名，该列必须是类似日期的格式。 |
| `closed`      | 定义时间窗口的闭合区间。<br />可选值：`'right'`（默认，包含右边界）、`'left'`、`'both'`、`'neither'`。<br />常用于精确控制时间边界是否纳入计算。 |
| `method`      | 指定计算方法。<br />`'single'` 表示对每一列单独应用；<br />`'table'` 表示将整个表作为一个整体应用（需配合 numba 等引擎使用）。 |

>
> | 偏移量代码   | 含义                  | 说明与典型应用                                         |

> | `M`          | 月末 (Month End)      | 将时间对齐到每月的最后一天。常用于月度重采样。         |

> | `Y` 或 `A`   | 年末 (Year End)       | 将时间对齐到每年的最后一天。                           |

## 用法与实战举例

`rolling()` 方法本身只返回一个“滚动窗口对象”，你需要在此基础上**继续调用聚合函数**（如 `.mean()`, `.sum()`, `.std()`）或 `.apply()` 来得到最终结果。

### 基础移动平均与处理开头 NaN

```python
import pandas as pd
import numpy as np

s = pd.Series([10, 20, 30, 40, 50])

# 计算 3 期移动平均（默认 min_periods=3，前两个值凑不够窗口，结果为 NaN）
print(s.rolling(window=3).mean())
# 输出: [NaN, NaN, 20.0, 30.0, 40.0]

# 设置 min_periods=1，窗口未满时依然计算
print(s.rolling(window=3, min_periods=1).mean())
# 输出: [10.0, 15.0, 20.0, 30.0, 40.0]
```

### 基于时间的滚动窗口

```python
# 创建带时间索引的数据
dates = pd.to_datetime(['2024-01-01', '2024-01-03', '2024-01-05', '2024-01-08'])
ts = pd.Series([10, 20, 30, 40], index=dates)

# 计算过去 3 天（3D）的滚动平均，而非过去 3 行
# 索引 '2024-01-05' 的窗口只包含 '2024-01-03' 和 '2024-01-05'（因为 01-01 超出了3天范围）
print(ts.rolling(window='3D').mean())
```

### 使用自定义函数

```python
# 计算滚动窗口内最大值与最小值的差（极差）
s = pd.Series([10, 25, 15, 40, 30])
print(s.rolling(window=3).apply(lambda x: x.max() - x.min()))
# 输出: [NaN, NaN, 15.0, 25.0, 25.0]
```

### 居中窗口

```python
# 默认 center=False，3期窗口计算结果对应第3个位置
# 设置 center=True，3期窗口计算结果对应中间位置（第2个位置）
print(s.rolling(window=3, center=True).mean())
# 输出: [NaN, 16.66, 26.66, 28.33, NaN]
```

# `ewm`

`pandas.DataFrame.ewm` 是 Pandas 中用于提供指数加权（Exponential Weighted）函数的工具。它主要用于计算指数加权移动平均（EWMA/EMA），与简单移动平均（SMA）不同，它给予近期数据更高的权重，而给予远期数据逐渐递减的权重，因此能更灵敏地反映数据的最新趋势。

## 函数使用格式

```python
DataFrame.ewm(
    com=None,        # 通过质心（center of mass）指定衰减程度，α = 1 / (1 + com)
    span=None,       # 通过跨度（span）指定衰减程度，α = 2 / (span + 1)
    halflife=None,   # 通过半衰期指定衰减程度，α = 1 - exp(log(0.5) / halflife)
    alpha=None,      # 直接指定平滑系数 α（0 < α ≤ 1）
    min_periods=0,   # 窗口中产生有效值所需的最小观测数，不足时结果为 NA
    adjust=True,     # 是否在初始阶段除以衰减调整因子，以修正相对权重的不平衡
    ignore_na=False, # 计算权重时是否忽略缺失值（True 表示基于相对位置计算权重）
    axis=0,          # 指定操作的轴向，0 代表行（默认），1 代表列
    times=None       # 指定与观测值对应的时间序列，仅适用于 mean() 且 halflife 为时间单位时
)
```

## 参数详解

| 参数          | 作用说明                                           | 可选值与注意事项                                             |
| ------------- | -------------------------------------------------- | ------------------------------------------------------------ |
| `com`         | 使用质心来定义权重的衰减速度。                     | 浮点数，要求 `com ≥ 0`。<br />与 `span`、`halflife`、`alpha` 四者必须且只能提供其中一个。 |
| `span`        | 使用跨度来定义权重的衰减速度。                     | 浮点数，要求 `span ≥ 1`。<br />在金融分析中常用来设定 EMA 的回看周期。 |
| `halflife`    | 使用半衰期来定义权重的衰减速度。                   | 浮点数（要求 `> 0`）、字符串或时间增量（timedelta）。<br />若配合 `times` 参数使用，可指定时间单位。 |
| `alpha`       | 直接指定平滑系数 α。                               | 浮点数，要求 `0 < α ≤ 1`。                                   |
| `min_periods` | 设定窗口内最少需要多少个非空观测值才能计算出结果。 | 整数，默认为 0。若观测数不足，结果将返回 NA。                |
| `adjust`      | 控制初始阶段的权重计算方式。                       | `True`（默认）：使用加权平均公式，修正初始权重偏差；<br />`False`：使用递归公式 `y[t] = (1-α)*y[t-1] + α*x[t]`。 |
| `ignore_na`   | 控制遇到缺失值（NaN）时的权重计算逻辑。            | `False`（默认）：基于绝对位置计算权重；<br />`True`：忽略缺失值，基于相对位置计算权重。 |
| `axis`        | 指定函数应用在哪个轴上。                           | `0` 或 `'index'`（默认，按行计算）；<br />`1` 或 `'columns'`（按列计算）。 |
| `times`       | 提供非均匀时间序列的时间戳。                       | 字符串（列名）、数组或 Series。<br />必须是单调递增的 `datetime64[ns]` 类型，仅适用于 `mean()`。 |

## 代码示例

假设我们有一组包含缺失值的时间序列数据，我们希望使用 `ewm` 函数计算其指数加权移动平均。

```python
import pandas as pd
import numpy as np

# 1. 准备包含缺失值的原始数据
df = pd.DataFrame({
    'B': [0, 1, 2, np.nan, 4]
})

print("原始数据：")
print(df)

# 2. 使用 ewm 计算指数加权移动平均
# 设置 com=0.5 来定义衰减程度，并计算均值
df_ewm = df.ewm(com=0.5).mean()

print("\n指数加权移动平均结果：")
print(df_ewm)
```

**运行结果：**

```
原始数据：
     B
0  0.0
1  1.0
2  2.0
3  NaN
4  4.0

指数加权移动平均结果：
          B
0  0.000000
1  0.750000
2  1.615385
3  1.615385
4  3.670213
```

在这个示例中，我们通过 `com=0.5` 定义了平滑系数。

可以看到，当遇到第 3 行的缺失值（NaN）时，由于默认 `ignore_na=False`，Pandas 依然会基于绝对位置计算权重，因此第 3 行的结果保持了上一行的值（1.615385），而第 4 行则结合最新的观测值 4.0 进行了更新。

# `clip`

`pandas.DataFrame.clip` 是 Pandas 中用于将数据限制在指定区间内的函数。它会将所有低于下限的值替换为下限值，将所有高于上限的值替换为上限值，而处于区间内的值保持不变。这在数据清洗、异常值处理以及数据可视化中非常实用。

## 函数使用格式

```python
DataFrame.clip(
    lower=None,      # 指定数据截取的下限，低于此阈值的所有值将被替换为该下限值
    upper=None,      # 指定数据截取的上限，高于此阈值的所有值将被替换为该上限值
    axis=None,       # 指定对齐的轴向，当阈值为数组时，决定沿着哪个轴进行逐元素截取
    inplace=False,   # 是否直接在原数据上进行修改，默认为 False（返回新对象）
    *args,           # 额外的位置参数，通常为了与 numpy 兼容而保留，无实际效果
    **kwargs         # 额外的关键字参数，通常为了与 numpy 兼容而保留，无实际效果
)
```

## 参数详解

| 参数      | 作用说明                                                     | 可选值与注意事项                                             |
| --------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `lower`   | 设置数据的最小阈值。                                         | 可以是单个数值（float）或类似数组的对象。<br />若设为 `None`（默认），则不设置下限；<br />若传入 `NaN`，该位置的值不会被截取。 |
| `upper`   | 设置数据的最大阈值。                                         | 可以是单个数值（float）或类似数组的对象。<br />若设为 `None`（默认），则不设置上限；<br />若传入 `NaN`，该位置的值不会被截取。 |
| `axis`    | 当 `lower` 或 `upper` 是数组时，指定沿哪个轴进行对齐和截取。 | `None`（默认）；<br />`0` 或 `'index'`（沿行对齐）；<br />`1` 或 `'columns'`（沿列对齐）。 |
| `inplace` | 控制是否原地修改原始数据。                                   | `False`（默认）：返回一个截取后的新 DataFrame/Series；<br />`True`：直接修改原数据，返回 `None`。 |

## 代码示例

假设我们有一份包含随机数值的 DataFrame，其中包含一些超出合理范围的异常值，我们希望将其限制在 0 到 10 的区间内。

```python
import pandas as pd
import numpy as np

# 1. 准备包含异常值的原始数据
data = {
    'col_0': [9, -3, 0, -1, 5], 
    'col_1': [-2, -7, 6, 8, -5]
}
df = pd.DataFrame(data)

print("原始数据：")
print(df)

# 2. 使用 clip 函数将数据限制在 [0, 10] 范围内
# 低于 0 的值会被替换为 0，高于 10 的值会被替换为 10
df_clipped = df.clip(lower=0, upper=10)

print("\n截取后的数据：")
print(df_clipped)
```

**运行结果：**

```
原始数据：
   col_0  col_1
0      9     -2
1     -3     -7
2      0      6
3     -1      8
4      5     -5

截取后的数据：
   col_0  col_1
0      9      0
1      0      0
2      0      6
3      0      8
4      5      0
```

在这个示例中，原始数据中像 `-3`、`-7` 这样低于下限 `0` 的值，都被自动替换成了 `0`；而处于 `0` 到 `10` 之间的数值则保持原样。

需要注意的是，`clip()` 默认会返回一个新的 Series 或 DataFrame，因此必须将结果赋值给变量（如 `df_clipped` 或重新赋值回原列），否则原始数据不会发生改变。
